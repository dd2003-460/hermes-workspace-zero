# LOOP — 循环协议

## 双脑架构概览

### 1-loop（策略层 / 主脑）
- `loop/1-loop/README.md` — 入口
- `双脑原则.md` — 主副脑分工规则
- `主脑.md` — 策略思考层规范
- `副脑.md` — 执行操作层规范

**触发条件**：讨论原则、动机、边界、是否进入执行阶段

### 2-loop（执行层 / 副脑）
- `loop/2-loop/README.md` — 入口
- `2.1-backup.md` ~ `2.6-execution.md` — 执行各阶段规范
- `SUB_STANDARD.md` — 副脑操作标准

**触发条件**：执行、备份、测试、验证、置信度检查

## 循环规则
1. **不空转** — 每一轮都要推进一个具体动作，或明确说明卡点和下一步
2. **先读后做** — 进入新循环前，按索引读取对应 README
3. **幂等性** — 所有操作可重复执行不产生副作用
4. **失败隔离** — 单步失败不影响已有数据完整性
