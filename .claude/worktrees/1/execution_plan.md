# Hermes Hook + 双脑Agent系统规划

## 项目目标
实现一个Hermes hook机制，当AI完成处理后完全静默时触发，启动主脑和副脑两个agent在同一个对话框中按照1-loop流程进行讨论。

## 核心需求
1. **Hook触发条件**：AI完成处理且完全静默时触发
2. **双脑Agent**：主脑和副脑在同一个对话框交流
3. **信息格式**：每个消息开头包含"应该读什么的信息"
4. **遵循流程**：按照1-loop的双脑原则进行讨论
5. **静默检测**：AI不在工作时触发

## 实现方案

### 1. Hook机制设计
- 监听Hermes的AI处理完成事件
- 检测AI是否处于静默状态
- 触发双脑Agent启动

### 2. 双脑Agent实现
- **主脑**：说明任务、目标和接受标准
- **副脑**：质疑主脑、检查原则、找出缺口
- **交流格式**：每个消息开头包含"应该读什么的信息"

### 3. 1-loop流程集成
- 遵循双脑原则.md的规范
- 只讨论原则，不做执行
- 判断是否进入2-loop

### 4. 静默检测机制
- 检测AI是否在处理信息
- 如果AI不在工作，触发hook
- 如果AI正在工作，不触发

## 技术栈
- Hermes内置hook机制
- Python脚本实现hook逻辑
- 双脑Agent通过delegate_task实现

## 实施步骤
1. 设计hook触发逻辑
2. 实现主脑和副脑agent
3. 集成1-loop流程
4. 测试静默检测
5. 完善信息格式

## 预期产出
- 可工作的hook系统
- 主脑和副脑agent实现
- 遵循1-loop流程的讨论机制
