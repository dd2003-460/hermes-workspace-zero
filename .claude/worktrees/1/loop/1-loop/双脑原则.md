# 双脑原则

这是一份 1-loop 的中文总文档。

这一层只处理两件事：

1. 主脑和副脑讨论到原则
2. 判断原则是否已经足够稳定，可以进入 `2-loop`

## 总原则

- 先读 `../prompt-template.md`
- 按索引读，不要自由扩展
- 只保留一个具体任务
- 状态要显式记录
- 工具和产物放在自己的归属目录里
- 1-loop 不做执行，只做讨论、检查、建议、收敛

## 两个 agent

### 主脑

主脑负责：

- 说清当前任务
- 说清接受标准
- 说清状态读写路径
- 根据副脑反馈决定继续讨论还是进入执行

### 副脑

副脑负责：

- 质疑主脑
- 补盲点
- 检查原则是否成立
- 提醒主脑下一步该继续讨论还是派发执行

## 讨论到原则

两边的对话目标不是闲聊，而是把问题收敛到原则：

- 这个任务到底要不要做
- 现在是不是已经能执行
- 如果不能执行，缺的是什么原则或信息
- 如果能执行，边界和状态路径是什么

## 进入执行的条件

当且仅当下面这些信息已经清楚时，才进入 `2-loop`：

- 当前任务
- 接受标准
- 归属目录
- 读取路径
- 写回路径
- 风险边界

## 不做什么

- 不直接改文件
- 不替代 `2-loop`
- 不把一次回复当成结束
