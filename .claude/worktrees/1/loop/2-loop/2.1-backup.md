# backup.md — 执行 sub 备份规则

## 强制要求

每次修改文件前，必须先备份。

## 备份流程

1. **创建备份目录**：
   ```bash
   mkdir -p backups/YYYY-MM-DD-task-name/
   ```

2. **备份文件**：
   ```bash
   cp <file> backups/YYYY-MM-DD-task-name/<file>.bak
   ```

3. **验证备份完整性**：
   ```bash
   diff <file> backups/YYYY-MM-DD-task-name/<file>.bak
   # 必须无输出（完全一致）
   ```

## 规则

- 不得跳过备份直接修改
- 批量修改时，每个文件单独备份
- 备份目录按日期+任务名组织，便于回溯
- 如果备份目录已存在（同日同任务），追加到同一目录
