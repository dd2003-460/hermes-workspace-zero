# test.md — 执行 sub 测试规则

## 强制要求

执行 sub 完成后，必须对产出的脚本/工具运行至少一次测试。

## 测试流程

1. **识别可测试产出**：新脚本、新工具、修改过的代码
2. **运行测试**：
   ```bash
   # Python 脚本
   uv run python <script> --help  # 至少验证可执行
   # Shell 脚本
   bash -n <script>  # 语法检查
   ```
3. **记录结果**：
   - `PASS` — 输出摘要 + 关键输出
   - `FAIL` — 错误信息 + 失败位置

## 测试失败

- **默认回滚**：`cp backups/.../<file>.bak <file>`
- 不在执行环内偷偷小修继续跑
- 回滚后标记任务状态为 `needs_replan`

## 豁免

- 纯文档/配置文件修改可豁免测试
- 但必须在输出中说明豁免理由
