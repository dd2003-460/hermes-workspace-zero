# verify.md — 执行 sub 验证环节

## 验证清单

执行 sub 在标记 completed 前，必须逐一完成：

### 1. 文件存在性验证
```bash
ls -la <产出文件路径>
# 确认文件确实存在
```

### 2. 内容验证
```bash
head -20 <产出文件路径>
# 读取并确认内容符合预期
```

### 3. 搜索验证
```bash
grep -n "关键声明" <产出文件路径>
# 确认关键声明存在
```

### 4. 置信度验证
对核心判断调用置信度工具：
```bash
uv run python scripts/confidence_scorer.py \
  -c "核心结论" \
  -e "data: 具体证据" \
  -e "reproducible: 是否可复现" \
  -r "推理过程"
```

## 验证结果

- **全部通过** → 可标记 completed
- **任一未通过** → 标记 `needs_replan`，不得跳过

## 证据要求

每个验证步骤必须附带命令输出摘要，不能只写"已验证"。
