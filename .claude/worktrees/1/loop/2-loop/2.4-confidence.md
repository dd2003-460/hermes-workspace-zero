# confidence-tool.md — 置信度工具使用规范

## 可用工具

| 工具 | 用途 |
|------|------|
| `scripts/confidence_scorer.py` | SOCRA TES 置信度评分 |
| `scripts/confidence_evaluator.py` | 置信度评估 |

## 调用方式

```bash
uv run python scripts/confidence_scorer.py \
  -c "判断结论" \
  -e "evidence1: 描述" \
  -e "evidence2: 描述" \
  -r "推理过程"
```

## 置信度门禁（强制）

| 评分 | 判定 | 动作 |
|------|------|------|
| < 0.6 | 低 | 必须发展至少 2 个独立验证分支，不得标 completed |
| 0.6-0.8 | 中 | 必须明确标注不确定，记录未验证假设 |
| > 0.8 | 高 | 可正常通过 |

## 核心原则

- **不能把低置信判断当已完成**
- 低置信 ≠ 失败，但必须显式处理
- 副脑和执行 sub 在关键判断时都必须调用此工具
