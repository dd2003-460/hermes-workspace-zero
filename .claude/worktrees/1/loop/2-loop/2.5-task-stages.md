# task-stages.md — 子任务环节标注

## 环节定义

每个子任务必须标注当前环节，执行 sub 必须在输出中声明。

| 标签 | 环节 | 说明 |
|------|------|------|
| `[search]` | 搜索 | 找信息、查数据、检索 |
| `[analyze]` | 分析 | 处理数据、推理、对比 |
| `[create]` | 创建 | 写文件、建工具、生成产出 |
| `[verify]` | 验证 | 测试、确认、门禁检查 |
| `[report]` | 报告 | 总结、写入状态、产出 artifact |

## 使用方式

在输出开头声明：
```
[环节: create] 正在写入 backup.md
```

## 规则

- 一个子任务可经历多个环节，但输出时声明当前环节
- 环节顺序通常是 search → analyze → create → verify → report
- 不得跳过 verify 直接到 report
