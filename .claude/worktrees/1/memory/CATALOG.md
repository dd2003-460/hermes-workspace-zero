# 探索分类体系

## 编号规则

按领域分层编号，格式：`主类.子类`
- 主类用一位数字：1=物理，2=数学，3=贝叶斯/概率，4=形式化方法，5=AI/Agent，6=系统设计
- 子类用两位数字：1.1, 1.2...
- 交叉领域用斜杠：1/2（物理+数学）

## 分类树

```
1. 物理
   1.1 天体物理
   1.2 凝聚态物理
   1.3 粒子物理
   1.4 量子信息
   1.5 统计物理

2. 数学
   2.1 代数
   2.2 几何/拓扑
   2.3 分析
   2.4 数论
   2.5 组合/图论

3. 贝叶斯/概率推理
   3.1 贝叶斯推断
   3.2 信息论
   3.3 随机过程

4. 形式化方法
   4.1 类型论
   4.2 范畴论
   4.3 证明助手

5. AI/Agent
   5.1 Agent 架构
   5.2 推理与规划
   5.3 学习算法

6. 系统设计
   6.1 分布式系统
   6.2 并发与并行

交叉领域（用斜杠）：
   1/2 物理+数学（如微分几何在广义相对论中的应用）
   3/5 贝叶斯+AI（如贝叶斯神经网络）
```

## 文件命名规则

探索笔记放在对应分类目录下：
```
memory/
├── CATALOG.md              # 本文件（分类规则）
├── INDEX.md                # 索引和当前进度（唯一状态文件）
└── {编号}/{主题名}/        # 探索笔记
    └── r{轮次}.md          # 每轮一个文件
```

例如：`memory/1.1/黑洞信息悖论/r01.md`

## 清理规则

探索完一个完整的小部分（能回答核心问题）后：
1. 在 `INDEX.md` 中记录该主题的索引条目（含结论摘要）
2. 删除该主题目录下的所有 `r*.md` 文件
3. **只保留索引条目**，不保留原始探索过程

这样 memory/ 目录始终保持整洁：只有 CATALOG.md、INDEX.md，以及少量正在进行的探索。
