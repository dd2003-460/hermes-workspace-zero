# Step 07: 变压器板块估值方法论整理

## 目标
把元宝会话中 A 股变压器板块估值分析的方法、框架、数据整理成结构化方法文档，作为估值模型和 tex 报告依据。

## 涉及文件
- `market-alpha/transformer-sector-valuation/docs/methodology.md`
- `market-alpha/transformer-sector-valuation/data/assumptions.md`

## 做法
1. 通读 step-03 落盘的会话 raw + 深度报告，抽取：
   - 覆盖标的全清单（特变电工、思源电气、平高电气、许继电气、中国西电、金盘科技、明阳电气、伊戈尔、保变电气、望变电气 + 对标组 GEV/ETN/VRT/Hitachi 等）
   - 估值方法（PE/PS 分位、目标价区间、全球对比口径）
   - 关键数据表（股价回撤、主力资金流、订单、AIDC 收入、毛利率、现金流）
   - 用户与元宝讨论出的"贡献因子分解"框架（盈利预期修正 vs 估值倍数压缩的对数分解法）
   - 五个核心判断（全球性重估、风格切换、估值中位数、金盘分歧、成本反直觉结论）
2. methodology.md：问题定义 → 标的与对标组 → 数据 → 估值方法 → 贡献因子分解框架 → 验证方式
3. assumptions.md：估值假设逐条（目标 PE、EPS 预测、汇率、铜价/硅钢价格路径等），标注来源+置信度
4. 数据缺口（元宝自己承认的 5 个缺口：海外估值快照、个股历史分位、筹码结构、招标均价、技术面）显式列出，作为 arena 核验的补充方向

## 验收标准
- [ ] methodology.md 含 5 节完整方法链，标的清单 ≥10 家 A 股 + ≥5 家海外对标
- [ ] 关键数据表（回撤幅度/资金流/订单/毛利率）数字与元宝报告原文一致（抽样核对 5 个数字）
- [ ] assumptions.md ≥8 条假设，含置信度
- [ ] 贡献因子分解框架（对数分解公式）完整记录
