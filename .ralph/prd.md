# D1-academic-AI 研究想法调研 PRD

## 背景
raw/ 目录下有若干研究想法，需要系统性地调研可行性并尽可能完整实现。

## 用户故事

### [ ] US-1: AI训练数据层级结构
调研AI训练数据是否层级化，RAG外挂检索的层级设计，改为层级结构的优势和机理分析。

### [ ] US-2: AI强CoT模型大小理论下限
研究强Chain-of-Thought模型是否存在理论大小下限，保留冗余的设计原则。

### [ ] US-3: 耦合/解耦定义与存在性
建立"耦合"的双射定义框架，设计解耦最小步更新测试循环，分析完美解耦的存在性条件。

### [ ] US-4: Agent自主完成工程完整计划
设计无人参与完成大型工程的Agent系统方案，包括web求助机制和任务分解策略。

### [ ] US-5: Agent规划能力检验
分析现有Agent规划能力检验方法的有效性，设计更完善的评估框架。

### [ ] US-6: Agent记忆系统
研究自适应token块记忆机制，优化精度与token效率的平衡。

### [ ] US-7: 数学同调群几何直观
梳理同调群的几何直观理解，建立数学直觉到形式化定义的桥梁。

### [ ] US-8: 信息论与计算统一
研究信息论视角下的计算复杂性统一框架，探索频率匹配与几何视角。

### [ ] US-9: 信息因子贡献与媒体操纵分析
分析信息传播中的操纵扩散机制，设计基于源头信息的指标系统。

### [ ] US-10: 智能的定义与本质
研究"智能是信息在选择压力下形成的结构性表征系统"这一假说的必然性与反例。

### [ ] US-11: 动态演化与泛函优化框架
设计基于动态演化的问题求解框架，将问题转化为优化问题并路由到最优工具。

### [ ] US-12: 信息论视角语言数学统一
探索信息论统一视角下的语言、数学描述，分析语义相似性与路径效率的关系。
