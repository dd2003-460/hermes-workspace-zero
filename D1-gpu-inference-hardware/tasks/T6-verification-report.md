## 五、已知局限

1. **中文二手市场数据**: RTX 3090/4090 二手价格来自闲鱼/知乎间接数据，未直接抓取闲鱼页面。实际成交价可能略有浮动。
2. **MI300X ROCm 生态**: 生态成熟度为推断（0.6），缺乏实际 ROCm LLM 推理的实测数据。
3. **双 RTX 3090 性能**: T3 报告中双 RTX 3090 的 ~75 OT/s 为推算值（置信度 0.6），缺乏实测。
4. **价格时效性**: 市场价格数据反映 2026-08 时点，可能随供需变化波动。
