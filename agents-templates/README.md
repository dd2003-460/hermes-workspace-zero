# agents-templates
# origin: ai

## 本文件夹主要功能

项目级 agent 模板目录，当前含 `RALPH-project/`（RALPH 项目模板：新项目接入时 `cp agents-templates/RALPH-project/CLAUDE.md` 到项目内，见 AGENTS.md「RALPH Loop 团队配置」）。

## 接口

- 输入：无
- 输出：可复制到新项目的 CLAUDE.md / agents 模板
- 对外函数签名：无（模板层）

## 调用说明

- 新建项目接入 RALPH：`cp agents-templates/RALPH-project/CLAUDE.md <project>/` + symlink `agents`
- 完整操作手册见 `loop/archived-20261016/ralph-team-setup.md`
