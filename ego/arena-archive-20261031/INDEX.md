抓取时间：2026-10-31。来源：arena.ai/agent 侧边栏全量滚动（147 个去重会话），按首条消息筛选出**有人味的后续对话**（非机械任务书 prompt）。

## 判定标准

机械任务书特征（已排除）：以「你是…核验者/调研员/审稿人」「先执行 git clone」「【执行前必读】」「只做第 N 轮，完成后停下汇报」「Arena Prompt: batch-N」「请按仓库内任务书执行」「验证推送通道」等结构化指令开头的会话——这些是外包给 arena 的批量任务，无人味。

保留标准：首条消息是口语短句、像真人随口问的话（"大概看看…"、"帮我看一下这几篇论文"、"混批在各种机器上真实负载到底怎么样"）。

## 边界与诚实声明

- 侧边栏只滚到 147 个会话就停止增长（连续 10 轮无新增），可能还有更老的历史没加载出来——arena 侧边栏是懒加载，我滚了约 2 分钟，如果实际有几百个会话，这个列表不全。
- "人味"判定基于首条消息，若某会话首条是任务书但后续转成真人讨论，会被漏掉——这种反向情况我没逐个点开核对（147 个全开一遍不现实）。
- 清理是启发式的（截断标记 + 侧边栏行过滤），个别段落可能有残留 UI 文本，阅读时忽略即可。
