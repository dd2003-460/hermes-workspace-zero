# 03-任务分解（Stage 3）

**输入**：`acceptance-criteria.md`（来自阶段 2）
**输出**：`task-decomposition.md`（子任务 DAG 列表）

---

## 操作步骤

### Step 1：分解为子任务
基于 `acceptance-criteria.md`，将任务分解为原子子任务。

**约束**：
- 每个子任务必须有明确的输入→输出→验证→回滚→置信度 [0,1]
- 不依赖外部即可执行
- DAG 有向无环（子任务间有明确的依赖关系）
- 每步可独立验证

### Step 2：定义子任务粒度
每个子任务必须满足：
- 一个 agent 不超出上下文设定长度即可独立完成
- 如果某个子任务过大，继续递归分解直到满足粒度要求

### Step 3：构建 DAG 依赖图
明确标注：
- 每个子任务的依赖子任务（如果有）
- 无依赖的子任务可以并行执行

### Step 4：写入 task-decomposition.md
输出格式：
```markdown
# Task Decomposition
## Subtask 1: [名称]
- 输入：[具体输入]
- 输出：[具体输出]
- 验证：[如何验证]
- 回滚：[如果失败如何回滚]
- 置信度：[0,1]
- 依赖：[子任务编号，无则为 null]

## Subtask 2: [名称]
...
```
