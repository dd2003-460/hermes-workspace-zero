# 06-决策（Stage 6）

**输入**：`gap-analysis.json`（来自阶段 5）
**输出**：`decision.md`（enter_2loop | continue_1loop）

---

## 转移硬条件（全部必须满足）

- [ ] `task-definition.md` 存在且不超过 3 行
- [ ] `acceptance-criteria.md` 存在，所有维度可验证
- [ ] `task-decomposition.md` 存在，DAG 无环，每步有输入→输出→验证→回滚
- [ ] `tool-inventory.md` 存在，无阻塞项
- [ ] `gap-analysis.json` 存在，所有高影响项 = complete
- [ ] 副脑无未解决的质疑

## 决策规则

### 如果所有硬条件满足 → enter_2loop

写入 `decision.md`：
```json
{
  "decision": "enter_2loop",
  "reason": "所有硬条件满足",
  "next_action": "执行 2-loop 流程"
}
```

### 如果有高影响项未 complete → continue_1loop

写入 `decision.md`：
```json
{
  "decision": "continue_1loop",
  "reason": "有高影响项未 complete",
  "high_impact_items": [...],
  "next_action": "重新执行 1-loop（从对应阶段开始）"
}
```

### 如果预期增益 < 执行错误成本 → 停止 1-loop

如果连续两轮 `gap-analysis.json` 变化 < 20% 且：
```json
{
  "decision": "enter_2loop",
  "reason": "最优收益已被提取",
  "next_action": "执行 2-loop 流程"
}
```

---

## 双脑原则（06 决策阶段）

**副脑永续**：副脑必须每轮必派，循环永远不能中断。副脑每轮需：
- [ ] 质疑主脑决策
- [ ] 找信息缺口
- [ ] 提醒不停止 1-loop 的条件

## 状态跟踪

每轮必须写回 `task-state.json`：
```json
{
  "iteration": 1,
  "phase": "decision",
  "input": {},
  "output": {},
  "novelty_assessment": "N0-N3",
  "tool_inventory": [],
  "gap_analysis": [],
  "next_action": "enter_2loop | continue_1loop",
  "decision": "enter_2loop | continue_1loop",
  "subtasks": [],
  "average_confidence": 0.8
}
```

---

## 输出文件

**必须存在**：`decision.md` + `task-state.json`

阶段 5 输出（`gap-analysis.json`）

- 如果 continue_1loop → 重新执行 1-loop（从对应阶段开始）
