# 06-决策（Stage 6）

**输入**：`gap-analysis.json`（来自阶段 5）
**输出**：`decision.md`（enter_2loop | continue_1loop）

---

## Agent 使用规范

决策阶段**必须 incorporate Agent findings**。Commander 的决策必须基于 Agent 的独立评估，不自行决定：

| 场景 | 使用 Agent | 原因 |
|------|-----------|------|
| 决策条件验证 | `prechecker` Agent | Agent 验证所有硬条件是否确实满足 |
| 预期增益评估 | `confidence-judge` Agent | Agent 评估 enter_2loop 的风险 |
| 分叉决策 | `fork-decider` Agent | Agent 评估是否需要分叉 |

**强制要求**：
- enter_2loop 决策前，必须通过 `prechecker` Agent 验证所有硬条件
- continue_1loop 决策前，必须通过 `confidence-judge` Agent 评估是否有继续价值
- Commander 不做无 Agent 支持的决策

---

## 转移硬条件（全部必须满足）

- [ ] `task-definition.md` 存在且不超过 3 行
- [ ] `acceptance-criteria.md` 存在，所有维度可验证
- [ ] `task-decomposition.md` 存在，DAG 无环，每步有输入→输出→验证→回滚
- [ ] `tool-inventory.md` 存在，无阻塞项
- [ ] `gap-analysis.json` 存在，所有高影响项 = complete

## 决策规则

### 如果所有硬条件满足 → enter_2loop

**通过 `prechecker` Agent 验证**：将 `gap-analysis.json` 和所有前置文件发送给 `prechecker` Agent，确认所有硬条件满足。

写入 `decision.md`：
```json
{
  "decision": "enter_2loop",
  "reason": "所有硬条件满足",
  "next_action": "执行 2-loop 流程"
}
```

### 如果有高影响项未 complete → continue_1loop

**通过 `confidence-judge` Agent 评估**：将 `gap-analysis.json` 发送给 Agent，评估这些高影响项是否值得继续投入资源。

写入 `decision.md`：
```json
{
  "decision": "continue_1loop",
  "reason": "有高影响项未 complete",
  "high_impact_items": [...],
  "next_action": "重新执行 1-loop（从对应阶段开始）"
}
```

### 如果预期增益 < 执行错误成本 → 停止 1-loop

如果连续两轮 `gap-analysis.json` 变化 < 20% 且：
**通过 `confidence-judge` Agent 确认**：Agent 确认最优收益已被提取。

```json
{
  "decision": "enter_2loop",
  "reason": "最优收益已被提取",
  "next_action": "执行 2-loop 流程"
}
```

每轮必须写回 `task-state.json`：
```json
{
  "iteration": 1,
  "phase": "decision",
  "input": {},

}
```
