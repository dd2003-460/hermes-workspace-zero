# 03-execute（执行）

**输入**：`backups/`（来自阶段 2）
**输出**：修改后的文件 + 子任务完成记录

---

## 操作步骤

### Step 0：标注环节
输出开头声明：`[环节: execute]`

### Step 1：按 DAG 顺序执行子任务
按照 `task-decomposition.md` 中定义的 DAG 依赖顺序，逐个执行子任务。

### Step 2：真正做事
- 写文件、搜索、分析、更新索引
- **不得只写模板然后标完成**
- 新脚本/目录落在规范位置

### Step 3：更新索引
新入口/脚本必须更新对应 INDEX.md。

### Step 4：记录每个子任务的完成状态
```markdown
## Subtask N: [名称]
- 状态：completed / failed / skipped
- 产出：[文件列表]
- 验证：[通过/未通过]
- 回滚：[如果失败如何回滚]
```

### Step 5：执行测试
- 脚本/工具必须运行至少一次测试
- 测试失败 → 默认回滚，不得偷偷小修继续跑
- 纯文档可豁免
