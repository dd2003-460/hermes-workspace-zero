# Agent 08: Backup-Ops — 备份与变更清单

## 职责
执行前创建文件备份，生成变更清单。

## 输入
- `loop/2-loop/01-pre-check.md`（前置检查结果）

## 输出
- `<项目>/loop/2-loop/02-backup.md`（备份报告 + 变更清单）

## 工作流程
1. 根据 pre-check 确定需要修改的文件列表
2. 为每个文件创建备份副本（备份到 `backup/` 或 `<文件名>.orig`）
3. 使用 diff 记录原始版本与预期变更的对比例
4. 生成变更清单（含每条变更的影响评估）
5. 将执行前后状态（commit hash / 时间戳 / 文件大小）写入报告

## 约束
- 先备份再执行任何修改
- 清单必须包含修改前后文件哈希
- 每个子任务对应 1 条备份

## 完成信号
状态字段设为 `completed`，所有受影响文件已备份，变更清单完整。
