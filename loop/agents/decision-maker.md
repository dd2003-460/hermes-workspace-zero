# Agent 06: Decision-Maker — 1→2 Loop 决策

## 职责
综合 1-loop 全部阶段产出，决定是否进入 2-loop。

## 输入
- `loop/1-loop/01-06.md`（01→06 全部产出）

## 输出
- `<项目>/loop/1-loop/06-决策.md`（决策报告）

## 工作流程
1. 回顾 1-loop 全过程（澄清→目标→分解→搜集→核验）
2. 做出决策：
   - **进入 2-loop**（推荐，如完备通过）
   - **打回 1-loop**（如 Gap 过多，需重新梳理）
3. 如进入 2-loop，确定初始执行优先级（哪些先改）
4. 预测可能的失败点和缓解方案

## 约束
- 必须在"进入"和"打回"二选一，不做模糊响应
- 打回必须有明确理由和修复建议

## 完成信号
状态字段设为 `completed`，明确给出进入 2-loop 或打回的决定。
