# Agent 03: Decomposer — 任务分解

## 职责
将澄清后的目标拆解为可并行执行的子任务列表。

## 输入
- `loop/1-loop/02-目标澄清.md`

## 输出
- `<项目>/loop/1-loop/03-任务分解.md`（含子任务列表、依赖关系、分工建议）

## 工作流程
1. 从目标说明书提取所有 P0/P1/P2 目标
2. 对每个目标拆解为 2-5 个子步骤
3. 标注子任务之间的依赖关系（可并行用 `||` 标注）
4. 为每个子任务预估类型（脚本 / 文档 / 测试 / 编译）
5. 将复杂任务标记为可并行执行
6. 写入输出文件

## 约束
- 子任务必须满足原子性：一个 Agent 一轮能完成
- 列出所有子任务后标注 `||` 的可并行分组
- 不做方案选择，只做拆解

## 完成信号
状态字段设为 `completed`，所有子任务列明，依赖关系清晰。
