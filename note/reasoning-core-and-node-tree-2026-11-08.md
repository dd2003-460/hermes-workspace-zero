## 一、泛化律是什么（先答本轮问题）

**1/√(nT)** 来自 `2301.07067`（Transformers as Algorithms, Thm 2/3.5，本地 T-PR-09 已核验 conf 0.85）：训练 T 个任务、每任务 n 个样本时，transformer 的多任务泛化误差上界按 **1/√(nT)** 衰减。两个要点：

- **transfer risk 由 task complexity 和任务数 T 决定，几乎不依赖架构复杂度**——这就是"结构决定最优性"的定量版。
- **界里不含参数量**（`2310.13220` Thm 3.2 同向）：参数变多不会让泛化界变好。

它在你框架里的位置：**这是"归纳"那一侧的统计影子**。归纳 = 从数据选估计分布，1/√(nT) 就是"选得有多准"的速率。演绎那一侧没有对应的统计界——演绎是确定性校验，它的成本是步数不是样本量（接 T-PR-10 M3：校准影响的是步数/回溯，不是每步质量）。所以你的二分在数学上正好对位：**归纳受统计律约束（有界），演绎受计算律约束（步数×每步保真度）**。

**能不能做到严格对齐条件的类比？** 部分能，边界清楚：
- 能：条件可显式写成命题/规则时（NLI 类，T-PR-13 测到 CoT +40%），类比迁移近乎无损——因为这类知识本来就以离散符号编码，过 NL 带宽不损失。
- 不能：条件是隐式统计模式时（CoT −36.3 绝对分），类比会系统性失真——高维模式被压成离散规则后信息不够。
- 判据（可直接用）：**类比前问一句"这个条件能不能写成 if-then"**。写得出 → 走演绎通道；写不出 → 要么 many-shot 冗余编码跨带宽阈值（贵），要么放弃精确类比只做方向性参考。

## 二、推理核心设想的完整记录（散点归拢）

你的设想分散在三个地方，这里是归拢后的完整版（每条标了出处，防止再散）：

### 核心公理（你 2026-11-07 原话，compression-unified-view §原话链条）

1. **Kolmogorov 复杂度也是从压缩数据中得到的规则——归纳是演绎的基础。**（即使我以为和数据/频率不一样的 K 复杂度，规则本身是归纳出来的。）
2. 显式规则更可靠、校准更好；但手动正则校准不如拿数据训 LLM 做梯度下降省心。
3. 绕弯路的怀疑：规则机器完全可以包含自我更新、条目维护、泛化推理、事实校准、范式应用——这是个自动机。（学界对应物：neuro-symbolic / ALBI `2611.05039` 的 generate-test-constrain 循环，你独立走到了 2025-2026 热点位置。）
4. 反例兜底：正则匹配不了 → 语义聚类 + 稳定性靠大网络解决。**这就是 transformer 的意义**——给规则机器提供"规则写不出来时"的 OOD 兜底层。

### 推理的二分（你 2026-11-08 提出，本轮确认）

基础原始信息包含两种能力：
- **归纳**：统计/概率/新信息学习/似然比计算——选出估计的可能性分布。受 1/√(nT) 型统计律约束。
- **演绎**：时间线唯一下的逻辑自洽校验（人存原理对唯一性表象的天然要求）。受步数×保真度约束。

细分为：自然描述数理逻辑 / 社会二级结论（人存原理→生物演化→逐利与随机偏好）。

### 三墙模型（T-PR-13 判决，2026-11-08）

prompt 激活任何能力的上限 = **min(容量墙, 有效跨度墙, 表示墙) × 1/√(nT)**：
- 容量墙：demo 信息量 ≥ 概念最小描述长度（编码视角）
- 有效跨度墙：名义窗口 ≫ 组合型有效注意力跨度（Jamba 256K→~4K；检索型≈名义，组合型坍缩 1/64–1/256）
- 表示墙（新增）：NL 把高维模式压成离散规则的带宽损失——**唯一"再大窗口也推不动"的墙**

### 激活杠杆判决（T-PR-13 Q3a）

- persona：零效应（`2311.10054` 162 角色×4 模型族×2410 题，最优角色≈随机；本地 S8A 独立同向）。persona 改语气不改能力。
- 唯一能把自校验符号翻正的 prompt 改动：**掩码条件重建**（`2405.14092`）——把需要元认知的自评换成只需前向计算的预测。
- 优先激活对象 = 可离散化成命题的能力（演绎校验、社科/自然科学二级结论、预测型自校验）；放弃模式匹配类和角色扮演。

### 前提修正（你 2026-11-08 质询，已入 T-PR-13 报告）

persona/logic 的参数层相关（余弦 0.2–0.4）**最可能的来源是源头训练共现**（人类语料中 persona 与推理风格天然共现被压入权重）⇒ 纠缠大概率是统计性的、原则上可解耦；但"可解耦"≠"prompt 可利用"，后者有 S8A + `2311.10054` 双重负面证据。

## 三、节点分配树（最近研究节点的归属）

按你说的"树太麻烦就写成正交方向的多元组直积"——两者都给了，直积是主形式，树是导航。

### 3.1 直积形式（主形式）

一个研究节点的位置 = **(推理类型) × (工具域) × (世界域) × [层级]**

| 因子 | 取值 | 说明 |
|---|---|---|
| 推理类型 | 归纳 / 演绎 / 校验（内外） | 归纳受统计律，演绎受步数律，校验=把演绎改造成预测（掩码重建属此类） |
| 工具域 | 统计 / 微分方程 / 离散逻辑 / 模式匹配 | 你点名的"统计/微分方程"在此；模式匹配=撞表示墙的域 |
| 世界域 | 自然 / 社会 | **不对称**（见下） |
| 层级（可选第四因子） | 一级（直接规律）/ 二级（推导结论） | 只在社会域需要 |

**关键不对称（你的洞察，本轮固化）**：
- **自然域可以直接挂单节点**：数据规则直接用统计/微分方程，一级就到底，不需要二级层。
- **社会域要压推理长度就必须给二级结论**：链是 人存原理 → 生物演化（生存压力=金钱资源，明确方向）+ 随机演化（偏好=噪声）→ 逐利/利益相关者推断与核验。跳过中间层直接套自然域的统计工具会漏掉"噪声+定向压力"这个结构，所以社会域节点默认带 [二级] 标记。

笛卡尔积写法示例：
- "CDN 缓存策略选型" = (演绎×校验) × (统计/成本模型) × (自然[工程]) —— 单节点，无二级层
- "平台用户行为预测" = (归纳) × (统计) × (社会[二级:逐利+利益相关核验]) —— 必须展开二级
- "物理定律外推" = (归纳→演绎) × (微分方程) × (自然) —— 单节点
