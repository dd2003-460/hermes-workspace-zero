# 浏览器控制可行性调研

## 调研背景

调研目标：在当前 Claude Code / Ralph Loop 架构下，能否让大模型通过浏览器直接 review 产出的文档/代码。

## 实验环境

- 平台：macOS (darwin 25.3.0, Apple Silicon)
- Claude Code：已安装
- Node.js：11.12.1 (npx)
- Python：3.14.4

## 调研结果

### 1. 当前环境支持的浏览器自动化工具

**Playwright** ✅ 可用

```bash
npm install playwright
npx playwright install chromium
```

实验验证：成功启动 headless Chromium，访问百度并获取页面标题。
- 已下载 Chrome for Testing 149.0.7827.55
- 已下载 Chrome Headless Shell 149.0.7827.55
- 浏览器路径：`/Users/a1-6/Library/Caches/ms-playwright/chromium-1228`

**Puppeteer** ⚠️ 未安装，但可通过 `npm install puppeteer` 快速安装

**CDP (Chrome DevTools Protocol)** ✅ 可用
- Chromium 自带 CDP 支持，Playwright 底层即基于此

### 2. Claude Code 的浏览器控制能力

**内置 Chrome 集成** ✅

Claude Code 支持 `--chrome` 和 `--no-chrome` 参数：
```bash
claude --chrome  # 启用 Claude in Chrome 集成
```

这意味着 Claude Code 可以直接与浏览器交互，实现：
- 读取网页内容
- 截图分析
- 页面导航
- DOM 操作

**MCP 配置支持** ✅

Claude Code 支持通过 `--mcp-config` 加载 MCP 服务器：
```bash
claude --mcp-config mcp-browser.json
```

### 3. MCP 浏览器控制工具

调研发现多个可用的 MCP 浏览器控制工具：

| 工具 | 描述 | 状态 |

| `@n8n/mcp-browser` | 基于 Playwright + WebDriver BiDi 的浏览器自动化 | ⚠️ 未安装 |
| `@iflow-mcp/playwright-mcp` | Playwright MCP 工具集 | ⚠️ 未安装 |
| `@modelcontextprotocol/server-puppeteer` | 基于 Puppeteer 的 MCP 服务器 | ⚠️ 未安装 |

**fetcher-mcp 实验**：
- 已安装 v0.3.9
- 作为 MCP 服务器运行，通过 stdio 与 Claude Code 通信
- 支持内容抓取、页面渲染、JS 执行

### 4. 快速安装配置可行性

**结论**：✅ 可以快速配置

```bash
# 方案 A：使用已有 Playwright (已安装)
# 直接编写脚本控制浏览器

# 方案 B：安装 MCP 浏览器工具
npm install fetcher-mcp  # 已完成

# 方案 C：使用 Claude Code 内置 Chrome 集成

```

### 5. 浏览器控制对"Review 产出"的价值

#### 核心价值

1. **视觉验证**
   - 直接渲染 Markdown/PDF/HTML，以视觉方式 review 排版效果
   - 检查图表、公式渲染是否正确
   - 截图反馈渲染问题

2. **交互式审查**
   - 在浏览器中打开本地文件，模拟用户视角
   - 检查链接有效性
   - 验证交互式内容（JavaScript、动画）

3. **多格式支持**
   - 浏览器是通用的文档查看器
   - 无需安装专用阅读器
   - 支持在线文档（arXiv、Google Docs 等）

4. **自动化测试**
   - 自动化回归测试
   - 页面可访问性检查
   - 性能分析

#### 具体应用场景

| 场景 | 价值 | 实现难度 |
|------|------|----------|
| Review LaTeX 编译后的 PDF/HTML | 高 - 直接看到最终效果 | 低 |
| Review arXiv 提交文档 | 高 - 模拟读者视角 | 低 |
| Review 代码在 IDE 中的显示 | 中 - 替代终端查看 | 中 |
| Review 在线文档链接 | 高 - 验证链接有效性 | 低 |

## 明确建议

### **有条件能** ✅

**条件**：
1. 需要安装 Chromium 浏览器（Playwright 已自带）
2. Review 场景需要通过脚本/MCP 服务器间接控制，而非直接由 Claude Code 原生控制
3. 对于文档渲染 review，建议采用 "Playwright 渲染 + 截图 + Claude 视觉分析" 的流水线

**推荐方案**：

```
产出文档 → Playwright 渲染 → 截图 → Claude 视觉分析 → Review 反馈
```

**实现步骤**：
1. 使用 Playwright 打开本地文件 URL (`file:///path/to/file.html`)
2. 渲染页面并截图
3. 将截图发送给 Claude 进行视觉审查
4. Claude 提供排版、公式、图表的 review 反馈

**技术栈**：
- Playwright (已安装) ✅
- Claude Code 视觉能力 (内置) ✅
- MCP fetcher-mcp (已安装) ✅
