## 工具经验
- arXiv API 被限流 (HTTP 429)
- Semantic Scholar API 也被限流 (HTTP 429)
- CrossRef API 免费、无 API key、不受限流影响
- 搜索命令: `https://api.crossref.org/works?query=<query>&rows=<n>`
- 返回: 标题、作者、年份、DOI
