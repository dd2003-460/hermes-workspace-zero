# 文献搜索：CrossRef API 替代方案（iteration 34）

## 背景
迭代 33 工具审计后，迭代 34 尝试文献搜索。

## 问题
- arXiv API 被 IP 限流（HTTP 429，持续中）
- Semantic Scholar API 也被限流（HTTP 429）

## 解决方案
- CrossRef API (api.crossref.org) 可用，不受限流影响
- 发现 4 篇与 D40 高度相关的文献
- 搜索结果写入 raw/crossref_literature_findings.md

## 文献发现（D40 相关）

2. **Roxas & Emekci TechRxiv 2025** (DOI: 10.36227/techrxiv.174439863.35906289) — 医学 vs 通用 LLM 比较
3. **Peng 2025** (DOI: 10.1201/9781003511601-1) — 深度学习的泛化理论
4. **Hochin & Nomiya 2013** (DOI: 10.1109/iiai-aai.2013.21) — 语义领域的专业化与泛化

## 经验
- CrossRef API 免费、无需 API key、不受 arXiv 限流影响
- CrossRef 搜索结果可获取 DOI，可用于后续深入搜索
- arxiv 包 + CrossRef 互补：arxiv 搜索技术/预印本，CrossRef 搜索同行评审论文
