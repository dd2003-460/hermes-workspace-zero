# bayesian-frame 纳入 $\mathbf{DistCat}$（iteration 58）

## 完成

### bayesian-frame 作为 $\mathbf{DistCat}$ 规范特例

**定义**：
- $\mathbf{C}_{\text{Bayes}}$：贝叶斯范畴（0-对象=先验+似然，1-态射=模型映射，2-态射=贝叶斯更新交换性）
- $\mathcal{F}_{\text{Bayes}}$：贝叶斯更新函子（先验+似然 → 后验）
- $\mathcal{O}_{\text{Bayes}}$：观测函子（后验 → MAP 估计）
- $\Gamma = d_{FR}$：Fisher-Rao 距离
- $\delta = D_{KL}$：后验 KL 散度
- $\eta$：Amari 引理的贝叶斯推广

### 特有定理

**定理 3.1（贝叶斯更新稳定性）**：
- $D_{KL}(p_1 \parallel p_2) \leq D_{KL}(\pi_1 \parallel \pi_2)$
- 观测使后验距离 $\leq$ 先验距离
- 贝叶斯更新是收缩映射

**定理 3.2（Fisher-Rao 作为扰动放大上界）**：
- 后验 Fisher 信息矩阵控制先验扰动放大
- 最优先验 = 使后验 Fisher 信息矩阵最大化的先验
- 与 D26 共振理论一致

### bayesian-frame 模块定位

| bayesian-frame | $\mathbf{DistCat}$ |

| prior/ | 先验分布 $\pi$ |

| readout/ | 观测函子 $\mathcal{O}_{\text{Bayes}}$ |
