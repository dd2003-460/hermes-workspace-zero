# D1 vs EMRI 定量等价分析

> **创建**: iteration 72
> **来源**: Agent a3788201d80a313b1 分析 + DISTCAT 统一框架 Sec.8.4
> **类型**: 定量比较分析
> **结论**: D1 与 EMRI 属于**不同的普适类**，但共享 DistCat 2-范畴结构

## 关键发现

### (a) 指数本质

**D1-grav-waves: α_D1 ≈ 1.84 (log-corrected quadratic)**
- 源距离: d_TV (代数态的总变分距离)
- 观测距离: ζ(θ) (Hellings-Downs 相关)
- 小角渐近: ζ(θ) - 1/2 ~ θ² ln θ
- 物理起源: **运动学/几何极限** — SO(3) 旋转对称性 + 自旋-2 张量场
- 对数项来自 AQFT 余配边类 + Hadamard 态两点函数的短距离奇异性
- 类比: 2D CFT 关联函数的对数发散、热核展开的对数项

**EMRI: α_EMRI = 0.5 (square-root)**
- 源距离: ||h_μν|| (度规扰动的 L² 距离)
- 观测距离: λ_T (Lyapunov 指数)
- 临界标度: λ_T ~ |ε - ε_c|^{1/2}
- 物理起源: **动力学相变** — KAM 破裂阈值处的同宿分岔
- 标准 Hamiltonian 混沌结果 (Peyrard-Auckly-Kuchlar 定理)
- 类比: pitchfork 分岔、saddle-node 分岔 (codimension-1 homoclinic bifurcation)

### (b) 统一普适类存在性?

**答案: 不存在。**

关键区别:
1. **临界点类型不同**: D1 的 θ→0 是观测空间边界（最小角分离），不是分岔。EMRI 的 ε→ε_c 是参数空间内部的分岔点。
2. **普适类成员不同**: D1 属于"带对数修正的二次类"（Fisher 信息几何也是指数 2）。EMRI 属于"同宿分岔类"（指数 1/2）。
3. **指数不可通约**: 1.84 > 1 (超线性) vs 0.5 < 1 (次线性)。无法通过变量变换匹配。
4. **距离结构不同**: d_TV 是量子信息距离 vs ||h_μν|| 是黎曼距离。

### (c) 共享的结构相似性

虽然指数不同，但两者共享:
1. **DistCat 2-范畴结构**: δ = Φ(Γ) 且有自然变换 η
2. **Lipschitz 上界**: δ ≤ C·Γ 全局成立
3. **临界慢化**: D1 中 δ'(θ)→0 (θ→0)，EMRI 中 δ'(ε)→∞ (ε→ε_c)
4. **重整化视角**: D1 的对数项可以解释为 RG 流动（耦合常数对数跑动）；EMRI 在 KAM 阈值处具有参数空间的尺度不变性

### (d) 与 DistCat 统一框架的关系

DISTCAT-unified-framework.md Sec.8.4 声称 D(D1) ≅_struct D(EMRI)，这是**范畴意义**上的结构等价，而非数值等价。Sec.9.2 明确说明：
> "不同 α 值不矛盾等价性 — 它们反映了同一距离等价类 [B] 的不同成员。"

这确认了 **DISTCAT 框架的普适性** — 它可以容纳不同物理机制产生的不同指数，同时保持统一的范畴结构。
