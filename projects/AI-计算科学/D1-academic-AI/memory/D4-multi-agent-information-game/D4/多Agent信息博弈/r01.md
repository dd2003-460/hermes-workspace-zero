# r01 — 多Agent信息博弈：竞争而非合作中的信息演化

## 探索主题
现有AI研究几乎全部假设**合作**或**独立决策**场景。当Agent之间存在**竞争关系**时，信息策略如何变化？是否存在"信息守恒定律"——一个Agent获取更多信息意味着其他Agent必须减少信息获取？

## 核心问题
1. 零和竞争中，均衡策略 $p^*$ 是否满足 $\sum_{i=1}^N I(p_i; \mathcal{O}) = \text{const}$（信息守恒）？
2. 竞争环境下的信息博弈值 $V^*$ 与单Agent情况有何本质差异？
3. "信息压力梯度"是否存在——资源稀缺时Agent是否会自发减少信息冗余？
4. 竞争vs合作条件下的表征质量差异是什么？

## 关键发现与分析

### 1. 零和竞争中的信息守恒猜想
- **直觉**：
  - 竞争环境中，信息是"有限资源"
  - Agent A获取更多信息 → 环境信息分布改变 → Agent B的信息增益减少
  - **类比**：热力学第二定律在信息空间的应用
- **数学表达**：
  $$\frac{\partial}{\partial t} \sum_{i=1}^N I(p_i; \mathcal{O}) = 0 \quad (\text{在均衡时})$$

### 2. 竞争vs合作的表征差异
- **合作条件**：
  - Agent共享信息，表征趋于一致
  - 信息瓶颈目标：$I(\text{shared}; Y)$ 最大化
- **竞争条件**：
  - Agent分散信息，表征趋于分化
  - 信息瓶颈目标：$\max_{p_1} \min_{p_{-1}} I(p_1; Y)$
- **关键差异**：竞争导致"表征多样性"而非"表征一致性"

### 3. 信息压力梯度机制
- **资源稀缺** → Agent减少冗余，提高信息密度
- **资源充裕** → Agent增加探索，接受冗余
- **动态方程**：
  $$\frac{dp_i}{dt} = -\nabla_{p_i} \text{Loss}_i + \lambda \cdot \nabla_{p_i} I(p_i; \mathcal{O})$$
  其中 $\lambda$ 随竞争强度变化

### 4. 与D9-I的关联
- D9-I关注**单Agent**的智能vs拟合边界
- D4扩展至**多Agent**竞争场景
- **关键问题**：竞争是否促进或抑制"智能级表征"的形成？

## 技术要点

### 信息博弈的定义
$$V^* = \sup_{p_1} \inf_{p_{-1}} \mathbb{E}\left[\sum_{i=1}^N R_i(p_1, \dots, p_N)\right]$$

### 竞争强度的量化
- **Nash均衡偏差**：竞争越激烈，实际策略偏离合作策略的程度越大
- **信息分布熵**：竞争环境下，信息在Agent间的分布更加均匀
