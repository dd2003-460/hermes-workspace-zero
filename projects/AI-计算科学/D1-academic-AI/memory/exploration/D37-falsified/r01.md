# D37 降档到 uncertain：4/4 命题被证伪

## D37 原理论
D37 关系均衡理论：恋爱关系中的成本-收益 Nash 均衡 + 迟滞路径依赖

## 实验结果

### D37-A (Nash Equilibrium) — 失败
- **预测**: Nash 均衡存在（成本向量收敛到稳定值）
- **结果**: 不收敛（converged=false），200轮后不平衡=0.141

### D37-B (Asymmetry Robustness) — 失败
- **预测**: 不对称成本下 Nash 均衡仍存在
- **结果**:
  - asym=0.0: 收敛（imbalance=0.0）— 仅对称情况下收敛
  - asym=0.3: 不收敛（imbalance=0.85）
  - asym=0.6: 不收敛（imbalance=1.02）
  - asym=0.9: 不收敛（imbalance=1.03）
  → 任何不对称性导致不收敛

### D37-C (Dead Zone Threshold) — 失败（实验 artefact）
- **预测**: 小 epsilon（死区）不影响均衡，大 epsilon 改变均衡
- **结果**: epsilon 0.01→0.2，所有指标完全相同！
  - early_imbalance = 0.765（所有epsilon）
  - late_imbalance = 0.906（所有epsilon）
  - imbalance_ratio = 0.844（所有epsilon）
  → 死区参数完全不影响结果

### D37-D (Hysteresis) — 弱
- **预测**: 扩张/收缩路径产生不同均衡（迟滞）
- **结果**:
  - Agent A: 无迟滞（area=0.0）
  - Agent B: 弱迟滞（area=0.078）
  → 总迟滞 = 0.078，远小于理论预期

## Bayesian 更新

D37 posterior: 0.51 → 0.30（falsified）
从 "pending" 降档到 "uncertain"

## 结论

D37 的核心理论（关系均衡 + 迟滞）在实验中被证伪：
1. Nash 均衡仅在完全对称情况下存在
2. 不对称性导致系统发散
3. 死区效应不存在
4. 迟滞效应微弱

D37 可能是过于简化的模型，或核心理论不成立。
