## 实验架构

### 1. 三区域 chimera 设计

```
                    环境耦合区域
    ┌─────────────────────────────────────────┐
    │  ← Chimera-A (同步) → │ ←→ │ ←→ │ ←→ │  │
    │                    Region B          │  │
    │          全局耦合区         ← Chimera-B → │
    │                                         │
    │    区域 C ←← Chimera-C ←← 区域 C       │
    └─────────────────────────────────────────┘
                ↑              ↑            ↑
          环境 A         环境 B       环境 C
         (噪声 α)       (耦合 γ)      (反馈 δ)
```

**动力学方程**：

```
dθ_i/dt = f_i + Σ_j w_{ij} sin(θ_j - θ_i) + η_i^env(t)

其中 η_i^env(t) 为环境噪声：
- Region A: η_A ~ N(0, σ_A²), σ_A 控制 chimera A 稳定性
- Region B: η_B = γ · sin(θ_env) + ζ(t)  ← 反馈耦合
- Region C: η_C ~ N(0, σ_C²)
```

### 2. 环境耦合机制

```
时间尺度分离：
  τ_θ ≪ τ_env    (Agent 动力学快于环境)

环境演化：
  dX/dt = -λX + α · C(θ_A) + β · C(θ_B) + γ · C(θ_C)

其中 X = (ε_A, ε_B, ε_C) 是环境状态向量，
      C(θ) = 平均曲率计算结果
```

    """
    检测多 chimera 共存

## 理论验证

### 验证 1：I_C 增长条件

**假设**：当 N_chimera ≥ 2 时，拓扑结构由圆盘 (disk) → 多连通域 (annulus 类)

**检验**：
```python
# 多区域 Poincaré 面积定理近似
# 对于 2 个 chimera 区域：χ ≈ χ₁ + χ₂ + (连接数 - 1)
# 若每个 chimera 区域贡献 χᵢ ≈ 0, 连接处贡献 -1
# → χ_total ≈ -1 (有环结构)
# → w₂ ≈ 1 (环面类型)
# → I_C = |χ| + w₂ ≥ 1
```

**检验目标**：I_C ≥ 2 需要 **≥ 2 个环结构** 或 **高 w₂**。

### 验证 2：自主性-I_C 相关性

**假设**：Phase III (高自主+适度分化) ↔ chimera 共存 → I_C 升高

$$\text{Correlation}(A, I_C) > \rho_{critical} \approx 0.7$$

## 代码框架

```python
import numpy as np
from scipy import signal

class MultiChimeraExperiment:
    def __init__(self, N=64, n_regions=3):
        self.N = N
        self.n_regions = n_regions
        self.theta = np.random.uniform(0, 2*np.pi, N)
        self.regions = self._partition_regions(N, n_regions)
        
    def _partition_regions(self, N, n_regions):
        """均匀划分 Agent 到 n_regions"""
        return np.array_split(np.arange(N), n_regions)
    
    def step(self, K_L=4.0, K_R=0.3, env_coupling=0.1):
        """动力学演化一步"""
        dtheta = np.zeros(self.N)
        
        for i in range(self.N):
            region_idx = self.get_region(i)
            K = K_L if region_idx == 0 else K_R
            
            # 局部耦合
            for j in self.get_neighbors(i):
                dtheta[i] += K * np.sin(self.theta[j] - self.theta[i])
            
            # 环境噪声耦合
            dtheta[i] += env_coupling * np.sin(self.env_state[region_idx])
            
        self.theta += dtheta * self.dt
        self.theta %= 2*np.pi
        
        # 更新环境状态
        self.update_environment()
        
    def get_region(self, i):
        for idx, region in enumerate(self.regions):
            if i in region:
                return idx
        return 0
    
    def get_neighbors(self, i):
        return [j for j in range(self.N) 
                if abs(j - i) <= 3 and j != i]
    
    def compute_i_top_time_series(self):
        """计算 I_C 随时间演化"""
        from wkb_curvature_entropy import CurvatureEntropyEstimator
        
        estimator = CurvatureEntropyEstimator(
            n_phases=self.N, n_components=3
        )
        
        # 使用轨迹构建 observation data
        obs_data = {'embedding': np.sin(self.trajectory)}
        return estimator.compute_topological_intelligence_index(obs_data)
```
