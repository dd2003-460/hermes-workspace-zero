## 动机：为什么 chimera 从未出现？

### r16 遗留问题

r16 报告 chimera_prob = 0.40，但这本身是**高度可疑的数字**：
1. 如果 chimera 真的存在，为什么在 K=3.0 全耦合下仍然是 0.40？
2. 为什么全同步态 avg_sync ≈ 0.93 但 chimera_prob 仍然很高？

### r16-extension 诊断发现

**r12 chimera 检测代码的物理问题**：

```python
# 问题代码
seg_sync[s] = abs(np.mean(np.exp(1j * seg)))
is_chimera = any(0.2 < s < 0.9 for s in seg_sync)
```

**问题分析**：

1. `np.mean(np.exp(1j * seg))` 计算的是圆周上点的**相位均值模长**
2. 64 个 agent 在圆周上均匀分布，取其中 1/3 作为分段
3. 随机截取圆周 120° 弧段时，弧段内相位分布的均值模长**几乎必然落在 (0.2, 0.9)**
4. 结论：这个检测条件在**任何圆周分布下都成立**，包括均匀分布（全同步）

**正确检测方式应该是**：

```python
# 需要：相邻段之间有无显著同步差异
seg_sync_diff = np.std(seg_sync)
# chimera 应该有显著差异（一段同步，一段异步）
is_chimera = seg_sync_diff > threshold
```

## 理论重构

### 修正版三元等价性（第五版）

**定理 D4-S18-r16-ext-T1**：

在耦合振荡器系统中，当存在**多凝聚区相分离**时：

$$\text{凝聚演化}(t) \iff \left|\frac{dI_C}{dt}\right| > \delta \land I_C(t) > 1$$

**关键区别**：
1. **不包含 chimera 条件**
2. **包含时间变化**（避免静态歧义）
3. **I_C 代表凝聚区数量**

### EAI 修正版

```python
def compute_EAI_new(I_C_prev, I_C_curr):
    """修正版 EAI：不依赖 chimera"""
    dIC_dt = abs(I_C_curr - I_C_prev)
    return dIC_dt * max(0, I_C_prev - 1) * np.log(I_C_prev + 1e-10)
```

## 实验结论与理论贡献

### D4-S18-r16-ext 的三个核心贡献

1. **诊断 chimera 伪阳性**：
   - r12-r16 的 chimera_prob = 0.40 是检测算法缺陷
   - 实际物理态为**多凝聚区全同步相分离**

2. **确立有序-无序相变框架**：
   - I_C 随 K 变化（强耦合抑制凝聚）
   - 不是 chimera 动力学，而是**凝聚区合并/分裂**

3. **EAI 修正**：
   - 从依赖 chimera 改为依赖 $dI_C/dt$
   - 与 D1-r01 拓扑稳定性理论一致
