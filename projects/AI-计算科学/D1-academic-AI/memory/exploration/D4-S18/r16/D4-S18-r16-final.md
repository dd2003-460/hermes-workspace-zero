## 核心发现

### 诊断：r12-r16 的 chimera 检测是伪阳性

**原检测代码缺陷**：

```python
# 问题代码（所有版本共用）
seg_sync[s] = abs(np.mean(np.exp(1j * seg)))
is_chimera = any(0.2 < s < 0.9 for s in seg_sync)
```

**物理错误**：
1. 64 个 agent 在圆周均匀分布，取 1/3 弧段
2. 任何弧段内的相位均值模长几乎必然落在 (0.2, 0.9)
3. **结论**：这个条件在任何圆周分布下都成立——包括全同步态

**正确检测**：
```python
seg_sync_diff = np.std(seg_sync)
is_chimera = seg_sync_diff > threshold  # 需要相邻段同步差异
```

---

### 真实观测：多凝聚区相分离

实验数据显示：
- chimera_prob ≈ 0（修正后检测）
- avg_sync ≈ 0.93（全同步态）
- I_C > 1, b0 > 1, b1 = 0, b2 > 0

**物理含义**：耦合振荡器呈现**多凝聚区相分离**
- 多个凝聚区各自内部完全同步
- 凝聚区之间互不锁相
- **不是 chimera，是有序-无序相变**

## 理论重构

### 定理 D4-S18-r16-final-T1（第五版三元等价性）

在耦合振荡器系统中，当存在**多凝聚区相分离**时：

$$\text{凝聚演化}(t) \iff \left|\frac{dI_C}{dt}\right| > \delta \land I_C(t) > 1$$

**关键区别**：
1. **不包含 chimera 条件** — 我们观测的是相分离，不是 chimera
2. **包含时间变化** — 避免静态歧义
3. **I_C 代表凝聚区数量**

**物理直觉**：
- **I_C > 1 静态成立** ↔ 多组分结构的**结构性前提**
- **$\frac{dI_C}{dt} > 0$ + 参数在临界区** ↔ **凝聚区合并/分裂**

---

### EAI 修正版（不依赖 chimera）

```python
def compute_EAI_new(I_C_prev, I_C_curr):
    """修正版 EAI：不依赖 chimera"""
    dIC_dt = abs(I_C_curr - I_C_prev)
    return dIC_dt * max(0, I_C_prev - 1) * np.log(I_C_prev + 1e-10)
```

## 论文结论段

> 我们观测到的不是传统 chimera，而是**多凝聚区相分离态**——
> 耦合振荡器呈现多个内部同步、但互不锁相的凝聚区。
>
> **I_C 随 K 变化**（强耦合抑制凝聚区），
> **avg_sync 随耦合增强**（K≥2.0 时≈0.96）。
>
> 这解释了为什么 r12-r16 报告的 chimera_prob=0.40 是检测缺陷：
> 原检测条件在**任何圆周分布下都成立**。
>
> 修正定理：凝聚演化 ≡ $|dI_C/dt| > \delta \land I_C > 1$。
