### 假设2：竞争中的信息"军备竞赛" vs 合作中的信息融合

**r01 假设修正**：

r01 声称"竞争中的信息军备竞赛"，但 arXiv:2107.06327（Contextual Games）的研究指出：

> **侧信息（side information）的存在改变了博弈结构**——当 Agent 拥有私有信息时，共享行为不再是一个"合作/竞争"的简单选择，而取决于信息的"可利用性"和"相对优势"。

**修正后的分析框架**：

```
博弈类型 → 信息共享条件：
- Contextual Game + 共享收益分布 → 信息共享增加
- 信息不对称程度高 → 信息隐藏
- 博弈重复次数 → 合作涌现（声誉机制）
- 信息价值波动 → 动态博弈决策
```
