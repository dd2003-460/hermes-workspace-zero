## 实验环境设计

### 1. Agent 动力学模型

```
状态空间：Θ = S^1 × [0,1]^2
- θ: 策略方向（环面）
- α: 探索率 ∈ [0,1]
- β: 可信度 ∈ [0,1]

演化方程：
  dθ_i/dt = -∇_θ L_i + α_i · ξ_i(t) + g · ∑_j w_{ij} · sin(θ_j - θ_i)
  dα_i/dt = η(α₀ - α_i) + γ · ∂Autonomy/∂α_i
```

### 2. 工具空间表示

**三区域模型**：
```
     T₁ (专精) ─────┐
                   ├─→ 工具选择概率分布 p(t)
     T₂ (通用) ─────┘
                   ├─→ Agent 收敛轨迹
     T₃ (混合) ─────┘
```

**概率转移**：
$$p_{ij}(t+\Delta t) = (1-\epsilon) p_{ij}(t) + \epsilon \cdot \frac{1}{|\mathcal{T}_j|}$$

### 3. 自主性测量

**定义**：自主性 = 个体策略方差对集体策略方差的比率

$$A = 1 - \frac{\text{Var}(\text{个体-群体差异})}{\text{Var}(\text{群体策略})}$$

- A → 0：完全从众（跟随群体）
- A → 1：完全自主（独立于群体）

## 代码框架草案

```python
def simulate_agent_autonomy(N=50, g=0.5, alpha=0.5, T=5000):
    """
    主实验函数
    """
    # 初始化
    agents = [Agent(theta=np.random.uniform(0, 2*np.pi)) 
              for _ in range(N)]
    
    # 演化
    history = {'autonomy': [], 'phase': [], 'chi': []}
    
    for t in range(T):
        # 博弈交互
        for a in agents:
            # 自治探索
            a.theta += alpha * np.random.randn()
            # 博弈耦合
            a.theta += g * mean_sin_neighbors(a, agents)
        
        # 测量
        a_val = compute_autonomy([a.theta for a in agents])
        history['autonomy'].append(a_val)
        
    return history
```
