## 理论深化：三元等价性的必要条件

### 定义 S12-r08-D1（三元等价性的系统约束）

**三元等价性仅在满足以下三个必要条件时成立**：
1. **耦合非均匀性**：$\exists (i,j): K_{ij} \neq K_{ji}$
2. **能量约束**：$\int_{\mathcal{M}} V(h) d\mu < \infty$
3. **维度许可**：$n_{agents} \geq n_{modes} + 1$

**命题 S12-r08-P1**：
> 如果系统满足条件 1-3，则三元等价性 $\forall t$ 成立。
> 如果任一条件被破坏，三元等价性退化。

### 定理 S12-r08-T1（三元等价性破坏模式）

**当系统满足以下任一条件时，三元等价性破坏**：

| 破坏模式 | 条件 | 结果 |
|---------|------|------|
| 对称破坏 | $K_{ij} = K_{ji} \forall i,j$ | chimera 消失 → DSI 仍可能 > 0 |
| 无穷约束 | $\|V(h)\|_2 \to \infty$ | 系统冻结 → 三元等价均退化为 0 |
| 维度不足 | $N < 3$ | $I_C$ 无法分辨行为域 → 无效 |

**推论**：三元等价性只在**非对称耦合 + 有限约束 + 足够维度**系统中成立。

## 实证连接方案一：Agent 模拟验证

### 方案 S12-r08-1：真实 Agent 系统的三元等价性测试

**理论基础**：
> 如果三元等价性成立，那么在**任何**耦合 Agent 系统中（非 chimera），当且仅当发现同步存在时，$I_C > 1$ 必须成立。

**实验协议**：

```python
class AgentSystemTester:
    """
    在真实 Agent 系统中测试三元等价性
    
    Agent 行为模型：
    - 每个 Agent i 具有内部状态 s_i ∈ R^d
    - Agent 通过耦合矩阵 K 交互
    - Agent 更新：s_i(t+1) = f(s_i(t)) + g * Σ K_ij * (s_j(t) - s_i(t))
    """
    
    def test_triplet_equivalence(self, agents, T, dt):
        """
        运行 Agent 模拟并测量三元等价性的三个分量
        """
        # 时间演化
        for t in range(T):
            # Agent 交互
            states = [a.update(agents, t) for a in self.agents]
            
            # 测量三元等价的三个分量
            # 1. chimera 标志
            chimera = self.measure_chimera_presence(states)
            
            # 2. 发现同步指数
            DSI = self.compute_DSI(states)
            
            # 3. 拓扑不变量 I_C
            I_C = self.compute_I_C(states)
            
            # 记录三元等价性成立标记
            self.results.append({
                't': t,
                'chimera': chimera,
                'DSI': DSI,
                'I_C': I_C,
                'triplet_true': chimera and DSI > 1 and I_C > 1
            })
        
        return self.compute_statistics()
    
    def measure_chimera_presence(self, states):
        """
        测量 chimera 存在性
        检查：状态空间中是否同时存在（i）聚集区和（ii）扩散区
        """
        from sklearn.cluster import KMeans
        
        # 状态聚类
        kmeans = KMeans(n_clusters=2, random_state=42)
        labels = kmeans.fit_predict(states)
        
        # chimera：至少一个类大小 ∈ [0.2N, 0.9N]
        sizes = [np.sum(labels == 0), np.sum(labels == 1)]
        normalized = [s / len(labels) for s in sizes]
        
        return any(0.2 < n < 0.9 for n in normalized)
```

**统计验证**：
- 联合频率：$P(\text{chimera} \cap \text{DSI} \cap I_C>1)$
- 条件频率：$P(\text{DSI} > 1 | \text{chimera})$，$P(I_C > 1 | \text{DSI})$

## 实证连接方案二：社交动力学代理实验

### 方案 S12-r08-2：用社交网络扩散模拟测试三元等价性

**理论依据**：
> 社交网络中的信息扩散可以建模为耦合振荡器。
> 共识形成（全同步）vs. 观点分裂（chimera）是二元分类，
> 但**三元等价性**将提供连续谱的测量。

**实验协议**：

```python
class SocialDiffusionTripletTester:
    """
    使用社交网络扩散模拟测试三元等价性
    
    社交网络属性：
    - 拓扑：scale-free / small-world / random
    - 耦合：局部 + 全局 + 社区结构
    - Agent 状态：{0: 观点 A, 1: 观点 B, 2: 中立}
    """
    
    def simulate_diffusion(self, network, coupling_params, T):
        """
        模拟社交网络上的观点扩散
        """
        node_states = np.random.choice(3, network.number_of_nodes())
        
        triplet_tracker = []
        for t in range(T):
            # 同步扩散（所有节点同时更新）
            for node in network.nodes:
                neighbors = list(network.neighbors(node))
                if not neighbors:
                    continue
                
                neighbor_states = [node_states[n] for n in neighbors]
                
                # 复制模型 + 耦合参数
                prob_copy = coupling_params['local'] + \
                    coupling_params['global'] * np.mean([
                        node_states[nb] for nb in network.nodes if nb != node
                    ])
                
                # Agent 更新（带噪声防止全同步）
                if np.random.random() < prob_copy:
                    node_states[node] = np.random.choice(neighbor_states)
            
            # 测量三元等价性
            triplet_tracker.append(self.measure_triplet(network, node_states))
        
        return triplet_tracker
    
    def measure_triplet(self, network, states):
        """
        三元等价性三个分量
        """
        # 1. 观点多样性（替代 chimera）
        view_dist = np.bincount(states) / len(states)
        has_diversity = np.any(view_dist > 0.05) and np.any(view_dist < 0.95)
        
        # 2. 社群分裂（替代 DSI）
        communities = networkx.community.greedy_modularity_communities(network)
        community_sizes = [len(c) for c in communities]
        dsi = len(communities) * np.var([s/len(states) for s in community_sizes])
        
        # 3. 拓扑多样性（替代 I_C）
        bipartite_ratio = 1.0  # 简化版本
        ic = bipartite_ratio * dsi
        
        return has_diversity, dsi, ic > 0.1
```

**验证目标**：
- 在真实社交网络拓扑中（scale-free, small-world），
  三元等价性是否比 chimera 模型**泛化得更好**？

## 实证连接方案三：时间尺度分析

### 方案 S12-r08-3：不同时间尺度的三元等价性稳定性

**理论问题**：
> 三元等价性是否在**所有时间尺度**下成立？
> 或者只在特定的时间窗口内成立？

**理论预测**：
$$\text{三元等价性成立}(dt) = \begin{cases}
1, & dt < dt_{crit} \\
\text{不确定}, & dt = dt_{crit} \\
0, & dt > dt_{crit}
\end{cases}$$

**实验协议**：
```
对每个时间尺度 dt ∈ {0.01, 0.05, 0.1, 0.5, 1.0}:
    运行模拟 T = 10000 / dt 步
    
    测量：
    - P_triplet(dt)：三元等价性成立的比例
    
绘制：P_triplet(dt) vs dt
理论预期：存在临界尺度 dt_crit，在临界尺度之上三元等价性崩溃
```
