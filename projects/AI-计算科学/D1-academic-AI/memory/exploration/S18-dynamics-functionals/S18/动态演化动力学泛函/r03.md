## 问题空间中的场论（Problem Space Field Theory）

### 统一泛函：问题求解的"拉格朗日密度"

$$\mathcal{L}[\phi, \pi] = \int_\Omega \left[\frac{1}{2}|\nabla \phi|^2 - V(\phi) + \mathcal{G}(\phi)\right] dx dt$$

其中：
- $\phi$：**问题表示场**——每个时空点表示对问题的一部分的"认知状态"
- $V(\phi)$：**势能项**——对问题的理解深度
- $\mathcal{G}(\phi)$：**交互项**——Agent 间的认知交互（博弈）

### S18 的原创假设：三种场论的统一

| 场论类型 | 物理对应 | 问题空间对应 |
|----------|----------|--------------|
| **动力学** | $\partial_t \phi = -\delta \mathcal{L}/\delta \phi$ | 梯度下降、牛顿法、一阶系统 |
| **变分法** | $\delta S = \delta \int \mathcal{L} dt = 0$ | 优化路径选择、最速降线 |
| **博弈** | Nash equilibrium 满足 $\nabla_i L_i = 0$ | 多目标优化的 Nash 点 |

## 从场论到 Agent 自主性：自主性作为场的**涌现属性**

### 核心洞察
当"问题空间"包含足够的复杂度时（如科学发现），**场论描述了系统的自发行为模式**。

**自主性 ≠ Agent 的内在属性**，而是：
$$A = \frac{\partial}{\partial \tau} \text{SymmetryBreaking}[\phi](\tau)$$

- **对称破缺**：当场在时空点自发选择特定方向（"认知偏航"）
- **涌现属性**：个体 Agent 无意识，群体场出现"意图"

### 场论中的三种自主性模式

1. **模式 A：惯性自主**（无外力）
$$\Box \phi + m^2 \phi = 0$$
- Agent 自主搜索（类似自由粒子运动）
- **对应**：Agent 自主探索

2. **模式 B：自发对称破缺**（场势能多峰）
$$V(\phi) = \frac{\lambda}{4}(\phi^2 - v^2)^2 - h\phi$$
- **对应**：科学范式转换——"突然改变观点"

3. **模式 C：边界条件驱动的场演化**
$$\phi|_{\partial \Omega} = f_{external}(t)$$
- **对应**：外部环境变化 → 系统响应
