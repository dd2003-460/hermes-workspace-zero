## 实现层 I：规范不变离散化

### 理论基础：为什么需要规范不变性？

任何场论 $\mathcal{L}[\phi]$ 都有**规范自由度**（gauge freedom）——场表示中不改变物理行为的部分。

**问题**：标准数值离散化会**丢失规范不变性**，导致数值解随网格参数 $h$ 不一致。

**S18 r05 贡献：Hermite 有限元法的规范不变离散化**

---

### 算法 1：Hermite-Fejér 规范不变离散化

**原理**：使用三次 Hermite 多项式插值，保证一阶导数连续性：

$$\phi_h(x) = \sum_{i} c_i H_i(x) + \sum_{i} d_i H'_i(x)$$

**规范不变性条件**：
$$\mathcal{L}[\phi] = \mathcal{L}[U_\alpha \cdot \phi] \quad \text{for all } \alpha$$

在离散化后满足：
$$\sum_{i,j} g_{ij} \partial_i \phi_h \partial_j \phi_h = \sum_{i,j} g_{ij} \partial_i(U_\alpha \phi_h) \partial_j(U_\alpha \phi_h)$$

---

### 算法 2：保辛积分器（Symplectic Integrator）

对于 Lagrangian 系统，使用 **Störmer-Verlet 方法**保持辛结构：

$$\begin{aligned}
p_{n+1/2} &= p_n - \frac{\Delta t}{2} \nabla_\phi V(\phi_n) \\
\phi_{n+1} &= \phi_n + \Delta t M^{-1} p_{n+1/2} \\
p_{n+1} &= p_{n+1/2} - \frac{\Delta t}{2} \nabla_\phi V(\phi_{n+1})
\end{aligned}$$

**关键性质**：保持相空间体积——**长时间数值稳定性**的保证。

```python
def classify_and_select(problem):
    """
    根据问题性质自动选择最优场论表示
    """
    properties = analyze_problem(problem)
    
    if properties.has_continuous_gradients:
        if properties.has_many_objectives:
            return "Pareto_flow", epsilon_1 = 1e-3
        else:
            return "gradient_flow", epsilon_1 = 1e-4
    
    elif properties.has_discrete_constraints:
        if properties.has_high_flexibility:
            return "annealing", epsilon_1 = 1e-2
        else:
            return "markov_chain", epsilon_1 = 1e-3
    
    elif properties.has_adversarial_dynamics:
        return "nash_flow", epsilon_1 = 1e-3
    
    elif properties.has_global_search_needs:
        return "path_integral", epsilon_1 = 1e-2
    
    return "gradient_flow", epsilon_1 = 1e-4  # default
```

## 完整场论求解器架构

### 统一接口定义

```python
class FieldSolver:
    """
    统一场论求解器——基于 S18 r05 的理论框架
    """
    
    def __init__(self, problem, gauge="abelian", num_scales=3):
        self.problem = problem
        self.gauge = gauge
        self.scales = [2^k for k in range(num_scales)]  # 多尺度
        
        # 初始化场表示
        self.phi = self._initialize_field()
        self.pi = self._initialize_momentum()  # 对偶变量
        
        # 场论选择器自动分类
        self.field_type = classify_and_select(problem)
        
        # 场论方程
        self.Lagrangian = self._construct_Lagrangian(self.field_type)
        
    def solve(self, tolerance=1e-6, max_iter=10000):
        """
        使用规范不变离散化求解
        """
        for i in range(max_iter):
            # 计算场论梯度
            dL_dphi = self._compute_Lagrangian_gradient()
            dL_dpi = self._compute_momentum_equation()
            
            # 使用保辛积分器更新
            self._symplectic_step(dL_dphi, dL_dpi, tolerance)
            
            # S1 r04 连接：更新频率权重
            self._update_frequencies()
            
            # 检查收敛（满足 Euler-Lagrange 条件）
            if self._check_convergence(tolerance):
                break
        
        return self.phi
    
    def _check_convergence(self, tol):
        """
        检查 Euler-Lagrange 方程：δL/δφ = 0
        """
        residual = self._compute_Euler_Lagrange_residual()
        return norm(residual) < tol
```
