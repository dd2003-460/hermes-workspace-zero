## r02 修正后的形式化定义

```
Definition (基于 arXiv:2404.09937):
智能系统 M 在环境 E 下的智能度定义为：

I(M) = I(M; G) / I(M; R)

其中：
- G = Goal state（目标状态，如最优策略）
- R = Random agent（随机基线）
- 比值越高，智能度越高

实证发现（arXiv:2404.09937）：
压缩比与智能表现呈线性正相关
α · compression_ratio + β ≈ I(M)

Necessary Condition:
I(M; G) ≥ I(G|E) - ε  （ε 表示环境不确定性）
```
