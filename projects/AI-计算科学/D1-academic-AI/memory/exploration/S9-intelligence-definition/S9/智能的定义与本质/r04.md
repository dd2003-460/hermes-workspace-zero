## r03 线性关系失效分析

### 回顾：r03 确认的线性关系

从 arXiv:2404.09937：
$$\text{Intelligence} = \alpha \cdot \text{Compression} + \beta$$

### r04 核心问题：**这条线性关系有边界吗？**

#### 假设 4.1（过压缩失配，Over-Compression Mismatch）

$$\text{IF} \quad H_{compressed} < H_{minimum\_structure} \quad \text{THEN} \quad I_{task\_retained} \downarrow \downarrow$$

**解释**：
- 当压缩比过高（压缩率 > $\eta_{crit}$），会丢失**结构不变量**而非**冗余信息**
- 这对应**统计学习中的表示瓶颈**：隐藏层容量不足时，无法编码所有任务相关特征
- **关键洞察**：存在一个**最优压缩窗口** $[\eta_{min}, \eta_{max}]$
  - $\eta < \eta_{min}$：欠压缩，冗余度高
  - $\eta_{min} < \eta < \eta_{max}$：智能最优（**线性区段**）
  - $\eta > \eta_{max}$：过压缩，结构破坏（**非线性失效区**）

## 临界行为分析：智能的"发散"

### 假设 4.2（智能量纲变化）

在临界压缩率 $\eta_c$ 附近，**信息保留速率发散**：

$$\frac{d I_{task}}{d \eta} \sim |\eta - \eta_c|^{-\nu}$$

其中 $\nu$ 是**临界指数**。

### 科学意义
- 当压缩率接近临界点时，**微小的压缩变化导致巨大的理解力变化**
- 这解释了**为什么某些压缩算法对科学推理有害**——即使整体压缩率不变，但它在临界点附近
- 类比到科学：某些学者只在**极高关注度下**才能理解新范式（"顿悟"），一旦注意力撤回，理解立即崩溃

## 操作性智能度量

### 定义：边际智能（Marginal Intelligence）

$$MI(\eta, \gamma) = \frac{\partial}{\partial \gamma} \text{TaskPerformance}(Compression(\eta), Bottleneck(\gamma))$$

- MI > 0：压缩增益（增加瓶颈容量提高了性能）
- MI = 0：瓶颈饱和（已达理解极限）
- MI < 0：瓶颈约束**太强**（压缩反而损伤智能表现）

### MI 相图（可检验预测）

| MI 区域 | 物理对应 | 科学社会学对应 |
|---------|----------|----------------|
| MI → ∞ | 临界涨落 | 范式转换前夕的高敏感度 |
| MI ≈ 0 | 平衡态 | 范式稳定，讨论循环不变 |
| MI < 0 | 冻结态 | 思维僵化，不接受新信息 |

## 从智能定义到 Agent 自主性

### 自主性的操作定义（r04 新贡献）

基于信息瓶颈：

$$A(\tau) = \lim_{T \to \infty} \frac{1}{T} \int_0^T \frac{d}{dt} \mathbb{E}_{x \sim \mathcal{D}}[I(x; M_t)] dt$$

**自主性 = Agent 随时间获取新压缩结构的速率**。

- $A(\tau) > 0$：Agent 在"学习"——即使在没有外部标注的情况下
- $A(\tau) = 0$：Agent 在"归纳"—只组合已知
- $A(\tau) < 0$：Agent 在"遗忘"—被新数据覆盖原有结构
