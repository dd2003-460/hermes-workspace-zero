## 从定义到测量：智能的操作性框架

- MI > 0：压缩增益
- MI = 0：瓶颈饱和
- MI < 0：过压缩损伤

## 实证框架 I：边际智能测量的三阶段方案

### 阶段 1：压缩率映射

**目标**：建立压缩率 $\eta$ 与模型规模 $n$ 的映射关系

**实验设置**：
```
模型规模序列：n = {10M, 50M, 100M, 350M, 700M, 1.5B, 3.5B, 7B}
压缩率估算：η(n) = log₂(n) / log₂(VOCAB_SIZE)
```

**测量协议**：
1. 在固定训练数据和任务上训练不同规模模型
2. 记录每个规模的**困惑度 PPL(n)** 和**任务准确率 Acc(n)**
3. 计算压缩率对性能的影响函数：$MI_\eta = \frac{d Acc}{d \eta}$

---

### 阶段 2：瓶颈容量映射

**目标**：测量瓶颈参数 $\gamma$ 与表现的关系

**实验设置**：
```
信息瓶颈实验：
- 固定模型：Transformer 6-layer, d_model=512
- 瓶颈容量变量：k = {8, 16, 32, 64, 128, 256}（中间表示维度）
- 瓶颈参数：γ(k) = I(Input; Representation) - I(Representation; Output)
```

**测量协议**：
1. 训练带有信息瓶颈约束的模型
2. 记录不同 γ 下的任务性能
3. 计算瓶颈对性能的影响函数：$MI_\gamma = \frac{d Acc}{d \gamma}$

---

### 阶段 3：边际智能的综合测量

**核心公式**：
$$MI(\eta, \gamma) \approx \frac{Acc(\eta+\Delta\eta, \gamma+\Delta\gamma) - Acc(\eta, \gamma)}{\Delta\eta \cdot \Delta\gamma}$$

**标准化协议**：
1. **基线设定**：$(\eta_0, \gamma_0)$ 作为参考点
2. **扰动测量**：计算四个角点的性能
3. **交叉验证**：确保 MI 测量的可重复性

## 实证框架 II：智能的临界行为测量

### 临界行为测量的理论基础

**基于定理 2（智能临界性定理）**：
$$\lim_{\eta \to \eta_c} \text{Adaptability}(\eta) = \text{PowerLaw}(\eta - \eta_c, \gamma)$$

**预测**：在临界压缩率 $\eta_c$ 附近存在**幂律关系**。

---

### 实验设计：临界点附近的幂律检验

**方法**：
1. 在**临界压缩率区域**密集采样
2. 拟合幂律关系：$\log(\text{Adaptability}) = \gamma \cdot \log(|\eta - \eta_c|) + C$
3. 检验幂律指数 $\gamma$ 的显著性

**临界点搜索算法**：

```python
def find_critical_compression(model_size_range):
    """
    搜索临界压缩率 η_c
    """
    best_fit = None
    for eta_candidate in np.linspace(0.1, 0.9, 100):
        adaptability = compute_adaptability(eta_candidate)
        
        # 拟合幂律
        fit = fit_power_law(adaptability, eta_candidate)
        r_squared = fit.r_squared
        
        if best_fit is None or r_squared > best_fit.r_squared:
            best_fit = fit
            eta_c = eta_candidate
    
    return eta_c, best_fit.gamma
```

## 实证框架 III：智能测量标准化协议

### S9 r05 核心贡献：智能测量标准（SIS）

**定义**：智能测量标准是一套**可重复、可比对**的智能评估方案。

---

### 协议组件 I：智能表征指数（Intelligence Representation Index, IRI）

$$IRI = \frac{MI}{MI_{max}} \times 100$$

其中 $MI_{max}$ 是在相同任务上观察到的最大边际智能。

**解释**：IRI = 100 表示边际智能达到观测最大值。

---

### 协议组件 II：智能稳健性指数（Intelligence Robustness Index, IRI）

$$RI = 1 - \frac{\sigma(MI_{perturbed})}{MI}$$

其中 $\sigma(MI_{perturbed})$ 是对输入扰动后的 MI 标准差。

**解释**：RI = 1 表示智能对扰动完全稳健。

---

### 协议组件 III：智能转移指数（Intelligence Transfer Index, ITI）

$$ITI = \frac{MI_{transfer}}{MI_{original}}$$

其中 $MI_{transfer}$ 是在迁移任务上的边际智能。

**解释**：ITI > 1 表示**智能溢出效应**——能力超过源任务需求。

**验证方法**：
