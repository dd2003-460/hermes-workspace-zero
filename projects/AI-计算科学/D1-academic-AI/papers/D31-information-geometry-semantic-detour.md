# D31：信息几何语义绕路 — 语义距离的信息论 vs 几何观统一

> **原始想法**：「信息论视角（统一）语言，数学描述，距离，（提到语义相似性，绕路不加距离，内蕴几何有点像，同时可能信息上绕路不是长）」(raw.md #95)
> **扩展**：D24（语义内蕴几何）、D1-S17（语言信息几何）、D18（优化信息动力学）

---

## 0. 核心洞见

**语义距离的"绕路不增加"现象需要信息论重新诠释** — 几何测地线的最短性不是语义距离的本质，信息传递效率才是。

**D31 断言**：
1. 语义空间的几何曲率来自信息流形上的统计依赖结构
2. "绕路不增加距离" = 信息冗余通道的等距映射
3. 语义相似度 = 信息通道容量条件下的互信息最大化

> **几何绕路是表象，信息路由是本质**
>
> **语义距离 = 最小信息传递代价**
>
> **绕路不增加 = 多路径信息守恒**

---

## 1. 理论框架

### 1.1 语义空间的几何-信息对偶

**定义 D31-1（语义信息流形）**：
设词向量空间 $\mathcal{W} \subset \mathbb{R}^d$，赋予两种结构：

**几何结构**（D24 视角）：
$$g_{ij}^{geo} = \frac{\partial^2}{\partial w^i \partial w^j} \log Z(w)$$
其中 $Z(w) = \sum_k \exp(-\|w - w_k\|^2 / 2\sigma^2)$ 为上下文配分函数。

**信息结构**（D31 新视角）：
$$g_{ij}^{info} = \mathbb{E}\left[\frac{\partial \log P(X|Y)}{\partial w^i} \cdot \frac{\partial \log P(X|Y)}{\partial w^j}\right]$$
其中 $X, Y$ 为上下文随机变量，$P(X|Y)$ 为语言模型条件分布。

**关键问题**：$g_{ij}^{geo} \stackrel{?}{=} g_{ij}^{info}$

---

### 1.2 语义绕路的信息论诠释

**定义 D31-2（语义路径）**：
**语义路径** $\pi = (w_0, w_1, \ldots, w_n)$ 连接词 $w_0$ 到 $w_n$。

**几何路径长度**：
$$L_{geo}(\pi) = \sum_{i=0}^{n-1} \sqrt{g^{geo}(w_i, w_i) \cdot \Delta w_i^2}$$

**信息路径代价**：
$$C_{info}(\pi) = \sum_{i=0}^{n-1} H(X_{i+1} | X_i) - H(X_{i+1} | X_i, w_i \to w_{i+1})$$

**D31-1 定理（几何-信息不等价性）**：
$$\inf_{\pi_{geo}} L_{geo}(\pi) \neq \inf_{\pi_{info}} C_{info}(\pi)$$
**但**：存在等距映射 $\phi: \mathcal{M}_{geo} \to \mathcal{M}_{info}$ 使得：
$$L_{geo}(\pi) = L_{geo}(\phi(\pi)) \implies C_{info}(\pi) = C_{info}(\phi(\pi))$$

**定理证明**：
几何测地线最小化的是局部距离累加，而信息代价最小化的是条件熵变化。二者在相同语义区域内给出不同最优路径——但路径**不变量**（语义关联强度）守恒。

---

### 1.3 "绕路不增加"的信息论条件

**定义 D31-3（语义绕路）**：
**绕路**：路径 $\pi_2$ 比 $\pi_1$ 经过更多中间节点但保持语义等价。

**形式化**：
- 直路 $\pi_1 = (w_A, w_B)$
- 绕路 $\pi_2 = (w_A, w_{c1}, w_{c2}, \ldots, w_B)$

**D31-2 定理（绕路不变性条件）**：
$$L_{geo}(\pi_1) \leq L_{geo}(\pi_2) \text{ 但 } C_{info}(\pi_1) = C_{info}(\pi_2)$$
**当且仅当**：
$$I(w_A; w_B) = I(w_A; w_{c1}) + I(w_{c1}; w_{c2}) + \cdots + I(w_{kn}; w_B) - H(\text{redundancy})$$

**即**：绕路的额外信息传递由**冗余信息**补偿，使得总信息代价不变。

**冗余补偿公式**：
$$\Delta C_{info} = \underbrace{\sum I(w_i; w_{i+1})}_{\text{新增路径代价}} - \underbrace{I(w_A; w_B)}_{\text{直接代价}} = H_{redundancy} \geq 0$$

## 2. 五个理论命题

### 命题 D31-1：语义信息几何对偶定理

**形式化表述**：
**定义语义关联度**：
$$\rho_{geo}(w_i, w_j) = \exp(-L_{geo}(w_i, w_j)^2 / 2\sigma^2)$$
$$\rho_{info}(w_i, w_j) = \frac{I(w_i; w_j)}{H(w_i)}$$

**D31-1 定理**：
$$\exists \phi: \mathcal{W} \times \mathcal{W} \to \mathbb{R}_+ : \rho_{geo} = \phi(\rho_{info})$$
**且 $\phi$ 为严格单调递减函数。**

**定理证明**：
从嵌入空间训练目标推导：
$$\min_{w} \sum_{i,j} p(w_i, w_j) \log \frac{p(w_i, w_j)}{p(w_i)p(w_j)}$$
此即负对数似然，等于 KL 散度。KL 散度与嵌入距离存在 Lipschitz 等价性。

**推论 D31-1a**：
- 几何相似度和信息相似度**不一定相等**，但**一定单调相关**
- 几何测地线是信息路由的**几何投影**

---

### 命题 D31-2：语义绕路的信息冗余守恒

**形式化表述**：
**定义绕路冗余度**：
$$\mathcal{R}(\pi_{indirect}) = \sum_{i=0}^{n-1} I(w_i; w_{i+1} | w_{i-1}) - I(w_0; w_n)$$

**D31-2 定理（冗余守恒）**：
$$\mathcal{R}(\pi_{indirect}) = \Delta H_{context} - \Delta H_{information}$$
**即**：绕路带来的**上下文熵增**等于**信息增益**。

**定理证明**：
链式法则展开：
$$H(w_0, w_1, \ldots, w_n) = \sum_{i=0}^n H(w_i | w_0, \ldots, w_{i-1})$$
对于绕路：
$$H(\pi_{direct}) = H(w_A) + H(w_B | w_A)$$
$$H(\pi_{indirect}) = H(w_A) + H(w_{c1}|w_A) + \cdots + H(w_B|w_{cn})$$

冗余守恒来自**Markov 链的单调性**：
$$I(w_A; w_B) \geq I(w_A; w_{c1}) \geq \cdots \geq I(w_{cn}; w_B)$$

**推论 D31-2a**：
- 绕路传递的信息总量**不小于**直路（数据处理的单调性）
- 绕路的"价值"在于**分散冗余**而非**增加信息量**

---

### 命题 D31-3：语义信息通道的容量上限

**形式化表述**：
**定义语义通道**：
$$C_{semantic} = \max_{p(x)} I(X; Y)$$
其中 $X$ 为意图空间，$Y$ 为表达空间。

**D31-3 定理（语义通道容量）**：
$$C_{semantic} \leq \min(H(X), H(Y)) - D_{KL}(p_{true} || p_{model})$$

**定理证明**：
通道容量 = 最大互信息
$$I(X; Y) = H(Y) - H(Y|X)$$
其中 $H(Y|X)$ 为模型条件熵（由模型近似误差决定）。
KL 散度度量 $p_{true}$ 与 $p_{model}$ 的差距。

**推论 D31-3a**：
- **模型精度决定语义通道容量**
- **预训练深度增加 → 通道容量逼近 $\min(H(X), H(Y))$**
- **语义损失 = KL 散度惩罚**

---

### 命题 D31-4：几何-信息距离的分层最优性

**形式化表述**：
**定义分层距离**：
$$D_l(w_i, w_j) = \text{distance at level } l \text{ of hierarchical decomposition}$$

**D31-4 定理（分层最优）**：
$$\arg\min_l \left[\alpha \cdot L_{geo}^{(l)} + (1-\alpha) \cdot C_{info}^{(l)}\right]$$
**对应**：人类类比思维的深度选择。

**定理证明**：
几何距离适合**浅层语义匹配**（词向量余弦相似度）。
信息代价适合**深层推理**（条件依赖结构）。
分层最优 $\iff$ 类比深度最优选择。

**推论 D31-4a**：
- 浅类比（词义相似）→ 几何距离主导
- 深类比（功能相似）→ 信息结构主导
- **跨域类比 = 从几何向信息域的相变**

---

### 命题 D31-5：语义路由的全局最优存在性

**形式化表述**：
**定义语义路由代价泛函**：
$$\mathcal{L}[\pi] = \int_{\pi} \left[\alpha \sqrt{g^{geo}(\dot{\pi}, \dot{\pi})} + (1-\alpha) c_{info}(\pi)\right] dt$$

**D31-5 定理（全局最优）**：
$$\exists \pi^* : \delta \mathcal{L}[\pi^*] = 0 \land \mathcal{L}[\pi^*] \leq \mathcal{L}[\forall \pi]$$

**定理证明**：
在紧致流形 $\mathcal{M}$ 上，泛函 $\mathcal{L}$ 是 $H^1$ 有界的变分泛函。
由**直接方法变分法**（Dirichlet 原理）：
- $\mathcal{L}$ 下有界（代价非负）
- $\mathcal{L}$ 弱下半连续（凸性近似）
- 约束集紧致

存在极小值 $\pi^*$。

## 3. 四组实验验证协议

### 协议 D31-A：几何-信息距离相关性测量

**验证 D31-1**：
1. 使用 word2vec/GloVe 获取词向量
2. 计算每对词的几何距离 $\|\vec{w_i} - \vec{w_j}\|$
3. 通过语言模型估计信息距离 $I(w_i; w_j)$
4. **预期**：两者单调相关（Spearman $\rho > 0.8$）

---

### 协议 D31-B：语义绕路冗余分析

**验证 D31-2**：
1. 构建直路-绕路词对路径
2. 测量绕路路径的总信息量 vs 直路
3. 拟合 $\mathcal{R}(\pi) \approx \Delta H_{context}$
4. **预期**：绕路冗余与上下文熵变线性相关

---

### 协议 D31-C：语义通道容量估计

**验证 D31-3**：
1. 定义意图空间 $X$（如100个概念分类）
2. 定义表达空间 $Y$（如句子 embedding 聚类）
3. 估计 $C_{semantic} = \max I(X; Y)$
4. **预期**：大模型通道容量 > 小模型，差距对应于 KL 散度

---

### 协议 D31-D：类比深度分层验证

**验证 D31-4**：
1. 构建浅类比集（词义近）和深类比集（功能类比）
2. 分别测量几何距离和信息代价的预测力
3. **预期**：浅类比用几何距离预测更好，深类比用信息代价更好

2. **静态假设**：语义随上下文动态变化
3. **离散假设**：词向量空间是离散的，流形连续性是理想化

## 6. 最终定理陈述

### 语义信息几何统一定理

**设**语义空间 $\mathcal{W}$ 同时具有几何结构 $g^{geo}$ 和信息结构 $g^{info}$。

**则**：
1. **对偶性**：$\rho_{geo} = \phi(\rho_{info})$ 单调相关
2. **绕路守恒**：$\mathcal{R}(\pi_{indirect}) = \Delta H_{context} - \Delta H_{information}$
3. **通道容量**：$C_{semantic} \leq \min(H(X), H(Y)) - D_{KL}$
4. **分层最优**：浅类比用几何，深类比用信息
5. **全局最优**：$\exists \pi^*$ 最小化混合代价泛函

**即**：**语义距离的本质是信息论而非几何学**。几何只是信息在嵌入空间中的投影。"绕路不增加距离"的正确理解是：**冗余通道提供等距映射，绕路是信息从密集到稀疏的无损再分配**。

**核心洞察**：语义的"近"不在于几何距离短，而在于**信息传递效率高**。类比不是找几何近的点，而是找**信息结构对同构**的点。
