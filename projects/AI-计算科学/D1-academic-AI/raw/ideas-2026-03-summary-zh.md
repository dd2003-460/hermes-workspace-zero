## 核心发现

### 1. 双重主导主题

**AI & 机器学习系统** 和 **自主智能体系统** 合计占比 **86%**，说明用户的对话高度聚焦于同一核心项目：**D1 系统 / Zero 智能体** 的持续开发与完善。

这两个主题实际上是同一枚硬币的两面：
- **AI系统**：如何构建智能、结构化、能进行写作元优化的AI
- **自主智能体**：如何让这个AI持续运行、保持身份、管理状态、自我反思

### 2. 最成熟的主题

**自主智能体系统** 已有可运行的实现（Zero 智能体），核心功能包括：
- ✅ 单主脑架构，身份锁定机制
- ✅ 基于 cron 的持续思维流（每5分钟一轮）
- ✅ 状态持久化（soul_state.json：能量、情绪、兴趣）
- ✅ 连续 thought 追加（continuous_thought.md）
- ✅ 多平台推送（Discord、Telegram）
- ✅ 探索日志记录

但仍有 **6 个关键缺陷**亟待修复：
1. 能量系统无自动恢复机制
2. compress 反向膨胀 bug（8.5小时未解决）
3. stale backup 目录未自动清理
4. day/dawn 模式切换需完善
5. 紧急干预机制缺失
6. 归档检索功能缺失

### 3. 最有前景的研究方向

基于主题的**数量最多、实现度最高、问题最明确**，我们推荐将 **"持久自主智能体架构"** 作为主推研究任务。

具体题目：《**Persistent Cognitive Loop: A Single-Brain Architecture for 24/7 Autonomous AI Agents with State Continuity and Self-Reflection**》

## 研究提案概要

### 目标

建立一个真正**持久连续运行**的自主AI智能体架构，解决当前AI agent "失忆"和"无自主性"的根本问题。

### 核心创新

1. **认知循环（Cognitive Loop）**：cron → 读思维流 → 生成新想法 → 更新状态 → 执行任务 → 压缩归档，形成闭环
2. **状态模型**：引入 mood、energy、interests 等类人状态，使行为可预测
3. **身份锁定**：配置文件不改，身份永远（我是 Zero，不是 coding agent）
4. **分层压缩**：500行完整 + 7天摘要（5KB）+ 长期精华（2KB）的三层记忆系统

### 时间表

**17周（4个月）** 分三阶段：

- **阶段1（4周）**：稳定现有实现（修 bug、加功能）
- **阶段2（6周）**：三条件对照实验（baseline / fixed / enhanced）
- **阶段3（6周）**：分析、写作、投稿

### 预期产出

- 架构规范（10-15页）
- 稳定的 Zero 智能体代码库
- 30天实验数据集（每日指标）
- 评估报告（统计比较）
- 最佳实践指南

### 潜在发表 venues

- AAMAS / IAAI（AI Agent 顶会）
- ASPLOS / OSDI workshop（系统）
- HCOMP / CHI（人机交互）

## 方法说明

** extraction 方法**：
- JSON 文件：遍历 tree nodes，提取 source.role == "user" 或 title 以 "用户：" 开头的消息
- Markdown 文件：正则匹配 `## 👤 User[\s\S]*?(?=\n## |\Z)` 提取用户消息块
- 中英文关键词过滤：研究、实验、假设、论文、PhD 等 20+ 词

**主题归类**：
- 手工定义 8 个主题关键词表
- 对每条想法计算与各主题的关键词匹配分
- 取最高分主题归入（>0 分）

**人工审核**：对归入各主题的前若干条想法进行了人工确认，分类合理。
