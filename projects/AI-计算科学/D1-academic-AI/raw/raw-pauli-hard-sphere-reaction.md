# Idea: 泡利不相容原理 = 硬球势类比

> # origin: human
> 核心直觉：泡利不相容不是量子力学的基本假设，而是全同粒子系统在短距离下的"硬球排斥"表现。

## 直觉锚点

1. **硬球模型** — 在统计物理中，硬球势 $V(r) = \infty$（当 $r < d$），$V(r) = 0$（当 $r \geq d$）用于描述排斥核心。费米子之间的"禁止态"类似于硬球之间的"禁止重叠"——两者都产生短距离排斥。

2. **与 D1-anyon-hawking 的 2D 统计关联** — 在 2D 中，粒子统计可以是任意的（任意子）。费米-玻色连续统通过拓扑规范场耦合实现。硬球势在 2D 中的散射性质与统计相位有关。这暗示：**统计性质可能由短距离的排斥相互作用决定，而非基本假设。**

3. **有效场论视角** — 在低能有效理论中，费米子的反对称波函数等价于一种排斥接触势：
   $$V_{\text{Pauli}} = \frac{2\pi\hbar^2 a}{m}\delta(\vec{r})$$
   其中 $a$ 是散射长度。$a>0$ 对应排斥，$a<0$ 对应吸引。费米子系统的 $a$ 由统计决定。

## 猜想陈述

**猜想 P1（泡利-硬球等价）**：
对于无相互作用的费米子系统，在低能散射极限下，其物理等价于一个包含接触排斥势的玻色子系统。具体来说，考虑 $N$ 个全同粒子在体积 $V$ 中，能量为：

$$E_{\text{Fermi}} = \sum_{k=1}^N \frac{\hbar^2 k^2}{2m}$$

等价于 $N$ 个玻色子，加上硬球势 $V(r) = \infty$（当 $r < d_{\text{eff}}$），其中有效直径：
$$d_{\text{eff}} \sim \lambda_T = \frac{\hbar}{\sqrt{2\pi mk_B T}}$$

**猜想 P2（统计-势对偶）**：
在 2D 中，任意子的统计参数 $\alpha$（$\alpha=0$ 玻色子，$\alpha=1$ 费米子）与短距离排斥势的强度 $g$ 存在对偶关系：
$$g(\alpha) = g_0 \cdot \alpha + \mathcal{O}(\alpha^2)$$
即：统计相位线性映射到排斥势强度。
