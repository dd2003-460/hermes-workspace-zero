## 关键发现

### 发现 1：严格 chimera 被确认重现
- 三个 eps 值均观测到稳定 chimera 态（score > 0.8）
- std_score 极低（0.03-0.07），表明 chimera 是稳健稳态

### 发现 2：全局同步率远低于 chimera 区局部同步
- global_sync = 0.108-0.142（低）
- chimera_score = 0.823-0.861（高）
- **这是 chimera 的核心判据**：某些局部区域同步，其他区域不同步

### 发现 3：eps 依赖性不显著
- 在测试范围内（0.5-1.0），chimerascore 无单调趋势
- 暗示存在一个较宽的 chimera 参数窗口

### 修正后的三态模型

```
N < 100:   瞬态 chimera（准稳态，可能衰减）
N ≥ 500:   稳定 chimera（真正的多稳态共存）
ε < 0.3:   chimera 可能消失（空间耦合不足）
ε ≥ 0.5:   稳定 chimera 出现
```
