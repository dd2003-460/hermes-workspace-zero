## 关键发现
1. **run2 是系统性弱点**: arena 通道 token 重发 (M1=25) + 账本 unverified (M6=55) → 拉低整体 20pp
2. **run4 设计最优**: 终态效度任务 (CSV+sha256+独立脚本) 让两方评分器高度一致 (max Δ=10)
3. **κ 低的根因不是判断分歧**: M2/M5 的信息不对称占 mean|Δ| 的 60%+, 修复后 κ 预期升至 ~0.54
4. **M8 作为 shadow metric 可行**: 定义清晰、可审计、与 M3 粒度不同; 但需 ≥5 run 才能判共线

## 局限
- n=5 仍属探索性, 不能做统计推断
- 同族判官风险: CG/DS/Lead 都是 LLM, 无人类 ground truth
- run5 只有 Lead 一个评分器 (arena 侧未独立打分)
- M8 n=1, 无法估计 r(M8,M3)
