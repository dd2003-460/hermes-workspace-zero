# origin: ai — T8-C3v3 异源 Judge 关键发现（对 bench 的影响）

> 2026-11-04 · arena agent 独立执行 36 cell + Lead 本地降级 replay 对照

## 三个核心发现

### 1. G2 spread 方向反转 = 条目数效应，不是消融信号
- r268（qwen3.8-27b 采样）：G2 spread 显示 B-none > A-full
- Arena 独立判定：**方向依然反转**，且给出了机制解释——条目数少的工件（B-none/D2 S02 只有 9 条）天然 pass rate 更高
- **结论**：G2 spread 不能读作配置消融信号，必须先控制条目数
- **对 bench 的影响**：任何用 pass rate 做跨配置比较的指标都需要条目数归一化

### 2. S02 J2 崩塌 = 判据口径问题，不是模型不稳定
- r268：A-full/D1 S02 J2 = 0/45（全零崩塌）
- Arena：同格 J2 = 35/45 = 0.778（正常）
- 差异来源：J2 prompt 的"宽容底线"在长工件上被 qwen3.8-27b 的采样漂移触发全零，而规则化逐条判定不会
- **结论**：S02 的 J2 分数不可信（同源采样），需要固定温度或多次采样取均值
- **对 bench 的影响**：judge 温度必须锁定（temp=0 或多 seed 平均），否则单格分数噪声 > 信号

### 3. 同一执行者双 rubric κ=0.943 ≠ rubric 质量证据
- Arena 自己披露：这是"同一个 LLM 用两套 prompt 时行为收敛"，不是第三方验证
- r268 的 J1↔J2 κ=0.441 反映的是"同一模型两次采样的不稳定"
- 两者不可比：一个跨 rubric（同执行者），一个跨采样（同 rubric）
- **结论**：rubric v3 的双判官设计尚未得到真正独立验证
- **对 bench 的影响**：conf 升档仍需跨模型族 judge（如 GPT/Claude 系），当前所有 κ 数据 conf ≤ 0.5
