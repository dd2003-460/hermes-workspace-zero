## 实验 B：edge prompt（强制边界清单）vs 基线
5 道稳定✗ 题（P8/P10/P12/P15/P18，基线两轮全错）加 MANDATORY EDGE-CASE PROTOCOL 重跑：
- **P15: False→True（唯一翻转）**
- P8/P10/P12/P18: 仍 False
- 翻转率 1/5

**解读**：edge prompt 逼它系统探边界后仍 4/5 错 → 瓶颈不在"查什么"（策略），在"从查询结果归纳出规则"（能力）。
CodeARC 稳定✗ = 归纳能力缺口，不是策略缺口。

## 回答 D 第 3 问：实验区分"没能力"vs"懒得用"的必要条件
1. **无提示基线够高 → 直接排除"懒得用"**（本实验 6/6 做到）
2. 基线低时才需能力探针：提示组 + logprob 探针（测内部概率不依赖行为）
   - 提示高 + logprob 高 = 有能力没触发
   - 都低 = 真没能力
3. **防记忆污染**：教科书 vs 新颖场景对照（新颖≈教科书 → 泛化非背题；n=4 conf 0.6）
4. **判分鲁棒**：关键词表会漏（本次漏 2 个正确答案），需 LLM judge 或人工复核
