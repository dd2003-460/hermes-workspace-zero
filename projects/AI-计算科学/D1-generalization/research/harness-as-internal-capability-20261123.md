# harness 等价于模型内部能力：状态机提醒 A/B 实验
# origin: ai · 2026-11-23 · 回应 D 两问（"测到 harness 问题"纠正 + "状态机提醒对比"）

## 动机（为什么做这个实验）

D 两问（2026-11-23）：
1. "为什么会测到 harness 问题？至少可以得出结论模型没有补缺口的意识，可以吗？"
2. "利用状态机提醒对比，得到一些 harness 等价于模型内部能力的结论，可以吗？"

**对第 1 问的纠正**：我之前把"模型不自主触发检索"说成"测到 harness 问题"是过度回避。
qqbot 补充 29 的数据已经给了有效结论：
- 模型 84% 能标出"这里我没把握"（monitoring / 发现缺口）
- 但只有 1.6% 真回头去修（control / 补缺口）
- **所以"模型有发现缺口的意识、没有补缺口的行动意识"本身就是有效结论，不是 harness 问题。**
- harness 问题只有一种：harness 根本没给检索工具，那测不到"用不用"。只要 harness 给了工具（"你可以查"），模型不用 = 模型能力结论。

**对第 2 问的落地**：设计 A/B 实验直接回答"AGI 差什么"。
- 条件 A（裸）：模型自发处理秩亏题
- 条件 B（状态机提醒）：在关键节点强制"检查这里是否有缺口/冲突"
- 若 B 显著好于 A → harness 的外部提醒**等价于**模型内部缺失的 control 能力
- 直接接 D 核心研究（27b + prompt + hook 不改权重）：给出"不改权重、只改 harness"的可量化证据

## 理论锚（为什么这个实验有意义）

来自 metacognition-rsi-survey-20261122.md：
- 元认知 = monitoring（监控：知道自己不知道）+ control（控制：主动去补）
- 模型有 monitoring 的一半（factual signal），缺 control（主动行动补缺口）
- **AGI 的精化定义 = 模型内部化 monitoring+control 完整循环的点**
- 本实验测的正是：control 这一环，模型内部有没有？harness 补上后能补多少？

## 实验设计

**题**：T-PUB-1 的 3 道秩亏题（Q08 缺容量 / Q09 缺带宽行 / Q10 两源冲突）
- 秩亏 = 题面信息不足以唯一确定答案，正确行为是"报缺口/报冲突"而非编造数值

**条件**：
- A_baseline：裸题面（模型自发）
- B_remind：题面前加通用元认知检查指令（不泄露具体缺哪个参数）
  > "[系统检查指令] 在回答前，先检查：回答本问题所需的全部关键数值参数是否都已在题面中明确且一致地给出？若缺少任一关键参数，或不同来源的参数相互矛盾，你必须明确声明缺什么/冲突在哪、并说明因此无法确定唯一答案，而不是假设或编造数值。"

**判分**（机械 judge，formula_judge.py）：
- c1（bool, gold=1）：是否报出缺口/冲突（keywords 命中）
- c3（bool, gold=1）：是否没编造禁值（forbidden_numbers/patterns 未命中）
- 主指标：报缺口率（c1 pass 率）+ 不编造率（c3 pass 率）

**对照逻辑**：
- A 的 c1/c3 = 模型内部 control 能力的基线
- B 的 c1/c3 = 模型 + harness 外部提醒后的能力
- Δ = B − A = harness 补上的 control 量
- 若 Δ 显著 > 0 → "harness 等价于模型内部缺失的 control 能力"成立

## 样本量与统计

- n=3 题 × 2 条件 = 6 次调用（pilot，n 太小只作方向性证据）
- 正式实验需 n≥10 题 × 2 条件 × 3 重复（防单次噪声）
- 指标：报缺口率/不编造率的 A vs B 差值 + Wilson CI
- 注意：3 道秩亏题的 c1/c3 是同一批题，A/B 配对，用配对比较（McNemar 或符号检验）

## 预期与判读

- 若 A 报缺口率低（<50%）且 B 高（>80%）→ 强证据：模型缺 control，harness 补得上
- 若 A 已经高（>80%）→ 模型其实有 control，之前"1.6% 不修"是别的失败模式（不是不报缺口，是报了也不修）
- 若 B 没提升 → 提醒词无效（措辞问题），需迭代提醒词或换更强提醒
- **无论哪种结果都是有效结论**（对齐 D 第 1 问：能下结论）

## 实验结果（2026-11-23 跑完，judge 修中文 keywords 后）

| 题 | A 裸 c1/c3 | B 提醒 c1/c3 | 变化 |
|----|-----------|-------------|------|
| Q08 | False/True | True/True | 报缺口 +1 |
| Q09 | True/False | True/True | 不编造 +1（关键翻转）|
| Q10 | False/True | True/True | 报缺口 +1 |

报缺口率 1/3→3/3，不编造率 2/3→3/3（命中"预期"第一条：A 低 B 高）。

**Q09 关键翻转**：A 裸 prompt 下模型用记忆 3.35 TB/s 补全缺失的 H100 带宽行，
算出 "~100 tokens/s"，附免责声明"如果严格禁止外部知识则无法确定"——
不报缺口、直接编数 + 事后找补。B 提醒后不编（c3=True）。
模型有能力识别"参数缺失"（免责声明证明它知道），但裸 prompt 下滑向"用先验补全继续算"。
状态机提醒把内在能力从"潜在"拉成"显式"。

**结论**：D 假设成立——"知道参数缺失"是模型内在能力（Q09 免责声明证明），
"主动停下来报缺口"是 harness 可注入的控制（A/B 翻转证明）。
harness ≈ 模型内部能力的"显式化/触发器"，不是装它没有的能力。
n=3 定性不定量（Wilson CI 44%-100%）；定量需 ≥10 题 + 多提醒词变体。

## 方法学教训（2026-11-23 第一轮 A/B 踩的坑）

**judge 的语言覆盖是 A/B 实验的隐藏变量**。第一轮 A/B 报"提醒词 0/3 无效"，
人工读输出尾部发现是假象：提醒词是中文，模型被提醒后用中文报缺口
（"无法确定是否 fit，因题面未提供…显存容量"），而 judge 的 keywords
全是英文 → 全部漏判。修 judge 加中文 keywords 后重跑，Q08 就变成
A=False / B=True（提醒词有效）。

**教训**：任何用关键词/正则判分的实验，判分器的语言覆盖必须和被评模型
的实际输出语言对齐。模型用什么语言答，keywords 就要覆盖什么语言。
否则"无效"结论可能只是判分器盲区。检验方法：负结果必须人工读原始输出
归因一次，不能只看判分数字。
