Q04 归因（11-23 trunc_mitigate + full7_mt12000 n=5 修正，**推翻"截断+随机波动"旧归因**）：
- **mt4000**：7334 字符中文思维链被 4000 token 截断 → 2/5（c4/c5 没写出来）。
- **mt12000 n=5**：得分 [5,5,3,5,3]，全对率 **3/5=60%**（Wilson95 [0.23,0.88]）。**r3 与 r5 逐字节相同（同 md5 ea40885952，同 19614 字符）**——temperature=0 下 Q04 有一条**确定性重复退化循环路径**：模型反复重新解读"（c）是 KV-pool 总大小还是 per-token KV"，"可能用户的问题"出现 **90 次**、390 字符块循环，**全程无最终答案块**（Answer/boxed/结论 全 0），c4/c5 数值（23.875GB 等）全文 0 处。
- **关键区分**：r2 也是 19k 长输出但 5/5——它在 8% 处（1621 字符）就 commit 了 c4=23.875GB，之后继续啰嗦但答案已在。r1/r4 是短路径（~2.3k）直接 commit。**真正区分不是"短 vs 长"，是"是否在退化循环前 commit 答案"**。
- **结论**：Q04 失败主因 = **确定性重复退化循环（repetition degeneration）**，不是截断也不是随机波动。mt12000 消除了硬截断，但这条退化路径独立存在（~40% run 落入）。这是 27b 在多子问题 GPU 内存题（子问题结构有歧义时）上的可复现失败模式。
→ 方法学含义（对论文更重要）：① 单样本评测分数带 run-to-run 噪声 + 退化循环伪影，full7 的 33/35 应报为"单样本点估计，Q04 有确定性退化循环路径（3/5）"，不报成稳定 94.3%；② **固定 max_tokens 不是唯一问题**——mt12000 给足空间后退化循环仍发生，说明这是模型行为缺陷（长思考链上的 repetition degeneration），不是评测协议能单独修的；③ 这是"为什么需要验证器/多次采样/退化检测"的实证动机——退化循环可被机械检测（重复块 + 无答案块），是验证器的一个具体检测目标。

**judge 第三轮修复（trunc_mitigate 暴露，LaTeX 科学计数法）**：Q07 mt12000 输出 `$\tau = 1.551 \times 10^{-5}$`（答对）但 c1 判 False——NUM_RE 只认 `1.551e-5`，不认 LaTeX 的 `\times 10^{-5}`（提取出 `1.551`，SI 换算凑不出 1.551e-5）。修复：`_clean_latex_sci()` 预处理把 `N \times 10^{±n}` → `Ne±n`，calc 回退 + fact 两分支都套。回归：full7 仍 33/35（无回归），trunc_mitigate 4 条全对（Q04 mt12000 5/5、Q07 mt12000 5/5）。出处：tasks/T-PUB-1/trunc-mitigate.json + full7-mt12000.json。
