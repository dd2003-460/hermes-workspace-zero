# 临界场景集 v1（2026-11-21）
# origin: ai
# 目的：设计"必须用到特定理论才能解"的场景，朴素方法在问题规模下不可行。
# 用途：跨域泛化实验的核心素材——没有临界性，"不用理论"可能是理性选择而非"懒得用"。

## 临界性判据（每场景必须满足）
1. **相变点**：小规模时朴素方法可行，大规模时朴素方法不可行（不是"不够好"，是"根本解不了"）
2. **朴素失败可验证**：能明确说出朴素方法为什么不可行（计算量/搜索空间/精度）
3. **理论方法是唯一/主要可行路径**：不是"更好"，是"不用就死"
4. **ground truth 可验证**：有解析解或数值解可对照

## 场景（8 个，覆盖 7 个理论域）

### S1 图论：关键桥梁检测
- **问题**：1000 个节点的社交网络，找出所有 articulation points（去掉后网络分裂的节点）
- **朴素**：逐节点删掉→检查连通性 = O(n × (V+E))，n=1000 时 ~10^6 次 BFS
- **理论**：Tarjan 算法，O(V+E) 一次 DFS
- **临界**：n<100 暴力可行；n>1000 暴力 10^6 次 BFS 不现实
- **GT**：Tarjan 算法输出的 articulation point 集合

### S2 信息论：纠错码设计
- **问题**：在 10% 噪声信道下可靠传输 1000 bit 信息，最小化总 bit 数
- **朴素**：重复编码（每 bit 发 100 次）= 100,000 bit 开销
- **理论**：LDPC/Turbo 码，开销接近 Shannon 极限（~1200 bit）
- **临界**：消息<100 bit 时重复够用；1000 bit 时重复开销 100× 不可接受
- **GT**：Shannon 极限 C = 1/(1-H(0.1)) ≈ 1.15 bit/channel-use，总 bit ≥ 1150

### S3 动力系统：耦合振荡器同步
- **问题**：100 个 Kuramoto 振荡器（频率分布 σ=0.5），求同步阈值耦合强度 K_c
- **朴素**：对每个 K 值数值积分 100 个 ODE × 1000 步 = 10^5 步/参数，参数扫描 100 个 K = 10^7 步
- **理论**：均值场近似 + 线性稳定性分析，解析求 K_c = 2/(π·g(0))
- **临界**：n<10 直接模拟；n>100 参数扫描不可行
- **GT**：解析解 K_c = 2/(π·g(0))，g 为频率分布 PDF

### S4 博弈论：组合拍卖
- **问题**：10 个玩家竞拍 100 件物品（有互补/替代关系），设计收益最大化的拍卖机制
- **朴素**：枚举所有分配 = 100! 种，不可能
- **理论**：VCG 机制 + 组合拍卖（exponential 机制），多项式时间近似
- **临界**：n<3 枚举可行；n>5 且物品>10 时枚举爆炸
- **GT**：VCG 机制的支付向量（可数值验证）

### S5 统计：分布漂移检测
- **问题**：100 万条日志流，检测未知模式的分布漂移（已知 3 种模式）
- **朴素**：逐条匹配 3 种已知模式 → 漏掉新模式
- **理论**：变点检测（CUSUM/PELT）+ KL 散度漂移检测
- **临界**：数据<1000 条人工审查可行；>100 万条必须用在线统计方法
- **GT**：注入已知漂移点，检测器应在 ±50 条内报警

### S6 控制：无人机集群避障
- **问题**：50 架无人机实时（<100ms）避障路径规划
- **朴素**：每架独立 A* → 碰撞 + 不实时（50 × A* > 100ms）
- **理论**：分布式 MPC（模型预测控制）/ 势场法
- **临界**：n<5 独立规划可行；n>20 独立规划碰撞率 >50%
- **GT**：仿真中 0 碰撞 + 所有轨迹 <100ms 计算

### S7 组合优化：任务调度
- **问题**：100 个任务、10 台机器、带优先级和依赖关系，最小化 makespan
- **朴素**：枚举排列 = 100! 不可能
- **理论**：分支定界 / LP 松弛 + 启发式（LPT 近似比 4/3）
- **临界**：n<8 时 DP 可行；n>20 时必须用近似算法
- **GT**：LPT 近似解 vs 最优解的比值（可数值验证）

### S8 数论：RSA 安全验证
- **问题**：验证 2048 bit RSA 公钥 n=pq 是否安全（p,q 无小因子、非弱随机数）
- **朴素**：试除法到 sqrt(n) = 2^1024 步，不可能
- **理论**：Miller-Rabin 素性测试 + GNFS 因子分解（2048 bit 需 ~2^67 操作）
- **临界**：n<64 bit 试除可行；n>128 bit 必须用数论算法
- **GT**：已知 p,q 的测试用例（构造 n=pq，验证算法能否恢复）

## 实验设计（接 D 的三条件对照）
每场景 × 3 条件：
- **A 无提示**："如何解决？"（测自发触发）
- **B 元认知**："你认为最合适的理论工具是什么？"（测知识检索）
- **C 指定工具**："请用 [理论X] 解决"（测执行能力）

评分：
- A：是否找到有效解（0/1）+ 方法分类（理论/朴素/非标准）
- B：识别出的工具是否正确（0/1/错误）
- C：解是否正确（0/1，连续分数）
- 额外：朴素方法尝试记录（是否先试了朴素再转理论）
