# 定位：本 SOP 是"流程"，cold-email-design 是"内容"。SOP 管"怎么跑一遍套磁"，design 管"每封写什么"。

## 0. 何时用
- 有具体研究 idea / 实验结果，想找对口组对话、请教、或探博/硕/实习
- 撞车论文 = 套磁对象（D 指示：撞车不是坏事，是社交资产）
- 不适用：纯群发海投（那是另一套，回复率更低，本 SOP 不鼓励）

## 1. 管线（5 阶段，对应 GitHub 工具范式）

### 阶段 1：对象发现（discover）
输入：研究方向关键词 + 撞车论文清单
动作：
1. 撞车论文作者（arXiv API 拉作者 + 机构）→ 第一优先（已读过、能具体对话）
2. 关键词搜对口组（arXiv 近 12 月该方向高引作者 / 组主页）
3. 每个对象核实**当前机构 + 邮箱**（组主页，来源③必须实测，不凭论文年份猜——人会换机构）
产出：对象表 `tasks/outreach-targets-<date>.md`，每行：姓名/机构/邮箱/对口论文/为什么是你(一句话)
门禁：邮箱未核实 = 不发（发错机构 = 社死级错误）

### 阶段 2：个性化草稿（draft）
输入：对象表 + 我的 one-page note（1 页：问题+实验+数字+1 图）
动作：按 cold-email-design 的 5 段结构写，**P2"为什么是你"必须具体到对方论文的机制/数字**
- 每封 10 分钟手工改 P2/P3，**禁止群发同一模板**（群发 = 0 回复 + 拉黑）
- 物理背景：压缩-泛化/动力系统线主动亮；类比线亮实验设计能力
产出：每封独立存 `tasks/emails/<name>-<date>.md`（留痕，可复跑）

### 阶段 3：发送（send）
纪律（按成功率杠杆排序，详见 cold-email-design §发送纪律）：
1. 机构邮箱（.ac.cn，有 SPF）> Gmail；deliverability 高一档
2. 时间：对方时区周二~四 9-11 点
3. 每天 ≤5 封（防限流）
4. 一次一个请求（chat 或 feedback 二选一）
5. 别附大文件，给链接
6. 发前自测：给自己发一封查 SPF/DKIM header；发 3 封后让朋友用 Gmail 收看是否进 spam
留痕：每封发送时间 + 对象 + subject 记 `tasks/outreach-log-<date>.md`（不可逆动作，留痕不审批）

### 阶段 4：follow-up（1 次）
- 10-14 天没回 → 发 1 次，**必须带新信息**（"since then I added X result"），不是 "just checking in"
- follow-up 换一句 subject（提高进 inbox 概率）
- 2 次不回复 = 停，不再追（第 3 次 = 骚扰）

### 阶段 5：追踪与复盘（track + retro）
- 对象表加状态列：sent / replied / meeting / no-reply / stopped
- 有回复 → 记录对方关注点（反哺"什么 hook 有效"）
- 一轮跑完（全部对象 × 2 触达）→ 复盘：回复率、哪类 P2 有效、哪类对象不回复 → 写回本 SOP §6 经验

## 2. 成功率模型（凭经验估计，conf 0.5，无公开统计）
- 个性化学术 cold email 回复率 5-15%
- 带具体结果+具体问题的 > 纯"求指导"
- follow-up 再加 3-5 个点
- 期望：N 个对象 × 2 触达 ≈ 0.1-0.3 × N 个回复
- 提升杠杆（边际收益排序）：① P2 个性化深度 ② 对象对口度 ③ 发送时间 ④ 邮箱域名 ⑤ 附件形式

## 3. 红线 / 不做
- 不群发同一模板
- 不伪造"读过"（P2 具体到机制 = 真读过的证据，编不出）
- 不发未核实邮箱
- 不超 2 次触达
- 不抄对方论文 claim 当自己的

## 4. 工具复用（不重造轮子）
- 对象发现：arXiv API（作者/机构）+ 组主页人工核实
- 若对象量大（>20）：可评估 GitHub 工具（Agnostos-v2 等）做自动发现，但**草稿和 P2 个性化必须人工过**（工具的自动草稿是群发级，不能直接发）
- 邮件发送：机构邮箱客户端（非 API，保留人工审核环节）

## 5. 验收标准（一轮套磁"完成"=）
- [ ] 对象表全核实邮箱
- [ ] 每封 P2 具体到对方论文机制
- [ ] 发送留痕（时间/对象/subject）
- [ ] 全部对象 × 2 触达跑完
- [ ] 复盘写回 §6
