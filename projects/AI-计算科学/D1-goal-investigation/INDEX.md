# D1 Goal Investigation — Agent 目标发现与探索

## 项目目标

研究 AI Agent 的 goal/task 执行机制，理解 Claude Code、Codex、Hermes 三者的异同，
分析"非完成即停止"的根因，并探索如何用 prompt 稳定激发 AI 的提问风格。

## 背景

用户在551条对话消息中，86%围绕goal/ralph loop。goal机制是项目的核心关注点。
