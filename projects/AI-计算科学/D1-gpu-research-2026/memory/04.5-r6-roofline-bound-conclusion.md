## 持久结论（durable, 一手推算✓ + 社区R标注）
1. **显存门（一手推算✓, 脚本验证）**: 27B 占用 = weights + KV(8K sliding) + 2GB。
   INT4=15.81GB / INT8=29.61GB / BF16=57.22GB。 -> BF16 排除 4090/5090(32G)/A100-40(40G);
   INT8 排除 4090(24G); INT4 全部可行。
2. **roofline 边界（一手推算✓, 脚本验证, load-bearing）**: single-stream decode 是
   memory-bandwidth-bound, roofline tok/s = bw / weights_bytes。
   5090 INT4=133 / INT8=66; 4090 INT4=75; L40S INT4=64; A100-40 INT4=115 / INT8=58。
   -> 任何"single-stream"社区数 ABOVE roofline 是 batched/aggregate 或 spec-decode, 不是 clean batch=1。
3. **H* 是 regime-dependent, 不是单一卡（核心持久结论）**:
   - batched / 高并发 (G4 high): H* = RTX 5090（真实 batched 吞吐, 1.8x bw + 32G headroom）。
   - true single-stream (batch=1) + 廉价 A100-40 refurb (~$1200): H* = A100-40 refurb
    （roofline 时 A100-40@1200 R@low 0.0960 BEATS 5090@1999 0.0664）。
   - 社区 11x 5090-vs-4090 性价比 margin = apples-to-oranges 伪（batched 5090 vs non-opt A100-40）;
     true like-for-like margin ~1.8x bw。
