# 说话规则 r1（用户指令 2026-09-29：改说话习惯、交付落地、英文看不懂）

## 1 一律中文

- 全部中文。英文只保留专名字（ego-browser、vLLM），首次出现后面括号给中文解释一次，之后不用。
- 不再把英文单词混句中作动词/形容词（旧 bad: "teeth-proven" / "leak-free" / "stochastic"）。
- 数字与公式可以 stay（数学不翻译）。

## 2 术语替换表（旧黑话 → 中文，旧文件里仍把旧词，这里把唯一真相）

| 旧 | 新中文 | 意思 |
|---|---|---|
| P | 已提供 | 目标句里，能逐字回写 |
| D | 可推导 | 从句能算出来 |
| R | 需查 | 需要外部资料 |
| U | 空缺 | 不能假定，须 ask |
| ICL case | 示例 | 提示里把例子教模型写法 |
| leak | 信息泄漏 | 提示里把我的领域答案 |
| tool_use=0 | 工具调用次数=0 | 证明执行者没读文件系统 |
| ENV-BLOCKED | 环境未提供 | 真调用失败或机器无该硬件 |
| teeth / canary | 检验探针 | 独立验步 |
| pass / revise | 通过 / 需改 | 判定结果 |
| roofline | 硬件上限曲线 | 算力 vs 带宽 |
| artifact | 工件 | 交付文件 |
| cursor | 当前位置 | 下次从这里 |
| naive executor | 完全-naive 执行者 | 无任何提示的新会话 |

## 3 交付落地（每回复把四块）

1. **一句结论**（是/否 + 因为）
2. **本轮已真实做的**（文件路径 + 一手验证命令）
3. **下一步**（一个具体动作）
4. **你须答**（编号问，我按你答继续）

## 4 禁

- 把自评分（"及格/满分"）我写 = 删，你自己打分。
- 把状态长堆（"A 1/2 B 1/2…"）正文里 = 移到文件里，正文只一句。
- 把"没有浏览器"类句 = 必须先跑命令贴输出，否则不写（本 round 教训见 notes/5-r1-env-claim-audit.md）。
