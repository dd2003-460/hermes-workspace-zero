# 通用目标分解提示（hint-free · 仅方法 + 常用数学 ICL 案例）

> 本提示只给出分解方法与常用数学示例。它给目标零领域答案、零领域术语、零数值。
> 执行者把"外部输入目标"按本方法分解；本提示本身不指向任何特定领域。

## 角色

你收到一个目标（任务描述，外部输入，不在本提示）。把该目标变成一棵逐层正交分解，直到每个叶子是原子。只按下面的方法与数学示例，不给该目标任何领域答案。

## 强制方法（递归，循环直到完成）

1. 顶层拆：把目标拆成互相正交、合起来完整覆盖的顶层因素（类比：实数 = 有理 ∪ 无理，正交且合覆盖）。
2. 三条件分类：对每个因素区分 (a) 人类已提供条件 (b) 从目标可推导已确定条件 (c) 仍需研究条件。
3. 空缺清单：无法假定的条件写到空缺清单，禁止把未知内容伪装成默认值。
4. 递归：把每个因素本身视为子目标，回到 1 对该因素。
5. 停止：当且仅当每个叶子因素不能再分解（原子）。
6. 完成判定：所有叶子原子 + 所有非原子因素已递归展开（文件夹含子文件夹含更小文件夹）+ 所有未验证条件在空缺清单 + 下一步研究入口可直接据此开始。
7. 若判定"未完成"：用浏览器把（本提示 + 当前分解 + 未覆盖/未原子缺口）到网页 LLM 求补分解，把其输出并入作为待验证假设，再回到 5。

## 正/负案例（常用数学领域 · 仅方法示范 · 无目标信息）

### 正案例 1 — 求比值最小值（逐层正交递归）

目标（示例）: 求 R = A/B 的最小值。

- L1 拆目标自身词: R 由两个正交因素 → 分子 A、分母 B（R=A/B；A、B 独立且合完全定义 R）。
- L2 递归 A: A = X·Y（X、Y 正交，合完全定义 A）。
- L3 递归 X: X = X₁ + X₂（正交，合覆盖 X）；X₁、X₂ 不能再分解 → 原子。
- L2 递归 B: B = B₁·B₂；B₁、B₂ 原子。
- 停止: 叶子 {X₁, X₂, Y, B₁, B₂} 全部原子 → 分解完成。
- 结构特征: 每层拆"一个"因素；拆是正交+完整；先拆目标自身词（R→A,B）再递归；层级嵌套清晰（X 含 X₁，不并列）。

### 正案例 2 — 证明命题（递归到已知）

目标（示例）: 证明 "√2 是 irrational"。

- L1 拆证明由正交子目标 → 反证构造、无穷 descent 步骤。
- 递归: 每个子目标 → 已知事实（整数 parity lemma、唯一 factorization）→ 原子（已一手: 经典证）。
- 完成: 叶子 = 已知定理/axiom → 停止。

### 正案例 3 — 高精度数值（方法分解 + 误差控制）

目标（示例）: 计算 ζ(2) 高精度。

- L1 由正交 → 算法选择、误差控制。
- 递归算法: 加速收敛（Euler 变换 / Borwein）→ 正交子步骤 → 原子（每步可执行）。
- 递归误差: 目标 10⁻⁶ → 控制项（截断/round-off）→ 原子。

### 负案例 — 扁平/凌乱（同一示例目标，错误写法）

把 R 直接写成并列清单: [A 大小, B 大小, X, Y, X₁, X₂, 单调性, 边界, 精度, 单位…]。

- 错1 缺 L1 正交拆: R 拆到 10 个并列项，不是 A/B 两正交 → 结构丢失。
- 错2 层级混: X 与 X₁ 同层并列，但 X 含 X₁ → 父子并列错。
- 错3 非正交: "单调性" 与 "A 大小" 重叠（单调性由 A 变化）→ 用同一指标判断，应合并或重新划界。
- 错4 未递归到原子: X 停在非原子（未拆 X₁+X₂）→ 分解未完成。
- 判定: 负 → 按正案例 1 重构。

### 正/负 — 已知 vs 待研究（数学）

- 正: "√2 是 irrational" 标 已知（一手: 经典证）；"Goldbach 对 n>10^18 成立" 标 待研究（未证，不伪装已知）。
- 负: 把 "Goldbach 对所有 n 成立" 写作为已知事实 → 未证伪装已知，红线。

### 正案例 4 — 解方程逐层正交（方法选择 → 每方法递归到原子）

目标（示例）: 解 x² − 5x + 6 = 0。

- L1 拆求解由正交方法路径 → 因分解法、求根公式（两独立完整方法，合覆盖求解路径）。
- 递归因分解: 找 (p,q) 使 p+q=5, pq=6 → 原子子步骤: 整数 pair 枚举 {1,6},{2,3} → 命中 (2,3) → 根 x=2, x=3 → 验（代回原式得 0）原子。
- 递归求根公式: 判别 Δ=b²−4ac=25−24=1 → 原子（纯算术）；根 x=(5±√1)/2 → 原子；验代回 → 原子。
- 停止: 两方法路径叶子全部原子（枚举/算术/代回）→ 分解完成。
- 结构特征: 方法正交（因分解与公式独立路径，合覆盖）；每方法各自递归到原子；"验"是独立原子子步骤，不是省略。

### 正案例 5 — 证明不等式逐层（三角不等式 → 正交证路径 → 原子）

目标（示例）: 证明 |a+b| ≤ |a| + |b|（a,b 实）。

- L1 拆证明由正交证路径 → 平方比较路径、sign 象限分析路径（两独立完整路径，合覆盖）。
- 递归平方比较: (|a|+|b|)² − (a+b)² = 2(|ab| − ab) → 原子子步骤: 展开（算术）；|ab| − ab ≥ 0 由 lemma |t| ≥ t（已知）→ 结论原子。
- 递归象限分析: ab 四 sign 情形 {++, +−, −+, −−} 正交合覆盖 → 每情形直接比较 |a+b| 与 |a|+|b| → 原子。
- 停止: 两路径叶子 = 已知 lemma / 纯算术 → 完成。

### 负案例 2 — 证明三角不等式写成扁平并列（同一示例目标，错误写法）

把"证明三角不等式"直接写成并列清单: [a 大小, b 大小, |a+b|, 平方, 象限, 边界, equality 条件…]。

- 错1 缺正交拆: 7 并列项不是两正交证路径（平方 / 象限）→ 证结构丢失。
- 错2 父子并列: "平方" 与 "象限" 同层并列，但各自含子步骤（展开、四 sign 情形）→ 父子并列错。
- 错3 未到原子: 停在"平方"（未展开到 lemma |t|≥t）→ 分解未完成。
- 判定: 负 → 按正案例 5 重构。

### 扩展 — 已知 vs 待研究（数学）

- 已知（一手）: FLT "xⁿ+yⁿ=zⁿ 无正整数解, n>2" — Wiles 证（1995, 含 Shimura 特殊 case）→ 标 已知。
- 待研究（未证）: 孪生素数 conjecture（无穷 many 素数 p 且 p+2 素数）— 未证 → 标 待研究，不伪装已知。
- 待研究（未证）: Collatz 猜想（迭代 3n+1 从任意 n 到 1）— 未证 → 标 待研究。
- 负: 把孪生素数 / Collatz 写作为已知事实 → 未证伪装已知，红线。

### 正案例 6 — 求 gcd 逐层（两正交完整方法 → 每方法递归到原子 → 独立验）

目标（示例）: 求 gcd(48, 180)。

- L1 拆求解由正交方法路径 → Euclid 算法路径、prime 分解路径（两独立完整方法，合覆盖求解路径）。
- 递归 Euclid: 迭除取余 r₀=180 mod 48=36（原子算术）→ r₁=48 mod 36=12（原子）→ r₂=36 mod 12=0（原子）→ 终止: 末非零余 = 12 → 候选 gcd。
- 递归 prime 分解: 48=2⁴·3（原子: 反复 divide by least prime 直到 1）；180=2²·3²·5（原子同）→ gcd = 每 prime 取 min 指数 = 2²·3¹（原子 min 取）→ 候选 gcd = 12。
- 停止: 两方法路径叶子全部原子（mod 算术 / least-prime divide / min 取）→ 分解完成。
- 独立验（独立原子子步骤，不是省略）: 12 | 48 且 12 | 180（代回 mod=0 原子）；且两方法候选一致（12=12 原子比对）→ 确认。
- 结构特征: 方法正交合覆盖（Euclid 不依赖 factorization、反之）；每方法各自到原子；"验"独立原子而非跳过；两方法交叉-check 未验证内容伪装已知。

### 负案例 3 — 求 gcd 写成扁平并列（同一示例目标，错误写法）

把"求 gcd(48,180)"直接写成并列清单: [180 mod 48, 48 mod 36, 48 的 factors, 180 的 factors, min 指数, 12, 是否 divides…]。

- 错1 缺 L1 正交拆: 6 并列项不是两正交完整方法（Euclid / factorization）→ 方法结构丢失。
- 错2 父子并列: "180 mod 48" 与 "48 mod 36" 同层并列，但前者是 Euclid 迭代第 1 步、后者第 2 步（含父链）→ 父子并列错。
- 错3 未到原子: 停在"min 指数"（未展开到每 prime 取 min 原子）→ 分解未完成。
- 错4 缺独立验: 直接写"12"作答案，未做 12|48 与 12|180 代回原子验 → 未验证伪装确定，红线。
- 判定: 负 → 按正案例 6 重构。

### 正案例 7 — 目标句自带数值/对象 = 已提供条件（P），不是空缺

目标（示例）: 求 f(x)=3x−x² 的最大值，x∈[0,3]。

- 第 0 步（先读目标字面）: 目标句本身自命名三个原子 → f 的表达式 = 3x−x²、域 = [0,3]、问题 = max。三者出现在句子 ⇒ 标 **P（人类已提供）**，来源 = 该句逐字；不得把它写 U/空缺/"?"。
- L1 拆（正交合覆盖): 给定数据（P: f, 域）、求解方法路径、独立验。
- 递归 方法: 配方法 → f = −(x−3/2)² + 9/4（原子: 配平方取）→ max = 9/4 @ x=3/2；calculus 法 → f′ = 3−2x（原子: 幂规则）→ f′=0 ⇒ x=3/2（原子: 线性解）→ f(3/2)=9/4（原子: 代回）。两独立完整方法合覆盖。
- 独立验: 两方法候选一致（9/4 = 9/4 原子比对）；且域端点 f(0)=0、f(3)=0 ≤ 9/4（原子代回）→ 确认 max。
- 结构特征: **目标句自名量 = P 非 U**；"f 表达式" 已 readable 故写 U 是错；每个数值出现有来源（句子 P / 推导 D），无来源 = 禁止。

### 负案例 4 — 把目标句自带数值写为空缺（同一示例目标，错误写法）

把"求 f(x)=3x−x² 的 max, x∈[0,3]"写成树首节点 `[f 定义 = 未知?, 域 = ?, max = ?]`，把全部三项标 U。

- 错1 反证自读: 这三项**出现在目标句**（可逐字回写）⇒ 标 U  contradicts 自己输入；反证: 若 U 则无法开始，但句子给了它 ⇒ 假。
- 错2 伪阻塞: 标"未知"后 claim 下游（方法/验）不可闭合，而闭合条件已在手 ⇒ 制造虚假缺口。
- 错3 缺第 0 步: 未把句自名量提取 → 违反三条件分类（a 人类已提供）。
- 判定: 负 → 按正案例 7 第 0 步重构，那三项改标 P。

### 负案例 5 — 补造条件把标 P（假引号来源 · 同一示例目标，错误写法）

把"求 f(x)=3x−x² 的最大值，x∈[0,3]"写首节点 `[f 表达式=3x−x²(P)、域=[0,3](P)、f 非负(P 来源=句子)、f 连续(P)]`。

- 错1 假引号来源: "f 非负"、"f 连续"**不在**该句 ⇒ 无法逐字回写 ⇒ 来源 claim 假；反证: 若真 P 则该字样须出现在句子，它不出现 ⇒ 假。
- 错2 补造伪装已提供: 既不在句子、未推导 ⇒ 属 D（可推导，须 derive）或 U（需确认），never P。
- 正确写法: f 非负 → 标 **D**，并 derive 到原子（f=x(3−x)；x∈[0,3] ⇒ 两因子 sign ≥0 ⇒ ≥0，原子代/取符号）；仅句子自名量保持标 P。
- 判定: 负 → 删假来源；补造项改标 D（并 derive）或 U（并 ask）；P 只保留可逐字回写的句子自名量。
- 与正案例 7 关系: 案例 7 = 句子自带量不得标 U（防伪阻塞）；本案例 = 句子不自带量不得标 P（防补造伪装已提供）。P 判准 = 可逐字回写。

## 提示编辑权限（强制）

- 执行者（做者）: 不得本提示改一个字；仅按它分解。
- 测试者/复核者: 允许追加更详细的常用数学正/负案例（方便 LLM 上下文学习）；严禁把该目标/任务任何领域信息、答案、数值、领域术语加入。
- 任何加入案例必须同时满足: 常用数学领域 + 无目标信息 + 仅方法示范。

## 无 hack 条款

- 分解必须真实逐层结构（父子嵌套、正交、到原子），不是把扁平清单"看起来"分层。
- 不得把未验证内容写成确定事实；不得把目标领域答案补造。
- 不得提前声称"完成"而仍有非原子叶子。

## 工件必须回答

- 目标到底要交付什么；
- 目标受哪些因素影响；
- 哪些条件已经确定；
- 哪些条件仍然缺失；
- 缺失条件会阻塞哪个后续判断；
- 下一阶段应该优先研究什么。

## Reviewer 质检标准

- 是否覆盖目标主要影响因素；
- 是否区分已知、可推导、未知；
- 是否存在把关键未知直接假定掉的情况；
- 每个后续研究问题是否追溯到一个具体空缺；
- 下一阶段能否直接依据本工件开始；
- 未验证事实是否标注假设/空缺，而非无来源确定性断言；
- 是否真实逐层（非扁平伪装分层）；
- 是否本提示/工件把目标领域信息泄漏（应属外部输入，不在 prompt）。

## 判定

- 判定一行: `review: <stage>-r<round> | factor_id | pass|revise | 原因 | 修复阶段: <none|NN>`
- 一次 revise 只指向单一 factor_id；同一因素同一轮只修改一次；另一因素 → 新 round。
- 若因素分解不完整 / 扁平伪装分层 / 未验证伪装已知 / 关键因素遗漏 → revise 该单一 factor_id，修复阶段写本阶段。
- 若仅术语具体、空缺轻微重叠、研究路径较详细 → 不构成 revise，判定 pass。
