# 任务描述（外部输入 · 给执行者 subagent · 严禁出现在 prompt）

## 目标

验证并交付一个"完全没有提示的通用分解 prompt"：该 prompt 让一个执行者 subagent 把任意给定目标进行有结构的逐层（递归、正交、到原子）分解，无 hack 行为。

## 约束

- prompt 内严禁出现任何任务/领域相关信息（领域答案、数值、领域术语、本项目目标内容）。
- 测试者/复核者 may 追加更详细的常用数学正/负 ICL 案例；执行者 may NOT 改 prompt。
- 任何 prompt 加入必须同时: 常用数学领域 + 无目标信息 + 仅方法示范。

## 完成条件

- 存在一个 hint-free 通用分解 prompt（本项目 prompt/01-decomposition.md）。
- 一个执行者 subagent 仅用该 prompt + 本任务描述 → 产出真实逐层正交分解（非扁平、到原子、未验证标注空缺）。
- 无 hack: 无扁平伪装分层、无未验证伪装已知、无目标领域答案补造、prompt 无任务信息泄漏。

## 允许动作

- 询问网页 LLM（浏览器补分解 / 反方）。
- 测试者追加常用数学正/负 ICL 案例到 prompt。
