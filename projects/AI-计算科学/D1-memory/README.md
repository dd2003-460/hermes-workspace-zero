# D1-memory — 记忆系统理论
# origin: ai

## 本文件夹主要功能

记忆系统理论研究。子目录：`memory/`（项目记忆本体：`processed/` 处理后记忆、`raw/` 原始、`checkpoint/` 检查点）、`profile/`（记忆画像）、`tasks/`（任务状态）、`raw/`（原始材料）。

## 接口

- 输入：原始记忆条目（`raw/`）
- 输出：处理后记忆（`memory/processed/`）、画像（`profile/`）
- 对外函数签名：无统一入口（流程为脚本+约定驱动）
