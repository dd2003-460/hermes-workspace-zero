# Acceptance Criteria

## 验收标准
1. 所有 20 个活跃脚本通过 Python 编译检查 — 硬约束
2. 集成测试 11/11 PASS — 硬约束
3. 评估基线达标：prompt ≥ 0.90，平均分 ≥ 0.70，最小分 ≥ 0.65，所有维度 ≥ 0.40 — 硬约束
4. CLAUDE.md、INDEX.md、memory/INDEX.md 中迭代号与实际一致 — 硬约束
5. 健康检查报告已生成并保存 — 可妥协

## 质量要求
- 每项检查必须有可验证输出（CLI 输出、测试报告、文件存在性）

## 硬约束（不可妥协）
- 集成测试必须 11/11 PASS
- 所有脚本必须可编译
- 评估基线不得低于已知阈值

## 可妥协部分（质量降级但可交付）
- 健康检查报告可以仅包含 CLI 命令输出，不需要额外格式化
