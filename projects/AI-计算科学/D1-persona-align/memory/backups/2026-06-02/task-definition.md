# Task Definition
## 一句话任务（不超过3行）

## 边界
- 范围：健康检查（只读验证 + 自动修复可识别问题）
- 边界：不修改 persona-v3 核心逻辑、不修改 idea 文件内容、不引入新功能

## 失败标准
- 集成测试 < 11/11 PASS，或任何评估基线低于阈值，或索引文件与实际状态不一致

## 硬约束
- 健康检查不超过 5 分钟
- 自动修复可发现的问题（脚本不可编译、索引文件过时等）
- 报告必须可验证（列出每个检查项的实际结果）
