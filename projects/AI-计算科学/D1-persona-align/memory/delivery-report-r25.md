## 1. 风格画像 (7+1维度)

完整分析见: `research/distill-style-repos/style-profile-7plus1.md`

**写作基因 (一句话)**: 成璐说话 = 在手机上跟AI边想边发，脑子里的东西滚出来就打字，编号是松散的（跳号是常态），空格代替句号，中英混用是默认态，断言+置信度标记（"我猜是XX"），物理动词不用来比喻抽象概念，跑题是自动的不是刻意的。

**禁用清单 (8条)**:
1. 不用物理动作动词描述抽象概念: 逼/拍/扣/卡死/刺/砍/压/拉/拽 + 非物理宾语
2. 不用AI套话: 值得注意的是/综上所述/显而易见/首先...其次...最后/总的来说
3. 不用感叹号加强情绪
4. 不用"我作为AI"或任何AI自我指涉
5. 不用"希望这对你有帮助"式结尾
6. 不用"让我来解释一下"式开头
7. 不用排比句增加气势
8. 不用"深入探讨/全面分析"等虚假深度词

### 2.4 关键差距分析

**做对的 (v7 vs v3)**:
- 物理动词比喻: v3=6处 → v7=0处 ✓
- AI自称: v3=3处 → v7=0处 ✓
- AI套话: v3=多处 → v7=0处 ✓
- 中英混用: v3=较少 → v7=密集 ✓
- 断言+conf: v3=有 → v7=有且更自然 ✓

**做错的 (v7 vs GT)**:
1. **括号插话**: GT有3处"（也许是因为我在的地方太垃圾？）"，v7有0处。这是成璐最标志性的语感——在断言中间突然插一句自我觉察
2. **自我暴露**: GT有"我傲慢地感觉"×2 + "我在的地方太垃圾"，v7完全没有。成璐会在技术讨论中突然暴露自己的心理状态
3. **跳跃感**: GT的编号是"1.2→2.2"（跳了2和2.1），v7是"0→1→2.1→2.2→3→4"（跳了2）。v7的编号太整洁，GT的编号是"脑子里滚的东西的快照"
4. **句子没说完就跳**: GT有"当然，这不是你（你是谁）"这种突然中断，v7没有
5. **"Show more"**: GT有截断痕迹，v7没有（这个其实不需要模仿，是界面残留）

**核心诊断**: v7是"好脑子+聊天皮"，GT是"脑子滚出来就打字"。差的是**无意识性**——成璐的文本有"没来得及想好就发出去"的感觉，v7的文本有"想好了再发"的感觉。

## 3. 蒸馏仓库测试结论

### 3.1 perfectly-replicate-writing-skills (7★)

**方法**: 7+1维度分析 → 风格画像 → 便携prompt → 盲测

**适用性**: 高。方法本身是通用的（语料→维度→画像→prompt），我直接在成璐271条语料上执行了Phase 0-3。

**产出**:
- style-profile-7plus1.md (7+1维度完整分析)
- portable-prompt-distilled.md (便携prompt)

**效果**: 盲生成S2 → 与GT对比71%相似度。主要差距在"无意识性"（括号插话/自我暴露/跳跃感）。

### 3.2 clonar-escrita (2★, Python)

**方法**: 6阶段pipeline (parse→filter→clean→stratified chunking→MAP→REDUCE)

**适用性**: 中。设计给WhatsApp聊天日志（.txt），不是结构化JSON。MAP/REDUCE的3-pass shuffled order验证机制有价值（3/3出现=真特征），但pipeline本身不需要——我已经手动做了等价的维度分析。

**未执行**: 需要适配输入格式（JSONL→chunked text），且核心价值（验证机制）已手动覆盖。

### 3.3 clone-chat (7★, JS)

**方法**: 导入聊天记录→本地LLM agent→以人物身份对话

**适用性**: 低。是产品不是方法。需要本地LLM runtime + 长期记忆系统，超出当前实验范围。

## 4. 结论

### 4.1 最像你的生成 = OPRO-v7

在所有已测方案中，OPRO-v7 (纯场景式prompt) 最接近你的风格：
- 物理动词比喻=0 (v3=6, v5=1)
- AI自称=0
- AI套话=0
- 中英混用密集
- 断言+conf自然
- 7+1维度总分 55/80 (GT=75/80, 71%相似度)

### 4.2 核心差距 = 无意识性

| 差距 | GT | v7 | 根因 |
|------|-----|-----|------|
| 括号插话 | 3处 | 0处 | 成璐在断言中间突然插自我觉察，v7没有这个"中断" |
| 自我暴露 | "我傲慢地感觉"×2 | 0处 | 成璐会在技术讨论中暴露心理状态，v7不会 |
| 跳跃感 | 1.2→2.2 (大跳) | 0→1→2.1→2.2→3→4 (小跳) | 成璐的编号是"脑子滚出来的快照"，v7的编号是"组织好的outline" |
| 没说完就跳 | "当然，这不是你（你是谁）" | 无 | 成璐会突然中断一句话，v7不会 |

### 4.3 下一步

1. **OPRO-v8**: 在v7基础上加"中断"行为——prompt里描述"你经常一句话说到一半突然跳走"，而不是列出"禁止XX"
2. **更多GT数据**: 当前只有3个场景(~3.2K字)，语料库有271条(263K字)。需要更多场景的GT来做盲测
3. **clonar-escrita的验证机制**: 3-pass shuffled order → 3/3出现=真特征。可以在维度分析中加入这个验证
