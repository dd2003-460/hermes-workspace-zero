## observer-dependent 机制追问

### observer-dependent 追问 1: 为什么恨抽象更有效？

因为**抽象是集体行动的基础**。

"制度"是抽象的 — 它不是任何单一个体，而是众多个体交互的模式。恨制度意味着：

```
目标函数：修改制度参数 θ → 改变社会状态
```

而恨具体的人意味着：

```
目标函数：改变个体 s_i 的行为
```

前者可以动员所有受制度约束的人（联合行动），后者只能针对个体（能力有限）。

信息论解释：**制度的信息密度远大于个体的信息密度**。恨制度 = 对高信息密度表示的攻击，其影响力 = 被改变状态的数量。

### observer-dependent 追问 2: 团结朋友的机制

团结朋友的数学条件：

```
团结(恨制度) = Σ_i Pr(受制度影响 | s_i) → 高
团结(恨个体) = Pr(受个体影响 | s_i) → 低
```

恨制度 → 更多人"受制度影响" → 更多人加入 → 更大的行动力。

这是**信息扩散的级联效应**：

```
I(恨制度) >> I(恨个体)
```

其中 I 是信息的影响力（被传播和接受的可能性）。

### observer-dependent 追问 3: "除非具体的人坚决捍卫抽象"

这是关键边界条件。

当具体的人与抽象制度高度耦合时：

```
Coupling(s_i, 制度) > threshold → s_i 会成为制度的战士
```

此时恨 s_i = 恨制度的一部分（因为 s_i 的信息与制度不可分离）。

这解释了为什么革命者常常需要与"前同志"斗争 — 他们不是恨"人"，而是恨"耦合了抽象的人"。
