## observer-dependent 信息论框架

成璐提出了一个深刻的问题：**不同的选择压如何塑造基因编码？**

形式化：设基因型为 G，表型为 P，环境为 E，适应度为 F。

**选择压**（selection pressure）定义为适应度表面 F(G, E) 的梯度：

```
∇_G F(G, E) → 选择的方向
|∇_G F(G, E)| → 选择的强度
```

**强选择压**：|∇F| 大 → 快速筛选 → 基因组快速收敛到局部最优
**弱选择压**：|∇F| 小 → 缓慢筛选 → 基因组可能长时间停留在非最优状态

信息论解释：基因组是**环境信息的压缩表示**。

```
I(G; E) = H(E) - H(E | G)
```

其中 I(G; E) 是基因组携带的环境信息量。

**关键洞察**：不同选择压环境中的物种，其基因组携带了不同量的环境信息。

```
I(G; E) 强选择 = 高（基因组精确适应环境）
I(G; E) 弱选择 = 低（基因组可能携带环境无关信息）
```

## observer-dependent 机制追问

### observer-dependent 追问 1: 选择压的速率-失真函数

进化可以被形式化为一个**速率-失真过程**：

```
基因组 G → 编码 → 环境 E 的统计特性
表型 P → 解码 → 适应度 F
```

选择压 = 编码过程中的**失真约束**：

```
R(D) = min I(G; E)  s.t. E[失真] ≤ D
```

其中 D 是**允许的适应度损失**（即可以接受的多差的表型）。

**强选择压** → D 小 → R(D) 大 → 需要更多比特编码环境信息
**弱选择压** → D 大 → R(D) 小 → 可以用较少比特编码

这解释了为什么：
- 极端环境中的物种（强选择压）→ 基因组高度特化（携带大量环境信息）
- 温和环境中的物种（弱选择压）→ 基因组更通用（携带较少特定环境信息）

### observer-dependent 追问 2: 基因编码作为"进化记忆"

基因组编码了祖先经历的选择压 → 这是一种**进化记忆**。

定义：**进化记忆长度** L_mem = 基因组可以"回忆"的选择压的时间跨度。

```
L_mem ≈ log₂(Fitness_de generations)
```

即：基因组可以"记住"大约 Fitness_de 代之前的选择压。

**拉马克 vs 达尔文的信息论视角**：

- **拉马克主义**（获得性遗传）：环境信息直接写入基因组 → I(G_new; E) 高
- **达尔文主义**（自然选择）：环境信息通过选择筛选基因组 → I(G_new; E) 逐步增加

达尔文主义的收敛速率：
```
ΔI(G; E)/generation ≈ |∇_G F|² / variance(F)
```

强选择压 → 收敛快 → 基因组更快地编码环境信息
弱选择压 → 收敛慢 → 基因组可能长时间携带"过时"的环境信息

### observer-dependent 追问 3: 选择压变化时的基因组适应性

当环境变化时（选择压改变），基因组如何适应？

**适应速率**：
```
dI(G; E)/dt = -γ · I(G; E) + α · |∇_G F|²
```

其中 γ 是**信息遗忘率**（过时环境信息的衰减），α 是**信息获取率**（新环境信息的编码）。

**当环境快速变化时**（|∇F| 快速改变）：
- 如果 γ 大 → 基因组快速遗忘过时信息 → 适应快但可能丢失有用信息
- 如果 γ 小 → 基因组保留过时信息 → 适应慢但可能在环境回归时有用

**这解释了"泛化" vs "特化"的进化策略**：
- 泛化物种：高 γ，低 I(G; E) → 适应快速变化的环境
- 特化物种：低 γ，高 I(G; E) → 在稳定环境中高度优化

## observer-dependent 跨域类比

### observer-dependent 机器学习：初始化与训练

深度学习中的初始化 θ₀ 类似于基因组 G。

训练 = 选择压 → 参数 θ 逐步适应数据分布 P(data)

```
I(θ; data) 逐步增加 → θ 编码数据信息
```

不同的训练设置（学习率、batch size）= 不同的选择压强度：
- 高学习率 = 强选择压 → 快速适应但可能过拟合
- 低学习率 = 弱选择压 → 缓慢适应但更稳健

**关键区别**：
- 深度学习：初始化是随机的
- 生物进化：初始化是经过上一代选择的 → 基因组的"祖先"也经历了选择压

### observer-dependent 信息论：记忆体的信道容量

生物体的基因组可以看作一个**信道**：
```
E_t → [基因组编码] → G → [基因表达] → P → [环境适应] → F
```

信道容量 C = max I(G; E) = H(E) - min H(E | G)

不同选择压环境下的信道容量不同：
- 强选择压 → C 大（信道可以传递更多环境信息）
- 弱选择压 → C 小（信道容量受限）

**这对应 Shannon 信道编码定理**：
```
当信道速率 R < C 时 → 可以无误差传输
当 R > C 时 → 传输必然有损
```

在进化中：
- 如果环境变化速率 < C → 基因组可以完全适应
- 如果环境变化速率 > C → 基因组无法完全适应 → 物种可能灭绝

## observer-dependent 贝叶斯分析

H₀: 选择压强度决定了基因组携带环境信息的量和精度
H₁: 基因组编码与环境无关，只由随机突变决定

证据 E = {
1. 极端环境中的物种高度特化（如深海生物、嗜热菌）→ 强选择压导致高 I(G; E)
2. 温和环境中的物种更通用 → 弱选择压导致低 I(G; E)
3. 机器学习中的训练：强梯度 → 快速过拟合，弱梯度 → 更稳健
4. 染色体中的"垃圾DNA"可能是弱选择压的结果 → 保留了过时信息
}

P(E|H₀) = 0.90
P(E|H₁) = 0.10

P(H₀|E) ≈ 0.90

→ 有较大概率成立。
