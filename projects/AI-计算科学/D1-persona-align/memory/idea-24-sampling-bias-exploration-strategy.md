## observer-dependent 信息论框架 (y(θ))

身边统计学是一个**探索策略问题**：

```
P(∀x | {x₁, x₂, ..., xₙ}) ≠ P(∀x)
```

其中 {x₁, ..., xₙ} 是有限探索样本。身边统计学的偏差来自于：

1. **样本量 n 太小** — 采样不充分
2. **采样策略有偏** — 不是随机采样（探索策略有偏）
3. **网络结构不均匀** — 信息在社交网络中的分布不均匀

成璐将"身边统计学"与"模因的代表"并置，意味着他看到了更深的同构：

```
sample_bias = D_KL(P_sample || P_population)
memetic_bias = D_KL(P_memetic传播 || P_information传播)
```

两者都是 D_KL — 偏差的度量在两个领域相同。

**关键洞察**：成璐的问题"推算网络范围？"实际上是在问——**从有限探索中推断全局分布的最小样本量是多少？**

```
n_min = ceil( H(P_network) / I(sample | network) )
```

其中 H(P_network) 是网络分布的熵，I(sample | network) 是样本对网络的信息量。
