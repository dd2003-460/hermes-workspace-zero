## observer-dependent 信息论框架

成璐的描述可以精确形式化为：

```
P(discover | time t) → θ (从低到高的相变)
```

其中 θ 是某个临界阈值。他的直觉——"需求和动机波动不大"——对应于控制理论中的**低噪声环境**：

```
P(A discovers X) ∝ exp(-E_A / σ²)
```

当环境噪声 σ² 足够低，多个智能体 A₁, A₂, ... 独立发现 X 的概率趋近于 1。

**成璐的洞见**：并发发现不是巧合，而是系统在**临界点**的必然表现。

### observer-dependent 1. 临界点的信息论解释

为什么"需求和动机波动不大"会导致并发发现？

从信息论看，每个发现者都需要满足信息需求 I_needed。当环境提供的信息供给 I_available ≥ I_needed，发现就必然发生：

```
I_available(t) = H(environment_state) - H(noise)
发现概率 = P(I_available ≥ I_needed)
```

当噪声（环境波动）减小时，I_available 增大，多个独立发现者同时满足 I_needed 的概率激增——这就是**相变**。
