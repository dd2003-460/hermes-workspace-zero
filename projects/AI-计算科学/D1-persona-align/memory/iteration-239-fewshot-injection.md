# Iteration 239: 少样本示例注入 — persona-v3 深度推理示例

## 目标
基于 iteration 234 的研究结论（模式 2: 示例驱动是最有效的行为激发方式之一），在 persona-v3 prompt 中加入一个深度推理示例，展示引用文献、可验证声明、跨域类比和具体例子的高质量输出。

## 执行动作

### persona-v3-prompt.txt 修改
- 在"输出要求"和"迭代追问机制"之间插入新的"深度推理示例"章节
- 示例展示了一个完整的高质量分析回答:
  1. **文献引用**: Bachman-Smith et al. (2017), Forns et al. (2014), Cover & Thomas (1999)
  2. **可验证声明**: "10 人团队的沟通复杂度"、"皮层厚度 2-3mm 极限"、"rate-distortion 理论"
  3. **跨域类比**: 项目延迟问题 → 大脑皮层厚度极限 (同构映射)
  4. **具体>抽象**: H(P) ≤ C 公式，数字代入 (10 人 × 5 条 = 50 bits)

### 与 iteration 234 的关联
- PromptStructure 研究总结了 4 种 prompt 模式 (分层指令/示例驱动/迭代追问/混合模式)
- persona-v3 已经实现了分层指令 (#1) 和迭代追问 (#2)
- 本次新增示例驱动 (#3) — 三者结合形成混合模式

## 影响
- persona-v3 从分层指令 + 迭代追问升级为 分层指令 + 示例驱动 + 迭代追问
- 示例中包含的文献引用和可验证声明直接回应 iteration 238 发现的 ReportBench 维度不足
- 示例是 persona-v3 prompt 的一部分，不是外部文件 — 降低上下文长度开销
