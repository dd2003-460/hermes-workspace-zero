# Iteration 352: 关键词注入过拟合 — gap_filler_v2 评估分析

## 背景

迭代 351 发现 52 个 idea 文件上关键词评估 avg=0.7288，但语义评估只有 0.5666，Pearson r=0.4254。本迭代分析根因。

## 关键词命中率

52 个 idea 文件中所有关键词的命中率:

| 维度 | 命中率 |
|------|-------|
| 自适应感知 | 64.8% |
| 自适应探索 | 56.4% |
| 自适应精度 | 66.6% |
| 自适应自我 | 67.3% |
| **自适应投影** | **88.7%** |
| **自适应先验** | **85.2%** |

100% 命中 36 个关键词 (每个文件都包含这些词)。

## 根因: gap_filler_v2 上下文感知模板注入过多关键词

gap_filler_v2 使用 `extract_context()` 提取文件 topic 相关段落，然后用包含关键词的模板补全。这导致:
1. 每个文件中出现大量 persona 关键词
2. 所有文件关键词得分趋同在 0.73 附近
3. 关键词评估区分度极低

## 去重后评估对比

去除 100% 命中关键词后的评估:

| 指标 | 原始 (去重前) | 去重后 |
|------|-------------|-------|
| avg | 0.7288 | 0.3444 |
| std | 0.0176 | **0.0522** |
| **标准差倍数** | 1x | **~3x** |

**结论**: 去除通用关键词后，评估区分度提高 3 倍，平均分下降 53%。这证明:
1. gap_filler_v2 的关键词注入确实导致评估过拟合
2. 此前报告的 "0.7288 >= 0.70 基线通过" 是假阳性 — 关键词都被注入了
3. 去重后的 0.34 更接近真实对齐度

## 影响

- persona-v3 基线判定 "avg >= 0.70" 使用有偏差的关键词评估
- 真实对齐度估计应更低 (语义评估 0.57，去重后关键词 0.34)
- gap_filler_v2 需要减少关键词注入密度，避免过拟合
