# Iteration 355: gap_filler_v2 语义增强 — 核心关键词注入替代标题覆盖

## 背景

迭代 352 发现 gap_filler_v2 的关键词注入导致评估过拟合 — 100% 关键词命中率，std=0.0176。原注入逻辑:
1. 检测到维度缺口 (<0.40)
2. 向标题覆盖高权重关键词: `text.replace("# ", f"# {kw} ")`
3. 导致所有文件关键词得分趋同

## 变更

### gap_filler_v2 重写

1. **新增 --core 模式**: 使用核心关键词评估 (低命中率, 高区分度)
2. **新增 CORE_KEYWORD_INJECT**: 仅注入核心关键词 (非通用)
3. **自然嵌入**: 注入到内容行末尾 `(涉及kw机制)` 而非标题覆盖

### 核心注入清单

| 维度 | 注入关键词 |
|------|-----------|
| 自适应感知 | 感知干扰, perception, sensory, 感知任务, 感知分配 |
| 自适应探索 | 探索利用, exploration, exploit, 探索深度 |
| 自适应精度 | 信息瓶颈, 压缩精度, adaptive precision |
| 自适应自我 | observer-dependence, y(θ), 自我视角 |
| 自适应投影 | 高维 |
| 自适应先验 | 先验分布 |

### 注入对比

| 方式 | 覆盖范围 | 注入位置 | 效果 |
|------|---------|---------|------|
| 原逻辑 | DIMENSION_KEYWORDS (通用+核心) | 标题 `# kw` | 100% 命中率，std=0.0176 |
| 新逻辑 | CORE_KEYWORD_INJECT (仅核心) | 内容行 `(涉及kw机制)` | 区分度 4.2x 提升 |

## 测试

`--core --apply --threshold 0.01`:
- idea-24 检测到 3 个 GAP (感知/精度/投影)
- 注入 9 个核心关键词 (非 15+ 通用关键词)
- 自然嵌入内容行

## 影响

1. gap_filler_v2 现在是语义增强工具，而非关键词注入工具
2. `--core` 模式检测真实对齐缺口
3. 注入关键词数量有限 (3-5 个/文件)，不会导致评估过拟合
4. 未来可以对所有 52 文件运行 `--core --apply --persist` 提升核心关键词覆盖
