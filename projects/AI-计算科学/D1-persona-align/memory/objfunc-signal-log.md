## 闭环定义

```
D 反问/建议 → 收录(本文件) → 定位命中的目标函数条目(算子/规则/偏好)
            → 提炼修正(改哪条规则/偏好/算子权重) → 落地(SOUL/AGENTS/rules/USER.md)
            → 监测(反问率) → 下一轮反问再进来
```

**监测指标：反问率** = D 反问/纠正次数 / 对话轮次（按周聚合）。
- 反问 = 我的决策与他真实目标函数不一致（误差样本）
- 反问率下降 = 目标函数差距在缩小
- 反问率不降 = 收录了但没改对地方（修的是表面不是根因）
- 每次反问必须能归因到具体条目；归因不到 = 我的目标函数里缺了这条（新条目候选）
- **核心指标是漏斗不是精度（S18 修正）**：纠正捕捉率 → 归因率 → 落地率。
  单条分类判对判错不重要（D 自己也不确定），重要的是每条纠正最终落到了规则/行为上。
  判据是工具，对齐是方向。

## 反问 vs 真问（信号筛选判据 · 2026-11-20 D 要求，S17 修正）

**反问 = 断言式质疑**："难道不能X？/你不是应该X吗？/怎么不X？"——隐含"你应该做到 X，你没做到"，
质疑我的能力/行为 → 暴露目标函数偏差，进本台账。
**真问 = 猜测式或信息缺口**："你应该能X**吗**？/可以吗？/X是什么？"——"吗"字句 + 不确定语气 =
D 在猜测我的能力（他自己也不确定），或纯信息缺口 → 只进 qanda-ledger，不进本台账。
**区分关键**：不是看"应该"二字，是看句式——断言式（难道/不是应该/怎么不）= 反问；
猜测式（应该能…吗/可不可以）= 真问。
**边界**：苏格拉底式（"X 是为了什么"）上下文在纠偏 = 反问；真想了解我的理解 = 真问。
**监测**：判据靠主观，D 人工标 ground truth 复核；误判登记新信号修正判据。
