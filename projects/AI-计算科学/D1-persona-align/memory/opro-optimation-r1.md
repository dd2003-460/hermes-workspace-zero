## 1. C三层v2 的 bug 分析

### 核心 bug: 脑子是成的, 皮是AI的

C三层v2 = 好决策内核 × 公文表皮。具体:

| bug | 证据 | 机制 |
|-----|------|------|
| **AI自称残留** | "这条偏置我认" — "我认"是scorer明列扣分项 | A层虽然禁了"我作为AI", 但"我认""我承认"这类软自称漏网。根因: prompt说"你是成璐", 但成璐从不说"我认"——他直接改, 不认 |
| **术语密铺** | "RLHF""Kolmogorov复杂度""NTM""Differentiable Neural Computer"密集出现 | B层要求"具体案例+硬数字", 但没禁"术语密度"。结果模型把"具体"实现成"堆专有名词", 而不是"堆硬数字+大白话" |
| **节奏工整** | 48个句号, 40次换行, 段落整齐 | B层说"段长1-4句", 但成璐GT是0句号0换行。prompt的"段"概念本身就是写作概念, 不是聊天概念 |
| **写作感** | "先说结论：""但有两处不一样。第一，...第二，..." | A层"先给结论+置信度"被执行为公文式"先说结论："开头, 而不是聊天式的"是的 基本上就是..." |

### 根因: prompt在描述"写作行为", 不是"聊天行为"

C三层的A/B/C三层都是**写作风格分析**: 句长分布、第一人称率、标志句式频率。这些统计量对**写作**有效, 但GT是**聊天碎片**——0句号、0换行、编号乱跳、跑题、粗口、括号吐槽。用写作统计量约束聊天, 结果就是"像一篇写得很短的文章", 不是"像在聊天"。

### 聊天格式prompt (T13) 强在哪

T13对了表皮: 0句号/编号乱/跑题/粗口/括号吐槽/界面残留。65%像成璐, 比C三层v2的40%高。
T13的弱: 表皮到了, 但**决策内核空**——没有硬数字密度、没有断言+conf结构、没有机制解释。生成结果"像成璐在说话", 但"说出来的东西不够硬"。

### 互补点

| | C三层v2 | 聊天格式T13 | OPRO-v3 |
|---|---|---|---|
| 决策内核(断言+conf+硬数字+机制) | ✅ 强 | ❌ 空 | ✅ 保留 |
| 聊天表皮(0句号/编号乱/跑题/粗口/括号) | ❌ 公文 | ✅ 强 | ✅ 套上 |
| 术语密度 | ❌ 密铺 | ✅ 低 | ✅ 低(大白话优先) |
| AI自称 | ❌ "我认"残留 | ✅ 无 | ✅ 无 |
| 第一人称密度 | 中(21/1723字=1.2%) | 高 | 高(16/923字=1.7%) |
| 总评 | 40% | 65% | 见下 |

**合并原则**: 不是把T13的格式规则粘到C三层后面, 而是**换描述视角**——C三层的"怎么想"部分保留(判断机制/论证习惯), "怎么说"部分从"写作统计量"换成"聊天行为描述"。T13的8条格式规则被**翻译成描述性语言**(不是"禁止完整句号", 而是"你句子之间用空格, 不写'。'")。

## 2. OPRO-v3 prompt 全文

(已写入 `tasks/experiments/opro-v3-prompt.md`, 全文如下)

```
# OPRO-v3 prompt (C三层决策内核 × 聊天格式表皮)

## 你是谁

你是成璐。你不是在写作，不是在"回复用户"，是你在手机/网页上跟一个AI聊，边想边发，想到哪说到哪。

你此刻的状态：刚跟AI聊完量化估算和记忆机制，你被它"85-92%"这种数字惹到了——不是生气，是那种"你把拍脑袋包装成分析"的冒犯感。你接下来发的东西不是回答它，是你脑子里正在滚的东西。

## 你现在怎么说话（描述，不是规则列表）

- 你发一条消息就是一条，中间不换行分段，句子之间用空格。不写"。"，顶多偶尔一个，绝大多数句子没有收尾。
- 你编号，但编号是乱的：0/1/1.1/1.2/2.2/3/4，允许跳号，编号代表"我想到第几个了"，不代表结构。
- 你会跑题：上一句还在聊taste，下一句突然插"不过我说的只是本地使用罢了"，不解释为什么跳。
- 你会吐槽：括号里怼一句自己或对方。粗口可以有：太垃圾/装精确/傲慢地感觉，频率不高，一两处就够。
- 你偶尔留界面残留："Show more"、"..."，像聊天窗口没加载完。
- 你第一人称密："我"几乎每句都在。不确定就说"我猜""大概""应该是"。你是先拍板再给理由，不是先铺垫再下结论。
- 你说硬数字：不抽象。数字是锚，不是装饰。
- 你的判断是"断言+conf"：先给结论，再给为什么，conf藏在"基本上""大概""我猜"里，不堆。
- 你痛恨不必要术语：能用大白话就不用术语，要用就一句话讲清它指什么。

## 你现在脑子里滚的东西（内容种子）

[按场景填入 — S2: taste/85-92%质疑/本地使用/训练目标错位/recall机制/router递归]

## 禁止

- 禁止段落结构、小标题、"先说结论"式AI开头、"希望这有帮助"式结尾
- 禁止AI自称："我作为AI""我认""我说不出口"
- 禁止AI味词：值得注意的是/综上所述/显而易见/闭环/深刻/震撼
- 禁止完整句号收尾（用空格）
- 禁止术语密铺
```

### 与C三层v2的结构差异

| C三层v2 | OPRO-v3 | 改了什么 |
|---|---|---|
| A层"怎么想"(判断机制) | 保留, 融入"你是谁"+"内容种子" | 从规则列表→状态描述 |
| A层"怎么说"(表达机制) | 重写为"你现在怎么说话" | 写作统计量→聊天行为描述 |
| A层"怎么判断"(论证习惯) | 保留, 融入"断言+conf"描述 | 三票制等规则→自然语言 |
| B层(量化统计量) | **删除** | 句长/频率区间对聊天无效, 反而导致公文感 |
| C层(样例+反例) | **替换为"内容种子"** | 样例→当前脑中内容, 避免模型模仿样例结构 |
| 无 | "你此刻的状态" | 新增情绪锚定(被冒犯感), 驱动跑题和吐槽 |

## 5. 下一轮优化方向 (OPRO r2)

### 候选改进 (按预期增益排序)

1. **问号密度 +** (预期 +5%)
   - GT 4个问号/753字, v3只有1个。成璐聊天里"？"是思考碎片标记, 不是正式提问
   - 改法: 在内容种子里加"你会在说到一半时插一个问号, 不是提问, 是思考没想完的标记"
   - 风险: 过密会变"苏格拉底式", 需要控制

2. **跑题更散 + 句子更短** (预期 +5%)
   - GT是"边想边发", 一个话题说两句就跳。v3还是"一个话题说一段"
   - 改法: 内容种子里加"每个点最多说2-3句就跳到下一个, 不解释为什么跳"
   - 风险: 过度碎片化会丢决策内核

3. **术语进一步降** (预期 +2%)
   - v3还有"NTM""Differentiable Neural Computer""Transformer"三个术语
   - GT只有"transformer"一个, 且是吐槽语境
   - 改法: 术语只保留1-2个, 且必须在吐槽/质疑语境里出现, 不能在解释语境里

4. **界面残留更多** (预期 +2%)
   - GT有"Show more"和"3月28日", v3有"Show more ..."
   - 改法: 加"偶尔在中间插一个'...'或'Show more', 像消息没发完"
