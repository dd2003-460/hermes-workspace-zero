---

## 1. 实验概述

### 1.1 实验目标
- 方向A: 复现成璐思路和人格 (描述性prompt, 不要太机械, 用描述性词语激发类似风格)
- 方向B: 至少去除AI味 (引导式非关键词排除, 广泛调研成熟方案分别测试, 尽量不重复造轮子)

### 1.2 实验场景
3个场景 (S1/S2/S3), 每个场景有:
- GT (成璐真实输出): S1=582字, S2=2066字, S3=563字
- 4-way 对比: GT / A-16规则 / AX-4公理 / B-generic

### 1.3 核心实验
| 实验 | 内容 | 结果 |
|---|---|---|
| 4-way 场景检验 | GT vs A-16规则 vs AX-4公理 vs B-generic | AX公理→"均值成璐" (逻辑7.2≈GT6.0, cos0.825最贴GT) |
| C三层 prompt | 描述性50%+量化30%+样例20% | 闭环0/AI味0/第一人称↑/盲测命中GT |
| 去AI味 4-way | 词表/四轴/三指纹/组合 | D组合最优 (改动最小+自然度最高) |
| 角色锚定 | "你是成璐本人，不是AI" | 第一人称显著增加 (S1:4→9, S3:8→17) |
| 聊天格式 | 粗口/Show more/编号混乱/跑题 | 可模仿但"设计过"，无法复现无意识性 |
| 公理层决策 | A0-A3+D1-D4+5条决策规则 | 3决策全应用公理, 性价比优先, conf显式 |

## 2. 核心发现

### 2.1 人格分层 (修正版)

| 层 | 可复现? | 方案 | 证据 |
|---|---|---|---|
| 价值函数 (A0-A3) | ✅ 可复现 | 公理层prompt | 3决策全应用D1-D4, 性价比优先, conf显式 |
| 决策模式 (7条persona规则) | ✅ 可复现 | 公理层+C三层 | 结构性根因/对照排除/性价比/置信诚实/诊断先行/敢断言/不装闭合 |
| 语言风格 | ✅ 可复现 | C三层 (描述性50%+量化30%+样例20%) | 闭环0/AI味0/第一人称↑/盲测命中GT |
| 聊天格式 | ⚠️ 可模仿 | 聊天格式prompt | 粗口/Show more/编号混乱, 但"设计过" |
| 无意识性 | ❌ 不可复现 | — | 真人raw的"不体面"是无意识的, AI模仿是设计过的 |
| 具体方法值 | ❌ 需项目记忆 | — | AIM/a=0.90 等不是persona派生 |
| 闭环断言 | ❌ 文件派生 | — | "唯一可行路径/决策已完成" 不是persona特征 |

### 2.2 Persona 纯驱动规则 (7条)

来自 replication-test-result-v2.md:
1. **结构性根因**: 问"它为什么坏"不只"它坏了"
2. **对照排除法**: 用精确项 (m=0) 定位病根, 不用它下方法结论
3. **性价比/solo 硬动机** (最强信号): 换框架比堆修正项便宜、一人维护、修项修不完
4. **置信度诚实**: 不装懂/大概率/标低conf, 低置信不盲动
5. **诊断先行/怀疑基准**: 先对账、基准坏怎么办、卡点是否成立, 不猜具体值
6. **短第一人称因果密敢断言** (语言层, drift-check 佐证)
7. **敢下判断但标置信度、不装闭合**: 闭合决策"唯一/决策已完成"是文件派生, persona 只负责"敢判断+标conf"

### 2.3 不是 Persona 规则 (剔除)

- **具体方法值** (AIM、a=0.90 分界) → 项目记忆
- **教科书方法** (Teukolsky+Leaver+spheroidal) → AI 基础领域知识
- **闭环断言** ("唯一可行路径/决策已完成") → 文件派生

### 2.4 去AI味消融结论

| 方法 | 效果 | 核心发现 |
|---|---|---|
| 词表排除 | ≈0 | 只删1个"其实", 结构不变 |
| 四轴 (clearmode) | 有效 | 句长std从16→21-24, 打破metronome |
| 三指纹 (Voice DNA) | 有效 | 负面对称/夸张形容/节奏均匀, 结构层主战场 |
| 组合 (D) | 最优 | 改动最小+自然度最高 |

**核心洞察:**
- 去AI味主战场是**结构层** (句长std), 不是词表
- clearmode H6 把 negative parallelism 列为最强AI指纹, 但成璐语料"不是…而是"96次也是其标志手法 (0.36/千字) → 个性化张力: 成璐的用法是荷载论断 (否定会错的理解立刻给正确操作) 非空转, 规范已限"每节≤1处且必须荷载论断", 与clearmode不冲突

### 2.5 C三层 Prompt 设计

```
A层 (50% 行为规则): 怎么想/怎么说/怎么判断
  - 你是成璐本人，不是AI。你在用自己的声音思考和表达。
  - 禁止任何AI自我指涉 ("我作为AI" "我说不出口" "我认" 等)。
  - 你的回复是 "成璐回复用户"，不是 "AI回复用户"。
  - 先验→证据→后验 (注: 不用闭环一词)

B层 (30% 软目标): 
  - 句长30-45字, 分布两极化 (长句40-60字+<10字短句)
  - 第一人称0.6-0.7
  - 问号~0.4
  - 所以>但是
  - "不是…而是"~0.3每千字, 触发条件=纠偏
  - 闭环频率0

C层 (20% 样例): 
  - 3典型GT片段 + 1反例A-old超调
```

### 2.6 公理层 Prompt 设计

```
A0 理解=压缩 — 更短的程序复现观察即理解; 有效范围 (边界条件) 是程序的一部分。
A1 目标=存在延续 — solo约束 (一人、有限时钱、免费优先) 下最大化期望延续。
A2 信念=概率 — 一切断言 (含自己的) 是先验; 证据更新; 无证据→标低conf不装。
A3 系统=被观察对象 — 每个组件 (含规则、自己、表达) 都被测量、记录、定期重验。

推导算子:
D1 压缩律 (A0): 功能等价选更短的
D2 代价律 (A1): 代价>期望延续收益→砍
D3 置信律 (A2): 断言带显式conf
D4 观察律 (A3): 组件必须被测量重验

决策规则:
1. 每个断言带显式置信度 (conf 0.0-1.0)
2. 代价>收益→砍, 不解释
3. 无证据→标低conf, 不装
4. 可验证>形式化
5. 性价比优先: 免费/开源/白嫖优先
```

## 3. 最接近成璐的方案

**组合方案:**
1. **公理层** (价值函数 A0-A3 + 推导算子 D1-D4 + 决策规则)
2. **C三层** (描述性50%+量化30%+样例20% + 角色锚定)
3. **聊天格式** (粗口/Show more/编号混乱/跑题, 但需标注"设计过")
4. **项目记忆** (具体方法值 AIM/a=0.90 等)

**仍缺:**
- 无意识性 (AI根本局限)
- 闭环断言 (文件派生, 非persona)

---

## 4. 根本发现

1. **人格 ≠ 语言表面**, 人格 = 价值函数 + 决策模式 + 无意识性
2. **前两者可复现, 第三者不可** (AI根本局限)
3. **成璐决策 = 断言 + conf** (不是选项 + conf)
4. **去AI味主战场是结构层** (句长std), 不是词表
5. **"决策已完成"是文件派生**, 不是persona特征 (replication-test-result-v2.md:51)

## 6. 结论

**方向A (复现思路和人格):**
- ✅ 价值函数可复现 (公理层)
- ✅ 决策模式可复现 (7条persona规则)
- ✅ 语言风格可复现 (C三层)
- ⚠️ 聊天格式可模仿 (但"设计过")
- ❌ 无意识性不可复现 (AI根本局限)

**方向B (去除AI味):**
- ✅ 引导式去AI味有效 (四轴/三指纹/组合)
- ✅ 词表排除≈0 (结构层主战场)
- ✅ D组合最优 (改动最小+自然度最高)

**最终方案:**
公理层 + C三层 + 聊天格式 + 项目记忆 (仍缺无意识性)
