# r15 实验结论 — persona/voice 对齐

> origin: ai | 2026-10-19 | 阶段 04.5 反方复核前
> 实验: 实验1(C三层盲生成) + 实验2(去AI味4-way消融)

## 消融结论

**1. 词表(纯排除式)收益≈0** — 只删1个"其实"，结构问题还在。证实"词表是症状不是病"。
- A词表 vs 原稿: AI味词从1→0(删"其实")，句长avg 38.4(原稿~40)，结构零改动。
- 结论: 纯排除式不够，必须改结构。

**2. 结构改写(四轴/三指纹)收益最大** — 句长std从~20提升到21-24(节奏更两极)，setup段首→结论前置。
- C三指纹: 5个段首加<10字短句打断节奏，2处setup段首改结论前置。
- D组合: 质量底线锁定→三指纹(节奏+段首)→四轴(加1处"说实话")→词表(仅1处)。
- 结论: 结构层是主战场。

**3. D组合改动最小且自然度最高** — 自评盲评自然度最高，改动最小化且均为标志手法。
- D vs C三指纹: D多了1处"说实话"级自我暴露(四轴Human轴)，词表只删"其实"。
- D vs B四轴: D以移位+打断为主，B因"加案例"引入了原文没有的内容(信息保留率最低~97)。
- 结论: D组合(4层方案)是最优去AI味流程。

**4. C三层盲生成** — 比A-old好很多，但"闭环"×3是主要AI味来源。
- 句长avg 27.8偏短(目标30-45)，std 16.1偏低(节奏不够两极)。
- "闭环"是成璐语料不常见词，3次过密。
- 结论: C三层prompt方向正确(描述性>机械规则式)，但需调B层软目标(句长区间+闭环频率上限)。

## 核心发现(回写 persona-axioms P9)

**C三层 > A(16规则spec)**: C三层用软目标分布(句长30-45/第一人称0.6-0.7)，A用16条规则spec(逐条约束)。
- C三层盲生成: 句长avg 27.8(偏短但在区间内)，节奏有变化(std 16.1)。
- A(16规则)从r10: 逻辑9.2超调，cos0.699偏低(峰值成璐)。
- 原因: 16条规则spec过密→过拟合峰值(每条都执行=密度超调)；C三层用描述性行为规则+软目标分布→均值成璐。
- P9再验证: **MDL表达约束(软目标分布) > 逐句命令(16规则spec)**，与r10结论一致。

## 04.5 反方复核

**反方1: 样本量 n=1**
- 实验1只测S2一个场景，实验2只改写A-old的S2输出。
- 风险: S2可能是特例(元评估类，成璐语料里占比高)。
- 缓解: r10已有4场景交叉验证(GT/A-16/AX-4/B-generic)，r15补充S2单场景深度实验。
- 建议: 下一轮扩展S1/S3/S4场景验证C三层prompt。

**反方2: 评分脚本粗糙**
- 只算了字数/句长/第一人称/所以但是/AI味词，没算: 苏格拉底自问率/生活类比数/加粗密度/硬数字数/置信度词分布。
- 风险: 漏掉了成璐风格的关键维度(苏格拉底+类比+硬数字是7手法中最重要的3个)。
- 缓解: scenario-score.py 有完整7维度评分，本脚本只是快速对比。
- 建议: 下一轮用 scenario-score.py 跑完整7维度对比。

**反方3: 去AI味≠风格对齐**
- 实验2证明"去AI味"有效(AI味词→0)，但不证明"风格对齐"(像成璐)。
- 去AI味是必要条件，不是充分条件。去AI味后的文本可能"不像AI"但也不像成璐。
- 风险: 成璐反馈"persona/voice都不能对齐"，去AI味只解决了"不像AI"，没解决"像成璐"。
- 缓解: 实验1(C三层盲生成)同时解决两个问题(去AI味+风格对齐)，结果比A-old好。
- 建议: 下一轮做盲测(把C三层输出+A-old输出+GT-S2混在一起，让subagent猜哪个是成璐)。

**反方4: "闭环"×3 是 C三层 prompt 的 bug**
- C三层 prompt 的A层写了"贝叶斯闭环: 每个判断标当前置信度"，subagent可能把"闭环"当成成璐常用词。
- 成璐语料里"闭环"频率低(不是标志词)。
- 修复: C三层 prompt A层删掉"贝叶斯闭环"这个表述，改成"先验→证据→后验"。

## 结论

1. **去AI味**: D组合(4层方案: 质量底线→三指纹→四轴→词表)最优。词表收益≈0，结构层是主战场。
2. **风格复刻**: C三层(描述性50%+量化30%+样例20%) > A(16规则spec)。软目标分布 > 逐句命令。
3. **P9再验证**: MDL表达约束成立。压缩世界→更短的程序(软目标分布)复现更多观测(风格)。
4. **下一步**: ①修C三层prompt(删"闭环"表述+调B层句长区间) ②扩展S1/S3/S4场景 ③scenario-score.py完整7维度 ④盲测(猜哪个是成璐)。

## 04.5 反方复核 (r19, 最终)

### 质疑1: 盲测命中GT ≠ 风格对齐
- 盲评者命中GT靠的是"无意识性"(编号无规律/跑题真岔了/界面残留), 不是"语言风格"
- 聊天格式(W)能模仿表面(粗口/Show more/编号), 但无法模仿无意识性
- **真人raw的"不体面"是无意识的, AI模仿的"不体面"是设计过的** = AI根本局限

### 质疑2: C三层v2 "AI扮AI" 问题
- Y(C三层v2) 整段是"AI在解释自己"(RLHF reward/训练信号), 成璐是审视方不是被审视的AI
- 角色锚定修复后AI自称减少, 但S2场景(讨论AI元评估)天然需要AI自我指涉
- 这不是prompt bug, 是场景特殊性

### 质疑3: n=1 盲测
- 3轮盲测(v1未命中/v2命中/v3命中) 样本量太小
- 但3轮趋势一致: 角色锚定修复后命中, 聊天格式是强干扰项

### 最终综合结论 (r15-r19)

**方向A: 描述性prompt激发风格**
- C三层(描述性50%+量化30%+样例20%) 有效改善语言风格: 闭环0/AI味词0/第一人称显著增加/所以>但是达标
- 角色锚定是关键bug: v1暴露AI自称, v2修复后盲测命中GT
- **但无法复现"无意识性"** — 这是AI根本局限

**方向B: 去AI味**
- 词表收益≈0(只删1个"其实")
- 结构层是主战场(句长std 21-24)
- D组合(三指纹: 句长两极化/去夸张/限"不是…而是"频率) 最优
- C三层+D组合 = 去AI味最优方案

**方向C: 聊天格式模仿 (r19新增)**
- 能模仿表面格式(粗口/Show more/编号混乱/跑题)
- 无法模仿无意识性(X编号无意识混乱 vs W有意识规整)
- 聊天格式是强干扰项, 但盲评者仍能区分

**根本发现: 格式vs风格vs无意识性**
1. **语言风格** (C三层): 可复现, 但只是表面
2. **聊天格式** (r19): 可模仿, 但"设计过"的
3. **无意识性** (GT): 不可复现, 这是AI根本局限

**人格 ≠ 语言表面**
- 人格 = 价值函数(公理A0-A3) + 决策模式 + 无意识性
- 前两者可复现, 第三者不可
- 最接近成璐的方案: C三层(语言) + 聊天格式(格式) + 公理层(价值函数), 但仍缺无意识性
