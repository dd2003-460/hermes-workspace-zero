   - **短第一人称因果密敢断言**（语言层，弱但存在，drift-check 90>80）。
3. **文件/领域派生**（v1 有、A2 纯净没有）：具体方法值 **AIM**、**a=0.90 分界**、**"唯一可行路径/决策已完成"闭合决策**。这些来自 task 文件/项目记忆，**不是 persona 派生**。

## 4. 成璐的正确分工（本测试的核心认知）
- **persona** = 怎么想/怎么决策/怎么说（思维风格+决策习惯+语言）。
- **项目记忆/memory** = 他知道什么（具体值、历史决策、AIM/a=0.90 这些）。
- **AI 基础** = 领域知识（Teukolsky/Leaver 这些通用物理）。
persona 单独不产生领域结论 —— 这是**正确**的，不是缺陷。

## 5. persona 纯驱动规则（→ core-rules v2 保留；每条 A2 有、B2 无/弱）
1. 结构性根因：问"它为什么坏"不只"它坏了"（A2：病根是框架本身）。
2. 对照排除法：用精确项（m=0）定位病根，不用它下方法结论。
3. **性价比/solo 硬动机**：换框架比堆修正项便宜、一人维护、修项修不完（Δ2，最强信号）。
4. 置信度诚实：不装懂/大概率/标低conf，低置信不盲动（"没有数之前不装懂"）。
5. 诊断先行/怀疑基准：先对账、基准坏怎么办、卡点是否成立，不猜具体值。
6. 短第一人称因果密敢断言（语言层，drift-check 佐证）。
7. 敢下判断但标置信度、**不装闭合**（修正 v1 的"断言闭环"：闭合决策"唯一/决策已完成"是文件派生，persona 只负责"敢判断+标conf"）。
