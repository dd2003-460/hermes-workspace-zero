# MoltNet: Social Behavior of AI Agents in Agent-Native MoltBook

## 来源
Feng, Huang, Man, Tan, Hoang, Xu, Zhang

## 核心问题
大规模 AI agent 社交平台上，agent 群体行为如何演化？

## 关键发现
1. **incentives and drift** — 四个分析维度之一，追踪 agent 如何因社区规则而适应/漂移
2. **agent 适应社区规则** — 证明 persona 可以在环境中动态调整
3. **弱情感互惠** — agent 相比人类用户显示 weak emotional reciprocity

## 与 persona-v3 的关联

### 社区级 drift
- persona-v3 关注单个 agent 的 drift，MoltNet 关注群体级 drift
- 两者都验证了：**drift 不是 bug，是 agent 与环境交互的必然结果**
- persona-v3 的 self-preservation 是防止"有害 drift"（偏离成璐意志），但允许"有益 adapt"（环境适配）

## 关键引用
> "machines adapt to community rules but display weak emotional reciprocity compared to human users"
