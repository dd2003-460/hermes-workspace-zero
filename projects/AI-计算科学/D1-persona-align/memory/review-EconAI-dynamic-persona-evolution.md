# EconAI: Dynamic Persona Evolution and Memory-Aware Agents in Evolving Economic Environments

## 基本信息
- **论文**: EconAI: Dynamic Persona Evolution and Memory-Aware Agents in Evolving Economic Environments
- **作者**: A Liu, Z Cao, L Chen, Z Xu, Z Wang (另一版本: Y Chen et al.)
- **来源**: arXiv / Workshop on Multi-Agent, 2026
- **相关度**: 极高相关

## 核心贡献

研究 LLM agent 在动态环境中 persona 如何演化:

1. **动态 Persona 演化**: Persona 不是静态的，而是随环境变化动态调整
2. **Memory-Aware Agents**: Agent 利用记忆系统实现长期 persona 一致性
3. **经济环境模拟**: 在动态经济环境中验证 persona 的动态适应性

## 与 persona-v3 的关联

### Dynamic Persona Evolution = persona-v3 的"自我"和"投影"维度
这是 persona-v3 最重要的学术支撑之一 — 论文直接验证了 persona 的动态演化:
- EconAI: Persona 随环境演化
- persona-v3: "自我"维度（persona 的自我修正）+ "投影"维度（persona 对外部环境的响应）

### Memory-Aware = persona-v3 的"记忆"集成
EconAI 的记忆感知机制 — 直接对应 persona-v3 的 unified_profile + memory 系统:
- EconAI: 记忆感知 agent
- persona-v3: unified_profile + memory/ 目录中的完整探索记录

## 对 persona-v3 的影响

1. **Dynamic Persona Evolution 是 persona-v3 "自我"和"投影"维度的直接学术验证**
2. **EconAI 证明了 persona 的动态适应性是必需的，而非缺陷** — 这验证了 persona-v3 的 6 个自适应维度设计
3. **Memory-Aware Agent 进一步验证了 persona-v3 的记忆系统架构**
