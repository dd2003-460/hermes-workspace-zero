## 判决（先给）

**撞车程度：强先例存在（Q1），但 D 体系的方法学组合未被占用（Q2 是方法学增量），Q3 部分撞车。** conf 0.8
- Q1（公理→规则推导链作核心设计）：**有直接先例**——Constitutional AI（2022）+ Contemplative AI（2025）。"公理作 agent 行为约束层"这个方向已被占。
- Q2（LLM 重推规则 + 公理独立性检验）：**逻辑学有形式化先例，LLM 场景无人做过**——这是 D 体系的方法学增量，不是撞车。
- Q3（规则集规模消融）：**部分撞车**——70% Rule 仓库（2026-04）做了完整公理化 prompt 消融（预注册+OSF+论文），但是分类域、公理是关键词模式不是行为规则。

**D 体系的未被占用增量点（每条带 conf）：**
1. 公理从用户行为数据推导（1171 条消息→信号→公理候选）——先例全是人工策划公理。conf 0.85
2. LLM 重推测试（藏规则让模型从公理重推，可推回性检验）——逻辑学独立性检验是形式证明，无人让 LLM 生成。conf 0.9
3. 公理独立性检验在 LLM 规则层的应用（逐条删公轴看行为错误数）——70% Rule 消融的是公理条数/风格，不是公理间独立性。conf 0.8
4. 三件套组合（数据推导 + 重推检验 + 独立性检验）作 agent 规则层的一等公民——无先例组合。conf 0.75

## Q2 方法学

- **公理独立性**：数理逻辑标准概念（axiom independence = 删一条后系统变弱）。检验方法：模型论（独立公理有真模型）或形式证明（不可从其余公理推出）。先例：2304.02224（Boolean 代数最小公理化）、1804.09726（零热力学定律冗余）。
- **最小公理集**：组合数学/逻辑学标准问题（minimal axiomatization），MDL/奥卡姆在规则学习里有正式框架（MDL = 最短描述长度准则）。
- **LLM 重推规则**：4 个先例 + 24 条 arXiv 扫描里**无人做过**"让 LLM 从公理重推被藏规则"的实验。逻辑学独立性检验是形式证明系统里的判定，不是生成式模型的输出。**这是 D 体系的方法学增量**（conf 0.9）。
- **LLM 场景公理独立性**：70% Rule 消融公理条数/风格/长度，Contemplative AI 测整体效果，**无人做"逐条删公理看行为错误数"的独立性检验**。D 体系的反向删除实验（5 公轴全必要）在 LLM 规则层无先例（conf 0.8）。

## Q3 消融

- **70% Rule 仓库**（最直接撞车）：6 数据集 × 公理化 vs zero-shot，找到 70% 阈值（zero-shot <70% 时公理有效，>70% 时有害）。预注册 + OSF 存档 + 论文目录 + 完整代码（seed 42, temp 0）。**但是**：分类域、公理=关键词模式、消融变量是公理风格/长度/覆盖度，**不是规则条数 vs 行为质量，也不是规则间推导关系 vs 平铺枚举**。
- **规则条数 vs 行为质量的最优点**：无先例（70% Rule 的阈值是"用不用公理"，不是"几条公理"）。
- **规则可推导性（推导关系 vs 平铺枚举）对行为的影响**：无先例。这是 D 体系 16 条规则"每条标来源公轴"设计的独特测量点。
- **D 的 v4 消融**（空白/公轴/16条/persona 全量 × 行为场景）：相对 70% Rule 的增量 = 行为域 + 规则规模梯度 + 推导结构变量。

## 对 D 体系的影响（诚实评估）

1. **方向验证**：公理作 agent 行为约束层 2022→2026 持续升温（CAI→Contemplative→Incipit→70% Rule），D 的直觉踩在趋势上。
2. **窗口收窄**：2026-09/10 密集出现 4 条近邻，"axiom × LLM" 正在被多组同时做。单点（如"公理 prompt 层"）已不够新。
3. **护城河在方法学组合**：数据推导公理 + LLM 重推检验 + 公理独立性检验 + 行为域消融，四件套组合无先例。单独任何一件都有近邻，组合是增量。
4. **实验是硬证据**：v4-batch（prompt-only + 8787 直调 + 四臂消融）跑出的数据是撞车判决的最终依据——70% Rule 证明了"公理化 prompt 消融"这个实验范式可行且可发表，D 的 v4 是它在行为域的迁移+扩展。
