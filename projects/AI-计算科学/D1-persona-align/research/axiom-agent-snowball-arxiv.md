## 1. 最相关 4 条近邻（按相关度排序）

### 1.1 Incipit: Axiom-Grounded Scaffolding (2609.31007, 2026-09) ★最相关
- 公理作为**可检查的上下文层**：1455 条文学公理 + 472 条类型化关系 → 检索-选择管道 → 三级蓝图（创意前提/故事节拍/章节大纲），写作者可检查编辑后再当 context 喂生成
- **与我们撞的部分**：公理系统作为 prompt 层行为约束、可检查/可编辑、"区分 axiom grounding 贡献 vs 层级规划贡献"的预注册评估设计（= 消融思想！）
- **不撞的部分**：文学创作域，不是 agent 行为；公理是人工策划的（curated），不是从行为数据推导的；没有独立性检验
- **可借鉴**：他们的"区分贡献"评估设计正是我们要做的消融；预注册思想

### 1.2 Axiomatic World Modeling / RLAWM (2610.24519, 2026-10)
- 发现失败模式 **modeling drift**：模型悄悄篡改给定量、编造定律、注入未声明假设，在"被腐蚀的世界"里推理
- 解法：RL 训练时惩罚"模型内部公理世界模型 (AWM) vs 真实世界"的漂移；两级奖励（modeling 层 + solving 层）
- **与我们撞的部分**：概念上同源——"agent 的公理系统 vs 真实世界"的偏差测量；"未声明假设注入"正是我们场景 A 里 A2 的行为
- **不撞的部分**：RL 训练时干预（改权重），我们是 prompt 层（不改权重）；物理推理域
- **可借鉴**：两级评分结构（modeling vs solving）可直接搬进我们的 judge 脚本

### 1.3 Fewer Assumptions by Design (2609.34886, 2026-09)
- LLM 辅助 Verus 形式化验证：最小化 trusted base（公理引理 + assume 语句）
- 结论：设计好的 skill（领域知识+任务分解策略）能让 LLM 生成强而低信任基础的规约
- **与我们撞的部分**："最小公理集 = 更强行为"的命题方向一致（我们的压缩律：短程序复现观察即懂）
- **不撞的部分**：形式化验证域，公理是数学引理不是行为规则

### 1.4 Axiom Satisfiability of Linear Rewards (2610.06892, 2026-09)
- 纯数学：线性奖励拟合违反 PO/PMC 公理时，强制满足公理的代价（slack）有界
- **不撞**：数学工具论文，但"公理可满足性有代价"的结论对我们有启发——公理集内部可能不可同时满足，这正是"独立性检验"要测的

## 3. 我们的独特性（相对 4 条近邻）
1. **公理从行为数据推导**（Incipit 是人工策划；我们是 D 的 1171 条消息 → 信号提取 → 公理候选）
2. **prompt 层不改权重**（RLAWM 是 RL 训练；我们是 27b + prompt + hook）
3. **独立性检验作为一等公民**（4 条近邻都没做"删一条公理看行为是否塌"的消融；Incipit 提了预注册评估但没做）
4. **agent 行为域**（4 条近邻分别是文学/物理/形式验证/数学，无一是通用 agent 行为）

## 4. 风险
- "axiom × LLM" 2026 年 9-10 月密集出现（4 条近邻全是 2026-09/10），方向在升温，窗口在收窄
