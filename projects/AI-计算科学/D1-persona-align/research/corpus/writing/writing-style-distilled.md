## 2. 风格特征（REDUCE 结论）

### 2.1 开场模式
- **反问开场**：每节以"你有没有想过，为什么 X？"式反问起笔（§1 L3）
- **预判读者回应**：紧跟"你可能会说：[预判]。没错，但这背后的逻辑比你想的更惊人。"（L5）— 先替读者说出浅层答案，再否定/加深
- 第二人称"你"贯穿，口语化但逻辑严密

### 2.2 论证节奏（固定节拍）
1. 提问（为什么 X？）
2. 条件枚举（X 需要什么条件？…）
3. 核心机制一句话（因为每个条件都是小概率事件，联合概率接近于零）
4. **生活类比**（`\textit{生活类比}` 标注：中彩票、调查人类群体"活着概率100%"）
5. **读者行为预测框**（tcolorbox 黄色：`现在你可能想反驳：… \textbf{啊哈，我就猜到你会这么想。}`）
6. 机制解释（这个效应会让我们产生错觉——…）
7. **严谨推导框**（tcolorbox 灰色，标题"严谨推导（可跳过）"，\small，数学形式化）
8. **逻辑衔接段**（`\paragraph*{逻辑衔接}`：总结刚讲完的 + 抛出更深层问题）
9. 节末哲学钩子（把问题推给下一节："这就是人存原理要回答的核心问题"）

### 2.3 排版签名
| 元素 | 用法 |
|------|------|
| `\textbf{}` | 核心概念加粗（存在、观察者选择效应、人存原理） |
| `\textit{}` | 类比、引述、读者的话 |
| tcolorbox 黄 | `读者行为预测`：预判反驳 + "啊哈，我就猜到你会这么想" |
| tcolorbox 灰 | `严谨推导（可跳过）`：数学形式，\small，可跳过标注 |
| `\paragraph*{逻辑衔接}` | 过渡段固定标题 |
| `\subsubsection*{补充说明：…}` | 数学补充块标题 |
| 短段 | 1-2 句一段，问答式节奏 |

### 2.4 语气
- 自信但不傲慢："啊哈，我就猜到你会这么想"（幽默）
- 不堆术语：先生活类比再上数学（中彩票 → 联合概率 → 条件概率公式）
- 数学块明确标"可跳过"（尊重读者）
- 每节末必留钩子（制造继续阅读动力）

### 2.5 禁用
- 不用"首先/其次/最后"式列表（用叙事节奏代替）
- 不在正文堆公式（公式只在灰框里）
- 不用"值得注意的是""需要指出"等学术腔
- 不预判失败读者（"你可能觉得这太简单了"）

## 4. Few-shot（语料原文节选）

> 你有没有想过，为什么宇宙中没有到处都是生命？
>
> 你可能会说：\textit{因为条件太苛刻了。}没错，但这背后的逻辑比你想的更惊人。
>
> \textit{生活类比}：这就像中彩票——选对一个数字很难，选对七个数字更难，连续选对七次难到几乎不可能。
>
> \begin{tcolorbox}[colback=yellow!5, title=\textit{读者行为预测}]
> 现在你可能想反驳：\textit{如果存在这么难，为什么我周围充满了存在的东西？}\\
> \textbf{啊哈，我就猜到你会这么想。这个问题的答案，在于\textit{观察者选择效应}。}
> \end{tcolorbox}
