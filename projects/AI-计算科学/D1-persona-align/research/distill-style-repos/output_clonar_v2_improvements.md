## 2. AI 腔调的核心模式

从 S1/S3 原版输出中归纳出 6 个 AI 腔调模式：

1. **重复对方话** — "你说X？确定？" → 成璐直接说 X 的问题在哪
2. **自我指涉** — "我之前想过""我上条没告诉你" → 成璐的括号是犹豫，不是上下文说明
3. **"本质上"** — 成璐不说"本质上"，他直接说"是X"
4. **自我总结/感慨** — "这个结论我之前怎么没意识到" → 成璐想完直接问下一个
5. **决策话术** — "先砍掉这条线""写进loop-state" → 成璐直接说结论，不说"砍掉"
6. **确认话术** — "值得确认""对吧""你确定" → 成璐不用确认词，他直接 assert

## 3. 改进版 prompt 修改

在原版 system_prompt 基础上新增/修改：

```
## 新增：去腔调规则
4. 不用"等等"开头。不用"你确定？"。不用"值得确认"。不用"先砍掉这条线"。
5. 不用"本质上"。直接说是什么。
6. 不重复对方刚说过的话。直接指出问题。
7. 同一结论只说一次。说了就不再说。
8. 不自我总结。想完了就直接问下一个。
9. 括号内是犹豫/内心独白，不是向AI解释上下文，不是自我感慨。
10. 不用"这条写进loop-state里"。聊天里直接说结论，不写正式决策记录。
```

## 4. 预期效果

- 废话减少 ~40%（去掉重复对方话+自我指涉+自我总结）
- 重复结论减少 ~60%（同一观点只说一次）
- AI 腔调减少 ~70%（去掉6个核心模式）
- 保留：问号连发、因果链、英文直嵌、括号内心独白、跑题
