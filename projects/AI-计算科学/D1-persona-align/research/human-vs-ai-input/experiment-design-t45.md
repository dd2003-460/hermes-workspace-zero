# T45 最终交付：1-2 个同风格样本 few-shot 实验设计

> origin: ai · 2026-10-22 · goal-0b22f789 r2
> 目的：验证 RESEARCH.md 核心假设 H1（人类 few-shot → burstiness↑）+ H4（只转表层）

## 1. 实验目的

验证：用 1-2 个成璐同风格样本做 few-shot → GPT-4o 输出 burstiness↑（更散）+ 人味检测分↑，但观点/矛盾密度不变（H4）。

## 2. 样本选取

**体裁**：技术笔记 / 研究日志（与成璐日常写作一致）
**风格多样**：1 个偏形式化（含公式/引用）+ 1 个偏直觉（含"我觉得"/类比）
**排除**：最近 2 周主题（避免 same-topic 反降归因 69.33%→36.00%）
**来源**：`/Users/a1-6/Desktop/workspace/raw-human/raw.md`（截取 2 段，各 300-500 词）

## 3. 前缀设计

50 词真实前缀（从 raw/ 截取，含成璐原声 + 任务描述）：
```
[前缀示例] 我们在做一个 27B 模型的硬件选择实验，需要比较 3090/A100/L40S/M2 Ultra 的 TCO。
关键约束：64K 上下文，90:9:1 缓存比例，decode ≥ 20 tok/s。我觉得带宽是瓶颈，但算力也不能忽略...
```

## 4. 对照组

**A 组（baseline）**：无前缀 + 无 few-shot（纯任务描述）
**B 组（few-shot）**：50 词前缀 + 1-2 个同风格样本 + 任务描述

## 5. 测量指标

- **burstiness**：输出 token 长度标准差/均值（越高越散）
- **人味检测**：GPTZero/ZeroGPT 人味分（%）
- **观点密度**：每 100 词观点句数（"我觉得"/"但是"/矛盾标记）
- **矛盾密度**：每 100 词矛盾标记数（"A 且 B"/"虽然...但是"）

## 6. 样本量

≥5 trials/组（n=1 无统计力，RESEARCH.md 已验证）

## 7. 盲评流程

双盲：评分人不知 which is A/B；用脚本随机化顺序 + 匿名编号

## 8. 预期结果

**H1 成立条件**：B 组 burstiness > A 组（Δ > 2σ）
**H4 成立条件**：B 组观点密度/矛盾密度 ≈ A 组（Δ < 2σ）

## 9. 执行步骤

```bash
# 1. 截取样本（从 raw/ 选 2 段，各 300-500 词）
# 2. 构造 prompt（A/B 组各 5 trials）
# 3. 跑 GPT-4o（5 trials × 2 组 = 10 次调用）
# 4. 测量 burstiness + 人味检测 + 观点/矛盾密度
# 5. 盲评（随机化 + 匿名）
# 6. 统计检验（t-test Δ > 2σ）
```
