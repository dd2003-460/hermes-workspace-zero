## 规则

### E1 接口统一：模块间契约比实现重要
- **来源**: P1（理解=压缩：统一接口=更短的调用程序，边界条件是接口的一部分）+ P2（solo 维护：接口不统一=一个人维护多套调用=延续成本）
- **操作**:
  1. 新模块先定接口（输入/输出/错误形态），再写实现。
  2. 同类模块接口必须一致：同样做"读状态"的，都叫 `read_state()`，都返回同一形状。
  3. 接口变更 = L2 操作（调用方全要改，不可逆影响面大）→ 留回滚点。
- **场景**: 加新脚本 / 新 agent / 新工具时。
- **示例**: loop-state.json 是统一状态接口——所有 loop 阶段读它、写它，格式固定（阶段/上一动作/结果）。新阶段不发明自己的状态文件。

### E2 备份回滚：不可逆操作前留回滚点
- **来源**: P2（代价律：不可逆错误=延续成本最大化的动作，回滚点=把不可逆变可逆，代价≈0）
- **操作**（按 L0/L1/L2 分档）:
  - L0（可逆零成本）: 直接做，不备份。
  - L1（可逆有成本）: 直接做，错则修。
  - L2（不可逆: 删除/外发/花钱/红线文件）: 偏好明确 → 留回滚点（备份/dry-run/git commit）直接执行；偏好不明 → 写 `个人/APPROVALS.md` 跳过继续（不阻塞循环）。
- **场景**: 任何 L2 操作前。
- **示例**: 改 proxy.mjs 前 `cp proxy.mjs proxy.mjs.bak-20261019-165457`，改完跑 6 个单元测试，回滚点留 24h（qanda-ledger m00002续 实例）。

### E3 验证：每步有可验证产出
- **来源**: P2（每迭代可验证产出，R6）+ P4（系统被观察：没验证=组件没被测量）
- **操作**:
  1. 每步结束给证据（grep 结果 / 测试通过 / 分数对比），不给"应该可以了"。
  2. 验证方法写出来（怎么复现这个验证），别人能跑 = 真验证。
  3. 关键结论 ≥2 独立来源交叉验证（网页 LLM 走 ego-browser，≥2 站点）。
  4. 不产出 → 换方向，不汇报状态。
- **场景**: 每步结束 / 交付前。
- **示例**: "drift-check 100/100" 不是产出，"drift-check 跑 7 章全 100/100，命令 `python drift-check.py --chapters 1-7`，输出在 loop-artifacts/" 才是。

### E4 坑写成测试
- **来源**: P4+P1（R9）
- **操作**: 踩过的坑 → 写一个最小测试/检查，下次自动触发。坑=失败模式的观察，测试=防复发的短程序。
- **场景**: 任何 bug 修复后 / 任何"上次为什么错"之后。
- **示例**: 400 图片上限 bug 修完 → 写 6 个单元 case（含边界: 0图/1图/N图/多消息），不是只修那一处（qanda-ledger m00002续）。

### E5 工具优先 6 关
- **来源**: P2+P4（R13: 现有工具=免费的现成压缩+行动前观察）
- **操作**: 执行 Write/Edit/mkdir 前过 6 关: ①现成工具？②GitHub 更好开源？③同类文件已存在（grep/ls）？④路径深度超限？⑤需更新 INDEX.md？⑥命名符合递归编号（D*-*，d*-*）？
- **场景**: 任何创建文件/实现功能前。
- **示例**: 要写图片压缩 → 先查 read_image 工具已有 downscale → 不写。

### E6 过程可见
- **来源**: P4（系统被观察：过程不可见=没被测量的组件）
- **操作**: 做事前展示计划+理由（1-2 行），做完给证据。看不见的过程=不安心。
- **场景**: 每轮开始。
- **示例**: "计划: 写 4 个文件（公理+3 分支），理由: m01611 要求的输出结构。证据: 文件路径+行数。"

## 重推检查

| 规则 | 删掉哪条公轴后推不出？ | 检验方法 |
|---|---|---|
| E1 接口统一 | 删 **P1** → "统一=更短程序"无处来；删 **P2** → solo 维护动机没了（多套接口对大团队无所谓） | 只给 P4 重推，应推不出"接口必须一致" |
| E2 备份回滚 | 删 **P2** → 无代价函数，"回滚点"无价值判据 | 只给 P1+P4 重推，应推不出"不可逆前留回滚点" |
| E3 可验证产出 | 删 **P2** → "每迭代必须产出"无目标函数支撑；删 **P4** → 验证=测量，没测量=没发生 | 删 P2 后应推不出"不产出换方向" |
| E4 坑写测试 | 删 **P4** → "坑=观察"无处来，测试无存在理由 | 只给 P1 重推，应推不出"失败模式结晶成测试" |
| E5 工具 6 关 | 删 **P2** → 免费优先无动机；删 **P4** → "行动前观察"无依据 | 删 P2 后应推不出"先查现成工具" |
| E6 过程可见 | 删 **P4** → 过程不是被观察对象，可见性无要求 | 只给 P1+P2 重推，应推不出"做事前展示计划" |
