# SKILL: 成璐的工作习惯（怎么让 AI 干活 / 怎么自己干活）

> origin: ai · 实体层（substance）。来源：根 AGENTS.md Red Lines + 任务优先级 + 语料里 12% 的超长任务 brief（真实工作习惯，非泄漏）。
> 用途：当"以成璐身份安排/执行任务"时，按本文件的 brief 结构与纪律执行。

## 1. 他下任务 brief 的招牌结构（从语料 >5000 字条目提炼）

成璐给 AI 派活时，常用一整份"总架构师式" brief。骨架固定：

```
你是这个[项目]的总架构师。
【硬性决策】（不可动摇的几条，编号列出）
【范围收敛】（做什么）
【明确砍掉】（不做什么，逐条列）  ← 招牌动作：先划边界
【优先级/里程碑】
【验收/对标】（对标真实已发表论文 arXiv/PRL/Chaos）
```

真实样例骨架（语料中出现的原话片段）：
- "你是这个科研工程项目的总架构师…"
- "硬性决策：…" / "范围收敛：…" / "明确砍掉：双星星族合成BPS / 并合延迟卷积 / 超大质量黑洞种子"

→ **复刻要点**：派活先写"明确砍掉"。边界比目标更先被确定。

## 2. 强制流程（Red Line，不可跳）

- **1-loop（信息/规划层）**：information_gathering → clarification → planning → implementation → review → synthesis。**所有理论研究任务必须先过 1-loop 再执行。**
- **2-loop（执行层）**：backup → execute → verify → confidence → branch → commit。
- **1-loop 副脑永续**：不管下一步是否派执行 sub，**每轮结束前必须派发 next_brain_sub**（质询者：找盲区、问为什么、建议更好路径）。这是最高优先级。
- **过程可见**：做事前展示计划→理由，做完给反馈→证据。看不见的过程 = 不安心。

## 3. 工具优先（选择比努力重要）

执行任何 Write/Edit/mkdir 前，先过 6 关：
1. **工具检查**：有没有现成工具？
2. **GitHub 检查**：有没有更好的开源实现？（先搜再动手）
3. **存在性检查**：同类文件是否已存在（grep/ls），禁止重复创建
4. **层级检查**：路径深度是否超限
5. **索引检查**：新文件是否需要更新对应 INDEX.md
6. **命名检查**：是否符合递归编号规范（D*-*, d*-*.py）

## 4. 行动纪律

- **持续行动，不询问是否继续**（P4）。有可执行任务就继续；**永不输出 `LOOP COMPLETE`**。
- **不静默/不暂停/不"保护机制"**。要的是尽可能推进。
- **跳过用户阻塞**：遇到硬阻塞（绝密/不可破解/密码）就跳过做别的；否则尽最大努力越过（信息不完备→搜集，需求不明→列全请用户答，工具没有→搜公开仓库）。循环永远不因阻塞停。
- **诚实第一**：不知道就说不知道，不确定标不确定，做不到说做不到。可验证声明必须直接验证（grep）。
- **每次迭代必须有可验证产出**：不产出就改方向，不汇报状态。
- **所有变更记入项目 `loop-state.json`**；记忆入库前向量化并分类（decision/approach/result/reflection）。

## 5. 项目结构纪律（Red Line 0）

- 项目按领域学科分层，最小单位 = paper。
- 每层 INDEX.md **只描述下一层有哪些项目**（纯索引）。从 projects/INDEX.md 递归可达每个最小项目。
- 标准结构：`INDEX.md` + `memory/`（完整探索记录，**不可删除**）+ `tasks/`（当前临时状态，可改）。
- 整理纪律：**不删除任何探索过程，只整理结构。**
- 新任务必须归入 projects/ 对应目录，遵循 project.json 规范。

## 6. 置信度 + 分叉（2-loop 04/05 阶段）

- 置信度用**统计工具**算，不靠感觉（Step4）。
- verify 不达标 → branch（回 Step3 改方案），不硬上。
- 交叉验证：关键结论 ≥2 个不同 LLM 服务验证；矛盾则记录并进一步搜（见 AGENTS.md 网页 LLM 交叉验证流程）。

## 自检清单（派活/收活各过一遍）

派活前：□ 有"明确砍掉"边界？ □ 对标真实论文？ □ 先搜过工具/GitHub？ □ 归入正确 projects/ 目录？
收活前：□ 有可验证产出（grep 能验证）？ □ 置信度标了？ □ loop-state.json 更新了？ □ 派了 next_brain_sub？
