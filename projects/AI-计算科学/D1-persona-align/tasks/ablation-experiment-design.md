# 去AI味 + 风格复刻 消融实验设计 (r15)

## 一、目标

验证 02.5 交叉验证的结论:
1. **三层架构**(A描述性50%+B量化30%+C样例20%) 是否比现有 A(16规则+voice spec) 更能避免"峰值超调"(逻辑密度 9.2→接近 GT 6.0)同时保留"像"(逻辑层手法方向)。
2. **去AI味4层方案**(质量底线→三指纹诊断→四轴验收→词表审查) 是否比单纯词表排除更有效。

## 二、实验1: 风格复刻 prompt 架构对比 (D1)

### 场景
复用 scenario-verification.md 的 S2(量化估算-元评估, GT 772字, 区分度最干净)。

### 对照组 (5-way)
| 组 | prompt | 预期 |
|---|---|---|
| GT | 成璐本人(参照) | 逻辑 6.0, cos ~1.0 |
| A-old | 现有 16规则+voice spec(peak) | 逻辑 9.2(超调), cos 0.742 |
| AX | 4公理(均值) | 逻辑 7.2, cos 0.907 |
| **C三层** | **新: A描述性50%+B量化30%+C样例20%** | **目标: 逻辑 6-7(接近GT), cos >0.85** |
| B | generic(无材料, 下界) | 逻辑 2.0, cos 0.507 |

### C三层 prompt 结构 (待 T2 完成后具体化)
- **A 描述性层 (50%)**: 成璐的判断机制/论证习惯/表达切换条件
  - 来源: persona.md L1-L3(身份/价值/怎么想) + how-i-think.md
  - 写法: 行为规则("你通常在...时先...再..."), 非形容词堆砌
  - 例: "遇到技术判断, 先给结论+置信度, 再给依据。不确定时标'我猜'或'大概'。"
- **B 量化层 (30%)**: 核心统计量+频率范围+触发条件
  - 来源: voice_features.md 真实统计
  - 写法: 软目标分布区间("平均句长30-45字", "第一人称率0.6-0.7"), 非逐句命令
  - 标志句式: "不是…而是"频率参考0.3/千字, 触发条件=纠偏/排除误解, 非口头禅
  - 特征词: "可能/应该/大概率/我猜" 频率参考, 非强制密铺
- **C 样例层 (20%)**: 3个典型段落+1个反例
  - 典型: GT-S2(结构丰富)/S1(性价比)/S3(短)
  - 反例: A-old 的超调输出(密铺编号+置信词, 说明"不要这样")

### 评分
- 逻辑层: 10签名手法 checklist(复用 scenario-verification.md)
- 语言层: 9维特征向量 cos + drift-check(复用 scenario-score.py)
- 新增: 密度指标(单场景手法数/千字), 验证"峰值超调"是否消除

### 通过标准
- C三层 逻辑层 6.0-7.5(接近 GT 6.0, 远低于 A-old 9.2)
- C三层 cos > 0.85(接近 AX 0.907)
- C三层 密度(手法/千字) 接近 GT, 非 A-old 的超调

## 三、实验2: 去AI味4层方案消融 (D2)

### 语料
从 A-old 的 S2 输出(已知峰值超调+密铺)生成"AI味"样本。

### 对照组 (4-way, 同原稿同模型同参数)
| 组 | 方法 | 预期 |
|---|---|---|
| A词表 | 纯排除式(检测AI味词就替换/删除) | 表面干净, 结构问题仍在 |
| B四轴 | 四轴框架(Plain/Human/Structured/Dense)评分+改写 | 结构改善, 但可能变"通用文风" |
| C三指纹 | 三结构性指纹诊断(节奏/空泛评价/模板化) + 改写 | 针对性强, 但3指纹未必覆盖全 |
| D组合 | 4层方案(质量底线→三指纹→四轴→词表审查) | 目标: 最有效 |

### 评分 (5维度, 不压缩成单一分数)
| 维度 | 度量 |
|---|---|
| 技术正确性 | 技术断言是否被改动/曲解(0-100) |
| 信息保留率 | 原文信息点保留比例(0-100) |
| 结构性AI味 | 三指纹命中数(越低越好) |
| 作者风格相似度 | 10手法 checklist(越高越好) |
| 盲评自然度 | 3个盲评(1-5分, "这段像人写的还是AI写的") |

### 通过标准
- D组合 在5维度上 ≥ 其他3组
- D组合 技术正确性 > 90(不为去AI味牺牲准确性)
- D组合 信息保留率 > 85
- D组合 结构性AI味 < A词表(词表无法处理结构问题)

## 四、执行依赖

- 实验1 依赖: T2(voice-anti-ai-zh.md 完成, 提供 C三层 prompt 的具体化) + 3个盲生成 subagent(同 A-old 协议)
- 实验2 依赖: T2 + 1个改写 subagent(对 A-old-S2 输出做4-way 改写)
- 评分脚本: 复用 scenario-score.py + 新增密度指标 + 新增5维度评分

## 五、caveat
- n=1 场景(S2, 选区分度最干净的) → 样本薄, 置信度 0.5
- 盲生成 subagent 用同底座(禁读 GT) → 隔离有效
- C三层 prompt 质量受"描述性层写得是否准确"约束 → 需人工校准 A层
- 实验2 盲评需 3 个独立评分者 → 用 3 个 subagent 盲评(禁读原稿)
