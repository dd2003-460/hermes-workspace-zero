## 归档清单与失败原因

| 文件 | 路线 | 失败原因（实验证据） |
|---|---|---|
| `c-three-layer-prompt.md` | 三层 spec（描述50/量化30/样例20） | 未锚定角色版把 AI 当"AI 回复用户"而非成璐本人→第一人称感低；加角色锚定后成历史中间稿。量化 spec 推高逻辑密度（峰值成璐≠均值成璐，P9：MDL 表达约束） |
| `chat-format-prompt.md` | 聊天格式硬模仿（粗口/跑题/编号混乱） | 可模仿表面但"设计过的"——真人 raw 的不体面是无意识的，AI 模仿是有意识的（r19 核心结论） |
| `opro-v3-prompt.md` | 排除式词表 | 物理动词跨域比喻污染（6 处）、AI 自称漏网；盲测 A 轴 7/10 偏高。词表路线收益≈0（消融 r16） |
| `opro-v4-prompt.md` | 排除式迭代 | 同上，机制相同 |
| `opro-v5-prompt.md` | 排除式+跨域比喻硬规则 | 3 处修复（跨域比喻/去比喻种子/自描述认知）方向对但绝对化（"不用比喻"→ 副脑质询后才发现连操作预期类比也禁了）；盲测过度收敛（A4/B34，跳跃感丢失） |
| `opro-v6-prompt.md` | 生成式单规则 | "你打字=你思考" 方向对（m01000 认可），但 537 字过短覆盖不够，中间稿 |
| `opro-v7-prompt.md` | 生成式扩展 | 中间稿，646 字/74 fragments；盲测 Y=34 之前版本 |
| `opro-v8-prompt.md` | 场景式零规则（主动跳跃描述） | 3 个修复全部失败：括号插话 0/自我暴露 0/编号比 v7 更整齐。根因：生成是连续的，模型不会"中断"自己——"主动跳跃"描述无效 |

## 保留在 experiments/ 的现役方案

- `opro-v8.1-prompt.md` — 被动中断描述（"你打字的时候经常被打断"）+ few-shot GT 原文。盲测 v6 胜出（轴B 34 最高 / 轴A 4 低），最像成璐。
- 配套后处理：`scripts/interruption_injector.py`（括号 0.4/千字 + 跳号 1.0/千字 + 截断 0.5/千字，确定性兜底）。
- `scene-guide-A/B-prompt.md` — r30 情景引导实验产物（A 纯场景最自然），保留作对照，非主力。

## 路线级结论（比单个 prompt 更重要）

1. **排除式词表 ≈ 无效**（消融：词表只删 1 个词，结构不变）。主战场是结构层（句长方差）。
2. **逐句命令式 spec 会超调**（逻辑密度 9.2 vs GT 6.0）。用软目标分布 + 场景描述。
3. **主动行为描述无效，被动状态描述有效**（v8 跳跃失败 vs v8.1 "被打断"成功）。
4. **角色锚定是前提**（"你是成璐本人非 AI"，第一人称 4→9/8→17）。
5. 完整证据链：`memory/persona-alignment-final-report.md`（r15-21）+ `memory/delivery-report-r29.md` + `memory/delivery-report-r30.md`。
