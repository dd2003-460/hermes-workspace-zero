## observer-dependent 信息论框架

成璐问了一个深刻的统计推断问题：**从身边的小样本（身边统计学）能推断出什么？**

形式化：设总体为 T，样本为 S ⊂ T。身边统计学是 S 的**选择偏差**。

```
S = {x ∈ T | x 在你的社交/信息圈中}
```

S 的选取机制不是随机的 — 它受到**社交结构、信息源、算法推荐**等因素的影响。

**选择偏差的信息论度量**：

```
D_KL(P(S) || P(T)) → 选择偏差的程度
```

如果 S 是随机样本 → D_KL(P(S) || P(T)) ≈ 0 → 无偏差
如果 S 是身边样本 → D_KL(P(S) || P(T)) >> 0 → 有严重偏差

**核心不等式**：
```
I(推断; T) ≤ I(样本; T) - D_KL(P(S) || P(T))
```

即：从样本 S 推断总体 T 的信息量，受选择偏差 D_KL 的惩罚。

## observer-dependent 机制追问

### observer-dependent 追问 1: 从 K 个样本推断 N（网络规模）

经典统计：从 K 个随机样本推断总体大小 N。

**最大似然估计（MLE）**：
```
N_hat = max(X₁, ..., X_K) · (K+1)/K
```

这是基于**标记-重捕法**（capture-mark-recapture）的经典公式。

但身边统计学的问题在于：**样本不是随机的**。

身边的样本受到**社交网络拓扑**的影响：
```
P(遇到 x | x ∈ S) ≠ P(x ∈ T)
```

而是：
```
P(遇到 x | x ∈ S) ∝ degree(x) · visibility(x) · algorithm_weight(x)
```

其中：
- degree(x) = x 的社交连接数
- visibility(x) = x 的可见度（媒体曝光等）
- algorithm_weight(x) = 推荐算法对 x 的加权

**结论**：身边的"大"个体被高估，"小"个体被低估 → 网络规模的推断有系统性偏差。

### observer-dependent 追问 2: 模因的代表性

成璐提到"模因的代表" — 你观察到的模因（meme）是否代表整个网络？

设模因 m 在网络中的真实频率为 p(m|T)。你身边观察到的频率为 p(m|S)。

**代表性度量**：
```
Repr(m) = p(m|S) / p(m|T)
```

如果 Repr(m) ≈ 1 → 代表性好
如果 Repr(m) >> 1 → 高估（m 在你的圈中过度代表）
如果 Repr(m) << 1 → 低估（m 在你的圈中被低估）

**问题**：在不知道 p(m|T) 的情况下，如何估计 Repr(m)？

一个**贝叶斯方法**：
```
p(m|S, α) ∝ p(S| m, α) · p(m|α)
```

其中 α 是**选择偏差参数**（描述 S 的选取机制）。

如果 α 已知 → 可以校正偏差
如果 α 未知 → 偏差不可恢复

**关键洞察**：α 通常**未知**（你不知道推荐算法如何工作，不知道你的社交网络如何影响你的信息输入）。

### observer-dependent 追问 3: 选择性样本的信息损失

选择性样本丢失的信息量：
```
Lost = I(T; T) - I(T; S) = H(T) - H(T|S)
```

其中：
- H(T) = 总体的信息熵（最大可能信息）
- H(T|S) = 给定 S 后的条件熵（剩余不确定性）

选择性样本的 H(T|S) >> H(T|随机样本) → 信息损失严重。

**信息损失的不可恢复性**：
```
如果 S 不是随机样本 → 无法从 S 中恢复关于 T 的完整信息
```

这是因为选择性样本引入了**结构性信息丢失** — 不是"样本不够"，而是"样本有偏"。

增加样本量 K 只能减少随机误差，不能减少选择偏差。

## observer-dependent 跨域类比

### observer-dependent 统计学：存活者偏差（Survivorship Bias）

二战期间，统计学家 Abraham Wald 分析了返航飞机上的弹孔分布：
- 弹孔集中在机翼 → 机翼中弹不会导致坠机
- 驾驶舱弹孔少 → 驾驶舱中弹会导致坠机（飞机无法返航）

**经典错误**：在弹孔多的地方加装甲（错误地认为那是脆弱点）
**正确做法**：在弹孔少的地方加装甲（那些位置的中弹会导致飞机无法返航）

**类比**：
- 返航飞机 = 可见样本（S）
- 坠机的飞机 = 不可见样本（T \ S）
- 身边统计学 = 只看到"返航飞机" → 错误推断

### observer-dependent 推荐系统：信息茧房

算法推荐系统根据你的历史行为选择信息：
```
P(看到内容 c | 历史 h) ∝ 相似性(c, h)
```

结果：你看到的内容越来越同质化 → p(c|S) 越来越偏离 p(c|T)。

**信息茧房** = 选择偏差的极端形式 → D_KL(P(S) || P(T)) → ∞

### observer-dependent 流行病学：抽样偏差

流行病学中的病例对照研究必须注意**抽样偏差**：
- 选择医院的病例 ≠ 选择总人口中的病例
- 医院病例可能更严重 → 病情估计有偏差

这与身边统计学完全同构：
```
医院 = 你的社交圈
病例 = 你身边的人
总人口 = 整个社会
```
