## observer-dependent 信息论框架

社会的分化与统一可以用**随机微分方程**建模：

```
dx/dt = -∇V(x) + η(t) + F+(x) + F-(x)
```

其中：
- V(x) 是"势场"（社会结构对个体的约束）
- η(t) 是噪声（个体不可控因素）
- F+(x) 是正反馈力（放大微小差异）
- F-(x) 是负反馈力（拉回平衡）

### observer-dependent 分化条件

当正反馈超过负反馈时：

```
|F+(x)| > |F-(x)| + σ_η
```

系统处于**双稳态或多稳态**区域 — 不同的群体演化到不同的吸引子，这就是"分化"。

### observer-dependent 统一条件

当负反馈主导时：

```
|F-(x)| > |F+(x)| + σ_η
```

系统收敛到单一吸引子 — 这是"统一"。

## observer-dependent 机制追问

### observer-dependent 追问 1: 正反馈的放大机制

正反馈在社会中的具体形式：

1. **信息级联**：一个早期信号被不断放大，后续个体只观察前人的选择而非自己的信息
2. **回声室效应**：相似观点的人聚集 → 更相似 → 更聚集（选择+强化的正反馈循环）
3. **马太效应**：已有优势的个体获得更多资源 → 优势更大
4. **身份极化**：小差异 → 身份标记 → 身份对抗 → 差异放大

这些机制的共同数学结构：

```
dx/dt = kx - γx³ + noise
```

k > 0: 正反馈系数（放大）
γ > 0: 饱和项（防止无限增长）

当 k > k_c（临界值），系统出现**对称性破缺** — 原来单一的吸引子分裂为多个。

### observer-dependent 追问 2: 负反馈的统一机制

负反馈在社会中的形式：

1. **制度约束**：法律、规范对偏离行为的惩罚
2. **市场调节**：供需关系对价格的拉回
3. **社交惩罚**：群体对极端观点的排斥
4. **共同外部威胁**：外部压力迫使内部统一

共同数学结构：

```
dx/dt = -γx + external Shock
```

γ > 0 越大，系统越"统一"（对扰动的恢复越快）。

### observer-dependent 追问 3: 历史周期率的反馈解释

"其兴也勃焉，其亡也忽焉" — 历史周期率的反馈解释：

1. **初期**：负反馈主导（新制度有明确目标，社会共识高） → 统一
2. **中期**：正反馈开始放大（利益集团形成，资源分配不均被放大） → 分化
3. **后期**：正反馈压倒负反馈 → 系统进入多稳态（不同群体走向不同未来） → 统一需要外部冲击重置

这是**Landau 理论**在社会科学中的直接应用 — 序参量的对称性破缺。

## observer-dependent 具体案例

### observer-dependent 案例 1: 美国政治极化

观察到的现象：
- 民主党/共和党的意识形态差距在过去 30 年扩大了一倍
- 两党支持者不再有重叠

反馈分析：
- 正反馈 1：媒体选择（Fox News → 共和党，MSNBC → 民主党）
- 正反馈 2：地理选择（自由派去沿海，保守派去内陆）
- 正反馈 3：社交选择（朋友越来越相似）
- 负反馈衰减：主流媒体衰落，"共同事实"消失

结果：k > k_c → 对称性破缺 → 社会分化。

### observer-dependent 案例 2: 中国改革开放前的统一

观察到的现象：
- 1950s-1970s 中国社会高度统一（但这是"强制统一"）
- 改革开放后分化加速（利益多元化）
- 但同时在某些领域又统一了（经济发展共识）

反馈分析：
- 负反馈强：意识形态控制（制度约束）
- 正反馈弱：市场机制受限（收入差距不放大）
- 改革开放后：正反馈增强（市场经济 = 马太效应） + 负反馈减弱（意识形态控制弱）
- 系统进入分化相
