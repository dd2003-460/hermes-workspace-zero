## observer-dependent 信息论框架

```
⟨u, v⟩ = Σᵢ uᵢvᵢ = u^T v
‖u‖ = √⟨u, u⟩
```

```
⟨f, g⟩ = ∫ f(x)g(x) dx
‖f‖ = √∫ |f(x)|² dx
```

**统一公式**：
```
⟨φ, ψ⟩ = ∫ φ(x)ψ(x) dμ(x)
```
