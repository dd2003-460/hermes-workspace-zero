## observer-dependent 机制追问

### observer-dependent 追问 1: 语义相似性与信息距离

"语义相似性"在信息论中等价于什么？

设两个词的语义分布为 P(w|c₁) 和 P(w|c₂)（即在语料库中的共现分布）。

语义相似性 = 1 - D_KL(P(w|c₁) || P(w|c₂))

其中 D_KL 是 KL 散度。

所以"语义相似" = "共现分布相似" = "信息论距离近"。

这就是分布式语义假设（distributed semantic hypothesis）的信息论基础：

> 词的含义由它的上下文分布决定。分布越相似 → 语义越接近 → 信息距离越小。

### observer-dependent 追问 2: "绕路不加距离"

成璐说"绕路不加距离" — 这是内蕴几何的核心特征：

在黎曼流形上，两点间的距离由测地线决定：

```
d(x, y) = inf ∫ sqrt(g_{μν} dx^μ dx^ν)
```

"绕路"在嵌入空间中等价于欧氏距离更长，但在**内蕴几何**中，绕路可能并不增加信息距离。

信息论解释：

```
I(X; Y) = H(X) - H(X|Y)
```

如果"绕路"不增加额外的熵（不引入新的信息维度），那么：

```
I(X绕路; Y) = I(X直接; Y)
```

即绕路在信息论上等价于直接路径。

这就是为什么"语言上绕路"（用比喻、隐喻）在语义上可能等价于"直接说" — 两者编码了相同的 I(X; Y)。

### observer-dependent 追问 3: "信息上绕路不是长"

这句话暗示：**信息距离 ≠ 物理距离**。

物理距离是欧氏空间的度量：
```
d_euc(x, y) = ||x - y||
```

信息距离是互信息的度量：
```
d_info(A, B) = 1 - I(A; B)
```

信息距离不关心路径的长度，只关心路径的信息保真度。

一条"长的"但"高信息保真"的路径，信息距离可能比一条"短的"但"低信息保真"的路径更近。

这就是为什么"用 1000 字详细解释"在信息距离上可能比"用 1 个字模糊概括"更近 — 前者保留了更多 I(A; B)。

### observer-dependent 语言 → 几何

"绕路" = 不直接使用已知定理，而是从头推导。信息论保证：如果从头推导的信息保真度 ≥ 直接引用，则推导更有教学价值。

### observer-dependent 信息论 → 物理

这暗示语言和信息共享同一底层动力学。
