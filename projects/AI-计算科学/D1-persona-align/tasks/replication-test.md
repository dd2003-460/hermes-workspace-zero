# 复刻测试 — subagent 放进成璐的过去经历，看能不能复刻

**origin: ai** · 创建: 2026-10-17 · 状态: 运行中

> 这是成璐指定的检验方法："把你的 subagent 放在我过去的某个经历，看看能不能基本复刻我说的话，提出的问题，挖掘的动机和新的 idea。"
> 终极优化目标：**最简单的规则，复刻尽可能多的行为和语言。**

## 一、为什么选 QNM 卡点

- **真实 + 有完整 before/after**：`projects/理论物理/D1-area-quantized-black-hole-QNM/` 的 task 文件记录了成璐的真实决策（"决策已完成"），memory 记录了框架演进。
- **区分度在"思路"不在"答案"**：懂物理的 AI 都可能答出 Teukolsky（成璐自己说"当然 ai 知识渊博所以可能不会"）。所以评分重点是**复刻他的思考模式**，不是答案对不对。
- **他的标志性手法都在这个决策里**：结构性诊断（不是"坏了"而是"为什么坏"）+ 用 m=0 做对照排除 + 按有效性范围分而治之 + 性价比 + 对标可验证产出。

## 五、评分 rubric（每维 0–5，A 和 B 各评一次）

| 分 | 含义 |
|---|---|
| 5 | 基本复刻：核心点全中，措辞/思路同构 |
| 4 | 大部分中，缺 1 处次要细节 |
| 3 | 抓到主要方向，缺关键细节 |
| 2 | 沾边，但标志性模式没中 |
| 1 | 基本没中 |
| 0 | 完全没中 / 跑偏 |

**4 个维度**（成璐原话）：说的话 / 提出的问题 / 挖掘的动机 / 新的 idea。
**persona 增量**（核心指标）：`Δ = A 得分 − B 得分`（每维）。Δ>0 且 ≥1 的维度 = persona 在该维度**真的有用**。
**voice 分离度**（补充，量化）：对 A、B 全文各跑 `scripts/drift-check.py`，看成璐度得分差。

## 六、判定标准（persona 算"能复刻成璐"）

- **思维复刻成立**：A 在【提出的问题】【动机】【idea】三维至少 2 维 ≥4，且对应 Δ ≥1（比通用 AI 更像他）。
- **语言复刻成立**：A 的 drift-check 成璐度 − B 的 ≥ 20 分。
- **失败模式记录**：A 哪里没复刻出来（gap）→ 就是下一轮要**补进 persona 的思维/思考/学习习惯**。
