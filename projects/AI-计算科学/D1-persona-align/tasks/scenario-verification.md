## 四、综合判定(4-way, 诚实版)

1. **4-way 排序(双层)**:
   - 逻辑层: A 9.2 > AX 7.2 > GT 6.0 > B 2.0 — A/AX 都命中 GT 全部手法方向; A 密度超调(峰值), AX 密度最贴 GT(均值), B 几乎无手法。
   - 语言层: cos AX 0.825 > A 0.634 > B 0.533 — AX 最近, A 被 spec 置信词密度推远, B 最远。
2. **点5 答案(公理充分性)**: 只喂 4 公理(禁规则/禁voice), 输出**双层都最接近 GT** → 公理体系单独足以复刻"均值成璐"(逻辑 7.2≈GT 6.0, 表面 cos 0.825); 16 规则 persona = 公理 + voice spec + 密度放大 → "峰值成璐"。置信度 0.7(n=3)。
3. **三层模型在公理层面被实证**: 公理直接编码 **LENS+METHOD**(3/3 稳定: 显式conf/证据先行/性价比/观察循环/自我质询/随机vs系统偏差); 表面 VOICE 是深层结构的**副产品而非独立编码** — 具体标记(编号子问)不稳定(仅 S2 有), 但句长/置信词用度/无空话等表面特征自然落到接近 GT。要完全钉住 VOICE 需 voice 画像单独加载(A 做了, 但 spec 带入密度超调)。
4. **P9(MDL 表达约束)获三角验证**: AX 无密度 spec, 输出密度(7.2)自然最贴 GT(6.0); A 被 spec 推到 9.2 → P9"单条消息手法数 ≤ 信息量支撑上限"更像系统属性而非 spec 调参, 仍标预测(无直接语料证据)。
5. **一句话**: 4 公理 → "均值成璐"(双层最贴 GT); 16 规则 → "峰值成璐"(比真实更密); generic AI → 双层都是另一个人。**公理编码"怎么想", voice 画像编码"怎么说", 完整成璐 = 两者组合; 公理单独已够"近似", 加 voice 够"像", 但 spec 过密会过拟合到峰值。**

## 五、caveat(不装)

- n=3 场景, 每场景 1 条 GT — 样本薄, 置信度 0.7
- A 的 16规则+voice inline → 高分部分反映"规则被遵守"(B 同底座低分证明隔离有效); **AX 的 4 公理也是 inline 喂的, 且公理本身导自成璐语料** → "公理充分性"的上界受公理质量约束, 不是完全盲测
- AX cos 高部分是 spec 超调 artifact(GT 短且无置信词, A 被 spec 强制密铺) → 语言层"AX>A"的置信度低于逻辑层"AX≈GT"

- 场景选自有答案的对话树 → 测"同场景反应近似", 非开放话题
- 本检验不碰运行时配置, A/B/C 接入仍等拍板
