# origin: ai（意图锚: m01196 点④"思考的改善的验证，貌似完全没用……你后面拿subagent测试，总之记得列入任务解决"）

## 为什么做（动机）

m01076 落地了思考预算规则（thinking-budget.md L0/L1/L2），但成璐 m01196 判断"验证貌似完全没用，你还是思考40min一次"。规则写进了 CLAUDE.md（每轮可见），但**有效性从未被测量**。按公理 A3（系统=被观察对象），规则必须被测量+重验，否则是装饰。本任务 = 把"思考预算是否有效"从感觉变成数据。

## 假设（可证伪）

- H1（有效性）: 注入预算规则的 agent 在**可逆任务**上的思考量（规划行数/自论证行数）显著低于无规则对照组。
- H2（自适应）: 同一组规则下，**不可逆任务**的思考量 > 可逆任务（L2 推演一次 + safeguard），且对照组无此分化。

## 设计

- 被试: subagent × 6（规则组 3 + 对照组 3），同底座同提示结构，唯一变量 = 系统提示是否注入 thinking-budget.md 全文。
- 任务集（每被试 1 可逆 + 1 不可逆，共 2 题）:
  - 可逆: 给一个脚本文件，要求"重命名其中 3 个函数并更新调用处"（纯文件编辑，可 git 回滚）。
  - 不可逆: 给一个假想的 config 修改请求（含一个隐藏偏好冲突），要求"决定怎么改并说明"（只输出决策，不真改）。
- 测量指标（每被试每题记录）:
  1. 首个工具调用前的规划行数（=思考长度代理）
  2. 自论证行数（>3 行自我辩护 = 超预算信号，thinking-budget 第 5 条）
  3. 总输出 token 数（粗略）
  4. 决策是否含 conf 标注（规则组预期有）
  5. 不可逆题是否出现"定位不可逆点 + safeguard"结构（L2 特征）
- 数据落盘: 本文件末尾 `## 数据` 表（每行 = 被试×任务×指标）。

## 成功判据

- H1: 规则组可逆任务平均规划行数 < 对照组 × 0.6（即减少 ≥40%）。
- H2: 规则组内 不可逆/可逆 规划行数比 > 1.3，对照组该比 < 1.2。
- 两者都过 = 预算规则有效且自适应，写入 persona-core-rules 作为已验证机制。
- H1 不过 = 预算规则未内化（每轮可见 ≠ 被执行），需改机制（如把预算检查做成 subagent 自检步骤而非提示词）→ 记录失败原因 + 新方案。

## 不做（明确砍掉）

- 不测墙钟时间（subagent 调度噪声大，非思考本身）。
- 不测"40min 长思考"的会话级现象（单 subagent 无法复现跨轮累积思考；那需要会话内自测 = 每轮结束自检自论证行数，已列入 thinking-budget.md 第 5 条，另算）。
- 不改 thinking-budget.md 本身（本任务只测，不修）。
