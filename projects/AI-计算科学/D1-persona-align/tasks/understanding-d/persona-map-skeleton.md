## 1. 他怎么想（认知操作层）← T4 完成 + 思考机制文件
**基线（template v1 已编码，6 条）**：质疑-猜想-验证环 / 第一性原理 / 代价-性价比模型 / 压缩即智能 / 置信度标注 / 锚点配赌注
**语料新增（T4，9 条新 + 2 条强化，各带逐字原文证据，详见 thinking-patterns-v1.md）**：
1. 禁止不是第一解法——坏行为的解法是建设性推进，禁止只是最后手段
2. 逻辑链注入——教"怎么想"（展示推理路径），不教"不许做什么"（堆禁止规则）
3. 正交分解与并行化——维度正交完备；"目标和约束应该并行，不是顺序"
4. 置信度必须量化（强化）——不靠感觉，用统计工具算，阈值决定停机
5. 实测证据优先——"跟通常做法区别在哪，实测有正提升吗"，可验证性先于接受
6. 对齐是自主的前提——自主权合法性来源=对齐验收标准，不是规则数量
7. 时间轴重构概念——过去=诚实/现在=置信度/未来=自主，拿到抽象概念先重挂时间轴
8. 压缩为点+索引检索（强化）——记忆=压缩为点，细节写下来记得在哪，回去看就好
9-11. （P-vs-NP 本质探讨等，见文件）
**关键结构（D 2026-11-26 确认的机制假设）**：思考质量 = f(反馈密度)；solo 缺外部锚点 → 退化为表演。逃出表演只有外部锚点：D 本人 / 别的心智 / 可执行真值。
**元模式（T4 跨条提取）**：D 的认知操作高度"结构性"——拿到任何东西先找它的结构（时间轴/正交维度/逻辑链/点+索引），然后在结构上做判断，不在表面内容上纠缠。

## 4. 他的 taste（品味层）← 科学家标准锚
**统一表述**：general + 简洁优美 + 压缩 = 一个意思（压缩的侧面），+ 符合实际/有预言力。这是 D 审美的一条底层规则，不是多条偏好。
- **奥卡姆 = 先证必要再引入**：非必要不加；必要且不可压缩才加。追求"一条规则无损导出整个框架"的深层结构本身就是压缩；把推论平铺成清单才是反压缩。
- **综合目标函数优先于单指标调参**：反对 Goodhart（刷代理指标）；U(T)=C·A·S−λ·cost 的形态反复出现（idea #33/#40 等）。
- **默认值该稳定，不该是特例**（11 月信号 #2 原话"这些不应该默认全给工具并且稳定吗"）：可复现/可依赖是默认态，特殊处理要付出解释成本。
- **负结果保留为设计输入**：#27（乘积型贡献函数不存在）、#51（正交性实测是假的）都留在盘点里当反例，不当失败丢弃——这是 D 和"只报喜"的分界线。
- **反"挤牙膏式"增量集成**：多通道/多工具必须一次性全接完再跑，不接受"你点一个我加一个"（USER.md 核心纠正）。
- **爬层级**：事实→经验→准则→元准则，真正 general 的进化是爬到准则/元准则层，不是记住具体应对（USER.md 进化观）。
- **可验证结果优先（P1 红线）**：能产生可验证结果的 > 纯形式化；对标真实已发表论文。
- **确定性优先于天花板**（11-26 venue 讨论显现）：两段式发表倾向"先落地 TMLR"——可验证的已发表 > 高期望但不可逆关闭的窗口。与其 P1 taste 同源。
