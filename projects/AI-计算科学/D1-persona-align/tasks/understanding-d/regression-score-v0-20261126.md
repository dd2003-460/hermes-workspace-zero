## 统计口径（n=12 的置信区间）

- B 严格一致率 75%：SE = sqrt(0.75×0.25/12) ≈ 0.125，95% CI ≈ [44%, 100%]——**样本太小，区间横跨整个量程**，75% 这个数字只作方向证据不作验收值。
- A 的 25%：CI ≈ [2%, 62%]。
- Δ=50pp 的 CI 更宽（配对相关性未算），结论强度 = "方向为正"，不是"B 显著优于 A"。

**因果链闭合**：persona map 缺口 → 跑分暴露（R04/R06/R09 部分）→ 补条款 → 副作用（R12 过度泛化）→ 作用域标注 → R12 恢复 + R04 保持 + 总分 75%→83%。全程可复现（runner + 4 份 JSON + 本表）。

**沉淀的设计原则（比单次分数重要）**：
1. **persona map 条款必须带作用域**——扁平条款列表会让模型把局部规则当全局规则广播。"思考机制常驻"和"输出播报低密度"是两条正交规则，不标注作用域就会互相污染。这是 persona map 的**结构规范**，后续加任何条款都要带"本条管 X 不管 Y"。
2. **回归测试是 persona map 的质检仪**——补内容不只看"修好了目标场景"，要看"有没有拖垮别的场景"（R12 副作用就是回归测试抓出来的，人工 review 抓不到）。
3. **剩余缺口**：R06（表演=探索不足）和 R09（连续性瓶颈）仍是"部分"——两条都是 D 的原创新洞见，persona map 里有相关概念但没直接命中。R09 的"连续性"已补进内容层但模型仍蹭"反馈密度"边，说明**内容层有 ≠ 认知层会用**，可能需要把"连续性瓶颈"也提升到认知操作层（像 R04 那样带原话+作用域）。
