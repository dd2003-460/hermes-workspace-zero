### SOTA 方法

|------|------|-----------|-------------|------|
| Mem0（2025） | https://arxiv.org/abs/2504.19413 | 抽取事实后对记忆做 ADD/UPDATE/DELETE/NOOP 更新，而非累积全部对话 | 中：需额外 LLM 调用与服务依赖；可借鉴"更新而非追加"的规则，不建议整套引入 | 0.6 |
| Zep / Graphiti（2025） | https://arxiv.org/abs/2501.13956 ；https://github.com/getzep/graphiti | 时间知识图谱：事实带有效期，过时事实标记失效而非删除，可追溯观点变化史 | 中低：能记录 D 观点何时改变，但需图数据库，工程成本高；列为第二阶段选项 | 0.5 |
| Letta / MemGPT（基础 2023；Letta 仓库 2026-10-18 最近 push） | https://arxiv.org/abs/2310.08560 ；https://github.com/letta-ai/letta | 分层记忆：常驻 core memory（对应 persona map）+ 外部 archival，由 agent 经工具读写 | 中：core memory 思路可直接映射到 Hermes 注入的常驻 persona 块；整套 runtime 迁移成本高，不推荐整体采用 | 0.5 |

### 推荐组合（≤5 行）

1. 底座：persona map 作为常驻块经 Hermes hook 注入，原始内容纳入 git 版本化（conf 0.5）。
2. 更新：采用 Mem0 式 ADD/UPDATE/DELETE/NOOP 判定，但更新须经人工确认后生效，防止自动漂移（conf 0.5）。
3. 漂移探针：对固定探针题定期测漂移，结果入库；协议参照 2402.10962（conf 0.4，未验证）。
4. 离线整理：夜间批处理合并冲突记忆，不以 5× 数字作为收益依据（conf 0.3）。
5. 暂不引入 Zep 图数据库；仅当"观点变化史"成为明确需求时再评估（conf 0.5）。

## Q2 思维操作可执行编码

### SOTA 方法

| 方法 | 链接 | 一句话原理 | 对我们适配度 | conf |
|------|------|-----------|-------------|------|
| Chain-of-Verification（基础 2023） | https://arxiv.org/abs/2309.11495 | 草稿 → 规划验证问题 → 独立回答（不看草稿）→ 修订 | 高：纯 prompt，27b 可跑；仅适用于"可验证的事实子断言"，不适用于风格判断 | 0.5 |
| Self-consistency（基础 2023，ICLR） | https://arxiv.org/abs/2203.11171 | 多路径采样后多数表决 | 中：只适用于有唯一答案的判断题；成本 ×N；不适用于风格输出 | 0.6 |
| Constitutional AI 批评-修订（基础 2022） | https://arxiv.org/abs/2212.08073 | 依据书面原则做 critique → revision | 高：推理期 critique 可把 D 的思维原则写成检查清单；不做 RL 训练 | 0.5 |
| DSPy Assertions（基础 2023） | https://arxiv.org/abs/2312.13382 | 把输出约束写成可执行断言，失败时触发修正重试 | 高：可把"必须标 conf""必须列出正交维度"写成断言，在注入后校验 | 0.5 |
| 口头置信度校准（基础 2023） | https://arxiv.org/abs/2305.14975 | 先列候选答案再给口头置信度，校准改善 | 高：直接对应"置信度标注"习惯；成本低，可在 27b 上直接测（本地未验证） | 0.5 |
| Reflexion（基础 2023，NeurIPS） | https://arxiv.org/abs/2303.11366 | 把任务反馈转为文字反思存入情景记忆，下轮读取 | 中：依赖可执行反馈；对"质疑-猜想-验证"过程的有效性未验证 | 0.4 |
| PRM / Math-Shepherd（基础 2023） | https://arxiv.org/abs/2305.20050 ；https://arxiv.org/abs/2312.08935 | 对推理步骤逐步打分的奖励模型 | 低：需训练奖励模型，且证据在数学域；与"不改权重"冲突。具体数字未回原文（未验证） | 0.6 |

注：2024–2026 的 Q2 方法覆盖不足，本表主要为 2022–2023 基础工作（见横向结论与附录 F）。

### 推荐组合（≤5 行）

1. 把思维习惯拆为可执行检查：置信度标注、正交维度列出、猜想附验证路径，写成断言并在注入后校验（conf 0.5）。
2. 事实子断言用 CoVe 式验证环（独立上下文回答验证问题）；风格判断不用此法（conf 0.5）。
3. 置信度采用"先列候选、后给 conf"的口头校准，并在本地 27b 上先测校准（conf 0.5，未验证）。
4. 唯一答案的判断题用 self-consistency 小样本表决，严格限定样本数以控制成本（conf 0.5）。
5. 不引入 PRM 训练，改用 critique 检查清单替代（conf 0.6）。

### 推荐组合（≤5 行）

1. 锚点优先级：可执行检查（测试、断言）> 异族模型 judge > 人工真值；同族 judge 只用于一致性监控（conf 0.6）。
2. 回归套件：persona 题集入 git，用 promptfoo 跑 CI；每次修改 persona map 必跑（conf 0.6）。
3. 黄金样本：从 D 的历史决策中人工筛选，作为真值候选（设计推断，未文献核验，conf 0.4）。
4. 异族 judge 依赖 ego-lite 通道；该通道当前在沙箱内不可用，需用户侧修复（conf 0.9，环境事实）。
5. 通用能力底线用 lm-evaluation-harness 做粗回归（conf 0.5）。

## 横向结论（≤10 行：三方向的最小系统形态）

1. 最小系统：persona map 常驻（Hermes 注入）+ 推理期断言/置信度/critique 检查 + git 版本化回归套件；不改权重、不训练奖励模型（conf 0.5）。
2. 不把"角色设定"当作思维复活手段：文献显示角色提示对客观题无正向收益，persona 应编码为可执行程序（conf 0.6）。
3. 记忆层：借鉴 Mem0 的更新规则与 Letta 的 core memory，暂不引入图数据库（conf 0.5）。
4. 外部锚点：同族 judge 不算锚点；必须有异族模型或可执行真值（conf 0.6）。
5. 证据缺口：没有任何被检索到的方法在"人格一致性"指标上有直接证据（conf 0.9）。
6. 所有数字来自作者在其他模型上的报告；本地 27b 上的效果全部未验证（conf 0.9）。
7. Q2 的 2024–2026 覆盖不足，多数为 2022–2023 基础工作（conf 0.9）。
8. 思考习惯原文（thinking-patterns-v1.md）与 idea 清单（idea-inventory-v1.md）在仓库中缺失，适配建议无法对照 D 的具体习惯（conf 1.0，事实）。
9. 网页 LLM 异族核验通道不可用，Q3 异族锚点目前只有文献层证据（conf 0.9，事实）。
10. 下一步：先做两个 27b 本地小实验（口头置信度校准、断言校验），再决定记忆层选型（conf 0.5）。
