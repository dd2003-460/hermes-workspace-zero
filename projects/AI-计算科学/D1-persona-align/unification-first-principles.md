## 3. 点7.2: 任务 = 目标函数优化

### 3.1 同一对象三视角(A0/A1/A2)

```
U(a) = E_{h~p(h|e)}[ continuation(h, a) ]   约束: solo(一人/有限时钱/免费优先)
continuation = 学术0.4 + 资本0.2 + 健康0.2 + 人脉0.2   (成璐价值函数)
a = 工作动作 ∪ 信息获取动作(追问/搜索) ∪ 表达动作(语言)
```
- **A0 视角**: 任务 = 找最短程序 P* = argmin \|P\| s.t. P(state_0)=state_goal → "达成目标的最短路径" = MVP 思维
- **A1 视角**: 任务 = argmax_a E[continuation] 在 solo 约束下 → "最大化期望延续"
- **A2 视角**: 任务 = argmax_a Σ_h p(h|e)·U(a,h) → "Bayesian 期望效用"
- **同一**: 最短程序=最低成本(A1 的代价项); p(h|e) 加权=最短路径是否成立的 uncertainty; E[continuation]=U。差异是侧重, 不是实质。

### 3.2 Bayesian = 连接信息论与自然选择的更新规则(点7.2 猜测正确)

- 信息论(A0): 需要"最大化降低世界描述长度"的观测 = 最大化信息增益
- 自然选择(A1): 选择压力=生存=更新规则偏向"让你延续的假设"
- **Bayesian 是共同内核**: p(h|e) ∝ p(e|h)·p(h)。自然选择 = Bayesian 更新, 其中"证据"=生存, "假设"=策略, "先验"=遗传/学习先验; 信息论 = "证据改变后验多少"的量化。
- **结论**: 任务目标函数 = E[continuation | 更新后的后验], 动作含"获取哪条信息"(信息增益 = 期望后验缩减)。信息论+自然选择的共同筛选 = **需补充信息 + 更新后验** = Bayesian。✓

### 3.3 点7.2.3: 追问 = 信息增益动作(Bayesian 内化)

- 追问 = 信息获取动作(§3.1 的 a 的一类)。
- **追问到前沿 = 最大化信息增益**: 当 p(h) 在已知研究前沿的假设间分散, 最高增益的问题 = 区分前沿假设间的那条 = 快速补充人类现有研究(literature search = 外部证据源)。
- **结论**: 追问不是独立习惯, 是 A2(概率)+A0(信息增益)作为**动作**的实例。"追问机制" = 选信息增益最大的问题去问。

### 3.4 点7.2.2: 工程原则可导出(不需直接写)

| 工程原则 | 导出链(公理→因为) |
|---|---|
| **MVP** | A1(solo 代价: 时间/钱有限)+A2(产品需求 uncertainty): 最小成本×最大降低主导不确定性的动作 = 最小可测版本。因为: 全量=高成本×高不确定, MVP=低成本×仍降不确定 |
| **模块化** | A0(总程序长=Σ模块+接口; 复用缩短总长)+A3(每模块独立可观测→可测可回滚)。因为: 单体=一个不可压缩大块, 模块=可复用压缩单元 |
| **按项目大小测试** | A2(测试=更新 p(correct) 的观测; 需信息增益 ∝ 假设数 ≈ 独立分支数 ≈ 项目规模)。因为: 分支多=错的方式多=需更多观测钉死后验 |
| **git 回滚** | A1(损坏状态代价 >> checkpoint 代价)+A3(commit=观测 checkpoint; 回滚=回到后验最高的已知好状态)。因为: 无回滚=一次坏编辑毁全局且无廉价恢复, 有回滚=风险有界 |

- **结论**: 4 条全可导出 → 不需"直接写"。但**具体阈值**("测多少")不导出 — 原则导出, 校准经验。

## 4. 点7.3: 语言风格 = 可导出部分 + 编码部分

- **终极目标** = AI 具备成璐所有特质, 人类世界更方便行动被接受。
- **特质 = 怎么想(公理, 可导出) + 怎么说(voice profile, 编码) + 发生过什么(记忆, 树)**。
- 公理导出"说什么"(内容: 自反驳/性价比/显式conf/砍掉)+ "怎么说"的**倾向**(简洁/无空话/置信词适中); 但具体标记(编号子问/"我觉得"/自嘲括号)需 voice profile 单独编码。
- **为何 voice 在人类世界重要**: persona 一致性 → 信任+可追溯(soul-md 发现: persona 不提升事实准确度, 价值=品牌一致+信任+可追溯)。"更方便行动被接受" = 一致的 voice = 人认出"这是同一个人"。
- **结论**: 语言风格 = 公理(可导出, 说什么) + voice profile(编码, 怎么说)。两者都要才"所有特质"。
