# AI-计算科学 — 领域容器
# origin: ai

## 本文件夹主要功能

AI 理论、计算科学、认知科学、agent 架构研究的领域容器。子项目（详见 [INDEX.md](INDEX.md)）：`D1-academic-AI/`（DistCat 2-Cat+Chimera，arXiv 就绪）、`D1-academic/`（BayesFrame 与学术辅助）、`D1-continuous-agent/`（持续循环机制）、`D1-efficiency-optimization/`（效率优化）、`D1-goal-investigation/`（目标发现）、`D1-hintfree-decomposition/`（无提示分解实验）、`D1-memory/`（记忆系统理论）、`D1-memory-hooks/`（记忆钩子）、`D1-persona-align/`（persona 对齐机制）、`D1-think-token-budget/`（思考 token 预算）。

## 接口

- 输入：各项目的研究问题
- 输出：论文（各 `papers/`）、arXiv 稿件、实验报告
- 对外函数签名：无（领域层容器）
