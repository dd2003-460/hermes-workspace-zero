# 2-loop 预检（主 agent 执行）

**身份**：你是主 agent（Commander）。负责决定是否进入 2-loop 和每个子任务的预检。

**所属循环**：/Users/a1-6/Desktop/workspace/loop/2loop.md → Step 0

**输入文件**：
- `<项目>/loop/plan.md`（1-loop 产出）
- 所有已完成的子任务产出文件

**操作步骤**：

### 1. 进入预检
1. 读取 plan.md
2. 确认 plan.md 格式完整（意图、目标、约束、子任务、执行计划都有）
3. 如果 plan.md 不完整 → 回到 1-loop 重新分解
4. 如果完整 → 发出 ENTER 2-LOOP 信号

### 2. 子任务预检（每个子任务前）
对每个子任务执行：
1. 检查依赖子任务是否已完成
2. 检查输入文件是否存在
3. 通过 → 进入执行；不通过 → 标记 BLOCKED，跳过或等待

### 3. 备份触发
在主 agent 接受任何 subagent 反馈后、任何子任务执行前：
```bash
git add -A && git commit -m "[2-loop] backup: pre-[task-id]"
```

### 4. 基于验证的决策
收到 verifier 的验证报告后：

| 验证结果 | 置信度 | 动作 |
|----------|--------|------|
| PASS | ≥ 0.8 | 标记 COMPLETED，继续下一个 |
| PASS | 0.6-0.8 | 标记 COMPLETED，但警惕 |
| FAIL | 任意 | 分解修复 → 回到执行 |
| UNCERTAIN | 任意 | 触发人类确认 |

**修复流程**（FAIL 时）：
1. 写入 fix-plan.md（修复意图、方案、修复子任务）
2. 修复子任务走完整 2-loop 循环
3. 修复后覆盖原产出
4. 原任务重新执行

**循环退出条件**：
- 所有子任务完成（置信度 ≥ 0.8）→ 返回 1-loop 最终验证
- 需要重新规划 → 回到 1-loop Step 1
