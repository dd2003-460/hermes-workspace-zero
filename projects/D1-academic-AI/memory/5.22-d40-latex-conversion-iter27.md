# D40 Pandoc→LaTeX 转换与修复记录（iteration 27）

## 背景
D40 原始论文为 Markdown 格式，需要转换为 LaTeX 以提交 arXiv。此前 iteration 23-24 尝试自定义 converter（markdown_to_latex.py, convert_d40.py）均失败。iteration 26 确认 pandoc 可直接生成兼容 .tex。

## 关键发现
- Pandoc 3.9.0.2 可直接将 Markdown → arXiv 兼容 LaTeX
- 生成的 LaTeX 包含所有数学表达式（55 inline + 27 display math）
- `D*\_expert` 格式错误（pandoc 未识别自定义数学语法）
- `article` 类不支持中文，需改用 `ctexart`
- pandoc 添加了冗余的字体处理代码（iftex/babel/fontspec），与 ctexart 冲突

## 修复内容（iteration 27）

### 数学符号修复
1. `D*\_expert` → `D^*_{\text{expert}}`（4处）
2. `D*\_general` → `D^*_{\text{general}}`（3处）
3. `P(D40\textbar evidence)` → `$P(\text{D40} \mid \text{evidence})$`
4. `→` 箭头在证明中 → `$\rightarrow$`
5. `dA/dD < 0` → `\((dA/dD) < 0\)`
6. abstract 中 R² → R$^2$
7. abstract 中 `1/sigma` → `\(1/\sigma\)`
8. abstract 中 `p=2.9×10⁻¹³³` → `\(p = 2.9 \times 10^{-133}\)`

### 结构修复
9. 删除重复结尾段落（footer 出现两次）
10. article → ctexart（UTF8）
11. 删除冗余 iftex/babel/fontspec 代码
12. 添加 figure 环境和 includegraphics
13. 添加 graphicx 包

## 结论
Pandoc 是处理 Markdown→LaTeX 转换的正确工具。自定义 converter 因为无法处理 Markdown 中的复杂模式（如 `\` 替换、table detection、`---` 区分）而失败。建议统一使用 pandoc 进行 Markdown→LaTeX 转换。
