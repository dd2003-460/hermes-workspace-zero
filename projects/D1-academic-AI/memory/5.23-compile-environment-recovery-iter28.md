# 编译环境恢复 — DNS修复 + TinyTeX安装（iteration 28）

## 背景
迭代 27 完成 D40 LaTeX 转换，但编译验证阻塞于无 LaTeX 环境。DNS 阻断导致无法下载 texlive。

## 关键行动
1. **DNS 修复** — `networksetup -setdnsservers Wi-Fi 8.8.8.8`（成功，DNS 恢复正常）
2. **TinyTeX 安装** — `curl -L https://yihui.name/tinytex/install-unx.sh | sh`（~300MB，快速安装）
3. **ctex 包安装** — `tlmgr install ctex`（中文文档必需）
4. **breqn 包安装** — `tlmgr install breqn`（D1-grav-waves 必需）
5. **PATH 永久添加** — `export PATH="$HOME/Library/TinyTeX/bin/universal-darwin:$PATH"` → ~/.zshrc

## 编译结果

### D40 (D1-academic-AI)
- **引擎**: xelatex（xelatex 原生支持 Unicode + macOS 系统字体 STHeiti/STSong）
- **结果**: ✅ 14页, 671K PDF
- **修复**:
  - `\textgreater{}` → `$>$`（\textgreater 是数学符号，不在文本模式下可用）
  - `\textless` → `$<$`
  - `D*_expert` 文本模式 `^` → `\(...\)` 数学模式
  - `\$)` 重复终止符 → `$)`
  - figure 路径 `Fig-D40-all-experiments.png` → `../chimera_lab/Fig-D40-all-experiments.png`
  - ctexart `fontset=mac` 使用系统字体
- **问题**: "Missing character" 警告（非致命，xelatex 使用 STSong 渲染中文字符）

### D1-grav-waves (D1-grav-waves)
- **引擎**: pdflatex（英文论文，标准 LaTeX）
- **结果**: ✅ 10页, 405K PDF
- **修复**:
  - figure 路径 `Fig1-Hellings-Downs-curve` → `papers/2026-GW-BacQFT/Fig1-Hellings-Downs-curve.png`
- **注意**: xelatex 对 PNG 有 "Division by 0" 错误，pdflatex 正常

## 工具发现
1. **TinyTeX 是正确选择** — 300MB vs MacTeX 5GB，按需安装额外包（`tlmgr install`）
2. **xelatex 优于 pdflatex 用于中文文档** — 原生系统字体支持，不需 CJK 字体包
3. **`fontset=mac` 在 ctexart 中自动选择 macOS 系统字体**
4. **`\textgreater`/`\textless` 是 amssymb 数学符号**，在文本模式下不可用
5. **`\( ... \)` 是安全的 inline math 分隔符**，`$ ... $` 在某些上下文中可能混淆
