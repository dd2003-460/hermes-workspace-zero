## 工具创建

### compile_paper.sh
- **位置**: `/Users/a1-6/Desktop/workspace/scripts/compile_paper.sh`
- **用途**: 可复用的 LaTeX 论文编译脚本
- **用法**: `compile_paper.sh <path/to/paper.tex> [pdflatex|xelatex]`
- **功能**:
  - 自动 sourcing ~/.zshrc（获取 TinyTeX PATH）
  - 清理旧的辅助文件
  - 编译两次（第一次生成引用，第二次解析引用）
  - 输出 PDF 统计（页码/大小）

### arxiv_submission_checklist.sh
- **位置**: `/Users/a1-6/Desktop/workspace/scripts/arxiv_submission_checklist.sh`
- **用途**: arXiv 提交前检查清单
- **用法**: `arxiv_submission_checklist.sh <paper-directory>`
- **检查项**:
  1. .tex 文件存在性
  2. PDF 生成
  3. 参考文献/bibliography
  4. 数学表达式
  5. 关键词
  6. 作者信息
  7. 摘要
  8. 图片文件
  9. includegraphics 使用
  10. 引用使用
  11. 章节结构
- **输出**: PASS/FAIL/WARN + 总评

## 经验总结

### TinyTeX 安装
```bash
curl -L https://yihui.name/tinytex/install-unx.sh | sh
export PATH="$HOME/Library/TinyTeX/bin/universal-darwin:$PATH"
# 永久添加: echo 'export PATH=...' >> ~/.zshrc
```

### xelatex vs pdflatex
- xelatex: 适合中文文档，原生系统字体支持，对 PNG 图片支持可能有问题
- pdflatex: 适合英文论文，PNG 支持好，无中文字体问题

### arXiv 提交要点
- arXiv 推荐 BibTeX 格式（`.bib` + `.bbl`），但内嵌 `thebibliography` 也接受
- 需要许可证声明
- 需要 arXiv 分类（如 cs.AI, gr-qc, hep-ph）
- arXiv 要求引用格式统一
