# arxiv_cat.py 重写（iteration 31）

## 背景
原有 arxiv_cat.py 使用 urllib 直接访问 arXiv API，在 DNS 阻断时被限流。需要绕过 DNS 限制的替代方案。

## 重写内容
1. **双层搜索策略**：urllib 优先 → curl --resolve 降级
2. **arXiv IP 硬编码**：`151.101.135.42`，绕过 DNS 解析
3. **改进搜索语法**：`ti:`（标题）+ `abs:`（摘要）前缀，提升相关性
4. **XML 解析改进**：直接从 curl 输出解析 Atom XML

## 搜索结果质量
- "AI precision accessibility tradeoff" → 相关论文 3 篇（可用性/媒体无障碍相关）
- "gravitational wave PTA Hellings-Downs" → 2023年 2 篇高度相关论文 + 无关结果
- 结论：ti:+abs: 搜索显著提升相关性

## 经验
- arXiv API 搜索限制：`all:` 搜索所有字段（低相关性），`ti:` + `abs:` 更精准
- curl --resolve 可以完全绕过 DNS，通过硬编码 IP 直接访问
- 限流基于 IP 而非 DNS，curl --resolve 不影响限流状态
