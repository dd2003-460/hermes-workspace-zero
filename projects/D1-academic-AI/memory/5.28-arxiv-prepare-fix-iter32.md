# arXiv 工具链完成（iteration 32）

## 背景
用户要求"工具复用和网络上工具，文献搜索，方法复用"。arXiv 提交流程缺工具。

## 完成工具

### 1. arxiv_prepare.py
- 从 .tex 文件提取元数据（标题、作者、关键词、许可证）
- 扫描资产（.tex、.pdf、figures、.bib、supplementary）
- 创建提交包目录 + manifest
- **关键修复**：balanced brace 嵌套匹配，正确处理 `\title{\textbf{...}}`

### 2. arxiv_cat.py
- arXiv 文献搜索
- 双层策略：urllib → curl --resolve 降级
- ti:+abs: 前缀精准搜索

### 3. arxiv_cats.py
- arXiv 分类推荐（基于相关论文类别统计）
- 同双层搜索策略

### 4. arxiv_tarball.sh
- 创建 arXiv 格式 tar.gz 提交包
- 排除编译产物（.aux, .log, 编译PDF）
- 只包含 .tex +  figures

### 5. _extract_title.py
- 提取 .tex 标题，支持嵌套 LaTeX 命令
- 支持 pandoc 生成的 ctexart 格式（无 \title{}）
- 三级 fallback：\title{} → 英文标题模式 → 第一个 \section{}
