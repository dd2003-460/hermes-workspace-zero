### $\mathbf{DistCat}$ 严格定义

**定义**：$\mathbf{DistCat}$ 是一个 2-范畴，其：
- 0-对象：基础结构 $\mathcal{B} = (\mathbf{C}, \mathcal{F}, \mathcal{O})$
  - $\mathbf{C}$：源范畴（基本组成单元）
  - $\mathcal{F}$：结构函子（将源映射到目标）
  - $\mathcal{O}$：观测函子（将源映射到观测）
- 1-态射：结构保持三元组 $(\Phi, \alpha, \beta)$
- 2-态射：距离导出配对 $(\Gamma, \delta)$ + 自然同构 $\eta$

### 两个特例

1. **D1-grav-waves**：$\mathbf{C} = \mathbf{Loc}_M^{\mathrm{ext}}$，$\mathcal{F} = F$（AQFT 函子），$\Gamma = d_{TV}$，$\delta = \text{HD}$
2. **D16+D24**：$\mathbf{C} = \mathbf{FinProb}$，$\mathcal{F} = \mathcal{P}$（统计模型），$\Gamma = d_{g_F}$，$\delta = D_{KL}$

### 结构性结果

- 定理 4.1：距离导出函子 $D: \mathbf{DistCat} \to \mathbf{Met}$ 存在性
- 定理 4.2：观测不可行性——不同基础结构可导出相同距离（距离等价类）
- 推论：D1 和 D16+D24 可能在特定极限下距离等价
