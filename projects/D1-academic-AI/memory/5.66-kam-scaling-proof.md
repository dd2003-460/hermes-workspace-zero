## iteration 66 结果

### 证明框架（基于 Peyrard-Auckly-Kuchlar 定理）

**引理 6.3.1**：EMRI 径向运动可写为哈密顿系统
H(r, p_r; φ) = p_r²/(2m) + V_eff(r; ρ_s, r_s, L)
φ 为演化参数，V_eff 由 Eq.(3.5)

系统性质：
1. 时间反演对称 (φ → -φ, p_r → -p_r)
2. 存在反演算子 I
3. 极限 ε → 0 退化为可积 Schwarzschild 势
4. 存在 homoclinic 轨道

**引理 6.3.2**：Peyrard-Auckly-Kuchlar 定理
若系统具有时间反演对称 + homoclinic 轨道 + 可逆变形
则 λ_T ~ |ε - ε_c|^{1/2}

**证明核心**：
1. 在 ε = ε_c 处，W^s 与 W^u 重合 (homoclinic orbit)
2. Melnikov 函数 M(φ_0) 给出 W^s/W^u 间距
3. M(φ_0) 的单重零点 → transverse homoclinic intersection → Smale 马蹄 → 混沌
4. 标度：Δφ ~ |ε-ε_c|^{1/2} (Melnikov 线性响应)
5. T_residence ~ |ΔE|^{-1/2} (Arnold homoclinic bifurcation)
6. λ_T ~ T^{-1} ~ ΔE^{1/2} ~ |ε-ε_c|^{1/2} □

### 对 EMRI 的应用
- ε = ρ_s, ε_c ≈ 0.04 (Case-III)
- V_eff DM 修正项对 ρ_s 线性 → ΔE ~ |ε-ε_c|
- 结论：λ_T ~ |ρ_s - 0.04|^{1/2}
