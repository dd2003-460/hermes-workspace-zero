# 多相凝聚态 vs Chimera — 理论定位注释

**来源**：D4-S18-r16-final chimera 伪阳性诊断 + 拓扑实验

---

## 1. 核心区别

### Chimera（严格定义）

```
一个连续子集 S₁ ⊂ {1,...,N}：所有 θ_i ≈ θⱼ（凝聚区 A）
另一个连续子集 S₂ ⊂ {1,...,N}：θ 随机分布（区域 B）
不连续边界条件：S₁ 和 S₂ 形成空间上连续的分离
```

**必要条件**：
1. **空间耦合变化**：K(i,j) 随空间位置变化
2. **或频率分布**：ω(i) 有空间梯度
3. **连续性**：S₁ 和 S₂ 必须是空间连续的区域

**论文来源**：
- Abrams, Strogatz (2004) — 首次发现 chimera on a ring with K(x) = K₀(1 + ε cos x)
- Omelchenko et al. (2013) — chimera dynamics in spatially extended systems

---

### 多相凝聚态（我们观测到的现象）

```
相位空间中出现 ≥ 2 个高概率密度子区域
每种子区域内部：相位集中（局部同步）
子区域之间：无锁相关系（局部解耦）
```

**特征**：
1. **不需要空间变化耦合**
2. **不要求区域连续性**
3. **由噪声 + 耦合竞争产生**
4. **是统计力学中的"多稳态"现象**

## 2. 拓扑实验结论

| 拓扑 | K=0.5 | K=1.5 | 全局同步 |
|------|-------|-------|---------|
| all-to-all | 0% | 100% | 0.78 |
| ring (k=2) | 16% | 70% | 0.18 |
| scale-free (m=2) | 0% | 100% | 0.001 |
| scale-free (m=4) | 36% | 20% | 0.14 |

**关键观察**：
- 所有拓扑在 K=1.5 时都产生多相凝聚
- global_sync 与 chimera_rate 不相关（全同步可以是多相的——例如 π/2 和 3π/2 两团）
- **不是 chimera，是 M-phase ordered state**

## 3. 物理图像

### 多相凝聚形成机制

```
t=0:  所有 θ 均匀随机分布 [0, 2π]
t→∞: 耦合使部分节点聚拢 → 凝聚区 A
       另一部分节点保持随机 → 区域 B
       结果：P(θ) 有 ≥2 个局部极大值
```

这类似于：
- **铁磁系统中的磁场反转**：两个磁化方向共存
- **液气相分离**：两个相态空间共存
- **自旋玻璃冻结**：多个亚稳态共存

## 4. 理论贡献

**D4-S18-r18：多相凝聚相变定理**

耦合振荡器在强耦合（K > K_c）且存在噪声源时，
会从均匀态转变为**多相凝聚态**：

$$P(\theta) = \sum_{m=1}^{M} w_m \delta(\theta - \theta_m^*)$$

其中 M ≥ 2 是凝聚区数量，与 D1-r02 的 I_C 对应。
