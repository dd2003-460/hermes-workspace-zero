## 理论深化：操作化定理

### 定理 A1-r09-T1（曲率守恒的操作化表述）

对于训练中的神经网络，定义**层间曲率变化率**：
$$\mathcal{C}_{grad}(l) = \left| \frac{1}{\|h_l\|} \nabla_h \text{Tr}(\text{Hessian}(h_l)) \right|$$

**理论断言**（基于 A1-r06 信息守恒定理）：
$$\mathcal{C}_{grad}(l) \leq \epsilon_{info} = \frac{I(D_l; D_{l+1})}{H(D_l)} \cdot \kappa_{model}$$

其中 $\kappa_{model}$ 是模型复杂度因子（参数量/层级数）。

### 定理 A1-r09-T2（Betti 数-层级深度线性关系）

**严格形式**：
$$\beta_0(l) + \ell = C_{constant} + O\left(\frac{1}{N}\right)$$

其中 $l$ 是层级深度，$N$ 是数据集大小。

**操作化预测**：
- $\beta_0(0) = \text{DataHierarchyDepth}$
- $\beta_0(L) \approx 1$（顶层只有一个连通分量）
- $\beta_0(l)$ 随 $l$ **单调递减**

## 实证协议 1：曲率梯度测量（可执行实现）

### 实验步骤

```python
class CurvatureTracker:
    """
    测量隐藏层激活的局部曲率
    
    实现方式：使用 Hessian-vector 乘积近似
    Tr(H) ≈ (1/m) * Σ v_i^T H v_i  (随机采样 m 个方向)
    """
    
    def estimate_hessian_trace(model, layer_idx, batch, n_samples=10):
        """
        Hessian 迹的随机估计
        Tr(H_f) = E_v[v^T H_f v]
        
        使用两样本法：H_f · v ≈ (f(x+v) - f(x-v)) / (2ε)
        """
        grads = autograd.grad(model.output, layer.output)[0]
        traces = []
        
        for _ in range(n_samples):
            v = torch.randn_like(grads)
            f_plus = model.output(layer.output + ε*v)
            f_minus = model.output(layer.output - ε*v)
            trace = (f_plus - f_minus) / (2*ε)
            traces.append(trace.item())
        
        return np.mean(traces)
```

### 测量序列

```
对于训练轮次 t = [0, 100, 200, ..., 1000]:
    对于每层 l = [1, 2, ..., L]:
        曲率(l, t) = Hessian_tr(layer_l(t))
    
    计算：d曲率/dl = (曲率(l+1,t) - 曲率(l,t)) / Δl

预期：
- 信息守恒 → |d曲率/dl| 应接近常数（曲率梯度守恒）
- 如果 d曲率/dl 变化剧烈 → 信息在层间**损失**或**膨胀**
```

## 实证协议 2：Betti 数-层级深度关联（拓扑持久性）

### 操作化实现

```python
class PersistentHomologyEstimator:
    """
    使用 Persim 库计算持久同调 Betti 数
    
    流程：
    1. 提取多层激活值 X ∈ R^(n_layers × n_samples × dim)
    2. 每层 X_l → 降维到 2D（PCA）
    3. 计算 2D 嵌入的持久同调
    4. 提取 β_0（连通分量）和 β_1（环）
    """
    
    def estimate_betti_per_layer(layer_activations, eps_range=(0.1, 10.0)):
        """
        layer_activations: R^(n_samples × dim)
        
        返回：(β_0_lifetime, β_1_lifetime)
        """
        # 降维
        X = PCA(n_components=2).fit_transform(layer_activations)
        
        # 距离矩阵
        dist = pairwise_distances(X)
        
        # 持久同调计算
        simplicial_complex = VietorisRipsComplex(
            diameter=max_dist, edges=dense_graph
        )
        persistence = simplicial_complex.persistence()
        
        # 分离 β_0 和 β_1
        beta_0 = [p for p in persistence if p[1] == 0]
        beta_1 = [p for p in persistence if p[1] == 1]
        
        return (len(beta_0), len(beta_1))
```

### 验证方案

```
对于不同层级深度的数据集 D_depth：
    训练网络 → 提取每层激活 → 计算 β_0(l)
    
绘制：β_0(l) vs l 曲线
横轴：层级深度 l
纵轴：β_0（连通分量数）

理论预期：β_0(l) = max(1, DataDepth - l)
控制实验：扁平数据（无层级）→ β_0(l) 无单调模式
```

## 实证协议 4：训练动力学中的流形演化（与 S18 对齐）

### 理论基础

**S18 统一动力学泛函**：
$$\mathcal{F}[h(t)] = \int_{\mathcal{M}} \left[ \frac{1}{2}\|\nabla h\|^2 + V(h) \right] d\mu$$

**操作化映射**：
- $\|\nabla h\|^2 \to$ 层间激活梯度方差 $\text{Var}(\nabla h_l)$
- $V(h) \to$ 权重范数正则化 $\|\theta\|_2^2$

### 测量协议

```python
class S18FunctionalTracker:
    """
    训练期间追踪 S18 动力学泛函 F[h(t)]
    
    F(t) = E_kin(t) + E_pot(t)
    E_kin  = 1/2 * ||∇h||²  → 用层激活梯度方差近似
    E_pot  = λ * ||θ||²     → 权重 L2 正则项
    """
    
    def measure_at_checkpoint(model, layer_outputs, t, λ_reg):
        """
        layer_outputs: 所有层输出 [h_1, h_2, ..., h_L]
        """
        # 动能：层间信息传播的"温度"
        gradients = [h_l - h_{l-1} for h_l, h_{l-1} in zip(layer_outputs, layer_outputs[:-1])]
        E_kin = 0.5 * np.mean([np.var(g.flatten()) for g in gradients])
        
        # 势能：参数空间的位置
        E_pot = λ_reg * sum(p.pow(2).sum() for p in model.parameters())
        
        F_t = E_kin + E_pot
        dF_dt = (F_t - F_prev) / dt
        
        return {
            'F': F_t, 'dF_dt': dF_dt,
            'E_kin': E_kin, 'E_pot': E_pot
        }
```

### 验证定理

**理论预测**：
$$\frac{d\mathcal{F}}{dt} < 0 \iff \text{训练收敛}$$

**更深刻的预测**：
$$\frac{d\mathcal{F}}{dt} < 0 \land \frac{d\beta_1}{dt} > 0 \iff \text{流形拓扑在演化}$$

（动力学收敛的同时拓扑环增加 — 模式分化）

## 实证协议 5：无层级数据对照实验

### 实验设计

**理论基础**（基于 A1-r06 层级守恒）：
- 有层级数据 → 曲率梯度守恒 → Betti 数单调
- 无层级数据 → 随机曲率 → 随机 Betti 演化

### 数据构造

```python
class HierarchicalDatasetGenerator:
    """
    生成具有明确层级结构的数据集
    层级深度 D 对应信息分层程度
    """
    
    def generate_hierarchical_data(n_samples, dim, depth, alphabet_size=5):
        """
        生成树状层级结构数据：
        - 根节点（全局类别）→ D-1 个中间节点 → 叶节点（细粒度类别）
        - 每个样本分配到叶节点
        """
        categories = []
        for d in range(depth):
            n_cats_at_level = alphabet_size ** d
            categories.extend(n_cats_at_level)
        
        # 生成特征：距离层级结构中节点的余弦距离
        features = []
        for _ in range(n_samples):
            # 随机选择一个路径到叶节点
            path = [random.choice(alphabet_size) for _ in range(depth)]
            
            # 特征编码层级距离
            feat = np.zeros(dim)
            for i in range(len(path)):
                feat[i % dim] += math.exp(-i * decay_rate)
            
            features.append(feat + noise(dim))
        
        return np.array(features), labels
```
