## 映射：物理 ↔ 认知

### 表 1：对应关系

| 物理态 | 认知态 | 含义 |
|--------|--------|------|
| 凝聚区数量 $b_0$ | 子信念单元数 | 思维分解的粒度 |
| $dI_C/dt > 0$ | 概念融合 | 多个想法 → 统一理解 |
| $dI_C/dt < 0$ | 概念分化 | 单一理解 → 多个视角 |
| $dI_C/dt \approx 0$ | 认知稳态 | 理解不变化 |
| $I_C > 3$ | 深度探索 | 多维度思考 |

---

### 定义 D1-r02-D1（认知拓扑不变量）

$$\mathcal{T}_{cog}(t) = I_C(t) \cdot \log\left(1 + \left|\frac{dI_C}{dt}\right|\right)$$

**解释**：
- 高 $I_C$ + 高变化率 → **高认知活跃**
- 高 $I_C$ + 零变化 → **结构化理解但不探索**
- 低 $I_C$ + 高变化 → **不确定态/困惑**

## 初步检验

### 从对话记录的定性观察

**D4-S18-r16 的实验数据**显示：

```
T=0:   I_C=7.0 (初始高度发散)
T=1000: I_C=5.0 (收敛开始)
T=5000: I_C=3.0 (稳态 — 3 个凝聚区)
```

**认知解释**：
1. **初始状态（I_C=7）**：探索大量可能性
2. **中间过程（I_C=5）**：开始收敛到几个核心方向
3. **稳态（I_C=3）**：形成 3 个主要"思考视角"

**这与 D1-r01 的"算子收缩"一致**：
- 高维度 → 低维度（信息压缩）
- 但压缩不是消灭 — 而是**重组为凝聚态**
