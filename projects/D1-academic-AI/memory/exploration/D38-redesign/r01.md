# D38 实验重新设计：D命题 artefact 分析与修正

## 问题

D38-D 原假设 "T* 随 V_future 递增" 被实验证伪，数据出现 V_future 越大 T* 越短的结果。

## 分析：原实验的 4 个问题

### 问题1：r=0.001 几乎不折现
exp(-0.001 * 365) = 0.694，折现差异只有30%。

### 问题2：sqrt(V_future) 压缩了100倍→10倍的变化
### 问题3：U_net 不依赖 V_future 但边际成本递增 → T*=1 artefact
### 问题4：理论自相矛盾 — "T*=1天 + 高膨胀幅度" 逻辑矛盾

**结论**：这是实验设计问题，不是理论问题。

## v3-v5 迭代尝试

v3-v5 尝试了多种效用函数结构，但都失败：
- v3: accumulated_burst 无界增长 → T*=364 for all V
- v4: U_long 只缩放不改变边际 → T*=17 for all V
- v5: 关系质量依赖但 V_future 只缩放 → T*=8 for all V

**根因**：V_future 只是缩放 U_long 的常数因子，不影响边际 trade-off。

## v6 最终设计：V_future 通过信号振幅放大

### 机制：$A_0(V) = A_{base} \cdot (1 + \alpha \cdot \frac{V}{1+V})$

V_future 影响初始信号振幅，而非只缩放折现项。高 V_future → 更高 A_0 → "短而强"策略。

### 结论：D38-4a 被数值确认

**高 V_future → 短膨胀期 + 高振幅**（"短而强"策略）

理论解释：边际成本固定，高 V_future 只放大信号振幅 → 短期信号边际收益 >> 边际成本 → 无需延长膨胀期。

**信号质量替代信号时长**的投资策略。

### 效用函数结构（v6）

```
U(T) = ∫₀ᵀ [A(t) - C(t)] dt + exp(-rT) · V_maint · (1 + γ_rel · rel_quality) · V_factor

A_0(V) = A_base · (1 + α · V/(1+V))  ← V_future 影响振幅
rel_quality = min(1, κ · ∫₀ᵀ A(t)dt)
V_factor = V/(1+V)
```
