## 共生态的 Liapunov 泛函

### 假设 4.1（共生态泛函存在性）

存在 Liapunov 泛函 $\mathcal{F}[I]$ 使得：
$$\frac{d}{dt} \mathcal{F}[I] = -\int_\Omega D[I] \cdot \left|\frac{\delta \mathcal{F}}{\delta I}\right|^2 dx \leq 0$$

其中：
$$\mathcal{F}[I] = \int_\Omega \left[\frac{\lambda}{2}|\nabla I|^2 + V_{\text{comp}}(I) + V_{\text{coop}}(I) - \mu Q_{\text{new}}[I]\right] dx$$

**各项物理含义**：
1. $\frac{\lambda}{2}|\nabla I|^2$：**竞争扩散能量**——竞争导致的"信息波动"
2. $V_{\text{comp}}(I)$：**竞争势垒**——竞争超过某个阈值后的"阻力"
3. $V_{\text{coop}}(I)$：**合作吸引势**——合作的正向反馈
4. $-\mu Q_{\text{new}}[I]$：**创新来源项**——使系统偏离平衡的力量

### 共生态的稳定性条件

**定理 4.1**：共生态在 $\mathcal{F}$ 的**局部最小值**处稳定。

**证明思路**：
- $\mathcal{F}$ 在共生态有 $\frac{\delta \mathcal{F}}{\delta I} = 0$
- 稳定性取决于 $\frac{\delta^2 \mathcal{F}}{\delta I^2}$ 的**正定性**
- 如果 $\alpha$（竞争强度）和 $\beta$（合作强度）满足特定不等式，系统收敛到共生态

## 共生态的三种稳定性模式

### 模式 1：**线性稳定共生**（弱耦合共生）

当 $\alpha \ll \beta$（合作主导）：
$$\mathcal{F}[I] \approx \int \left[\frac{\lambda}{2}|\nabla I|^2 + V_{\text{coop}}(I)\right] dx$$

**特征**：
- 系统趋向**最小竞争**（近似合作）
- $Q_{new}$ 项只能维持小的扰动
- 类似**谐波振荡**——小幅波动后回到平衡

### 模式 2：**非线性稳定共生**（强竞争平衡）

当 $\alpha \approx \beta$ 且竞争势垒有**局部最小值**：
$$V_{\text{comp}}(I) = \frac{\alpha}{2}(I - I_{\text{eq}})^2 + \frac{\alpha_4}{4}(I - I_{\text{eq}})^4$$

**特征**：
- **多吸引子结构**——共生态可能锁定在不同"竞争水平"
- 类似于**Ising 模型的相变**——竞争强度的突然跳跃

### 模式 3：**极限环稳定共生**（动态平衡）

当 $\mu Q_{\text{new}}[I]$ 项主导时：
$$\frac{d}{dt} \mathcal{F}[I] \approx 0 \text{ with } \mathcal{F} \text{ oscillating around } \mathcal{F}_{\text{steady}}$$

**特征**：
- **没有静态平衡**，系统持续在共生态附近振荡
- 类似**van der Pol 振荡器**——竞争-合作交替占优
- **这是科学共同体最可能的状态**——持续的创新循环

## 共生态的相变边界（Lyapunov 不稳定点）

### 共生态的**临界竞争强度**

**假设 4.2**（共生态临界强度）：
$$\alpha_c = \frac{\beta^2}{4\mu} \cdot \frac{1}{\langle \nabla^2 \rangle}$$

当 $\alpha > \alpha_c$ 时：
- $\frac{d}{dt} \mathcal{F} > 0$——Liapunov 泛函**不再递减**
- 共生态**失稳**，退化为纯竞争

**当 $\alpha < \alpha_c$ 但接近 $\alpha_c$ 时**：
- **共生态是亚稳态**——微小扰动可能导致相变
- 这是"达尔文式竞争"在科学中的作用——**维持适度的不稳定**

## D4 r04 与 S18 r04 的理论统一

### 博弈动力学作为场论的特例

S18 r04 提出统一泛函：
$$\mathcal{L}[\phi, \pi] = \int_\Omega \left[\frac{1}{2}|\nabla \phi|^2 - V(\phi) + \mathcal{G}(\phi)\right] dx dt$$

D4 r04 共生态 Liapunov 泛函：
$$\mathcal{F}[I] = \int_\Omega \left[\frac{\lambda}{2}|\nabla I|^2 + V_{\text{comp}}(I) + V_{\text{coop}}(I) - \mu Q_{\text{new}}[I]\right] dx$$

### 直接映射

| S18 泛函项 | D4 泛函项 | 物理含义 |
|------------|-----------|----------|
| $\frac{1}{2}|\nabla \phi|^2$ | $\frac{\lambda}{2}|\nabla I|^2$ | 空间扩散能量 |
| $-V(\phi)$ | $V_{\text{comp}}(I) + V_{\text{coop}}(I)$ | 势垒结构 |
| $\mathcal{G}(\phi)$ | $-\mu Q_{\text{new}}[I]$ | 外部输入/源 |

**统一公式**：
$$\mathcal{L}_{\text{D4-S18}}[\phi] = \mathcal{F}[I] + \gamma \int_\Omega \frac{\partial \phi}{\partial t} \cdot \nabla I \, dx dt$$

其中 $\gamma \int \frac{\partial \phi}{\partial t} \cdot \nabla I \, dx dt$ 表示**场-信息耦合项**。
