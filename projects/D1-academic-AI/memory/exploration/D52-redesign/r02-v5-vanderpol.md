# D52 重构记录：v3→v4→v5 Van der Pol

## v3 问题总结
- 线性振荡器无法产生迟滞（D52-D = 0.000000）
- 记忆核机制太弱（mu_0 在 [0, 0.4] 范围内，对 zeta=0.3 的基础阻尼影响 <5%）
- 预规划强度 alpha 对能量有 10x 影响（这是真正有价值的信号）

## v4 初步尝试
- 使用 Van der Pol 方程替代线性振荡器
- D52-A：mu 增大 → 能量增加（slope=0.070, p=0.77）
- D52-B：alpha 对能量有显著影响（slope=0.65, 非单调）
- 迟滞计算方式有缺陷（独立稳态解而非时间-varying 扫描）

## v5 改进（关键修正）
1. **迟滞计算**：使用 time-varying mu 扫描（单次长积分），而非独立稳态解
2. **外部驱动**：振荡 forcing cos(omega*t)，非恒定 forcing
3. **频率-能量对偶**：清晰测量 mu 对极限环频率的影响

## v5 结果

### D52-A: 频率-能量对偶性
| mu | 能量 | 振幅 | 频率 |
|----|------|------|------|
| 0.0 | 0.50 | 1.00 | 0.16 |
| 1.0 | 2.05 | 2.01 | 0.17 |
| 5.0 | 2.49 | 2.02 | 0.09 |
| 20.0 | 2.79 | 2.01 | 0.03 |

**发现**：
- 频率~mu 斜率 = -0.0072 (p=0.15) — 趋势明显但不显著
- 能量~mu 斜率 = +0.0656 (p=1.75) — 正相关
- 振幅收敛到 2.0 — Van der Pol 极限环标准性质
- **高 mu 下频率急剧下降**：0.16→0.03（relaxation oscillation 相变）

### D52-B: 预规划强度 alpha
- 能量最小值在 alpha=1.5（E=1.00）
- alpha>2 后能量急剧上升（~alpha²）
- 非单调关系，存在最优预规划强度

### D52-C: 迟滞效应 **✓ 关键突破**
- **迟滞面积 = 318.6**（归一化 0.78）
- 不同 alpha：178–324（alpha=2.0 时最小，强驱动抑制迟滞）
- **线性振荡器 v3: 迟滞 = 0.000000**
- **Van der Pol v5: 迟滞 = 318.6**
- 这是 D52 理论的核心验证：非线性是迟滞的必要条件

### D52-D: alpha-mu 交互
- 最低能量：mu=0, alpha=0.7（E=0.17）
- 随 mu 和 alpha 增大，能量变化范围扩大
- 非线性阻尼使系统对 pre-planning 更敏感

## 结论

D52 需要重构为：
1. **非线性振荡器框架**（Van der Pol）
2. **核心发现**：频率-能量对偶 + 迟滞效应
3. **预规划-回调 trade-off**（alpha 的非线性影响）
4. 线性振荡器模型不能产生迟滞
