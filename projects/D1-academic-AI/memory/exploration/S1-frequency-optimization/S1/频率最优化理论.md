## 核心问题

### Q1：什么是"频率最优化"？

**直觉理解**：系统不是均匀访问所有维度，而是根据频率（重要性/变化率）分配注意力资源。

**信息论形式化**：
$$\text{访问}(d) \propto \exp(-\beta \cdot \omega_d \cdot C(d))$$

其中：
- $\omega_d$：维度 $d$ 的"频率"（变化率或重要性权重）
- $C(d)$：访问维度 $d$ 的代价
- $\beta$：注意力预算参数

**频率最优化核心命题**：最优访问策略将注意力集中在**高频高代价**区域——因为这些区域对系统状态影响最大。

---

### Q2：预规划代价泛函的形式

**原始 idea 直觉**：在进行"预规划"（预先探索/规划）时，需要一个代价泛函来优化规划深度和广度。

**从 S18 场论获取形式**：
$$\mathcal{L}_{\text{plan}}[\phi] = \int \left[\frac{1}{2}|\nabla \phi|^2 + \gamma \cdot \text{Frequency}(\phi) + \lambda \cdot \text{Cost}(\phi)\right] dx$$

**S1 新贡献——预规划代价泛函的**三项分解**：

$$\mathcal{L}_{\text{preplan}} = T_{\text{explore}} + V_{\text{frequency}} + W_{\text{opportunity\_cost}}$$

| 项 | 含义 | 来源 |
|----|------|------|
| $T_{\text{explore}}$ | 探索代价 | 预规划中的计算成本 |
| $V_{\text{frequency}}$ | 频率适配 | 根据信息频率调整规划粒度 |
| $W_{\text{opportunity}}$ | 机会成本 | 预规划时间内放弃的"在线探索"收益 |

---

### Q3：频率最优化与信息瓶颈的关联

**假设**：频率最优化本质上是在做**动态信息瓶颈**。

**形式化**：
$$\min_{p(z|x,t)} I(X; Z | t) \text{ s.t. } \sum_t \omega_t I(Z_t; Y) \geq \gamma$$

**解释**：
- 每个时间步 $t$ 有不同的重要性权重 $\omega_t$
- 标准 IB 假设等权重建模
- **频率最优化**假设**变化快的特征**需要更多容量

---

### Q4：频率最优化如何与场论统一框架连接？

**与 S18 r04 的连接**：
- 场论求解器的"场表示层"需要选择基函数
- 基函数选择本质上就是**频率最优化**——高频模式用更多自由度

**统一公式**：
$$\mathcal{L}_{\text{unified}} = \mathcal{L}_{\text{S18}} + \mathcal{L}_{\text{S1}} = \int \left[\frac{1}{2}|\nabla \phi|^2 + \gamma |\nabla \phi|_{\text{freq-weighted}} + V(\phi)\right] dx$$

其中 $|\nabla \phi|_{\text{freq-weighted}}$ 表示**加权梯度**——高频空间变化惩罚更重。

## 技术要点

### 频率估计算法（对给定问题空间）

$$\hat{\omega}_d = \frac{1}{\tau} \sum_{t=0}^{\tau} \left|\frac{\partial J(\theta_t)}{\partial \theta_{d,t}}\right|$$

这是**基于梯度的频率估计**——在训练中实时估计每个参数的"重要性"。

### 预规划算法结构

```
function PREPLAN(problem, budget=β):
    ω = estimate_frequencies(problem, τ)  // Q1 的频率估计
    L = construct_preplan_Lagrangian(ω)    // Q2 的泛函构造
    φ = minimize(L, constraint=budget)     // 预规划求解
    return φ                                  // 规划结果（场表示）
```
