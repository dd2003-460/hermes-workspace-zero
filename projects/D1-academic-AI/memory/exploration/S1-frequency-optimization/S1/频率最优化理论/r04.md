## 从理论到检验：频率 oracle 概念

### r03 的理论问题

r03 提出了频率演化方程：
$$\frac{d\omega_s}{dt} = \alpha_s \nabla^2 \omega_s - \beta_s \omega_s + \gamma_s \cdot \text{surprisal}_s(\phi)$$

但有一个关键问题：**我们如何知道 $\{\omega_s^*\}$ 是最优频率分布？**

### r04 创新："频率 oracle"定义

**假设 4.1（频率 oracle 存在性）**：
对于任何优化问题 $J(\phi)$，存在一个**验证函数** $\mathcal{O}[\{\omega_s\}]$ 使得：

$$\mathcal{O}[\{\omega_s\}] = \max_{\{\omega_s\}} \mathbb{E}\left[\frac{d}{dt} \text{Performance}(\phi, \{\omega_s\})\right] - \min_{\{\omega_s\}} \mathbb{E}\left[\frac{d}{dt} \text{Performance}(\phi, \{\omega_s\})\right]$$

**直观解释**：频率 oracle 测量——**改变频率分布时，性能变化的方差**。方差越大，说明该频率分布**越接近最优**（性能对频率分配越敏感）。

**等价定义**：
$$\mathcal{O}[\{\omega_s\}] = \text{Var}_{\omega_s}[\nabla_\phi J] \implies \omega_s^* = \arg\max_{\{\omega_s\}} \mathcal{O}[\{\omega_s\}]$$

## 频率最优化与自适应优化算法的统一

### 核心假设 4.2（自适应优化器的频率权重）

**观察**：所有自适应优化器（Adam、AdaGrad、RMSProp）本质上都在**动态调整频率权重**。

**形式化**：
$$\omega_d(t) = \frac{1}{\sqrt{v_d(t) + \epsilon}}$$

其中 $v_d(t)$ 是 Adam 的二阶矩估计——本质上是**维度 $d$ 的历史变化频率**。

**S1 r04 的核心命题**：
> **自适应优化器的收敛性由频率最优性保证——当 $\omega_d(t)$ 接近最优时，收敛速度最大化。**

---

### 定理 4.1（频率约束下的收敛速率）

**表述**：对于 L-Lipschitz 连续梯度且频率分布 $\{\omega_s\}$ 满足 **$\|\omega_{s+1} - \omega_s\| \leq \delta$** 的问题，收敛速率为：

$$\| \phi_T - \phi^* \| \leq O\left(\frac{1}{\sqrt{T \cdot \min_s \omega_s}}\right)$$

**推论**：
- 如果 $\min_s \omega_s \to 0$（某个频率被忽略），收敛速度**退化到 O(1/√T)**
- **这与观察到的大模型在训练后期"注意力衰减"现象吻合**——某些维度的频率权重趋于零

## 实证检验框架

### 检验 I：自适应优化器的频率追踪实验

**方法**：
1. 训练语言模型（如 GPT-2 124M）
2. 在每个训练步记录维度 $d$ 的梯度方向变化率 $\dot{\theta}_d(t)$
3. 计算自适应优化器的等效频率权重 $\hat{\omega}_d^{Adam}(t)$
4. **验证**：$\hat{\omega}_d^{Adam}(t)$ 是否接近最优频率 $\omega_d^*$？

**可检验预测**：
- 最优 $\omega_d^*$ 应该接近 $\hat{\omega}_d^{Adam}(t)$ 的**长期时间平均**
- 如果人为**注入噪声到 $\omega_d$**（扰动自适应权重），收敛应该下降

### 检验 II：频率预测的实验——"前视频率"

**方法**：
1. 使用 **LSTM/Transformer 预测未来 $K$ 步的梯度频率 $\hat{\omega}(t+K)$**
2. 对比"实时频率"vs"前视频率"的收敛速率
3. **验证 r03 的"预规划有价值"假设**

**可检验预测**：
- 当频率变化率 $\frac{d\omega}{dt}$ 快时，**前视频率的价值**更大
- 当频率变化率慢时，实时频率与预规划价值相当

### 检验 III：跨任务频率迁移

**方法**：
1. 在任务 A 上训练模型并记录 $\omega^*_A$
2. 在任务 B 上初始化使用 $\omega^*_A$ vs 均匀初始化
3. **验证**：任务间频率分布的**迁移性**

## 与 S18 r04 的统一深化

### 频率作为场论的**基函数选择器**

S18 r04 提出场论求解器的**基函数选择准则**：
$$\psi_s(x) = \text{basis function for scale } s \text{ chosen by } \arg\max_s \omega_s(x)$$

**S1 r04 的严格化**：

**定理 4.2（频率最优基函数）**：
如果 $\{\omega_s^*\}$ 是最优频率分布，则基函数 $\psi_s$ 的选择最小化了：
$$\mathbb{E}\left[\|\phi_{\text{true}} - \sum_s c_s \psi_s(\omega_s^*)\|^2\right]$$

**证明思路**：
- 最优频率分布最大化信息保留
- 对应的基函数捕捉了**最大方差方向**
- 方差方向 = 信息理论中的"信息几何方向"（Fisher 信息矩阵特征向量）
