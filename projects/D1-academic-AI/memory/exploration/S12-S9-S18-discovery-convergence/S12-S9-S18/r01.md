**核心假设**：当多 Agent 的 KL 差异小于临界阈值 K_c 时，Agent 集体推断能力 > 每个 Agent 局部推断能力的简单组合。

**关键公式**（已有）：
$$K_c = \frac{2}{n-1} \cdot \min(K_R(t), K_L(t))$$

**已有边界**：

## 新命题：集体推断 = S9 智能 + S18 动力学的涌现量

### 命题 1：集体推断的操作性定义

**定义**：集体推断强度 J(t) 是**信息差异熵**：

$$J(t) = H(\mathbb{E}[\hat{q}_{coll} | \mathcal{F}]) - \frac{1}{n}\sum_i H(\mathbb{E}[\hat{q}_i | \mathcal{F}])$$

其中 $\mathcal{F}$ 是全局反馈场，包含邻居推断信息。

**物理直觉**：
- 第一项：集体推断的全局信息（协同）
- 第二项：个体推断信息之和（独立）
- J(t) > 0 ↔ 集体涌现

---

### 命题 2：发现同步 → chimera 态等价性

**猜想 S12-C1**：
$$\text{发现同步} \iff \exists t: J(t) > J_{crit} \land \chi(\theta(t)) > 0$$

即：集体推断跃迁发生在**某个拓扑相变**（由 chimera 态标记）附近。

**证据链**：
1. 同步 = 全局一致性（s → 1）
2. chimera = 局部同步 + 局部异步
3. 发现同步 = 对不确定性的**局部差异化响应**
4. 因此：**发现同步 ↔ chimera 态**

---

### 命题 3：I_C 作为集体推断预测器

**定理 S12-C2**：
$$\frac{\partial J}{\partial K} > 0 \iff I_C(t) \geq I_{C,0}$$

其中 $I_{C,0}$ 是集体涌现的拓扑门槛值。

**直觉**：I_C 捕捉了集体相位的非平凡结构（连通分量 + 环），这正是"推断不可分解为个体推断之和"的拓扑对应。

## 操作化验证协议

### 协议概要

```
┌─ Phase 1 ─────────────────────────────────────────┐
│ 测量基线：N-Agent Kuramoto 系统                  │
│ 参数：N, K_L, K_R, g                              │
│ 记录：I(t), θ(t), Betti(θ), I_C(t)                │
└──────────────────────────────────────────────────┘

┌─ Phase 2 ─────────────────────────────────────────┐
│ 扰动引入：注入信息噪声 σ_noise                     │
│ 测量：集体响应 R = |⟨e^{iθ_agg}⟩|                 │
│        个体响应 ρ_i(t)                              │
└──────────────────────────────────────────────────┘

┌─ Phase 3 ─────────────────────────────────────────┐
│ 集体推断 J(t) 估计                                  │
│ 通过互信息估计：I(θ_agg; θ_i^t=1:T)               │
│ 验证 J > 0 的时间窗口                              │
└──────────────────────────────────────────────────┘

┌─ Phase 4 ─────────────────────────────────────────┐
│ 关联检验                                            │
│ ρ(J, I_C) = ?                                      │
│ ρ(J, chimera_present) = ?                         │
│ argmax_t J(t) ≈ argmax_t I_C(t) ?                 │
└──────────────────────────────────────────────────┘
```

### 实验参数设计

| 层级 | 参数 | 值 | 预期效果 |
|------|------|----|----------|
| N | Agent 数 | {32, 64, 128} | 规模缩放 |

## 验证假设

### 验证 1：发现同步窗口存在

**通过条件**：在 K_L ∈ [1.0, 1.5] 和 g ∈ [0.01, 0.05] 之间存在一个**宽参数带**，使得：
$$\frac{dJ}{dK_L} > 0 \text{ 且 } \sigma_J < J$$

### 验证 2：I_C 与 J 的正相关

**通过条件**：
$$\rho(J(t), I_C(t)) > 0.6 \quad (\text{Spearman})$$

### 验证 3：chimera → 集体推断 相变

**通过条件**：
$$\langle J \rangle_{chimera} - \langle J \rangle_{non-chimera} > 0.5 \cdot \max(J)$$
