## 实证验证方案 I：数值实验（P0 优先级）

### 实验 N.1：Chimera 寿命分布的实证检验

**理论预测**（来自 S12 r05）：
$$P(L) \sim L^{-\alpha} e^{-L/\tau}$$

**实验设置**：

```python
# 基于 S12 r05 的数值模拟框架
def experiment_chimera_lifetime_distribution(N_simulations=1000):
    """
    检验 Chimera 寿命是否服从幂律-指数截断分布
    """
    lifetimes = []
    
    for i in range(N_simulations):
        # 不同初始条件
        n_agents = random.choice([200, 500, 1000])
        K = random.uniform(0.5, 3.0)  # 耦合强度
        alpha = random.uniform(0.5, 1.5)  # KS 色散系数
        
        # 运行模拟
        simulator = ScientificConsensusSimulator(
            n_agents=n_agents,
            coupling=K,
            noise=0.01,
            alpha_kd=alpha
        )
        simulator.initialize_chimera_state()
        
        # 追踪 chimera 存在时间
        chimera_start = None
        chimera_alive = True
        
        for t in range(10000):
            simulator.step()
            
            # 检测 chimera 状态
            score = simulator.measure_chimera()
            
            if score < THRESHOLD and chimera_start is None:
                chimera_start = t  # 消失
                chimera_alive = False
            elif score > THRESHOLD and chimera_alive:
                if chimera_start is not None:
                    lifetimes.append(t - chimera_start)
                    chimera_start = None
        
        if chimera_start is not None:
            lifetimes.append(10000 - chimera_start)
    
    return lifetimes
```

**统计检验**：

1. **幂律拟合**：使用 powerlaw 库拟合 $P(L) \sim L^{-\alpha}$
2. **截断检验**：对比纯幂律 vs 幂律+指数截断
3. **参数一致性**：$\alpha$ 和 $\tau$ 是否随 N 和 K 变化

**理论验证**：
- 若 $\alpha \approx 1.5$：对应于**临界现象中的普适指数**
- 若 $\tau \propto N^\gamma$：验证标度关系

**操作化指标**：
$$KDI_{17C}(t) = \frac{N_{calculus}(t) \cdot R_{avg}}{V_{mathematics}(t)}$$

其中 $N_{calculus}$ 是与微积分相关的论著数量。

**预测**：
- 1680 年之前：低 KDI，FTD 大（时间差数年到数十年）
- 1680-1710：KDI 超越临界值，FTD 显著缩小（两位独立工作发表间隔）

```python
def analyze_discovery_concurrence(inspire_data, discovery_event):
    """
    分析某项发现的团队间时间分布
    """
    papers = inspire_data.query(
        subject=discovery_event,
        year_range=(start_year, end_year)
    )
    
    # 计算时间差分布
    dates = sorted([p['publication_date'] for p in papers])
    time_gaps = [dates[i+1] - dates[i] for i in range(len(dates)-1)]
    
    # 计算 FTD
    ftd = np.var(time_gaps) / np.mean(time_gaps)**2
    
    # 关联 KDI（该领域年均论文数）
    kdi = len(papers) / (end_year - start_year) / N_physicists_field
    
    return ftd, kdi
```

**预测**：FTD 与 KDI 呈**负对数线性关系**。
