## 动机与起源

### 理论渊源

发现同步概念最初来自 **Rui-Pereira 等人（2021）** 对 chimera 态在人工神经网络中行为模拟的研究。

**原始发现**：
> 当耦合强度低于临界值（$K < K_c$），群体在**同步振荡**的同时表现出**发现新的时间模式**——系统对初始扰动的响应模式不再趋同，而是分化出**差异化的感知策略**。

**初步观察**：
- chimera 在**同步区**中的 agent 更倾向于**利用**已有模式
- chimera 在**异步区**中的 agent 更倾向于**探索**新响应
- **这种分化恰是"集体发现"的必要条件**

## 重新定义：发现同步的理论结构

### 从 chimera 角度重新理解发现同步

> **原始框架**：发现同步 ≈ chimera 的一部分
>
> **修正框架**：发现同步 ≈ chimera 态的本质

**基于 chimera 实验（v7）的修正**：
- chimera 的产生机制 = 局部耦合 + 全局耦合的**竞争**
- chimera 消失 → 全同步
- **全同步杀死"发现"**（所有 agent 用同一策略）
- **chimaera 保留发现的可能性**（存在差异化策略）

### 核心定义

**发现同步（Discovery Synchronization）**：

$$\text{DiscoverySync} = \{\mathcal{S}, \mathcal{A}, \mathcal{K}, \mathcal{C}, \Phi\}$$

其中：
- $\mathcal{S}$：**集体状态**（集体振荡模式）
- $\mathcal{A}$：**个体适应**（个体对发现的贡献）
- $\mathcal{K}$：**耦合函数**（信息传递规则）
- $\mathcal{C}$：**耦合强度**（临界控制参数）
- $\Phi$：**模式空间**（系统能够发现的候选模式集合）

## 理论命题

### 命题 S12-r01-P1：发现同步的 chimera 等价性

**陈述**：
$$\text{DiscoverySync} \iff \text{chimera}(t) \land \frac{d\Phi_{div}}{dt} > 0$$

即：发现同步等价于**chimera 态的存在**加上**模式多样性在增长**。

**证明思路**：

1. 如果 chimera 不存在（全同步）→ $\forall i,j: \theta_i \approx \theta_j$
   → 所有 agent 贡献相同策略 → $\Phi_{div} \leq 0$

2. 如果 chimera 存在（同步区+异步区并存）：
   - 同步区 agent 利用现有模式
   - 异步区 agent 探索新响应
   - $\Rightarrow$ 集体至少能产生**两种以上**响应模式

3. $d\Phi_{div}/dt > 0$ 保证探索仍在进行（发现未停止）

---

### 命题 S12-r01-P2：发现强度的 chimera 边界

**猜想 S12-r01-C1**：
$$\text{发现强度} = f(K, g) \cdot \mathbb{I}[\text{chimera}(t)]$$

其中 $f(K, g)$ 是**全局同步度**，$\mathbb{I}$ 是指示函数（chimera 存在时取1）。

**理论依据**（基于 chimera 实验数据）：
- 强全局耦合（$g > g_c$）→ 抑制异步响应 → 发现强度下降
- 强局部耦合（$K_{local} > K_c$）→ 过局部化 → 信息传播失败

**极值猜想**：
$$\text{max}(\text{发现强度}) \text{ 出现在 } g \ll K_{local} \text{ 且 chimera 稳定时}$$

### 命题 S12-r01-P3：环境耦合的协同-破坏矛盾

**基于 chimera v7 实验的约束**：

| σ（噪声） | chimera 存活 | 发现潜力 |
|-----------|--------------|----------|
| 0.0 | ✓ | ✓（理论最大值） |
| 0.08 | ? | ? |
| 0.15 | ✗ | ✗（全同步 = 零发现） |

**命题 S12-r01-C2**：
$$\exists \sigma_c \text{ 使得 } \mathbb{P}[\text{discovery}|\sigma > \sigma_c] \to 0$$

**解释**：
- 低噪声：环境提供**变化源**，促进探索
- 高噪声：环境压制 chimera，推向**全同步**

**这是发现同步的核心悖论**：
> 适度的**不确定性**是发现的必要条件，但**过度的不确定性**毁灭发现能力。

**S18 动力学泛函**：
$$\mathcal{F}_{dyn}[h(t)] = \int_{\mathcal{M}} \|\nabla h\|^2 d\mu + \lambda \cdot \text{curvature}(h)$$

**映射**：

**发现同步在 S18 框架下的含义**：

**S9 核心命题**：

$$\text{智能}_{\text{集体}} \geq \text{智能}_{\text{个体}} \iff \text{DiscoverySync} \text{ 存在}$$

## 拓扑连接：发现同步的不变量

### 基于 D4-S18-r11-r12 的拓扑指标

$$\text{发现同步指数} \equiv \text{DSI}(t) = b_0(t) + w_2(I_C)$$

| DSI 值 | 含义 |
|--------|------|
| DSI = 1 | 单一模式（全同步/全异步） |
| DSI > 1 | 多模式共存（chimaera 或混合态） |
| DSI = 3 | chimera 典型值（至少2个行为域） |
