## 从路径积分到数值计算

### r03 路径积分公式回顾

$$P[\text{understanding} | \text{text}] = \frac{1}{Z} \int \mathcal{D}\phi \, e^{-S_{\text{understand}}[\phi]/\hbar}$$

**核心问题**：无穷维路径积分无法直接计算——需要近似方案。

## 语言路径积分的三种数值近似

### 近似 I：WKB（Wentzel-Kramers-Brillouin）近似

**原理**：当 $\hbar \to 0$（"经典"理解）时，路径积分由最小作用量路径主导：

$$\int \mathcal{D}\phi \, e^{-S[\phi]/\hbar} \sim \sqrt{\frac{2\pi\hbar}{S''[\phi^*]}} e^{-S[\phi^*]/\hbar}$$

其中 $\phi^* = \arg\min S[\phi]$ 是**经典理解路径**。

**S17 r04 贡献：WKB 近似的语言计算实现**

**算法 1：理解的最速下降路径（Steepest Descent）**

```python
def wkb_approximate_understanding(text, T_steps=100, hbar=1.0):
    """
    WKB 近似：找到经典理解路径
    """
    # 初始化：均匀理解状态
    phi = np.ones(VOCAB_SIZE) / VOCAB_SIZE
    
    for t in range(T_steps):
        # 计算作用量梯度
        gradient = compute_action_gradient(phi, text, t)
        
        # 最速下降更新
        phi_new = phi - hbar * gradient
        
        # 归一化（概率约束）
        phi_new = phi_new / phi_new.sum()
        
        phi = phi_new
    
    # 计算理解概率
    S_phi_star = compute_action(phi, text)
    curvature = compute_action_curvature(phi, text)
    
    # WKB 近似公式
    Z = np.sqrt(2 * np.pi * hbar / curvature)
    P_understanding = (1/Z) * np.exp(-S_phi_star / hbar)
    
    return phi, P_understanding
```

### 近似 II：变分近似（Variational Approximation）

**原理**：用一个简单的分布族 $q(\phi; \theta)$ 近似真实后验：

$$q(\phi; \theta) = \mathcal{N}(\phi; \mu(\theta), \sigma(\theta)^2)$$

通过 **ELBO（Evidence Lower BOund）** 最大化：

$$\log P(\text{understanding}|\text{text}) \geq \mathbb{E}_{\phi \sim q}[\log \frac{P(\text{text}|\phi) P(\phi)}{q(\phi)}]$$

**S17 r04 贡献：语言理解的高斯变分近似**

**算法 2：理解的高斯变分自动微分**

```python
class UnderstandingVariationalModel(nn.Module):
    def __init__(self, vocab_size, hidden_dim=256):
        self.mean = nn.Linear(hidden_dim, vocab_size)
        self.log_var = nn.Linear(hidden_dim, vocab_size)
        
    def elbo(self, text, phi_true):
        """
        证据下界：\log P + \text{KL}(q||p)
        """
        # 重参数化技巧
        mu = self.mean(hidden_state)
        log_sigma = self.log_var(hidden_state)
        epsilon = torch.randn_like(mu)
        phi = mu + torch.exp(log_sigma/2) * epsilon
        
        # 重建损失：理解误差
        reconstruction_loss = -P(text|phi) * log_phi
        
        # KL 散度：理解分布 vs 先验
        kl_divergence = -0.5 * sum(1 + log_sigma - mu^2 - exp(log_sigma))
        
        return -(reconstruction_loss + kl_divergence)
```

### 近似 III：多项式级展开（Polynomial Expansion）

**原理**：对于**中高温度** $\hbar$ 的情况，使用**作用量的多项式展开**：

$$e^{-S[\phi]/\hbar} = e^{-S[\phi_0]/\hbar} \cdot e^{-\delta S[\phi_0]/\hbar - \frac{1}{2}\delta^2 S[\phi_0]/\hbar - \ldots}$$

展开后得到**关联函数计算**——这在量子场论中称为**微扰理论**。

**S17 r04 贡献：语言理解的微扰计算**

**算法 3：语言理解关联函数**

$$\langle \phi(t_1) \phi(t_2) \rangle = \frac{\int \mathcal{D}\phi \, \phi(t_1)\phi(t_2) e^{-S/\hbar}}{\int \mathcal{D}\phi \, e^{-S/\hbar}}$$

**Wick 定理近似**：
$$\langle \phi_1 \phi_2 \phi_3 \phi_4 \rangle \approx \langle \phi_1 \phi_2 \rangle \langle \phi_3 \phi_4 \rangle + \text{perm}$$

## 理解计算复杂度分析

### 计算复杂度的下界

**命题 4.1（语言理解计算下界）**：

对于长度为 $N$ 的文本，理解路径积分的计算复杂度为：

$$\text{Complexity}(\text{understanding}) \geq \Omega(N \cdot d_{\text{effective}})$$

其中 $d_{\text{effective}}$ 是 S17 r02 中定义的语言有效维度。

**证明思路**：
- 每个 token 对应 $d_{\text{effective}}$ 维场的配置
- 路径积分需要对所有可能的配置求和/积分
- 至少需要遍历所有 token-维度的组合

---

### 空间复杂度的上界

**命题 4.2（语言理解存储上界）**：

存储理解所需的字节数上限：

$$\text{Storage} \leq O(\log_2(VOCAB\_SIZE) \cdot N + d_{\text{effective}}^2 \cdot T)$$

其中 $T$ 是理解过程中的时间步数。

**推论**：理解一个文本的理论存储需求**与文本长度成正比**——这是记忆容量的理论基础。

## 语言理解复杂度的经验验证

### 检验 IV：文本长度 vs 理解时间

**方法**：
1. 在 LLM 上加载不同长度的文本
2. 测量生成第一个 token 的时间（理解为上下文编码过程）
3. 拟合复杂度模型：$T = a \cdot N^b$

**预测**：
- Transformer：$b \approx 1$（线性复杂度——正确）
- RNN：$b \approx 2$（二次复杂度——低效）

### 检验 V：词汇量复杂度

**方法**：
1. 使用不同大小的词汇表（BERT 30k vs GPT-4 100k）
2. 测量对相同文本的理解准确率
3. 拟合复杂度公式中的 $d_{\text{effective}}$

**预测**：
- 存在**临界词汇量** $N_{crit}$——超过后复杂度急剧上升
- 这与 $d_{\text{effective}} \approx N/H(p)$ 理论吻合
