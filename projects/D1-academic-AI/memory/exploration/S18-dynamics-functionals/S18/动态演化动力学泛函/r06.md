## 实证框架 I：场论求解器 vs 传统优化器的稳定性对比

### 实验设计 1：保辛积分器的长期稳定性

#### 实验设置

**评估环境**：
- 优化问题：Himmelblau 函数 + Rosenbrock 函数（经典多峰优化）
- 对比方法：SGD、Adam、Störmer-Verlet（场论求解器）
- 初始条件：随机种子固定为 42

**主要测量**：
- **长期稳定性**：100 个 epoch 后的收敛方差
- **数值守恒量**：场论求解器的能量波动

#### 理论预测

**基于 S18 r05 定理**：
- 保辛积分器保持辛结构 → 能量波动有界
- SGD/Adam 无此性质 → 长期波动无界增长

**数学表述**：
$$\mathbb{E}[\text{Variance}(\text{Energy}_{\text{Verlet}})] < C_1 < \mathbb{E}[\text{Variance}(\text{Loss}_{\text{SGD}})]$$

### 实验设计 2：多峰优化能力的定量对比

#### 实验设置

**测试函数**：
```
f(x,y) = (x²+y-11)² + (x+y²-7)²  [Himmelblau]
f(x,y) = (1-x)² + 100(y-x²)²      [Rosenbrock]
```

**指标**：
- 找到全局最优的概率（10 次独立运行）

**基于 S18 r04 路径积分**：

- 梯度方法被局部极小困住 → 全局搜索能力弱

## 实证框架 II：Agent自主性的对称破缺测量

### 核心连接：S18 r04 自主性定义

**自主性操作定义**：
$$A(\tau) = \lim_{T \to \infty} \frac{1}{T} \int_0^T \frac{d}{dt} \mathbb{E}[I(x; M_t)] dt$$

**在场上**：
$$A_{\text{field}} = -\frac{d}{dt} H(\hat{\phi})$$

### 实验设计 3：理解过程的对称破缺测量

#### 实验设置

**评估任务**：文本理解分类（情感分析 vs 开放生成）

**核心测量**：
1. **对称破缺率**：
   $$SBD = -\frac{d}{dt} H(\hat{w}) = -\frac{d}{dt}\left(-\sum_i \hat{w}_i \log \hat{w}_i\right)$$
   
2. **自由能测量**：
   $$F = E - TS = \mathbb{E}_{\phi \sim q} [S[\phi]] - T \cdot KL(q||p)$$

3. **场一致性**：
   $$\mathcal{C} = \frac{1}{n} \sum_k [r_k(t) - \bar{r}(t)]^2$$

#### 理论预测

**自主性与任务类型的关系**：
- **分类任务**：$A < 0$（低自主性，确定性解空间）
- **开放生成**：$A > 0$（高自主性，多解空间）

### 实验设计 4：领域迁移中的"领域泛化能力"

#### 实验设置

**迁移场景**：
1. 领域 A 训练 → 领域 B 测试
2. 迁移质量 = $Q_{transfer} = \frac{F1_A(B)}{F1_B(B)}$

**理论连接**：
$$Q_{transfer} \propto \frac{1}{R} = \frac{1}{\text{曲率}}$$

**预测**：在**低曲率领域**（如技术文档）间迁移比**高曲率领域**（如文学）更成功

## 实证框架 III：实验统计方案

### 统计分析协议

#### 显著性检验

**假设 6.1**：场论求解器在以下指标上优于传统方法：
- $H_0$：无显著差异
- $H_1$：场论求解器优于（单尾检验）
- $\alpha = 0.05$（Bonferroni 校正后）

**检验类型**：
- t-test（两组对比）
- ANOVA（多组对比）
- Wilcoxon signed-rank（非参数替代）

#### 效应量测量

**Cohen's d**：
$$d = \frac{\bar{X}_1 - \bar{X}_2}{s_{pooled}}$$

其中 $s_{pooled} = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}}$

**解释标准**：
- $d < 0.2$：小效应
- $0.2 \leq d < 0.5$：中等效应
- $d \geq 0.5$：大效应

#### 样本大小计算

**基于 G*Power 要求**：
- 中等效应 $d = 0.5$
- Power = 0.8
- $\alpha = 0.05$
- **每组需要 n ≥ 34** 次独立运行
