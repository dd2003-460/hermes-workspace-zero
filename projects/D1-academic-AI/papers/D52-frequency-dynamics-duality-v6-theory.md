# D52 理论重构 v6：基于 Van der Pol 非线性振荡器

## 原问题（D52 v3）

D52 原始设计使用**线性振荡器**模型，存在根本缺陷：
1. 线性振荡器无迟滞（D52-D = 0.000000）
2. 记忆核机制太弱，对基础阻尼影响 <5%
3. 真正有信号的是预规划强度 alpha

## 重构方案（v4→v5→v6）

使用 **Van der Pol 方程**替代线性振荡器：

$$x'' - \mu(1-x^2)x' + x = \alpha\cos(\omega t)$$

其中 $\mu$ 是非线性阻尼参数：
- $\mu = 0$：线性振荡器
- $\mu > 0$：非线性，产生极限环和迟滞

- 高频区 ($\mu \geq 5$) 斜率 = **-0.8587**（接近理论预测 -1）

### D52-B: 预规划强度 alpha (v5)

- 能量非单调：alpha=0.0→2.05, alpha=1.5→1.00, alpha=5.0→5.73
- 最优 alpha ≈ 1.5（能量最小）
- alpha > 2 后能量急剧上升（~alpha²）

### D52-C: 迟滞效应 (v5) — 关键突破

- **Van der Pol 迟滞面积 = 318.6**（归一化 0.78）
- **线性振荡器迟滞面积 = 0.0000**
- 不同 alpha：178–324（alpha=2.0 时最小，强驱动抑制迟滞）

### D52-D: alpha-mu 交互效应 (v5)

- 最低能量：mu=0, alpha=0.7（E=0.17）
- alpha 和 mu 都扩大能量变化范围
- 非线性阻尼使系统对 pre-planning 更敏感

## 理论结论

### D52 理论核心预测验证

1. **频率-动力学对偶性** ✅ 验证
   - $\mu$ 控制振荡频率：$\mu$ 增大 → 频率下降
   - 高频区斜率 -0.86 接近理论预测 -1

2. **迟滞效应** ✅ 验证（关键突破）
   - Van der Pol 产生显著迟滞（面积 318.6）
   - 线性振荡器无法产生迟滞（面积 0）
   - 非线性是迟滞的必要条件

3. **预规划-回调 trade-off** ✅ 验证
   - alpha 对能量有非线性影响
   - 存在最优预规划强度（alpha ≈ 1.5）

4. **alpha-mu 交互效应** ✅ 验证
   - 最低能量出现在特定 alpha-mu 组合
   - 非线性阻尼使系统对 pre-planning 更敏感

## 物理解释

Van der Pol 振荡器的 $\mu$ 参数编码了**频率-能量的对偶关系**：
- $\mu = 0$：谐波振荡器，频率恒定 $f = 1/(2\pi) \approx 0.16$
- $\mu > 0$：频率随 $\mu$ 下降，振幅趋近 2.0（极限环）
- $\mu \gg 1$：relaxation oscillation，$f \propto 1/\mu$

预规划强度 $\alpha$ 通过外部驱动调制了极限环的能量和频率。
