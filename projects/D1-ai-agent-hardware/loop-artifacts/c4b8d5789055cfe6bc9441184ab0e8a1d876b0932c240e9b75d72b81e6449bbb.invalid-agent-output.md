- **新卡性价比** → **RTX 4070 Ti Super (16GB)** 或 **RTX 4070 Super (12GB)**

- **入门尝试** → **RTX 4060 Ti (16GB)**：最适合小预算的入门卡

### 关键决策因素

1. **显存容量 (VRAM)**：本地 AI 的最关键指标
   - 7B 模型需要 ~6-8GB
   - 13B 模型需要 ~10-12GB
   - 70B 模型需要 ~40-48GB (单卡不够，需要多卡或蒸发了)

2. **显存位宽**：影响推理速度
   - 4090：384-bit (最快)
   - 4080：320-bit
   - 4070：192-bit

3. **显存带宽**：直接决定 token 生成速度
