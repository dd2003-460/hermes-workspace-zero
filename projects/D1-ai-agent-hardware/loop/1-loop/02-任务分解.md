## 调研目标

为本地 AI agent 选型性价比最优的 GPU 方案。

**核心判定标准**:
- 性价比 = (推理性能 tokens/s + VRAM 容量) / 成本
- 必须覆盖消费级、专业级、Mac 统一内存、云端四类方案
- 所有价格必须实际来源验证（非标价）
- 推理性能必须有实测数据或可信推算

**置信度 ≥ 0.8** 才能进入 2-loop 决策。
