## 3. 场景-方案映射 (已修正)

### 场景A: 日常本地AI agent (7B-30B模型)
- **最优: RTX 4090 二手 ($2,000-2,500)** — 性价比最高，VRAM足够
- **次优: RTX 4090 新货 ($3,000-4,200)** — 如果买不到二手
- ~~❌ RTX 5090 不再推荐: 溢价2-3倍($4,100-5,200)，性价比被稀释到与RTX 6000 Ada同级~~
- **注意**: RTX 4090二手价格($2,000-2,500)高于此前估算($1,300-1,400)，但仍远低于RTX 5090实际售价($4,100-5,200)
- **理由**: 7B-30B模型在24GB VRAM下足够运行，RTX 4090性价比远超RTX 5090

### 场景B: 70B-130B 模型推理
- **最优: A100 80GB PCIe ($17,800-26,000)** — 最快但最贵
- **备选: Mac M3 Max 128GB ($4,000-8,000)** — 慢但能跑，性价比更高
- **云端: A100 80GB RunPod ($1.99-2.79/hr)** — 偶尔使用
- **注意**: 70B 4-bit = ~35GB VRAM，单卡不够，需双卡或多卡

### 场景C: 不确定需求，试水
- **最优: RTX 4090 二手 ($2,000-2,500)** — 转卖亏损有限 (~$200-300, ~8%)
- **注意**: 买新用半年后卖出亏损约 8-10%，远低于持有1-2年后的25%+折旧
- **理由**: 24GB VRAM对7B-30B模型足够，二手市场成熟，残值中等偏上

### 场景D: 长期运行 + 灵活扩展
- **最优: A100 80GB 云端 ($1.99-2.79/hr, RunPod)**
- **对比**: 买A100 80GB PCIe $22,000 = 每天$2.50 × 2500小时 = $6,250/年
- **结论**: 年使用 < 2000小时 → 云端(RunPod)；> 2000小时 → 自购

### 场景E: 需要跑最大模型 (130B+)
- **最优: Mac M4 Ultra 192GB (~$8,000+)** — 最大VRAM
- **备选: Mac M3 Max 128GB (~$4,000-8,000)** — 便宜但勉强
- **双 A100 80GB PCIe** (~$36,000-52,000) — 快但需要服务器

## 4. 关键发现 (已修正)

### 4.0 RTX 4090 二手 — 价格高于预期但仍为最优选择
- ~~二手价格 $1,300-1,400~~ → **$2,000-2,500 (eBay 实际售价)**，溢价约 **54%-79%** 高于此前估算
- **原因**: RTX 4090 在 AI/LLM 推理市场有持续需求 (24GB VRAM 稀缺性)，RTX 5090 发布后二手价格仅下压 10-15%
- **对比**: 新货价格 $3,000-4,200，二手仅低 25-40%
- **关键发现**: 假卡/拆机卡泛滥 (TechSpot 2024.4 报道)，购买需验机 (GPU-Z截图、3DMark基准、12VHPWR接口检查)
- **结论: RTX 4090 二手 ($2,000-2,500) 仍远低于 RTX 5090 实际售价 ($4,100-5,200)，仍为 7B-30B 场景最优选择**

### 4.1 RTX 5090 — 规格优秀但价格失控 (关键修正!)
- ~~MSRP $1,999~~ → **实际售价 $4,100-$5,200 (Newegg)**，溢价 **105%-260%**
- ~~512-bit位宽+1100 GB/s带宽~~ → **512-bit位宽+1792 GB/s带宽** (比之前估计高63%)
- **结论: RTX 5090 规格确实优秀，但实际价格使其性价比被稀释到与RTX 6000 Ada同级。不再是最优选择。**

### 4.2 RTX 6000 Ada — 专业级性价比意外突出
- ~~标价$6,800-8,000~~ → **实际成交价 $6,000-7,300 (Newegg/titanxp.com)**
- 价格/GB $125-152，与RTX 5090同级
- **结论: 对于需要48GB VRAM+ECC+专业驱动的场景，RTX 6000 Ada是专业级最优选择**

### 4.3 A100 80GB PCIe — 远比预期贵
- ~~二手$4,000-6,000~~ → **新货$17,800-26,000 (Newegg PNY)**
- 价格/GB $222-325，性价比差
- **结论: A100 80GB二手市场需通过VEX/Gputek等专业经销商询价，退役机$15,000-20,000估算可能更现实**

### 4.4 Mac方案的两面性
- **优势: 价格/GB极低，可用VRAM最大**
- **劣势: 推理速度只有CUDA卡的1/4-1/8**
- **核心矛盾: 买的是VRAM容量而非速度**
- **适用: 偶尔需要跑大模型，不关心速度的场景**

### 4.5 云端 RunPod — 性价比最优平台
- **RTX 4090: $0.69/hr (RunPod Pods)** — 远低于AWS/GCP/Azure (~$3-4/hr)
- **RTX 5090: $0.99/hr (RunPod Pods)** — 可尝试试水
- **A100 40GB: $1.39/hr (RunPod)** — 可替代自购
- **核心发现: 同是H100，RunPod ($2.89/hr) vs CoreWeave ($49.24/hr) 价差17倍**
