## 2. 为什么需要 RTX 6000 Ada?

| 特性 | RTX 4090 | RTX 6000 Ada |
|------|---------|-------------|
| VRAM | 24GB GDDR6X | **48GB GDDR6** |
| ECC | 不支持 | **支持** |
| 双精度 | 0.98 TFLOPS | **24.7 TFLOPS** |
| 功耗 | 450W | **300W** |
| 显存位宽 | 384-bit | **384-bit** |
| PCIe | 4.0 x16 | 5.0 x16 |
| NVLink | 不支持 | 不支持 |
| 保修 | 3年 | 3年 |

**适用场景**:
- 需要 48GB+ VRAM 跑 70B 参数模型
- 需要 ECC 显存（科学计算/财务计算）
- 需要双精度浮点性能（物理模拟）
- 7×24 稳定运行环境

**不适用场景**:
- 跑 70B 以下模型 (RTX 4090 更划算)
- 偶尔推理 (RunPod 更灵活)
- 无 ECC 需求 (RTX 4090 够用)

## 3. 购买渠道

### 渠道 1: 海外直邮 (eBay/Amazon)

**操作**:
1. 在 eBay 搜索 "RTX 6000 Ada"
2. 筛选: 全新，价格最低
3. 确认支持中国直邮
4. 支付 (使用 PayPal Goods & Payments)

**费用**:
- 商品: $6,000-6,500
- 国际运费: ~$100-200
- 关税: 约 0% (GPU 通常免税)
- 增值税: 约 13% (海关征收)
- 总计: ~$7,000-7,500

**优点**: 有保修，价格透明
**缺点**: 保修需寄回美国

### 渠道 2: 国内代理商

**推荐代理商**:
- 北京: 新格科技、华宇创实
- 上海: 中电数据、英硕电子
- 深圳: 华强北经销商（深圳华强北赛格市场）
- 广州: 百脑汇经销商

**操作**:
1. 联系代理商询价
2. 提供型号: NVIDIA RTX 6000 Ada Generation
3. 确认是否含税/含运费
4. 安排付款和提货

**价格**: ¥45,000-55,000 (含增值税)
**保修**: 通常 1-3 年

**优点**: 有本地保修，无关税烦恼
**缺点**: 价格可能偏高，需甄别信誉

### 渠道 3: 闲鱼二手

**操作**:
1. 搜索 "RTX 6000 Ada" 或 "RTX6000 Ada"
2. 联系卖家，要求提供:
   - GPU-Z 截图 (确认型号和显存)
   - 3DMark 截图
   - 使用情况说明
3. 走闲鱼验货宝
4. 当面验机后确认收货

**价格**: ¥35,000-45,000
**风险**: 无保修，假卡可能性低但存在

**优点**: 价格最低
**缺点**: 无保修，需验机

## 6. 进口关税说明

### GPU 进口中国关税

- **HS Code**: 8471.50.00 (处理单元)
- **GPU 关税**: 通常 0%
- **增值税**: 13%
- **总税费**: 约商品价格的 13%

### 示例计算
```
eBay 价格: $6,000
国际运费: $150
完税价格: $6,150
增值税 (13%): $800
总计: $6,950 ≈ ¥50,500
```
