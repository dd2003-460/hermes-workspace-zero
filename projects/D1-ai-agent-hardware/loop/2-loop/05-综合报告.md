## 4. 核心发现

### 4.1 RTX 4090 二手市场修正

**价格修正**: 从 iter41 的 $1,300-1,400 修正为 $2,000-2,500
- 原因: S2 Agent eBay 交叉验证发现实际成交价更高
- 影响: 仍为最优性价比方案 (原置信度 0.60 → 修正后 0.90)

### 4.2 假卡风险确认

TechSpot 2024.4 报告确认:
- 假卡类型: 显存降配、拆机核心、塑料封印
- 高发渠道: eBay 大陆直邮、闲鱼低价区
- 检测方法: GPU-Z + 3DMark + Furmark 三步验机

### 4.3 RunPod 性价比

$0.69/hr 的 RTX 4090 定价在云端市场中最低:
- Lambda Labs: ~$1.00/hr (高 ~45%)
- CoreWeave: ~$0.85/hr (高 ~23%)
- Vast.ai: $0.40-0.70/hr (可能更低但可靠性参差)

### 4.4 Mac 方案评估

Mac M3 Max 128GB 在 LLM 推理上有独特优势:
- 统一内存架构可加载 70B+ 模型
- 但推理速度远低于 GPU (估计 < 2 tokens/s for 7B)
- 适合"偶尔跑"场景，不适合持续推理
