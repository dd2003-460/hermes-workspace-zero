# D1-grav-waves figure 路径修复（iteration 30）

## 问题
pdflatex 解析 `\includegraphics` 路径时相对于**当前工作目录**，而非 .tex 文件所在目录。导致：
- 从 D1-grav-waves 项目根目录编译：找不到 `papers/2026-GW-BacQFT/Fig1.png`
- compile_paper.sh 从 papers/2026-GW-BacQFT/ 目录编译：找不到 `Fig1.png`（相对路径解析问题）

## 解决方案
将 PNG 复制到项目根目录 + includegraphics 使用 `.png` 扩展名。
pdflatex 在任一目录编译都能找到 figure。

## 验证结果
| 编译方式 | 结果 |
|---------|------|
| `pdflatex` from project root | ✅ 10页/405K PDF，含 figure |
| `compile_paper.sh` from project root | ✅ 10页/405K PDF，含 figure |

## arXiv 注意事项
- arXiv 接受 .png, .pdf, .eps 图片
- 推荐 .pdf 矢量图用于学术论文
- pdflatex 原生支持 .pdf 和 .png
- xelatex 对 .png 支持好，但 .pdf 可能有 "Division by 0" 错误

## 经验教训
- `\graphicspath{{./}}` 不改变 pdflatex 的基本行为（已在 CWD 中查找）
- 将相关文件复制到多个目录比修改路径更可靠
- 编译脚本应始终从 .tex 文件目录运行
