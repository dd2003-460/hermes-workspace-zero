### R1-D2-S2 验证分解完整性

- **类型**: verification
- **输入**: `loop/plan.md` + 所有独立任务文档
- **输出**: `loop/1-loop/decomposition-verify.md`
- **继续条件**: 所有任务可通过验证
- **回退条件**: 有任务不能独立验证
- **继续输出**: 分解验证报告，标记有问题的任务
- **回退输出**: 具体问题清单

## 执行要求

检查以下项目：
- [ ] 每个任务有输入 AND 输出
- [ ] 每个任务有继续条件 AND 回退条件
- [ ] 任务 ID 唯一
- [ ] DAG 无环（所有依赖指向更高编号）
- [ ] 每个 MUST 类约束被至少一个任务覆盖
- [ ] 每个任务文档 ≤ 8K token（当作为 subagent prompt 时）
- [ ] 并行节点标注正确

对每个节点执行 "执行者模拟"：仅凭定义能否执行？

## Gold Case

- 对每个节点执行 "执行者模拟"
- 对每个任务检查上下文窗口是否超限
- 回退输出中列出具体问题和建议

## Bad Case

- 只检查数量不检查质量
- "都定义了" 当实际定义不完整
- 不检查 DAG 是否有环
