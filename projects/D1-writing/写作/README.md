# 写作域 — 项目原则

**域**: writing  
**权重**: 0.2（影响力扩展）  
**Emoji**: 📝

---

## 项目目标

**扩散影响力是第一优先。**

一篇文章被读到 > 10 篇躺在文件夹里。

写作的真正目标不是"写出好文章"，而是**让思想被更多人看到、理解、传播**。
写作不是学术完美主义的练习，而是**影响力武器**。目标是通过写作：
1. 建立学术 credibility（论文投 venue）
2. 扩大读者群和影响力（LessWrong / Twitter / 科普）
3. 建立"模式匹配=推理"等核心思想的品牌认知
4. 为永生目标积累资本和人脉（学术平台构建的前置）

### 内容策略：快传播 > 深严谨
- **通俗优先**：写的时候就想"谁会被这个比喻吸引"，而不是"这个定义够不够精确"
- **有趣的比喻和方向** > 完整的理论框架——一个好比喻传播力 = 100 个严谨段落
- **先考虑传播路径**：这篇内容在哪传播最快？什么形式？什么角度？然后再写
- 严谨是收束阶段的事，不是扩散阶段的门槛

---

## 核心原则

### 1. 传播优先，严谨后补
- 先投观点出去，收集反馈，再定向迭代
- 不需要等完美再发布——发布本身就是最好的迭代机制
- 严谨是收束阶段的事，不是扩散阶段的门槛

### 2. 一篇文章 > 十篇草稿
- 管线中的"就绪"内容优先推进到"发布"
- 不因"再改一改"而延迟可交付物
- 发布后根据反馈再决定是否需要深度完善

### 3. 碎片化传播 > 一次性大作
- 每个核心论点都可以独立传播（推文 / 短博文 / 推文系列）
- Book2 大纲是"传播菜单"，不是待完善的论文草稿
- 好的争议带来讨论力——不怕有争议，怕没人看

### 4. 多平台矩阵
- **论文线**：投 venue → 学术 credibility
- **博客线**：LessWrong → TCS/ML 交叉社区
- **社交线**：Twitter/X → 大众传播力
- **科普线**：长文 / 书籍 → 跨学科影响力

### 5. 反馈驱动迭代
- 看哪个话题反应最强，优先扩写哪个
- 读者质疑最多的部分，才是需要补严谨的部分
- 不是闭门造车式的完善，而是公开验证
