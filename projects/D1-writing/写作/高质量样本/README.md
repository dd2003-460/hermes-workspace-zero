# 写作域 — 高质量对话样本

**创建**: 2026-04-03  
**来源**: ai_chats 原始对话中提取  

## 标准（写作视角，不是学术视角）

### ✅ 高质量写作样本的特征
- **好比喻**：能用一句话把复杂概念讲明白
- **好类比**：不同领域之间的有趣映射
- **情感冲击**：读者会说"这就是我"
- **争议性表达**：能引发讨论的观点
- **口语化的深刻**：不装、不说教，但直击本质

### ❌ 不是写作样本的标志
- 纯知识复述（让 AI 讲已知概念）
- 只有结论没有表达技巧
- 太学术化、无法传播
