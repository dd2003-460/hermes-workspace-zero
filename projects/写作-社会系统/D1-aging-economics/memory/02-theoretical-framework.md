## 理论模型

### 基础增长模型

将经济增长建模为生产函数，受人口结构影响：

```
Y_it = A_it · F(K_it, L_it, H_it)
```

其中 Y = 产出，K = 资本，L = 劳动，H = 人力资本，A = 全要素生产率。

人口老龄化通过三个渠道影响产出：

**渠道 1 — 储蓄/资本渠道**:
```
Aging ↑ → 生命周期储蓄 ↓ → K growth ↓ → Y growth ↓
```
生命周期假说：老年人消耗储蓄而非积累，老龄化率上升降低整体储蓄率。

**渠道 2 — 劳动力供给渠道**:
```
Aging ↑ → 劳动年龄人口占比 ↓ → L ↓ → Y ↓
```
劳动力供给直接减少，同时劳动参与率可能下降。

**渠道 3 — 人力资本/创新渠道**:
```
Aging ↑ → 劳动力结构老化 → 创新 ↓ → A growth ↓ → Y growth (长期) ↓
```
年轻劳动力减少 → 技术采纳和创新速率下降 → 长期 TFP 增速降低。

### 基准计量模型

```
GDP_growth_it = α + β·Aging_it + γ·Controls_it + μ_i + λ_t + ε_it
```

其中：
- `GDP_growth_it`: 省份 i 在年份 t 的人均 GDP 增长率
- `Aging_it`: 老龄化率 (65+ / 总人口)
- `Controls_it`: 固定资产投资率、教育水平、城镇化率、开放度
- `μ_i`: 省份固定效应（控制不随时间变化的省份异质性）
- `λ_t`: 年份固定效应（控制不随省份变化的时间趋势）

### 可检验假设

| 假设 | 方向 | 检验方法 |
|------|------|----------|
| H1: 老龄化抑制经济增长 | β < 0 | 面板固定效应 |
| H2: 储蓄率传导 | β_savings < 0 | 中介效应模型 |
| H3: 劳动力供给传导 | β_labor < 0 | 中介效应模型 |
| H4:  LTC 试点缓解冲击 | β_did > 0 (在试点城市) | 多期 DID |
| H5: 东部影响小于中西部 | |β_east| < |β_central|, |β_west| | 分样本回归 |

## 机制分析框架

### 中介效应模型

```
M_it = α_m + β_m·Aging_it + γ_m·Controls_it + μ_i + λ_t + ε_m_it
```
```
GDP_growth_it = α + β'·Aging_it + δ·M_it + γ'·Controls_it + μ_i + λ_t + ε_it
```

其中 M_it 是机制变量（储蓄率、劳动力供给比例、消费结构）。

如果 β·γ ≠ 0，则存在中介效应。使用 Bootstrap 检验中介效应显著性。

### 异质性框架

分三个维度检验异质性：

| 维度 | 分组标准 | 预期结果 |
|------|----------|----------|
| 区域 | 东/中/西 (国家统计局分区) | 东部弹性最小（产业转型能力强） |
| 初始老龄化 | 中位数分组 | 初始老龄化高的省份效应更强 |
| LTC 试点 | 试点 vs 非试点 | 试点城市冲击更小 |

## 识别策略

### 外生性讨论

老龄化率的核心挑战是内生性：经济增长也可能反向影响生育率、移民和死亡率的老龄化率。

**解决方案**:
1. **工具变量**: 使用生育率政策变化（独生子女政策执行强度）作为 IV
2. **滞后项**: 使用 Aging_{i,t-1} 避免反向因果
3. **DID 策略**: 利用 LTC 试点的外生冲击（政策选择由中央决定，非省级）

### LTC 试点作为自然实验

**两批试点城市**:
- 2016 年: 上海、南通、成都、秦皇岛、泰安、合肥 (6 个)
- 2020 年: 广州、深圳、青岛、济南、南昌、中山 (6 个)

**处理组**: 试点城市
**对照组**: 非试点城市（但通过 PSM 匹配相似城市）

**平行趋势假设**: 若无 LTC 试点，处理组和对照组的老龄化经济效应趋势一致。

**DID 模型**:
```
Y_it = α + β·Treat_i × Post_t + γ·Controls_it + μ_i + λ_t + ε_it
```
