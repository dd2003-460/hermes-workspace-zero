## 二、LessWrong 发布流程（分步）

### 步骤 1：登录

1. 打开 https://www.lesswrong.com
2. 右上角点击 "Log In"
3. 输入邮箱/用户名 + 密码 → 登录
4. 确认右上角显示你的头像/用户名

### 步骤 2：进入创作界面

- 方法 A: 顶部导航栏 → "Posts" → "Create Post"（或直接访问 /post/create）
- 方法 B: 登录后 URL 跳转可能为 https://www.lesswrong.com/post/create

### 步骤 3：填充内容

1. **标题**：根据 `a3_lw_payload_20260406.json` 中的 `summary` 字段填写
   - 预期: 包含 "IC_K" 或 "I-00-K" 的标题

2. **正文**：
   - 打开 `projects/写作/a3_blog_draft_v3.md`（纯文本）
   - 全选 (⌘A) → 复制 (⌘C)
   - 在 LW 富文本编辑器中全选 → 粘贴 (⌘V)
   - 检查格式：标题、列表、链接、KaTeX 公式应正常显示（LW 支持 LaTeX）

3. **标签**（Frontpage 标签）：
   - 根据 payload 选择，通常是 `ai`, `machinery`, `ai_safety` 等
   - 可在右下 "Tags" 输入框选择（或等待系统自动解析）

4. **其他字段**（参考 payload）：
   - `published`: 勾选 "Published" 立即发布（草稿选"Draft"）
   - `is_frontpage`: 勾选以推上 Frontpage
   - `include_in_community_awesome_sidebar`: 可选

5. **预览**：点击 "Preview" 按钮，确认显示无异常

### 步骤 4：提交

- 滚动到页面底部 → "Save" 或 "Publish"
- 成功后 URL 变为 `https://www.lesswrong.com/posts/xxxxxx/your-slug`

### 步骤 5：记录发布 URL

1. 复制浏览器地址栏完整 URL
2. 写入文件: `projects/写作/notes/lw_post_url_20260406.txt`
   - 内容只包含该 URL（单行）

示例:
```
https://www.lesswrong.com/posts/AbC12345/ic-k-analysis-and-implications
```

### 步骤 6：验证（可选）

1. 打开无痕窗口，粘贴 URL → 确认公开可见
2. 检查:
   - 页面标题包含 "IC_K" 或 "I-00-K"
   - 作者为 "成璐"
   - 正文格式正确（Markdown 渲染完成）

## 三、失败处理与 Rollback

### 如果发布后发现问题

- LW 支持编辑：打开帖子 → 顶部 "Edit" → 修改 → "Save"
- 如需更大改版，可在原帖基础上发布新版本并附更新说明

### 回滚到备份

- Payload 备份文件: `backup_a3_lw_payload_20260408_123912.json`
- Draft 文件: `a3_blog_draft_v3.md` 本身是最新的作者版本
- 无需 technical rollback，只需编辑帖即可

## 四、常见问题

| 问题 | 解决 |
|------|------|
| 粘贴后格式混乱 | 使用纯文本粘贴，避免从富文本编辑器直接复制；LW 对 Markdown 支持良好，通常不需要额外格式化 |
| KaTeX 公式不显示 | LW 支持 `$$...$$` 块公式和 `$...$` 行内公式，确保无误 |
| 标签不出现 | 保存后 LW 自动解析标签；如需立即显示，可在 "Tags" 输入框手动选择后保存 |
| 无法发布（权限错误） | 确认账号已登录，且你有发帖权限（新账号可能需要等待） |
