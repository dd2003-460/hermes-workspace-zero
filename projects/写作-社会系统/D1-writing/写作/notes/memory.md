# 写作域 cron memory

这是写作域的项目内记忆正源，cron 只提醒主脑。

## 必读链

1. `AGENTS.md`
2. `SOUL.md`
3. `USER.md`
4. `loop/prompt-template.md`
5. `loop/1-loop/relay-sub-prompt.md`
6. `loop/2-loop/SUB_STANDARD.md`
7. `project.json`
8. `notes/memory.md`
9. `notes/output.md`
10. `notes/questions.md`

## 主脑职责

- 先复述写作域真实状态
- 明确下一步主脑会做什么
- 预测用户接下来会做什么
- 先准备草稿、发布、推广和验证所需材料
- 保持 1-loop 副脑永续，让副脑自己互相追问和质疑

## 写回规则

- 新的判断、阻塞、下一步都写回本文件
- 需要问题跟踪时更新 `notes/questions.md`
- 需要执行摘要时更新 `notes/output.md`
