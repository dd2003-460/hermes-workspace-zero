## 核心命题(conf 0.7)

内容传播的 KPI **不是曝光量, 是认知解码成本下的信念状态迁移期望流量**。

- 信念状态迁移: 受众从状态 A(不信/不知道) 迁到状态 B(相信/知道), 可观测、可测
- 认知解码成本: 受众"听懂"需要花多少认知资源 ≈ 表达的信息熵/冗余(理解=压缩, 压缩率越低解码越贵)
- KPI = Δ信念 / Δ成本, 类比物理里的"信号量纲": 曝光量是能量, 信念迁移才是功

这个命题让"传播"从玄学变成可度量的工程问题, 是全书区别于所有营销入门书的根。
