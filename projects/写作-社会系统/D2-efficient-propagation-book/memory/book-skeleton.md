# 《高效传播》6 层书骨架

# origin: ai
# status: v1 骨架 conf 0.7(2026-10-18, 死锁期纯文字推演, 待 KB.1 三篇 note 落定后升 v2)

## 核心命题(全书之根)

KPI = Δ信念 / Δ成本(认知解码成本)。曝光量是能量, 信念迁移才是功。

## 6 层

### L1 度量层(第一稿起点)

- 定义 KPI: Δ信念(受众信念状态迁移量)/ Δ成本(认知解码成本)
- 信念状态怎么测: 可观测行为代理(转发/引用/改变决定)+ A/B 自然实验
- 解码成本怎么测: 阅读完成率/回看率/提问率 + 信息论(表达冗余度≈香农熵差)
- Shapley 归因: 一次传播里"谁"(哪个节点/哪个版本/哪个渠道)贡献了多少信念迁移(复用成璐的文明贡献框架: Shapley+ATE 因果分解)
- 依赖: KB.1 传播效率 note(名词层已备)

### L2 网络层

- 小世界 + 无标度 + 社区边界 + Granovetter 阈值模型
- 关键洞见: 传播瓶颈往往不在内容, 在网络位置(社区边界上的桥节点)
- 依赖: KB.1 网络拓扑 note

### L3 动力学层

- SIS/SIRS/Bass 模型 + 思想 R0(一个信念平均迁移几个新主体)
- 新 idea 的梗为什么会"死" = 群体免疫(受众已感染, 同样的表达不再迁移信念)conf 0.7
- 推论: 同一观点要反复换"压缩格式"(表达)重发, 不是换观点
- 依赖: KB.1 传播学 note + 传播效率 note

### L4 控制层

- optimal seeding( Kempe 2003, top-K 节点, 贪心 (1-1/e) 近似)
- 均值场博弈: 受众是有策略的主体, 会"装没看见"(防御性忽视)
- 关键洞见: 控制目标不是"触达最多", 是"迁移成本最低的路径"
- 依赖: L1+L2

### L5 设计层

- "理解=压缩"应用于内容设计: 内容 = 信念迁移的最短程序
- 成璐 voice 特征 = 高效表达的实证样本(271 语料量化: 句长39/置信词/不是而是≤1/禁空话)
- 关键洞见: 风格不是装饰, 是解码成本参数(这就是 persona 工作反哺本书的接口)
- 依赖: DPA.1 voice_features.md

### L6 资产化层

- 书=种子(一次性生产, 永久传播) / 课=放大器(高互动高 R0) / 社群=R0>1 的载体 conf 0.6
- viral vs 慢烧 = 交易冲击下的执行策略(Almgren-Chriss 跨域类比: 大仓位分拆执行)conf 0.6
- 关键洞见: 书不是终点, 是资产组合的第一笔
- 依赖: 全部前 5 层

## 明确砍掉(3 条)

1. 不写营销入门(引流/话术/平台技巧)
2. 不追平台算法推荐机制(移动靶, 不可验证)
3. 不声称"完整理论"(只声称可证伪框架, 每条结论带 conf)
