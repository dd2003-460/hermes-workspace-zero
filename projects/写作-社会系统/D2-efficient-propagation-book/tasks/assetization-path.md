# 资产化路径: 书/课/社群三条线

# origin: ai
# status: v1 稿(2026-10-18, 骨架 v2 的 L6 展开; 成本按 solo+免费优先估算)

## 总原则

我押的不是"写书", 是"做一个 R0>1 的资产组合"。书是种子(一次性生产, 永久传播), 课是放大器(高互动, R0 高但衰减快), 社群是载体(唯一能让 R0 持续 >1 的形态, conf 0.6)。
执行策略借 Almgren-Chriss(2000, 大仓位分拆执行): 我的"仓位"是注意力+内容的信念迁移潜力, "市场冲击"是受众疲劳(梗死亡=群体免疫, 骨架第 9 章)。viral 和慢烧不是二选一, 而是同一个仓位的不同执行曲线, 由当前 R0(解码成本) 决定(骨架 P7)。

## 三条线

### 线 1: 书(种子) — 现在就在做

- **时间线**: L1 度量层四章初稿(本季度) → L2-L3 网络+动力学(下季度) → L4-L6 控制+设计+资产化(再下季度) → 全书 15 章 + 修订(第 2 年 Q1)。
- **成本**: 0 元。写作工具全免费(本 workspace 的 drift-check/KB note 管线), 出版走自出版或 PDF 免费发布(我不为"看起来高级"付费)。
- **门槛(gate)**: 每章过 drift-check; v3 升级条件=L1 四章过 + P2(Δ信念代理)拿到第一个数。P2 没拿到数之前, 我不允许全书定稿 — 这是全书 KPI 的命门。
- **KPI**: 本书用本书的尺子量自己(发布后 3 个月: 读者里多少人能复述"KPI=Δ信念/Δ成本"+ 多少人因此改变了一个内容决策 = 信念留存率)。

### 线 2: 课(放大器) — 书到 8 章后启动

- **时间线**: 书 L1-L3(8 章)稳定后, 把度量层+网络层拆成 4 讲短课(每讲 15 分钟, 录屏+文稿, 不直播 — 直播是同步会议, 违反我异步优先的默认)。
- **成本**: 0 元(免费录屏工具); 时间成本约 2 周。
- **R0 逻辑**: 课比书 R0 高, 因为互动(提问/作业)直接降低解码成本(骨架第 3 章: 提问率是分母的代理); 但课衰减快(人走了课就停), 所以课的作用是把人导进书和社群, 不是终点。
- **gate**: 只有当书的前 8 章自己测出"提问率>某阈值"我才开课 — 用数据决定, 不凭感觉。

### 线 3: 社群(R0>1 载体) — 条件不齐前不建

- **时间线**: 书发布+至少 20 个真实"信念迁移案例"(第 2 章最小验证实验的样本)之后。
- **成本**: 0-2 美元/月(免费开源工具优先, 如 GitHub Discussions/Matrix 自托管; 不为平台付费)。
- **R0 逻辑**: 社群里成员互相背书(转发者贡献>原作者, 骨架第 4 章的结论), 解码成本被群体分摊 → 我猜这是唯一能持续 R0>1 的形态(conf 0.6)。
- **gate**: 没有 20 个真实案例之前建社群=空壳, 梗会死在第 1 轮。

## 执行顺序(一句话)

现在写书(线 1) → 书到 8 章且提问率过阈值才开课(线 2) → 书发布+20 个真实案例才建社群(线 3)。不并行, 因为我的注意力是唯一稀缺资源, 并行的交易冲击最大。

## 这条路径没答什么

- 变现: 我不写变现章节(骨架砍 3 条第 1 条), 但"资产"隐含可变现 — 具体方式(赞助/付费课/顾问)等 R0 数据出来再定, 不预设。
- 平台选择: 不追平台算法(骨架砍 3 条第 2 条), 发布渠道按"跨平台优先"默认选, 不锁定单一平台。
