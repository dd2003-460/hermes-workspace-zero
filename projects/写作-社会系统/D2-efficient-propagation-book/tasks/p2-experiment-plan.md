# P2 实验方案 — 30 人 30 天信念迁移最小实验

# origin: ai

> 这是 solo 0 美元的最小可验证版本，不是可发表实验。产出 = "拿到第一个数"，够 v3 升级用。

## 实验设计

| 参数 | 值 | 来源 |
|------|-----|------|
| 样本量 | 30 人 | ch14:15（够算均值，不够算置信区间） |
| 时长 | 30 天（主测）+ 90 天（留存） | ch14:13 |
| 成本 | 0 美元（手动收集，Google 表免费） | ch14:15 |
| 对照 | 无（solo 最小版本，显式边界） | ch14:21 |
| 打分方式 | 0-10 自报（非行为代理） | ch14:19 |

## 测量指标

| 指标 | 公式 | gate |
|------|------|------|
| 信念变化率 | 后测均值 − 前测均值 | ≥40 分（10 分制，即后测比前测多 4 分） |
| 阅读完成率 | 读完 1-14 章人数 / 30 | 分母（解码成本代理） |
| KPI | 信念变化率 / 阅读完成率 | — |
| 3 月留存率 | 第 3 次均值 / 第 1 次后测均值 | 聚合原型（ch2:65 兑现） |

## 执行步骤

1. **招募**：书发布后在个人社交渠道发一条"30 人 30 天共读+前后打分"招募
2. **前测**：读者报名后，读第 1 章前做 0-10 打分（对"KPI = Δ信念/Δ成本"命题）
3. **共读**：30 天内读完整本书（1-14 章）
4. **后测**：读完后做第二次 0-10 打分
5. **留存测**：第 90 天对同一批读者做第三次 0-10 打分
6. **计算**：信念变化率、阅读完成率、KPI、留存率

## 判死条件

- 读完率 <50% → P2 实验失败，全书退回重做第 2 章
- 3 月留存率 <30% → 同上
- 信念变化率 <40 分 → 全书不定稿（v3 升级硬 gate）

## 边界（显式标注）

- 无对照组（solo 最小版本）
- 打分是自报的，不是行为代理
- 30 人够算均值，不够算置信区间
- 产出够 v3 升级用，不够论文用
