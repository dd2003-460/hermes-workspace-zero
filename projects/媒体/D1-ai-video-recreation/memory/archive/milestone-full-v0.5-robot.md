# milestone-full-v0.5.md — v0.5 笨笨机器人 + 环境动效 (2026-10-20)

## 目标
修复 full_v0.1 自审的「画面静止」差距（诚实差距 4 条中的第 2 条）：加笨笨机器人角色 + 环境动效，让画面"活"起来，对标参考片的角色存在感。

## 渲染预算约束（关键）
- 7070 帧（117.833s × 60fps），全渲染 ~200s。
- **只能用廉价动效**：1px 操作、sin 波、确定性伪随机（`floor(t*60)` 派生）。
- **禁止 Math.random**（每帧必须可复现，否则重渲染不一致）。

## 新增（render_full_pixel.js）
- **调色板**：`robot:#e08a3c` `robot2:#c9762f` `robotEye:#12151c` `belly:#f2ead8`（暖橙笨笨，呼应参考片橙色方头机器人）。
- **`drawRobot(x,y,t,mood='normal'|'sad', think=false)`**（L85，14×20）：
  - 天线（sin 摆动 + 绿闪 `t%1.6<0.1`）
  - 方头 12×7 + 2×2 方眼（3.2s 周期眨眼：`t%3.2<0.12` 时眼高 1px）
  - 白肚皮 4×4（think 时闪烁 `t%0.9<0.45`）
  - 双脚
  - `mood='sad'`：低头（头 y+1）+ 眼角 1px
  - `bob = sin(t*2.2)>0.35 ? -1 : 0`（轻微呼吸浮动）
- **`drawDust(t)`**（L110）：5 个确定性 1px 上浮粒子（`((i*53 + floor(t*8)) % 148)` 派生 y，x 固定错位）。

## 各场景应用
- **S1**（终端开场）：scanline 漂移 `floor(t*8)%3` + `drawRobot(BW-38,88,t)`（右下角）。
- **S2**（消息流）：钉住 📌 1px 摆动 + 输入光标闪烁 `px(52,132,2,5)` + `drawRobot(BW-42,100,t)`。
- **S3**（代码编辑器）：代码逐行打字（行 i 起点 `sStart+1.0+i*2.0`，18 字/秒）+ slot0 呼吸 glow `0.5+0.5*sin(t*3)` + `drawRobot(270,112,t)`。
- **S4**（空行累积）：slot0 脉冲 + `drawRobot(BW-44,104,t,'sad')`（望着空行）。
- **S5**（等待循环）：屏幕闪烁 `f=floor(t*60); if(f%97===0) px(0,(f*37)%148,BW,1,'#0a0e14')` + `drawRobot(BW-44,56,t,'normal',true)`（思考，肚皮闪）。
- **S6**（金句收束）：`if(local>3.0) drawRobot(BW/2-7,112,t,'sad')`（金句下方安静地）+ `drawDust(t)`（尘埃上浮）。
