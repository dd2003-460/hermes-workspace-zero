## TOP 5 差距 (H/M/L)

1. **[H] "打字动效"名不副实 —— 0.6s 打完整行**
   `render_full_pixel.js:261-265` S1：`n = Math.floor(local / 0.6 * line.txt.length)` —— `local≥0.6` 时 n 恒等于全长，所谓逐字打出在 0.6s 内完成，肉眼=瞬间出现。字幕同病：`:498` 用 `local/0.8*len`，0.8s 打完一行。S2 的"打字动效"（check_25s 三行全静态）同理。**修法：n 按字符数×40~70ms 步进，末行加光标闪烁。**
2. **[H] CARD 段打破像素美学 —— 全片最大破绽**
   `render_full_pixel.js:527-558`：CARD 直接用 bctx 画 `#F5E6A3` 实色矩形 + `strokeRect` + `rgba(255,255,255,0.4)` 胶带 + `bold 14px monospace` 文字，**完全绕过 `txt()` 的 alpha>110 二值化**（:63-86）。f_01400 帧实测该块含抗锯齿灰边，是全片唯一"非像素"区域。S2 的 📌 emoji（系统 emoji 字体渲染，彩色抗锯齿）同级别破绽。
3. **[H] 音频无叙事动态，结尾反而比中段响**
   实测 final_mix_v0.6.wav：RMS 全程 0.077–0.109 几乎一条直线；peak 0.90 在 60–65s（58s heartbeat）；**80–85s RMS=0.109 > 70–75s 的 0.082**——S6 是"晚安"冷色收尾，画面在变安静，音乐却顶到全片最响。`mix_sfx.py` 无 ducking/淡出逻辑，`gen_strings.py` 的 strings 层也未随 S5/S6 减薄。
4. **[M] S1 开场前 5s 过空**
   check_05s 只剩标题行，黑场感强。参考片 1 的办公室场景（条纹墙+晾衣绳便签+橙色机器人）在 S1 完全没有体现——**任务书 S1 描述是"暖色办公室"，实际渲染是纯黑终端**。叙事从"办公室早晨"被偷换成了"CLI 会话"，暖色基调直到 S2 便签才出现。
5. **[M] 场景边界与代码 SCENES 常量不一致**
   任务书 S5=63.1–78.9s，但 70s 帧实测呈现的是"紫绿文字卡片"（更像 S3 pinned 的视觉语言）；f_04200 与 check_70s 色彩指纹一致（14 色）却与"心跳日志+大肥鱼"的 S5 描述不符。**需逐场景核对 SCENES 常量 vs 注释 vs 任务书三方**，否则 v0.9 改动画效时改错段。

## v0.9 优先改动 (3条)

1. **修打字节奏（差距 1）**：`render_full_pixel.js:261` 改 `n = Math.min(line.txt.length, Math.floor(local / 0.06))`（60ms/字，中文行约 0.5–1s 打完），`:498` 字幕同步改 `local/0.08`；每行末追加 1px 光标方块 `Math.floor(t*2)%2` 闪烁。S2 聊天三条消息改为依次入场（间隔 1.2s），入场时用同一 n 步进。
2. **CARD 走像素管线（差距 2）**：`:527-558` 的 CARD 矩形改用 `txt()` 同款二值化路径——先在离屏 320×180 画，再 `ctx.imageSmoothingEnabled=false` 放大；胶带从 `rgba` 半透明白改成 2px 实色 `#E8D9A0` 方块；文字改 `txt()` 函数出（或 3×5 像素点阵字）。顺手把 S2 的 📌 emoji 换成 8×8 手画 pin（2 色）。
3. **音频收尾 duck（差距 3）**：`mix_sfx.py` 末尾加 78.9s→86.5s 的 1.2s 线性淡出（作用于 strings 层），S5 心跳段 63–78s 整体 -3dB；`gen_strings.py` 的 S6 段 strings 密度减半或直接切长音 pad。重混后复测 80–85s RMS 应 < 70–75s。

## 像素一致性

- **干净区**：S5/S6 实测 14 色量化；`txt()` 的 alpha>110 二值化让中英文字基本 crisp；Clawd（20×9 平顶+2×2 黑眼+4 短腿）与大肥鱼（16×8 oval+阶梯尾）轮廓都是硬边，符合像素语言。
- **破绽区（按破坏程度排序）**：
  1. CARD 整块（实色矩形+半透胶带+AA monospace 字）——全片唯一"非像素"物体
  2. S2 📌 emoji（系统字体彩色 AA）
  3. `txt()` 阈值 110 偏严，小字号（<12px 等效）偶有笔画断裂——f_04200 绿色小字可见
  4. 扫描线/暗角（S1）是连续渐变，严格说不是像素——但属于风格化选择，可接受

## 音频混音

`gen_strings.py`（173 行）+ `mix_sfx.py`（103 行）静态分析 + numpy 实测：
- **无动态**：RMS 曲线 0.077–0.109 平坦，无随叙事起伏的 ducking；heartbeat@58s 把 peak 顶到 0.90，其后无回落设计。
- **结尾倒挂**：80–85s RMS(0.109) > 70–75s(0.082)，S6"晚安"画面收、声音不收，是全片叙事-声音最脱节处。
