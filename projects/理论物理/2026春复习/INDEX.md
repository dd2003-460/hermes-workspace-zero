# 2026春复习

**描述**: 春季学期课程复习资料
**更新时间**: 2026-06-06

## 使用方法

1. 阅读本 INDEX.md 了解复习结构
2. 选择对应课程进入目录
3. 先读复习指南，再读详细讲解，最后做模拟练习

## 课程列表

| 课程 | 说明 |
|------|------|
| [宇宙学](宇宙学/) | 复习指南 + 3个详细讲解模块 (FLRW, 慢滚暴胀, 功率谱) |
| [规范场论](2026规范场论/) | 复习指南 + 5个详细讲解模块 (规范不变性, RG, 反常, 旋量螺旋度, SSB) |

## 每个课程目录结构

| 文件 | 说明 |
|------|------|
| 复习指南.md | 知识地图 + 核心公式清单 + 预测题型 + 复习优先级 |
| 详细讲解-模块*.md | 每个公式的逐步推导 + 动机 + 物理图像 |

## 复习建议

1. 先读复习指南 -> 了解整体框架
2. 再读详细讲解 -> 理解"每步怎么想到的"
3. 最后做模拟练习 -> 巩固理解
