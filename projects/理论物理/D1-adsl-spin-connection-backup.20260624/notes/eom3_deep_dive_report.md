# EOM3 残差深潜报告

> 任务ID: adsl-eom3-deep-dive | 创建时间: 2026-04-01 | 关联项目: adsl-spin-connection

## 执行摘要

对 AdSL BTZ 黑洞 JHEP09(2023)185 论文的 EOM3 残差进行了 4 条系统性调查路径。**结论：4 条路径均无法消去残差，且残差实际上有两个独立分量而非一个。EOM3 残差是真实存在的物理/数学问题，不是符号错误。**

## 残差精确描述

### 原始残差（入射 EF 帧）

EOM3: `F^a + (1/2ℓ²)ε_{abc}e^b∧e^c = 0`

对于 a=0，有两个非零分量：

| 分量 | 指标 | 值 | 状态 |
|------|------|---|------|
| (1,2) = (dr,dφ) | dr∧dφ | `2r/ℓ²` | ❌ 非零 |
| (0,2) = (dv,dφ) | dv∧dφ | `r(ℓ²(M+b) - r²)/ℓ⁴` | ❌ 非零 |

**注意**：任务描述中说残差在 (dv,dr) 分量，但实际计算表明残差在 **(dv,dφ)** 和 **(dr,dφ)** 两个分量。原 (dv,dr)=(0,1) 分量实际为零。

### 残差分解

F⁰ 的两个分量来源：

```
F⁰ = D_ω σ⁰ + (1/2)ε^{0bc}σ_b∧σ_c

D_ω σ⁰:
  (dr,dφ) = r/ℓ²         ← 来自 dσ⁰
  (dv,dφ) = br/(2ℓ²)     ← 来自 -ε^{012}ω_1∧σ_2

(1/2)ε^{0bc}σ_b∧σ_c:
  (dv,dφ) = r(M+b)/(2ℓ²) - r³/(2ℓ⁴)

F⁰ 合计:
  (dr,dφ) = r/ℓ²
  (dv,dφ) = rM/(2ℓ²) + br/ℓ² - r³/(2ℓ⁴)

(1/2ℓ²)ε_{0bc}e^b∧e^c:
  (dr,dφ) = r/ℓ²         ← 来自 ε_{012}·e_1∧e_2
  (dv,dφ) = rM/(2ℓ²) - r³/(2ℓ⁴)

EOM3 = F⁰ + (1/2ℓ²)εe∧e:
  (dr,dφ) = 2r/ℓ²        ← 残差#1
  (dv,dφ) = r(ℓ²(M+b)-r²)/ℓ⁴  ← 残差#2
```

---

## Path 1: σ⁰ dv 分量修正 — ❌ 失败

**方法**：令 σ⁰ = σ⁰_paper + δσ⁰_dv(r)·dv，代入 EOM3 求解。

**结果**：
- δσ⁰_dv 的微分 `d(δσ⁰_dv)/dr` 出现在 EOM3 的 (dv,dr) 分量中（原来该分量为零）
- 但原残差在 (dv,dφ)，σ⁰ 的 dv 分量对 (dv,dφ) 无贡献（wedge 中 dv∧dv=0）
- **修正破坏 EOM2**：EOM2 的 (dv,dr) 分量出现 `-2r/ℓ² + r·δσ⁰_dv ≠ 0`
- EOM2 的 (dv,dφ) 分量也出现 `r·δσ⁰_dv ≠ 0`

**结论**：σ⁰ 的 dv 分量修正既无法消去 EOM3 残差（目标分量不对），又破坏 EOM2。

---

## Path 2: σ¹≠0 检验 — ❌ 失败（EOM2 强制 σ¹=0）

**方法**：参数化 σ¹ = s1_v·dv + s1_r·dr + s1_p·dφ，代入 EOM2+EOM3 联立求解。

**结果**：
- EOM2 产生 6 个约束方程（3个分量 × 多个形式分量）
- `eq[0]: -2r/ℓ² = 0` → 矛盾（与 σ¹ 无关，说明 EOM2 本身有残差）
- `eq[1]: -r·s1_v = 0` → s1_v = 0
- `eq[2]: -r·s1_r = 0` → s1_r = 0
- `eq[3]: -J·s1_r/2 - s1_p - 2 = 0` → s1_p = -2（但 eq[4,5] 给出矛盾）
- 无一致解

**单分量测试**：
- σ¹ = s1_v·dv：EOM2 无解
- σ¹ = s1_p·dφ：EOM2 无解

**结论**：EOM2 严格强制 σ¹=0，且 EOM2 自身已存在 `-2r/ℓ²` 残差（与 σ¹ 无关）。σ¹ 非零无法修复 EOM3。

---

## Path 3: σ∧σ 项贡献 — ✅ 正确计算，但不可消去

**方法**：逐项分解 (1/2)ε^{abc}σ_b∧σ_c 在 a=0 时的贡献。

**结果**：
- ε^{012}σ_1∧σ_2 + ε^{021}σ_2∧σ_1 = -σ_1∧σ_2 + σ_2∧σ_1 = -2σ_1∧σ_2
- σ_1∧σ_2 的 (dv,dφ) 分量 = `-r(M+b)/(2ℓ²) + r³/(2ℓ⁴)`
- 因此 (1/2)ε^{0bc}σ_b∧σ_c 的 (dv,dφ) 分量 = `r(M+b)/(2ℓ²) - r³/(2ℓ⁴)` ✓
- **σ_1∧σ_2 没有 (dr,dφ) 分量**，所以 σ∧σ 项不贡献 (dr,dφ) 残差

**结论**：σ∧σ 计算正确。它贡献了 (dv,dφ) 残差的一部分，与 D_ω σ⁰ 同号叠加。

---

## Path 4: ℓ² 因子排查 — ❌ 无单一因子可同时消去两个残差

**方法**：将 (1/2ℓ²) 替换为 α/ℓ²，求解使残差为零的 α。

### 通用 α 的残差

```
EOM3[0̄]:
  (dr,dφ) = r(2α + 1)/ℓ²
  (dv,dφ) = r(ℓ²(2Mα + M + 2b) - r²(2α+1))/(2ℓ⁴)
```

**消去 (dr,dφ)**：需 2α+1 = 0 → **α = -1/2**

**α = -1/2 时的 (dv,dφ)**：
```
(dv,dφ) = r(ℓ²(-M + M + 2b) - r²·0)/(2ℓ⁴) = br/ℓ²
```
除非 b=0，否则 (dv,dφ) 不消失。

**消去 (dv,dφ)**：需 `2Mα + M + 2b = (2α+1)r²/ℓ²` 对所有 r 成立
- 左边为常数，右边为 r² → **不可能**

### 其他变体测试

| 修改 | (dr,dφ) | (dv,dφ) | 结论 |
|------|---------|---------|------|
| α = 1 (无1/2因子) | 3r/ℓ² | 更差 | ❌ |
| α = 1/4 | 3r/(2ℓ²) | 不消失 | ❌ |
| ε_{abc} 替换 σ∧σ 中的 ε^{abc} | 2r/ℓ² | -br/ℓ² | ❌ |
| F^a 中无1/2因子 | 2r/ℓ² | 更大 | ❌ |
| 完全去掉 σ∧σ 项 | 2r/ℓ² | 缩小但非零 | ❌ |

**结论**：没有任何单一因子修改能同时消去两个残差分量。

---

## 综合诊断

### 4 条路径总结

| 路径 | 结果 | 核心障碍 |
|------|------|----------|
| 1. σ⁰ dv 修正 | ❌ | 目标分量错位 + 破坏 EOM2 |
| 2. σ¹≠0 | ❌ | EOM2 强制 σ¹=0 |
| 3. σ∧σ 审计 | ✅正确 | 计算无误，不可消去 |
| 4. ℓ² 因子 | ❌ | 无单一因子同时消去两个残差 |

### 可能的真正原因

1. **论文中 ω, σ, e 的定义可能有微小偏差**：不是简单的符号/因子错误，而是某个分量的表达式有 r-依赖性偏差
2. **BTZ 度规的具体形式**：论文可能使用了与我们假设不完全相同的度规（如不同的 J, M, b 参数化）
3. **双重连接问题**：EOM3 中的 D_ω 可能使用的是与 EOM1/EOM2 不同的连接（full connection vs dual connection）
4. **论文本身可能有 typo**：JHEP 论文的 EOM3 或给出的 ω/σ 表达式可能有印刷错误

### 下一步建议

- 仔细对读论文全文（不仅是 §2），确认 ω, e, σ 的完整定义
- 检查论文是否提到双重连接的细微差别
- 尝试用论文中的度规直接数值验证（代入具体数值 ℓ=1, M=1, b=0.5, J=0）
- 考虑联系论文作者确认
