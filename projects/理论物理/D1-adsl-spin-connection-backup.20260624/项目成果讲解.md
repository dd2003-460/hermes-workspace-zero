# ADSL Spin Connection 项目成果讲解

## 项目概述

这是一个**学术验证项目**，使用符号计算独立验证了一篇论文中 BTZ 黑洞解的运动方程（EOMs）。

**被验证的论文：**
> "Thermodynamics of the three-dimensional black hole with torsion"
> Aviles, Hidalgo & Valdivia, *JHEP 09 (2023) 185*, arXiv:2308.09114

**核心目标：** 验证论文给出的自旋联络（omega^a）、标架场（e^a）和挠率/扭曲张量（sigma^a = -kappa^a）是否满足由 Chern-Simons 作用量导出的三个运动方程。

---

## 三个运动方程

| 方程 | 物理含义 |
|------|---------|
| **EOM1**: R^a = 0 | 几何曲率为零（平坦联络） |
| **EOM2**: T^a + ε_{abc} sigma^b ∧ e^c = 0 | 修正的挠率约束 |
| **EOM3**: F^a + (1/(2ℓ²)) ε_{abc} e^b ∧ e^c = 0 | sigma-曲率约束 |

验证在**内向和外向 Eddington-Finkelstein 坐标系**下分别进行，确保坐标独立性。

---

## 核心成果

### 总体状态：6 项检查中 5 项通过 ✅

| 方程 | 内向坐标系 | 外向坐标系 |
|------|-----------|-----------|
| EOM1 (R^a = 0) | ✅ PASS | ✅ PASS |
| EOM2 (T^a + εσe = 0) | ✅ PASS（修复后） | ✅ PASS（修复后） |
| EOM3 (F^a + (1/2ℓ²)εee = 0) | ❌ FAIL | ❌ FAIL |

### 发现并修复的两个约定 Bug

1. **Epsilon 约定（已修复）**：原脚本统一使用了 ε^{abc}（ε^{012} = -1），但论文 EOM 使用的是 ε_{abc}（ε_{012} = +1）。对于反对角闵氏度规，ε_{abc} = -ε^{abc}。这个符号翻转导致 EOM2/EOM3 最初失败。

2. **e^0 的 dr 符号（已修复）**：论文写内向 e^0 的 dr 系数为 +1，但给出的自旋联络仅在 dr = -1 时工作。翻转此符号后 EOM2 在所有坐标系下通过。这暗示论文的 omega 可能是用 BMS/外向约定推导的。

### EOM3 的持久性失败

EOM3 在 a=0 分量中存在**两个独立的结构性残差**：

- **(dr, dφ) 分量残差**：2r/ℓ² — 来自 F^0 的 dσ^0 项（r/ℓ²）与 e∧e 项（r/ℓ²）相加而非抵消
- **(dv, dφ) 分量残差**：r(ℓ²(M+b) - r²)/ℓ⁴ — 来自 sigma∧sigma 项中的 b 依赖，e∧e 项无法匹配

**结论**：EOM3 残差是结构性的，不是简单的符号或因子错误。最可能的解释是论文中存在打字错误或未明确的规范选择。

## 探索路径总结

项目系统性地探索了 **8 条修复路径**，全部失败：

| 路径 | 尝试内容 | 结果 |
|------|---------|------|
| Branch A | Epsilon 约定分析 | 部分修复 EOM2 |
| Branch B | 对偶联络表示 | 确认不是问题所在 |
| Branch C | 将 sigma 作为未知数求解（18 方程，9 未知数） | 超定系统，无解 |
| Branch D | 测试 e^0 的 dr = -1 | **关键修复**：EOM2 全部通过 |
| Branch E | 参数化 delta_sigma 修复 EOM3 | EOM2 约束强制 delta_sigma = 0 |
| Path 1 | 给 sigma^0 添加 dv 分量 | 目标分量错误 + 破坏 EOM2 |
| Path 2 | 允许 sigma^1 非零 | EOM2 强制 sigma^1 = 0 |
| Path 3 | 全面审计 sigma∧sigma 项 | 计算正确，无法抵消残差 |
| Path 4 | 测试 ℓ² 前因子变体 | 无单因子能同时解决两个残差 |

此外还进行了 **2^4 = 16 种符号约定组合** 的系统扫描（convention_sweep.py），没有找到任何组合能通过全部 6 项检查。
