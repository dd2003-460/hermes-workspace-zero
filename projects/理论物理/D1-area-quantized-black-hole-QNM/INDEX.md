## 已有工作的结论

**QNM频率公式已有解析计算。** Maggiore (2007) 利用 highly excited modes (n→∞) 的渐近行为，建立了频率与面积量子化的关系：

- Schwarzschild BH: ∆A = 8πl_p² （Maggiore修正了Hod原始的 4log(3)l_p²）
- Kerr BH: ω_R→0 (a→0 与 n→∞ 不交换) — 旋转情况下结论不同
- 频率公式: ω_n = (ακ/8π)(n + 2Ω_h + O(N⁻¹)) — Chakravarti (2023)

**关键已确认的空白：**

1. **非渐近区域 (n 有限) 的 QNM 谱** — Maggiore 只用了渐近 n→∞ 的极限
2. **∆A = 8π vs 4log(3) 的实验可区分性** — 谁是对的？观测能否判定？
3. **旋转QBH的完整QNM数值计算** — Chakravarti 用了 Maggiore 的渐近公式，但没有做完整的数值GR模拟
4. **弦理论/QG 预测的比较** — 是否有其他量子引力方案给出不同的 QNM 谱？
5. **GW回波 (echoes) 信号** — Agullo 预言了但尚未被观测到
