## 1. 问题定义

**核心科学问题**: 面积量子化黑洞 (QBH) 的准正规模 (QNM) 谱在旋转Kerr背景下是否偏离经典Kerr QNM谱？偏离程度是否可达可观测？

- Schwarzschild QBH QNM: Maggiore (2007) 给出渐近谱 ∆A = 8πl_p²
- Kerr QBH: **所有文献使用Maggiore渐近公式，没有独立数值计算**
- 最大研究空白: 旋转QBH的完整QNM谱数值计算

## 2. 理论框架

### 2.1 面积量子化假设

**Maggiore (2007)** 基于QNM渐近谱推导:
```
∆A = 8πl_p²
```
其中 l_p = √(ℏG/c³) 是普朗克长度。

**其他候选值**:
- Hod (1998): ∆A = 4log(3)l_p²
- Bagchi et al. (2024): ∆A = 4ln(2)l_p² (Landauer原理)

**我们的选择**: ∆A = 8πl_p²（最广泛使用的值）

### 2.2 Kerr度规+面积量子化修正

**经典Kerr度规** (几何单位制 G=c=1):
```
ds² = -(1 - 2Mr/Σ)dt² - (4Mar sin²θ/Σ)dtdφ + Σ/Δ dr² + Σ dθ² + [(r²+a²)² - Δa²sin²θ]/Σ sin²θ dφ²
```
其中:
- Σ = r² + a²cos²θ
- Δ = r² - 2Mr + a²
- a = J/M 是单位质量角动量

**QBH修正** (基于Chakravarti et al. 2310.18022):
```
A = 16πM²(1 + ε(n)) = 8π(M + √(M²-a²))
```
其中 ε(n) 是面积量子化的离散修正，n 是面积量子数。

**关键修正项**: 在视界处引入反射率边界条件。

### 2.3 QNM数值计算方法

**方法选择**: Regge-Wheeler-Zerilli 方程 +  Wentzel-Kramers-Brillouin (WKB) 近似

**标准方法**:
1. 将扰动方程化为Schödinger-like形式:
   ```
   d²Ψ/dr*² + [ω² - V(r*)]Ψ = 0
   ```
   其中 r* 是乌龟坐标 (tortoise coordinate)

2. 边界条件:
   - 视界处: Ψ ~ e^(-iωr*) (纯吸收)
   - 无穷远处: Ψ ~ e^(+iωr*) (纯辐射)

3. QNM条件: 纯出射波 (no ingoing radiation at ∞, no ingoing at horizon)

**QBH修正**:
- 在 r* → -∞ (视界) 处引入反射率 R:
  ```
  Ψ ~ A_in e^(-iωr*) + R A_in e^(+iωr*)
  ```
- 经典黑洞: R = 0 (纯吸收)
- QBH: R ≠ 0 (反射率与面积量子化相关)

### 2.4 数值计算方案

**Step 1: 基准验证** — 先复现经典Kerr QNM谱
- 使用标准Kerr度规 (R=0)
- 验证与已知结果的偏差 < 1%

**Step 2: 引入反射率修正**
- 选择反射率模型 (基于面积量子化假设)
- 计算不同 R 值下的 QNM 谱偏移

**Step 3: 参数空间扫描**
- 自旋 a ∈ [0, 0.998] (Kerr极限)
- 角量子数 l ∈ [2, 5], m ∈ [-l, l], n ∈ [0, 2]
- 反射率 R ∈ [0, 10⁻¹⁰] (预期极小)

## 3. 预期结果

1. **QNM频率偏移**: δω/ω ~ O(10⁻³⁸) (普朗克尺度效应)
2. **旋转增强**: a→M 时量子效应增强 (因为ergoregion)
3. **回声信号**: 如果 R ~ 10⁻³-10⁻⁶，可能产生可观测GW回声

## 4. 技术挑战

1. **反射率模型不确定**: R的具体形式未知，需要假设
2. **数值精度要求**: QNM谱偏移极小，需要高精度数值计算
3. **旋转Kerr的复杂性**: Kerr QNM本身比Schwarzschild复杂，需要求解耦合偏微分方程
