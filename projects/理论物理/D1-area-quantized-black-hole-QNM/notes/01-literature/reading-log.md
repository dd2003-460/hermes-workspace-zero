## R1: Rovelli & Vidotto (2007) arXiv:0707.2153

### 核心内容

首次提出面积量子化与 QNM 的关系。利用 Loop Quantum Gravity (LQG) 的结果：
- 黑洞视界面积本征值：A_j = 8πγℓ_P² Σ√(j_i(j_i+1))
- 最小激发对应 j = 1/2 → ΔA = 8πγℓ_P²√(3/4) = 4π√3γℓ_P²
- 结合 Wald-Zurek 公式：Γ = 2πω/ln((n+1)/n) = 2π/β
- 得到 ω 与面积量子化的关系

### 关键公式

```
Re(ω) ≈ 2π/ln(3) × 1/(4√3γℓ_P² × 4M) = 2π/(4√3γℓ_P² × 4M × ln(3))
```

### 争议点

- 使用等间距面积谱 ΔA = 8πγℓ_P² — 这个假设在 LQG 社区有争议
- 实际上 LQG 的面积谱不是等间距的！
- 对大 l 模，ΔA = 2π × 4M × Re(ω) 的推导依赖于 QNM 是"基本"激发

### 结论

开创性工作，但面积量子化假设需要修正。

## R2: Maggiore (2008) arXiv:0711.3145

### 核心内容

提出 QNM 的"谐振子类比"：
- 将 QNM 解释为黑洞的振动模，类似谐振子
- 实部对应"频率"，虚部对应"阻尼"
- 大 n 极限下，Γ → 0，QNM 变成"稳定"的振动

### 关键发现

```
当 n → ∞ 时：
Re(ω_n) → const (收敛到某个频率)
Im(ω_n) → 0 (阻尼消失)
```

这意味 QNM 频谱在高泛音极限下变得等间距！

### 与面积量子化的联系

```
ΔA = 2π/κ × Re(ω_∞)
```

其中 κ 是表面引力。对 Schwarzschild，κ = 1/(4M)，所以：
```
ΔA = 8πM × Re(ω_∞)
```

这是面积量子化的"观测"基础 — 如果能测量到 QNM 频率，就能推断 ΔA。

### 结论

提供了面积量子化的理论基础，但 n→∞ 的极限是否物理存在是有争议的。

## R3: Chakravarti et al. (2023) arXiv:2310.18022

### 核心内容

直接计算面积量子化修正的黑洞 QNM。这是最相关的文献。

### 方法

将面积量子化作为微扰添加到标准 Schwarzschild 度规中：
```
ds² = ds²_Schw + δg_μν(A_quant)
```

然后求解修正的 Regge-Wheeler 方程：
```
d²Ψ/dr*² + [ω² - V_0(r) - δV(r)]Ψ = 0
```

其中 δV 是面积量子化导致的势函数修正。

### 结果

- 计算了 n=0,1 的 QNM 频率修正
- 发现修正项 δω/ω ~ O(ℓ_P²/M²) — 对天文黑洞非常小
- 但对于原初黑洞（M ~ 10¹⁵g），修正可能可观测

### 评价

1. 计算正确，但势函数修正 δV 的具体形式依赖于面积量子化的模型
2. 没有考虑旋转（Kerr）黑洞
3. 没有与观测数据对比

### 我的研究方向

这篇是 R1-R12 中最相关的，但有几个空白：
1. **旋转黑洞（Kerr）面积量子化 + QNM** — 完全空白
2. **非微扰方法** — Chakravarti 用微扰论，但面积量子化可能是大的
3. **射击法数值验证** — 先精确计算标准 Schwarzschild QNM，再加修正

## 综合结论

### 已确认的

1. ✅ 面积量子化与 QNM 的关系在理论上是成立的
2. ✅ Chakravarti et al. (2023) 提供了第一个微扰计算
3. ✅ 对标准天文黑洞，修正项非常小（O(ℓ_P²/M²)）

### 空白（研究机会）

1. **旋转黑洞（Kerr）+ 面积量子化 QNM** — 最大空白
2. **非微扰数值计算** — 目前只有微扰结果
3. **不同面积量子化模型的对比** — LQG, 等间距, 非等间距
4. **观测可测性分析** — 能否被 LIGO/Virgo 或未来 GW 探测器探测

### 下一步

1. 先用射击法精确计算 Schwarzschild QNM（基准）
2. 再计算 Kerr QNM（基准）
3. 最后加面积量子化修正

**优先顺序**: Kerr 基准 > Kerr 修正 > Schwarzschild 修正

理由：Kerr 黑洞更真实，且 Kerr QNM 的文献更少。
