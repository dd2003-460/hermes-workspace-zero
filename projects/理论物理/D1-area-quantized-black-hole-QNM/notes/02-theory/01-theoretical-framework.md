## 1. 理论基础

### Kerr 度规 + 面积量子化修正

Kerr 度规描述旋转黑洞：
```
ds² = -(1 - 2Mr/Σ)dt² - (4Mar sin²θ/Σ)dtdφ + (Σ/Δ)dr² + Σdθ² + sin²θ(r² + a² + 2Ma²rsin²θ/Σ)dφ²
```

其中：
- Σ = r² + a²cos²θ
- Δ = r² - 2Mr + a²
- a = J/M 为旋转参数

面积量子化修正：
- 视界面积 A = 8πMr₊ 被量子化：Aₙ = γ·8πlₚ²·n（n 为正整数）
- 这导致了视界半径 r₊ 的离散修正
- 进而修改了 QNM 的频率谱

### Regge-Wheeler 方程

在外场扰动下，扰动场 Ψ 满足：
```
d²Ψ/dr*² + [ω² - V(r)]Ψ = 0
```

其中 tortoise 坐标 r* 满足：
```
dr*/dr = (r² + a²)/Δ
```

势函数 V(r) 依赖于自旋权重 s：
- s=0（标量）
- s=1（电磁）
- s=2（引力）

## 2. QNM 数值计算方法

### Leaver 方法（已验证，标准方法）

1. 将解展开为级数：Ψ(r*) = Σ cₙ e^{λₙr*}
2. 得到三递推关系：αₙcₙ₊₁ - βₙcₙ + γₙcₙ₋₁ = 0
3. QNM 条件要求级数收敛，给出连分数条件
4. 解连分数方程得到离散频率 ω

**问题**: 之前 v6-v10 实现中，ABC 系数在 n=100 时增长到 10⁴⁰，
导致数值溢出（gamma 符号错误：使用了 1+4iωM 而非正确的 1-2iωx₀）。

### 射击法（Shooting Method，v11 实现）

1. 在 RKK 方程中，从视界出发积分到无穷远
2. 视界边界条件：纯出射波 Ψ = e^{-iωr*}
3. 无穷远边界条件：dΨ/dr* + iωΨ = 0
4. 最小化边界条件违反，优化 (Re[ω], Im[ω])

## 4. 技术挑战

1. **Leaver 方法的数值不稳定**：大 n 时 Taylor 系数指数增长
2. **旋转效应**：Kerr QBH 需要球谐函数展开，计算复杂度增加
3. **边界条件处理**：r* → -∞（视界）和 r* → +∞（无穷远）的数值处理
