## 1. Kerr 度规 + 面积量子化修正

### 1.1 Kerr 度规（Boyer-Lindquist 坐标）

```
ds² = -(1 - 2Mr/Σ)dt² - (4Mar sin²θ/Σ)dtdφ 
     + (Σ/Δ)dr² + Σdθ² + sin²θ(r² + a² + 2Ma²rsin²θ/Σ)dφ²
```

其中：
- Σ = r² + a²cos²θ
- Δ = r² - 2Mr + a²
- a = J/M（比角动量）

### 1.2 视界与面积

```
r_± = M ± √(M² - a²)
A = 4π(r_±² + a²) = 8πM(M + √(M² - a²))
```

### 1.3 面积量子化假设

**假设 1（等间距）**:
```
A_j = 8πγℓ_P² j,  j = 1/2, 1, 3/2, ...
```
其中 γ 是 Barrett-Crane 自旋网络标记（Barrett-Crane spin-network mark）。

**假设 2（LQG 精确谱）**:
```
A = 8πγℓ_P² Σ_i √(j_i(j_i+1))
```

两种假设对 QNM 的影响不同，需要分别计算。

### 1.4 面积量子化对度规的修正

假设面积量子化导致视界半径的离散化：
```
r_+ → r_+(j) = M + √(M² - a² + δA_j/4π)
```

其中 δA_j 是面积量子化的修正。

### 1.5 度规扰动

将量子化修正作为度规微扰：
```
g_μν → g_μν + δg_μν
```

其中 δg_μν 由 δr_+ 引起。

## 2. Regge-Wheeler 方程的修正

### 2.1 标准 Regge-Wheeler 方程

对于 Schwarzschild 黑洞（s = -2）：
```
d²Ψ/dr*² + [ω² - V_l(r)]Ψ = 0
```
```
V_l(r) = (1 - 2M/r)[l(l+1)/r² - 6M/r³]
```

### 2.2 修正后的方程

```
d²Ψ/dr*² + [ω² - V_l(r) - δV_l(r)]Ψ = 0
```

其中 δV_l(r) 是面积量子化引起的势函数修正：
```
δV_l(r) = δ[(1 - 2M/r)][l(l+1)/r² - 6M/r³] 
          + (1 - 2M/r)δ[l(l+1)/r² - 6M/r³]
```

### 2.3 微扰计算

对于小修正 δM → δM + ε：
```
δV_l ≈ (∂V_l/∂M)ε
```

计算：
```
∂V_l/∂M = 2/r²[l(l+1)/r² - 6M/r³] - 6/r³[1 - 2M/r]
```

### 2.4 微扰方程的求解

使用微扰论：
```
ω = ω_0 + δω
Ψ = Ψ_0 + δΨ
```

其中 ω_0 是标准 Schwarzschild QNM 频率。

微扰方程：
```
d²δΨ/dr*² + [ω_0² - V_l]δΨ = -[2ω_0δω - δV_l]Ψ_0
```

用 Green 函数方法求解 δω：
```
δω = <Ψ_0|δV_l|Ψ_0> / <Ψ_0|2ω_0|Ψ_0>
```

## 3. Kerr 黑洞 QNM

### 3.1 Teukolsky 方程

Kerr 黑洞的扰动满足 Teukolsky 方程：
```
[ (r² + a²)²/Δ - a²sin²θ ]⁻¹ (∂²/∂t²)Ψ
- [ 2aMr/Σ ](∂²/∂t∂φ)Ψ
+ [ a²/Δ - 1/sin²θ ](∂²/∂φ²)Ψ
- Δ^(-s) ∂/∂r(Δ^(s+1) ∂/∂rΨ)
- (1/sinθ) ∂/∂θ(sinθ ∂/∂θΨ)
- 2s[(a/r - a²/Δ) + i cosθ/sin²θ]∂/∂φΨ
- 2s[s/r - r/Δ + ia(cosθ/sin²θ)]∂/∂tΨ
= 0
```

### 3.2 分离变量

```
Ψ = ∫ dω e^(-iωt) ∫ dmlm(θ)e^(imφ) R_lm(r)
```

其中 lm(θ) 是 spin-weighted spheroidal harmonics。

### 3.3 Kerr QNM 的数值计算

与 Schwarzschild 不同，Kerr QNM 需要：
1. 数值求解 spheroidal harmonics
2. 径向方程的 shooting 法
3. Newton-Raphson 求根

目前最精确的计算方法仍是 Leaver 连分数法（对 Kerr 的数值稳定性比 Schwarzschild 更差）。

### 3.4 我们的方法：射击法

对 Kerr 黑洞，使用 tortoise 坐标的 shooting 法：
1. 选择展开点 x₀（类似 Schwarzschild 的情况）
2. 从 r* = -L 积分到 r* = +L
3. 使用 RK4 确保数值稳定性
4. 修正势函数包含面积量子化效应

### 3.5 面积量子化对 Kerr 的影响

对 Kerr 黑洞，面积量子化修正更复杂：
```
δA = 8πγℓ_P² × f(a/M, j)
```

其中 f(a/M, j) 是自旋参数 a/M 和面积量子化量子数 j 的函数。

修正后的视界：
```
r_+(a, j) = M + √(M² - a² + δA_j/4π)
```

然后重新计算 QNM。

## 5. 技术细节

### 5.1 数值精度要求

| 参数 | 精度要求 | 原因 |
|------|----------|------|
| 积分步长 h | 10⁻⁶ M | 保证 RK4 精度 |
| 牛顿收敛 | 10⁻¹⁰ | QNM 频率需要高精度 |
| 面积量子化修正 | 10⁻¹⁵ M | 修正量非常小 |

### 5.2 潜在数值问题

1. **tortoise 坐标的数值计算**：r → 2M 时 r* → -∞，需要小心处理
2. **Kerr spheroidal harmonics**：需要数值求解
3. **大自旋参数**：a → M 时，数值难度增大

### 5.3 计算资源需求

- 标准 Schwarzschild: CPU < 1 小时，内存 < 1GB
- Kerr: CPU < 10 小时，内存 < 2GB
- 面积量子化修正: CPU < 1 天，内存 < 2GB
