## 第一阶段：Leaver 连分数法 (v6-v10)

### 选择理由

- Leaver (1985) 是 Kerr QNM 计算的标准方法
- 理论上精度最高（连分数收敛比数值积分快）
- 适合后续扩展到 Kerr 度规

### 实现过程

**v6** — 初始实现
- 代码：`d1-qbh-qnm-solver-v6.py`
- 公式：γ₁ = 2(iωM)(1 + 4iωM) ❌（错误）
- 结果：全部 NaN

**v7** — 尝试改变展开点 x₀
- 代码：`d1-qbh-qnm-solver-v7.py`
- 修改：更换连分数展开点
- 结果：仍然 NaN

**v8** — 添加 NaN 诊断
- 代码：`d1-qbh-qnm-solver-v8.py`
- 发现：NaN 出现在连分数递推早期

**v9** — 修正 gamma 公式
- 代码：`d1-qbh-qnm-solver-v9.py`
- 修正：γ₁ = 2(iωM)(1 - 2iωx₀) ✅（正确公式）
- 结果：仍然 NaN

**v10** — 系统性诊断
- 代码：`d1-qbh-qnm-solver-v10.py`
- 诊断工具：`diagnose_v10.py`
- 发现：
  - 第一个 NaN 出现在 n = 50
  - ABC 系数范数在 n = 100 时达到 10⁴⁰
  - 即使使用正确 ω = 0.3737 - 0.0890i，迭代仍然发散
  - Taylor 系数在围道积分计算中精度不够（半径 R = 0.3 太小）

### 失败根因

| 问题 | 描述 | 影响 |
|------|------|------|
| Gamma 符号错误 | v6 使用 (1 + 4iωM) 而非 (1 - 2iωx₀) | 初始条件错误，递推发散 |
| Taylor 系数数值不稳定 | 围道积分半径太小，大 n 系数指数增长 | n = 50 处首次 NaN |
| 连分数递推溢出 | 系数增长至 ~10⁴⁰，有效数字丢失 | 无法收敛到任何 ω |

### 决策：放弃 Leaver 法
**理由**：需要系统性重写连分数递推的数值稳定化（如 recombination technique），工作量与后续扩展性不匹配。

## 第二阶段：Shooting 法 (v11-v13)

### 选择理由

- 数值稳定性优于连分数法（RK4 积分可控）
- 物理直观：初值积分→边界条件匹配
- 修改势函数只需改 V(r)，扩展性好
- 理论笔记 (02-theory/) 规划的方法

### v11 — 初始 Shooting 法

- 代码：`d1-qbh-qnm-solver-v11.py`
- 方法：RK4 积分 Regge-Wheeler 方程
- 积分区间：r*_min = -80M, r*_max = +80M
- 边界条件：
  - 视界：Ψ = e^(-iωr*)，纯出射波
  - 无穷远：dΨ/dr* + iωΨ = 0
- 优化：scipy.optimize.minimize 最小化 BC 违反
- 结果：❌ RK4 卡死（CPU 96.7%，>180 秒无输出）

**根因**：固定步长 RK4 在视界附近（f = 1-2M/r → 0）数值不稳定，步长控制困难。

### v12 — 尝试不同积分区间

- 代码：`d1-qbh-qnm-solver-v12.py`
- 修改：在 r 空间直接积分而非 r* 空间
- 方程变换：
  ```
  f² d²Ψ/dr² + f f' dΨ/dr + (ω² - V)Ψ = 0
  ```
- 发现：
  - 视界处 1/f 奇异性：f → 0 导致 dΨ/dr 的方程右边有 1/f 和 1/f² 项
  - 导数爆炸：horizon 初值 dΨ/dr = -iω/f × Ψ 在 f→0 时爆炸
  - solve_ivp 无法处理：解 Ψ ~ (r-2M)^{-2iωM} 在视界附近快速振荡
  - BC 违反值始终为 6e+13 量级，优化器陷入局部极值
- 结果：❌ 卡死

### v13 — 改用 R* 坐标

- 代码：`d1-qbh-qnm-solver-v13.py`
- 核心改进：直接在 r* 空间积分
  - r* 空间中没有 1/f 奇异性
  - 方程本身就是光滑 ODE：d²Ψ/dr*² + (ω² - V_l(r))Ψ = 0
- 数值方案：
  - r*_min = -40M, r*_max = +60M
  - 视界初值：Ψ = exp(-iωr*), dΨ/dr* = -iω exp(-iωr*)
  - 用 solve_ivp (RK45) 积分
  - 优化：minimize_scalar 扫描 ω
- 预计算：r_grid → r*_grid → interp1d(r*_grid, r) → r(r*)
- 结果：⚠️ 部分改善但未验证（r* 离散化精度仍不够，没有完成完整验证运行）

### Shooting 法失败总结

| 问题 | 描述 |
|------|------|
| RK4 卡死 | 视界附近 r* → -∞ 区域，步长控制困难 |
| BC 匹配困难 | 需要同时满足视界和无穷远，Newton-Raphson 对初值敏感 |
| r 空间奇异性 | 1/f 在视界处发散 |
| r* 空间精度 | tortoise 坐标离散化不够精确 |

### 决策：继续探索其他方法
**理由**：Shooting 法理论正确，但需要解决数值稳定性问题。转用其他方法可能更高效。

## 第三阶段：FDTD 方法 (v14-v20)

### 选择理由

1. **数值稳定性**：Leapfrog 格式显式、无条件稳定性（在 CFL 条件下）
2. **天然适应本征值问题**：波包演化→FFT 分析 → 直接提取 QNM 频率
3. **物理直观**：模拟波包散射，直接可视化势垒穿透
4. **扩展性强**：修改势函数和边界条件只需改几个参数
5. **文献支持**：Kokkotas & Schutz 1992 等使用 FDTD 计算 QNM

### 核心方法

波动方程：∂²ψ/∂t² = ∂²ψ/∂r*² - V(r*)ψ

Leapfrog 离散化：
```
ψ^{n+1}_i = 2ψ^n_i - ψ^{n-1}_i + (dt/dr*)² × [δ²ψ - Vψ]_i
```

- 初始条件：高斯波包 + 初速度
- 边界条件：Sponge layer 吸收
- 频率提取：FFT 谱分析

### v14-v19 — 迭代修复

v14-v19 是 FDTD 框架的渐进稳定过程。关键修复：

| Bug | 版本 | 描述 | 修复 |
|-----|------|------|------|
| V_peak_idx 索引越界 | v19 | 用 r_grid 索引找 V 峰值，但用该索引索引 rstar_grid | 在 rstar_grid 上直接找峰值 |
| Sponge layer 不完整 | v19 | 只在边界应用 sponge | 对所有 sponge 区域应用阻尼 |
| CFL 过于激进 | v19→v20 | CFL=0.95 接近显式格式极限 | 降为 CFL=0.5 |
| interp1d 外推负势 | v19→v20 | V_grid 最小值 -0.025，负势导致指数增长 | Clip 到 V ≥ 0 |

### v20 — FDTD 稳定版本（基准框架）

- 代码：`d1-qbh-qnm-solver-v20.py`
- 关键修改：
  ```python
  # 在 rstar_grid 上找 V 峰值
  V_peak_pos_rstar = rstar_grid[np.argmax(V_grid)]
  
  # CFL = 0.5
  dt = drstar * 0.5
  
  # 完整 sponge
  for i in range(N_rstar + 1):
      if i < W_sponge or i > N_rstar - W_sponge:
          sponge_factor[i] = np.exp(-alpha * (i / W_sponge)**2)
  
  # Clip 负势
  V_grid = np.maximum(V_grid, 0.0)
  ```
- 验证结果：

| (l,n) | 理论 ω_R | 测得 ω_R | 相对误差 | 状态 |
|-------|----------|----------|----------|------|
| (2,0) | 0.37373134 | 0.37029964 | 0.92% | ✅ |
| (2,1) | 0.37329352 | 0.37029964 | 0.80% | ✅ |
| (2,2) | 0.37265595 | 0.37029964 | 0.63% | ✅ |
| (3,0) | 0.59187029 | 0.59529182 | 0.58% | ✅ |
| (3,1) | 0.58971841 | 0.59529182 | 0.95% | ✅ |
| (4,0) | 0.75906205 | 0.75778618 | 0.17% | ✅ |

**所有 6 个基准 QNM 频率验证通过（误差 < 1%）**。

**结论**：FDTD v20 数值稳定且频率精度 < 1%，可以安全用于 Kerr 和面积量子化扩展。

## 第四阶段：Kerr 扩展 (v21-v23)

### v21 — 首次 Kerr 扩展

- 代码：`d1-qbh-qnm-solver-v21-kerr.py`
- 方法：将 Kerr 度规的旋转修正 δV_rot 加入 Regge-Wheeler 势
- 频率误差：90-95% ❌
- **根因**：tortoise 坐标硬编码 a=0.5 + δV_rot 形式不对

### v22 — Kerr(l=2) 基准设计

- 代码：`d1-qbh-qnm-solver-v22-kerr.py`
- l=2，扫描 a ∈ {0, 0.1, 0.3, 0.5, 0.7, 0.9, 0.95, 0.99}
- 结果：
  - a=0.5：误差 0.03% ✅
  - a=0.9/0.99：势垒完全消失 ❌
- **重大发现**：E_lm(aω) 在 aω > ~0.7 时翻转 → 势垒消失
  - 简单 RW+旋转修正框架在 aω < ~0.7 时有效
  - a>0.7 时框架失效，必须用 Teukolsky 方程

### v23 — Kerr(l=3) 验证

- 代码：`d1-qbh-qnm-solver-v23-kerr-l3.py`
- l=3，同样扫描 a 参数
- 结果：
  - a=0.5：误差 1.02% ✅（略高于 l=2 的 0.03%）
  - a=0.9/0.99：势垒仍然消失 ❌
- **确认**：增大 l 不能阻止高旋转下势垒消失 → 框架失效范围确认为 aω < ~0.7

### I-4 结论

- 简单 RW+旋转修正框架在 **aω < ~0.7** 时有效
- a>0.7 时 E_lm(aω) 翻转 → 势垒完全消失
- 这意味着：Kerr QNM 不能用 Schwarzschild 框架简单推广
- 高旋转 Kerr QNM 必须使用 **Teukolsky 方程 + AIM** 方法

## 第五阶段：面积量子化修正 (v25)

### v25 — QBH 反射率边界扫描

- 代码：`d1-qbh-qnm-solver-v25-qbh.py`
- 基于 v22 FDTD 框架重写
- R 扫描：{0, 1e-30, 1e-20, 1e-10, 1e-6, 1e-3, 0.01, 0.1}
- 结果：
  - 从 R=0 到 R=0.1，ω_R **完全相同**（1.525513，仅 0.03% 数值误差）
  - **负结果**：简单反射率边界条件不足以产生可观测的 QNM 频率偏移
- 物理原因：QNM 由势垒散射共振决定，视界处的反射率改变只影响势垒左侧的驻波模式，对高度衰减的 QNM（ω_I ~ 0.1），边界反射被迅速耗散

## 方法选择矩阵

| 方法 | 稳定性 | 精度 | 扩展性 | 实现难度 | 最终决策 |
|------|--------|------|--------|----------|----------|
| Leaver 连分数 | ❌ 差（溢出） | ✅ 高 | ❌ 差 | ❌ 高 | 放弃 |
| Shooting 法 | ⚠️ 中（RK4 卡死） | ✅ 高 | ✅ 好 | ⚠️ 中 | 放弃 |
| **FDTD** | ✅ 好 | ✅ 好（<1%） | ✅ 好 | ✅ 低 | **采用** |

## 关键教训

1. **数值稳定性优先于理论优雅** — Leaver 法理论上最优雅但数值上最脆弱
2. **坐标系选择至关重要** — r 空间奇异性是 v11-v12 卡死的根本原因
3. **Sponge layer 和 CFL 是 FDTD 成败关键** — v19 的四个 Bug 修复使求解器从 NaN 到稳定
4. **aω < ~0.7 是框架边界** — 这一发现比任何单一数值结果都重要
5. **负结果也是结果** — I-5 证明简单反射率不足以产生可观测效应，排除了一个研究路径
