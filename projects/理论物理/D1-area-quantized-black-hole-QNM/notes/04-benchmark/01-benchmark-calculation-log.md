## v6-v9: 直接尝试，全部 NaN

初始代码中 gamma 公式有符号错误：
- ❌ `gamma = 1 - 2iωM(1 + 4iωM)` — 视界位置代入错误
- ✅ `gamma = 1 - 2iωx₀` — x₀ 是展开点，不是 M

展开点 x₀ 的试探值：[2.0, 2.5, 3.0, 3.5, 4.0]

对所有 l ∈ {2,3,4}, n ∈ {0,1} 尝试 Newton-Raphson 求根，全部输出 NaN。

## v10: 系统性诊断

### 诊断工具: diagnose_v10.py

核心发现：

1. **Gamma 公式仍不正确**（v10 中修正为 gamma = 1 - 2iωx₀，但仍有问题）
2. **Taylor 系数数值不稳定**：
   - 轮廓积分半径 R = 0.3 太小
   - 对 n > 50，ABC 系数范数增长到 10⁴⁰ 量级
   - 第一次 NaN 出现在连分数递推 n=50 附近
3. **连分数递推溢出**：当系数增长到 ~10⁴⁰ 时，数值差分导致有效数字丢失

### 诊断详细输出

```
检查 A, B, C 的范数:
  n=10: |A|≈10², |B|≈10², |C|≈10²
  n=20: |A|≈10⁴, |B|≈10⁴, |C|≈10⁴
  n=30: |A|≈10⁶, |B|≈10⁶, |C|≈10⁶
  ...
  n=50: 首次 NaN
  n=100: |B|≈10⁴⁰
```

这说明 Taylor 系数随 n 呈指数增长，根本原因是轮廓积分半径选择不当 + 被积函数在 z=0 附近有极点。

### 根因总结

| # | 问题 | 影响 | 解决方向 |
|---|------|------|----------|
| 1 | Gamma 公式符号错误 | 视界边界条件错误，整个递推基准偏移 | 已修正为 γ = 1 - 2iωx₀ |
| 2 | 轮廓半径 R = 0.3 太小 | Taylor 系数指数增长 | 增大 R 或使用其他积分方法 |
| 3 | 连分数递推在 n≈50 处 NaN | 无法完成求根迭代 | 改用射击法避免连分数 |

## 决策：放弃 Leaver 连分数法

Leaver 方法在理论上非常优雅（它将微分方程的边值问题转化为连分数求根问题），但数值实现中：
1. 需要高精度的泰勒系数，这本身就是一个数值困难问题
2. 连分数递推在系数增长时不稳定
3. 对于我们的应用（后续要加面积量子化修正），需要一个更灵活的方法

因此转向 **射击法（Shooting Method）**，详见 notes/03-solver/02-shooting-method-design.md
