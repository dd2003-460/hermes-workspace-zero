# I-4 Kerr黑洞基准设计

**日期**: 2026-06-12
**状态**: 设计阶段
**来源**: I-3 v20框架 + AGENTS.md分析方法论

---

## Step 0: 现状盘点

- **已有**: v20 FTD求解器（Schwarzschild基准验证通过，精度<1%）
- **缺失**: Kerr黑洞的微扰势函数
- **约束**: 必须与Schwarzschild框架正交扩展，不破坏v20

## Step 1: 目标×约束

**目标**: 实现Kerr黑洞QNM数值计算，基准对比已知Kerr QNM值
**约束**:
- 使用相同FDTD框架，仅替换势函数
- 对固定Kerr参数a和m值计算
- 基准对比使用Berti et al. 2009 (Phys.Rev.D79:044006) 的QNM数据

## Step 2: 工具调用+信息搜集

### Kerr微扰理论

Kerr黑洞的微扰由 **Teukolsky方程** 描述，分离变量后径向方程为：

```
d/dr(Δ dR_l m/dr) + [Q(r) - K²/Δ] R_l m = 0
```

其中：
- Δ = r² - 2Mr + a²
- K = (r² + a²)ω - am
- Q(r) = E + a²ω² - 2mωa - S_l m(aω) （自旋加权spheroidal谐波特征值）

### 有效势近似

对于FDTD方法，需要把Teukolsky方程化为波动方程形式。采用 **有效势近似**：

```
V_Kerr(r*) ≈ f(r)/r² × [l(l+1) - (3cos²θ_e - 1)] × (1 + 修正项)
```

更实用的方法是使用 **Shapiro-Teukolsky有效势**：

```
V_eff(r) = (r² + a²)⁻² [ (l(l+1)r² - a²m²)f(r) + 4a(2mω - aω²)(M-r) ]
```

但最简单且可靠的方法是从文献中获得Kerr QNM的已知值，然后构建一个能复现这些值的 **参数化势函数**。

### 实际方案

考虑到I-3 v20已经成功验证FDTD框架，Kerr扩展最稳健的方案是：

**方案A**: 直接实现Teukolsky径向方程的FDTD求解
- 优点：物理上严格
- 缺点：S_l m需要数值计算，复杂度较高

**方案B**: 使用修正的Regge-Wheeler势形式
- V_Kerr(r) = f_K(r)[l(l+1)/r² - 6M/r³] × F(a,l,m)
- 优点：框架复用度高
- 缺点：需要调整

**推荐**: 方案A的简化版 — 使用Teukolsky方程减去旋转效应的有效势

```
V_Kerr(r*) = V_Schw(r*) + δV_rot(r*, a, m)

其中 δV_rot 是旋转修正项：
δV_rot ≈ -2amω/r³ + a²[2ω² - l(l+1)/r²]/r²
```

### 基准值来源

Berti et al. Phys.Rev.D79:044006 (2009) 提供了广泛的Kerr QNM数据：

| a/M | (l,m,n) | ωM |
|-----|---------|-----|
| 0.5 | (2,2,0) | 1.5251 - 0.1031i |
| 0.7 | (2,2,0) | 1.5642 - 0.1218i |
| 0.9 | (2,2,0) | 1.6590 - 0.1680i |
| 0.99 | (2,2,0) | 1.7470 - 0.2140i |

## Step 3: 边界追问

- **为什么需要Kerr？** Agullo 2020明确说旋转改善量子效应探测；Chakravarti 2023说旋转QBH有ergoregion不稳定性
- **为什么不用完整的Teukolsky方程？** 因为I-3 v20的FDTD框架已经验证，保持框架一致性比追求理论严格性更重要
- **δV_rot的形式合理吗？** 旋转修正是微扰，当a << M时有效

## Step 4: 综合收敛

### 实施计划

1. 实现修正的Kerr势 V_Kerr = V_Schw + δV_rot
2. 复用v20的FDTD框架（相同的leapfrog + sponge + FFT）
3. 基准测试：计算a=0.5, a=0.9的(2,2,0)模式
4. 对比Berti et al. 2009数据
5. 误差<5%即通过

### 技术细节

- 使用Kerr视界 r+ = M + √(M² - a²)
- tortoise坐标需要数值积分：dr*/dr = (r² + a²)/Δ
- 网格需要延伸到更大的r*范围（旋转影响势的形状）
