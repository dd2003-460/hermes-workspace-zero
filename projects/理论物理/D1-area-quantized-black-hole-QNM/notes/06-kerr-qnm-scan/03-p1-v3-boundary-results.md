## 关键发现

### 发现 1: 框架有效边界远超出预期

I-4 预测 "aω < ~0.7" 时框架有效。实际结果：
- 对 l=2, m=2：框架在 a=0.9 仍有效 (V_peak=0.035，误差仅 0.08%)
- 对 l=3, m=3：框架在 a=0.85 仍有效，a=0.9 开始失效
- **实际边界不是全局阈值，而是 (l,m) 依赖的**

### 发现 2: V_peak 递减趋势 — 势垒消失边界

合并 P1-v2 + P1-v3 refined 数据，高 m 模式的 V_peak 随 a 递减：

| a | l=2,m=2 V_peak | l=3,m=3 V_peak | 状态 |
|---|--------------|--------------|------|
| 0.55 | 0.083 | 0.171 | 安全 |
| 0.60 | 0.077 | 0.148 | 安全 |
| 0.65 | 0.070 | 0.124 | 安全 |
| 0.70 | 0.063 | 0.100 | 安全 |
| 0.75 | 0.056 | 0.076 | 安全 |
| 0.80 | 0.049 | 0.054 | 安全 |
| 0.85 | 0.042 | 0.035 | 安全 |
| 0.90 | 0.035 | **0.019** | l=3,m=3 临界 |
| 0.95 | 0.028 | **0.008** | 全崩溃 |

线性外推预测 V_peak=0 的位置：
- **l=3, m=3**: a ≈ 0.97 — 最先消失
- **l=2, m=2**: a ≈ 1.10 — 超过极端黑洞 (a=M)，势垒不消失

### 发现 3: 双重失效机制

**机制 1: 势垒消失** (高 m 模式)
- l=3,m=3 在 a≈0.93 时 V_peak 接近 0 → 势垒高度不足 → 波包无法被限制 → QNM 频率无法正确提取
- 这是 I-4 原文描述的失效方式

**机制 2: 近似阶数失效** (a=0.95 全面崩溃)
- a=0.95 时 **所有模式** (包括 m=0，V_peak=0.15 和 0.37) 全部失败
- 势垒仍然存在，但框架给出的频率完全错误 (误差 77%-95%)
- 原因：Mashhoon (1989) 的 E_lm 展开为 aω 的低阶多项式，在 aω → ~0.6 后高阶项已不可忽略
- 具体影响：E_lm(aω) 的截断误差 → δV_rot 中的 (E_lm - l(l+1)) 项错误 → 势垒形状整体偏移 → 共振频率偏移

**双重机制总结**:
```
a < 0.85: 安全区 — 所有模式可靠
0.85 < a < 0.92: 临界区 — l=3,m=3 因势垒变低开始失效
0.92 < a < 0.95: 双重区 — 高 m 模式势垒消失 + 低 m 模式近似失效
a > 0.95: 失效区 — 框架全面崩溃 (近似阶数不足主导)
```

### 发现 4: m=0 模式在所有自旋下保持不变

V_peak (m=0) = 0.151 (l=2) 和 0.372 (l=3)，在 a∈[0, 0.95] 完全恒定。
直到 a=0.95，m=0 模式给出错误频率 → 框架的近似阶数是全局性限制，不因 m=0 而避免。

**m=0 是最稳健的模式，但其有效上限同样是 a ≈ 0.9。**

### 发现 5: 三次多项式 vs 线性外推差异极小

在 a≤0.9 范围内，两种外推方式的 ω_R 差异 < 0.1%。这说明 Berti et al. 2009 数据中 ω_R 随 a 的变化近似线性（在 a>0.5 后变化率几乎恒定）。三次多项式外推在 a<0.9 的误差 < 0.1% (由 ω_R 总变化 < 0.5% 保证)。

## 综合：I-4 结论修正

原结论：*"RW+旋转修正在 aω < ~0.7 时有效"*

修正后：**"RW+旋转修正框架 (Mashhoon 1989) 的精确失效边界：**

| 区域 | 范围 | 状态 | 失效机制 |
|------|------|------|---------|
| 安全区 | a ≤ 0.85 | 全部模式误差 < 5% | — |
| 临界区 | 0.85 < a < 0.92 | l=3,m=3 开始失效 | 势垒高度不足 |
| 过渡区 | 0.92 ≤ a < 0.95 | 低 m + l=2,m=2 仍可靠 | 近似仍有效 |
| 失效区 | a ≥ 0.95 | 全部模式失效 | **近似阶数不足** |

**有效上限**: a ≈ 0.92 (l=2,m=2) / a ≈ 0.90 (l=3,m=3)
比 I-4 预期的大 30-40%。**"**

## 对 Teukolsky 实现的启示

1. **RW+旋转修正的实际有效范围**: a ∈ [0, 0.92] (对 l=2,m=2) / [0, 0.90] (对 l=3,m=3)
2. **Teukolsky 必需区域**: a > 0.92 (统一覆盖所有模式)
3. **渐进极端黑洞 (near-extremal, a>0.99)**: Teukolsky 的核心场景，长寿命 QNM 对天体物理观测最关键
4. **Mashhoon 近似的两重限制**:
   - 势垒消失 (由 -2amω 项导致，模式依赖)
   - E_lm 展开截断 (全局性限制，a>0.9 后主导)
5. **E_lm 高阶修正被排除为替代路径** (2026-06-16 分析确认):
   - 数值分析确认 E_lm 的 (aω)^6 项贡献 < 0.001 (a=0.95 时)，对 delta_rot 的影响 < 0.5%
   - m=0 模式下 E_lm = l(l+1) 精确无误（无展开截断），但 a=0.95 时仍然 81% 错误
   - **根本原因**: RW+旋转修正框架的结构近似在 a>0.9 后整体失效，不是 E_lm 阶数问题
   - 框架忽略了 frame-dragging 对径向方程本身的修正（RW 方程来自 Schwarzschild 度规）

## E_lm 高阶修正排除分析 (2026-06-16)

### 分析结果

对所有 (l,m) 组合的系数分析：

| l | m | A2 | A4 | A6(估) | |A2*beta^2| |A4*beta^4| |A6*beta^6| |
|---|---|------|--------|--------|-----------|-----------|-----------|
| 2 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 2 | 1 | -3.20 | +0.61 | ~0.12 | 0.41 | 0.010 | 0.0002 |
| 2 | 2 | -8.00 | +0.95 | ~0.11 | 1.02 | 0.016 | 0.0002 |
| 3 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 3 | 1 | -4.29 | +0.71 | ~0.12 | 1.36 | 0.072 | 0.004 |
| 3 | 2 | -13.71 | +1.83 | ~0.24 | 4.37 | 0.185 | 0.008 |
| 3 | 3 | -18.00 | +1.40 | ~0.11 | 5.73 | 0.142 | 0.004 |

(beta = a*omega = 0.357 for l=2, 0.564 for l=3 at a=0.95)

### 关键论证

1. **A6*beta^6 < 0.008** 在所有模式中 → 对 delta_rot 的贡献 < 0.001 量级
2. **m=0 模式在所有 a 下 E_lm 精确**（A2=A4=A6=0），但 a=0.95 时 81% 错误
3. m=0 的 delta_rot = 0（精确）→ 退化为纯 Schwarzschild 势 → 但 Kerr QNM m=0 频率随 a 变化
4. **框架本质缺陷**: RW 方程来自 Schwarzschild 度规，无法捕捉 frame-dragging 对径向方程本身的影响

### 结论

**E_lm 高阶展开 (aω)^6+(aω)^8 不能延长效用范围。** 这是否定性结论，置信度高（由 m=0 分析保证）。

**a>0.92 后必须使用 Teukolsky 方程 + AIM 方法。**
