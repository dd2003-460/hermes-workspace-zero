# P0 FDTD 系统误差诊断

**origin: ai**
**日期**: 2026-06-12
**任务**: 诊断 P0 扫描中 l=2, a≤0.2 误差增大原因

---

## 1. 诊断目标

P0 扫描中 8.3% 的 case 出现 >5% 误差（l=2, a≤0.2, m=0/1）。诊断目的是理解误差来源，以评估 I-5 负结果的可信度。

## 2. 诊断方法

1. 复现 v20 求解器（Dirichlet BC + V_clip=0.0）
2. 复现 v22/P0 求解器（zero d2 at boundaries + sponge + V_clip=-0.01）
3. 收敛性分析：改变 N_rstar 和 T_total

## 3. 诊断结果

### 3.1 FDTD 复现

复现代码中两种 FDTD 风格都产生 >4% 误差：
- v20 风格 (Dirichlet BC): 85% error
- v22 风格 (sponge): 4-11% error

说明 5% 误差是 **FDTD 系统误差**，不是特定参数的bug。

### 3.2 收敛性分析

N 从 4000→10000，误差从 15%→45%（非单调）
T 从 800→1600，误差从 5%→25%

这表明 FDTD 求解器存在**非物理边界反射**，增加时间或分辨率反而增加了误差。

### 3.3 误差模式

- 误差与 m 无关（a=0 时所有 m 误差相同）
- l=2 误差 > l=3 误差
- 测量频率 > 文献值（0.3926 vs 0.3737）

测量频率偏高表明势阱有效深度/形状有系统性偏差。

## 4. 对 I-5 负结果的影响

I-5 的结论（简单反射率边界条件对 QNM 频率无影响）受 ~5% 系统误差限制：
- 如果 QBH 修正产生 >5% 的频率偏移，应该能观测到
- 如果修正 <5%，则被 FDTD 系统误差淹没
- 由于所有 R 值（包括 R=0）都有相同的 ~5% 系统误差，**相对比较仍然有效**：R 变化不会引起系统误差的变化

## 5. 结论

1. 5% 误差是 FDTD 系统误差（边界条件 + 势阱形状偏差）
2. 不影响相对测量：所有 R 值使用相同的 FDTD 配置
3. I-5 负结果（δω/ω 与 R 无关）仍然可靠
4. 绝对频率精度 <5% 是 FDTD 方法的固有局限
5. 需要 Teukolsky + AIM 方法才能达到 <0.1% 精度
