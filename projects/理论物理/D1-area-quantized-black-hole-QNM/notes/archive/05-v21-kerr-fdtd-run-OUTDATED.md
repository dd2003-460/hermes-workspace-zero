## 第二次运行根因分析

### 问题 1: `kerr_tortoise()` 使用了固定 a_test=0.5

```python
def kerr_tortoise(r_horizon, r_max, N_pts):
    a_test = 0.5  # ← 硬编码！对于 a=0.9/0.99 计算错误
    ...
```

a 参数不同，Kerr 视界位置和 tortoise 坐标完全不同。a=0.9 时视界 r+ ≈ 1.436，固定用 a=0.5 的 tortoise 坐标会完全错误映射 r → r*。

### 问题 2: 旋转修正势 δV_rot 不够

```python
delta_rot1 = -2.0 * a * m * omega_guess / r_grid**3
delta_rot2 = a**2 * (2*omega_guess**2 - l*(l+1)/r_grid**2) / r_grid**2
```

这个修正量级太小，不能产生 Kerr 黑洞正确的势垒结构。Kerr QNM 频率比 Schwarzschild 高约 30-40%，但此修正未能体现这一物理趋势。

### 问题 3: 测量频率 0.14 vs 理论 1.525 — 差约 10 倍

这表明势场深度/宽度完全不对，波函数没有被正确束缚。
