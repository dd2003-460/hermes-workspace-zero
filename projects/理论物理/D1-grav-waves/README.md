# D1-grav-waves：引力波背景源判别

> **⚠️ 状态说明：** 这是一个理论物理研究项目，核心产出是一篇 JHEP 格式论文。论文已完成理论推导和静态审查，但尚未进行实际数据验证。详见本文第 7 节"诚实评估"。

---

## 1. 这个项目在解决什么问题？

### 1.1 引力波背景（GWB）的发现

2023 年，NANOGrav 合作组（以及欧洲 PTA、pulsar timing array）宣布了一个里程碑式的发现：他们在纳赫兹（nanohertz，10^-9 Hz）频段探测到了一个**引力波背景**（Gravitational Wave Background, GWB）。

**引力波是什么？** 广义相对论预言，大质量天体加速运动会产生时空的涟漪——引力波。2015 年 LIGO 首次直接探测到了黑洞并合产生的引力波（频率约 100 Hz）。而纳赫兹引力波是另一种完全不同的信号：它们的频率极低，波长长达数光年，来自超大质量黑洞双星系统的长期演化。

**为什么是"背景"？** 不像 LIGO 探测到的单个黑洞并合事件，纳赫兹引力波是无数遥远超大质量黑洞双星系统叠加形成的"背景噪声"，类似于你听到整个交响乐团的合奏而不是单个乐器。

### 1.2 源判别问题

NANOGrav 发现了这个背景，但**不知道它来自哪里**。最可能的两个来源是：

| 来源 | 描述 | 特征 |
|------|------|------|
| **超大质量黑洞双星（SMBHB）** | 星系中心黑洞相互绕转并最终并合 | 离散源，分布不均匀，与星系大尺度结构相关 |
| **宇宙学起源** | 早期宇宙的原初引力波（如暴胀、相变、宇宙弦） | 连续源，高度各向同性 |

**为什么区分来源很重要？** 因为它告诉我们宇宙演化的根本机制。SMBHB 告诉我们星系形成的历史；宇宙学起源告诉我们暴胀或早期宇宙相变的过程。这是完全不同的物理。

### 1.3 判别工具：Hellings-Downs 相关性

区分来源的关键工具是 **Hellings-Downs (HD) 相关性曲线**。

**直观理解：** PTA 使用数十颗脉冲星作为"钟"，监测脉冲到达地球的时间。引力波经过时，会微妙地改变脉冲到达时间。如果两个脉冲星之间的角度是 θ，它们接收到的引力波信号之间的相关性由 HD 函数 ζ(θ) 给出。

HD 曲线的形状是引力波背景的"指纹"——只有正确的引力波理论才能预测出这个特定的曲线形状。

**关键问题：** HD 曲线假设引力波背景是**各向同性**的（均匀分布在天空各处）。但如果来源是 SMBHB（离散黑洞分布），天空应该是不均匀的——某些方向有更多的源，因此 HD 相关性应该出现**各向异性**（anisotropy）。

**这就是本项目的核心问题：不同来源产生的各向异性幅度有多大？能否大到足以区分它们？**

## 2. 核心思路：为什么用 QFT？

### 2.1 直觉

标准引力波检测使用"微扰理论"——把引力波当作背景时空的小扰动。但这种方法有几个局限：

1. **只适用于特定坐标选择** — 计算依赖于你怎么定义"背景时空"
2. **无法自然地处理不同几何结构** — 如果时空拓扑复杂，微扰方法会很麻烦
3. **缺乏统一框架** — 不同源类型的判别需要不同的方法

**代数量子场论（AQFT）** 提供了一个不同的视角：

- AQFT 的核心思想：用**代数**（代数结构，如算子代数）来表示物理可观测量，而不是用具体的波函数或场
- AQFT 的"局部协变性"（local covariance）：物理定律的形式不依赖于你选择什么样的时空背景——它说的是物理结构在不同时空之间的**自然映射**
- **范畴论**（category theory）是处理这种"结构之间的映射"的语言

**直觉类比：** 想象你要比较两幅画的"相似性"。传统方法是用像素差异（类似微扰理论，依赖于具体的坐标选择）。AQFT 的方法是用更抽象的结构——比如这两幅画在什么变换下保持相同（对称性）。这不依赖于你"怎么看"画，而是依赖于画本身的结构。

### 2.2 应用到 PTA

本项目的核心洞察是：

> **HD 相关性不是偶然出现的数学公式，而是时空几何结构和量子场论代数结构之间深层关系的体现。**

更具体地说：
- PTA 探测到的每个脉冲星信号，对应于 AQFT 框架中某个**局部代数**的期望值
- 两个脉冲星之间的 HD 相关性，对应于 AQFT 中连接两个代数的**自然变换**
- 自然变换是范畴论中的概念——它是"函子之间的映射"，描述了两个不同数学结构之间的"一致性变换"

**这意味着：** HD 曲线的形状（对数上升、90 度最小值、180 度趋于 1/2）不是某个特定计算的偶然结果，而是时空的 SO(3) 旋转对称性和量子场论代数结构之间的必然联系。

### 2.3 源判别

不同来源（SMBHB vs 宇宙学）产生不同的**代数态**（algebraic states）。在 AQFT 中，两个态如果"不等价"，意味着你可以用某个可观测量区分它们。

本项目证明了一个定理（Theorem 1）：SMBHB 和宇宙学背景在总变分距离（total variation distance）上是**可区分的**，而且区分的能力取决于脉冲星对数 P 和源数 N_src。

**量化结论：**
- SMBHB 的各向异性幅度：~O(1-10%) — 因为离散黑洞分布不均匀
- 宇宙学起源的各向异性幅度：~O(10^-5) — 因为早期宇宙高度均匀
- **1000 倍差距**，如果测量精度足够，可以明确区分

## 3. 技术细节

### 3.1 AQFT 基础

**代数量子场论（AQFT）** 的核心定义：

1. **局部代数**：给定时空区域 O ⊆ M（M 是时空流形），AQFT 分配一个 C*-代数 A(O)，表示局限于该区域的物理可观测量
2. **函子性**：映射 O ↦ A(O) 是一个函子——它保持时空嵌入（嵌入映射）和代数同态之间的关系
3. **局部协变性**：如果 φ: M₁ → M₂ 是一个等距嵌入（即 M₁ 是 M₂ 的一个子区域且保持度量），那么存在代数同态 A(φ): A(M₁) → A(M₂)

**自然变换**：如果 F 和 G 是两个函子，自然变换 η: F → G 是一个映射族 {η_X: F(X) → G(X)}，满足对所有 f: X → Y，有 η_Y ∘ F(f) = G(f) ∘ η_X。

### 3.2 HD 相关性作为自然变换

**命题 1（HD 相关性作为自然变换）：** 在 Minkowski 时空中，HD 相关性 ζ(θ₁₂) 是相关函子之间的自然变换在长波极限下的特例。

**证明思路：**
1. 引力波度规扰动 h_ij 在横无迹规范下展开为平面波叠加
2. 脉冲星 i 的时间残差 R_i(t) 是局部代数 F(w_i ∩ I_t⁺) 中的可观测量
3. 两个脉冲星之间的相关性 = ⟨R₁R₂⟩，这对应于连接两个世界线的**探测器协形（detector cobordism）**
4. 在长波极限下（PTA 频段），红移响应函数 g(t') → 1，相关性函数简化为标准 HD 形式

**关键洞见：** HD 函数中的对数项不是某个特定计算的偶然结果——它来自连接两个世界线的协形类在扩展范畴 Loc_M^ext 中的非平凡结构。

### 3.3 源判别定理

**定理 1（源判别）：** 对于 PTA 观测，SMBHB 和宇宙学背景之间的总变分距离满足：

d_TV(ω_SMBHB, ω_cosmo) ≳ c · P^(-1/2) · |σ²_N(SMBHB) - σ²_N(cosmo)|

其中：
- P = N(N-1)/2 是脉冲星对数
- σ²_N 是源计数的分数方差
- c 是依赖于谱指数差 Δγ 的常数

**物理含义：**
- 统计不确定性随脉冲星对数 P 的增加而减小（~P^(-1/2)）
- SMBHB 源的方差 ~O(N_src^(-1)) — 因为泊松噪声
- 宇宙学源的方差 ~O(N_mode^(-1)) — N_mode >> N_src（更多的多极模式）
- **判别条件：** P^(-1/2) < |σ²_N(SMBHB) - σ²_N(cosmo)| — 即统计精度要高于源方差差异

**SKAO 时代的判别信噪比：**
- N ~ 200 脉冲星 → P ~ 20000
- 判别信噪比：~14-140（取决于 N_src = 10^4-10^6）

### 3.4 各向同性定理

**定理 2（各向同性缩放）：** 对于不同来源，HD 相关性的各向异性校正具有不同的幅度和结构：

- **SMBHB：** ζ_SMBHB(θ₁₂) = ζ₀(θ₁₂) + O(N_src^(-1/2)) · Y_lm^LSS(n̂₁₂)
  - Y_lm^LSS 追踪大尺度结构
  - 幅度 O(1-10%)
  
- **宇宙学：** ζ_cosmo(θ₁₂) = ζ₀(θ₁₂) + O(C_ℓ^cosmo) · Y_lm^cosmo(n̂₁₂)
  - C_ℓ^cosmo ~ O(10^(-10))（原初密度涨落）
  - 幅度 O(10^(-5))

**判别性：** 不是缩放阶数的差异（都是小校正），而是**物理起源和幅度**的巨大差异。SMBHB 各向异性追踪星系分布，而宇宙学各向异性反映原初密度场。
