## 0. 一句话总览

老师的代码是**用宇宙学模拟 + 半解析方法算"黑洞并合引力波源在宇宙里的分布"**的完整流水线，
分两个时代、两组脚本：

| 组 | 目录 | 年代/语言 | 干什么 |
|---|---|---|---|
| 第一组 | `老师源码_Millennium并合率2017/`（7 个） | 2017，Python 2 | 从 Millennium 模拟算**黑洞并合率随红移的分布**，再"吹"出一个 6 Gpc 大的超级立方体，按距离壳层抽样引力波源 |
| 第二组 | `老师源码_GW光锥选源2024/`（7 个，编号 01–07） | 2024，Python 3 | 从模拟的并合树里**挑出双黑洞并合事件 → 投影到光锥 → 算每个事件的引力波频率和振幅 → 画图** |

两组合起来就是一篇典型的"半解析引力波宇宙学"论文的计算链：
**模拟给出星系/黑洞 → 按经验规则让黑洞并合 → 算并合率 → 放进光锥 → 算可观测量（振幅/频率）**。

## 1. 第一组：Millennium 并合率流水线（2017，Python 2）

### 1.1 文件清单与角色

| 文件 | 角色 |
|---|---|
| `m_BH_m_ZAMS.py` | **遗迹质量公式**：输入前身星质量 M_ZAMS 和金属丰度 Z，输出遗迹（黑洞）质量 M_rem。这是 Spera+2015 附录 C 的拟合式 |
| `R_za.py` | 并合率计算**主力版**：多进程（parallel python, `pp`），对每条星系记录算 IMF 权重 |
| `R_zanp.py` | 单机版：同 R_za，额外输出每个星系的 mBH |
| `R_zanps.py` | 又一个变体（调试/小规模用） |
| `R_zanpN.py` | **分块版**：`nn=21` 表示"我是第 21 块"，21 个进程各算 10 万条，手工并行 |
| `R_zmrdboxa.py` | 把并合率按红移分箱，算**并合率密度** MRD(z) |
| `superGW6e3.py` | 把 62.5 Mpc/h 的小盒子**周期复制**成 6000 Mpc/h 的大盒子，按半径壳层伯努利抽样引力波源，画 3D 分布图 |

### 1.2 数据从哪来（代码注释里的 wget 行）

```python
# wget -O mMR.csv "http://gavo.mpa-garching.mpg.de/MyMillennium?...
#   select snapnum,galaxyID,lastProgenitorId,x,y,z,stellarMass,metalsStellarMass,sfr
#   from Guo2010a..mMR"
```

- `mMR.dat`：Millennium 模拟（Guo+2011 星系表）每个星系在每个快照的一行：
  snapnum（快照号）、galaxyID、lastProgenitorId（最后一代祖宗 ID，用来判"是不是祖宗星系"）、
  x/y/z（位置 Mpc/h）、stellarMass（恒星质量）、metalsStellarMass（**恒星**里锁着的金属质量）、sfr。
- `snapinfo.csv`：每个快照的宇宙学信息（snapnum, a, z, H(z), lookbacktime）。
  注意金属丰度不是现成字段，而是 **metalsStellarMass / stellarMass 现算**。

### 1.3 核心物理：imf() / imfbh() 函数（R_zanp.py 第 38-61 行）

这是全组脚本的物理核心，做三件事：

1. **算金属丰度**：`metal = metalsStellarMass/stellarMass`（无量纲质量分数），
   参照 `metalSun = 0.0134`（太阳金属丰度，注意和我们项目用的 0.02/0.0142 是另一套约定）。
2. **造一个随金属丰度变陡的 IMF**：`cons = 40*(((metal/0.01/metalSun)**0.2+1)/40/0.3)**(1/1.8)`
   ——金属越多 cons 越大；IMF 常数 phi0 由 3–100 M⊙ 区间归一化定。
3. **从 IMF 反抽一个黑洞质量**：`ran = np.random.rand()`，然后
   `mBH = (3^(-1.35/1.8) - 1.35*ran*cons^1.35/phi0)^(-1.8/1.35)`。
   直白说：**金属丰度 → IMF 形状 → 从 IMF 里随机抽一个恒星 → 这个恒星就是黑洞前身星**。
   抽出来的 m 又代回 `phi = phi0*m^-2.35` 得到 IMF 密度值，作为权重。

**这和我们项目的关系**：我们项目 2.1（Salpeter IMF）+ 2.2（Spera 遗迹轨迹）把同样的事做得更细——
IMF 固定为 Salpeter、遗迹质量用 Spera+15 附录 C（就是第一组的 `m_BH_m_ZAMS.py`）。
老师这里用的是"IMF 随金属丰度变形 + 直接抽 mBH"的简化版，**Z 有两个入口**的雏形（改 IMF + 改遗迹）。

### 1.4 cycle()：并合率的主循环（R_zanp.py 第 63-73 行）

对每个"目标星系" i（在 snap 时刻）：

```
对 i 的所有祖宗星系 j（满足 ob_id < galaxyID_j <= lastProgenitorId_i）:
    并合率 += sfr_j × IMF_j × 1/(t_j - t_snap) × (t_j - t_{j+1})
```

直白说：**祖宗星系 j 在它存活的那段时间里，以 SFR×IMF 的速率生产黑洞前身星，
这些前身星在目标时刻 t_snap 全部并合掉**（假设延时时间为零，或说延时已含在 1/Δt 里）。
这就是最朴素的"推前（push-forward）"：不跟踪每颗恒星，用速率×时间近似。

### 1.5 三个下游脚本

- `R_zmrdboxa.py`：按快照把并合率加起来，除以盒子体积 `sma_len^-3`，得到**并合率密度** MRD(z)，
  归一化到 z=0 的 1e-7，存 `MRDa.dat`。
- `superGW6e3.py`：周期平铺小盒子 → 大盒子（`expand = int(R/sma_len)+1` 圈复制），
  对每个事件：如果 `randnum <= MRbh[i][0]`（伯努利抽样，概率=并合率）就收下，
  且只收落在当前半径壳层 [r2, r1) 里的。**这就是光锥构建**——和我们的 1.3 一个思想，
  但用的是"盒内复制 + 半径判据"而不是我们的"洋葱皮红移壳层"。
  最后画 3D 散点 + 一个天图扇形（floating_axes 极坐标天图，RA 范围 π/4–5π/16，
  对应真实望远镜视场，如 HXMT/EP 的监测天区）。

### 1.6 Python 2 遗留（运行前必须知道）

- `print 'xxx'`、`long(...)`、`map()` 返回列表全是 **Python 2 语法**，Python 3 直接报语法错；
- `import pp`（parallel python）早已停止维护，Python 3 没有；
- 想复现：装 Python 2.7 + `pip install pp`，或把 `print`/`long`/`map` 三件事改掉（见 annotated 版说明）。

## 2. 第二组：GW 光锥选源流水线（2024，Python 3，@author: Qing）

### 2.1 七步流水线总览

```
01PickMergingEvents.py      从并合树找"双黑洞并合事件"      → merging_cases.csv
02mergingcasewithdistance.py 给事件加共动距离 + 外半径        → merging_cases_binary_withdistance.csv
03SelectLightconeEvents.py   周期平铺选光锥内事件            → lightcone data/lightcone_events_*.csv
04AddGWfreAmp.py             算频率 + 振幅                   → lightcone_events_withfA_*.csv
05CaculateIsoAmp.py          按频率分箱累加振幅²             → 各向同性应变曲线
06MerEventsScatterPlot.py    3D 散点图
07MerEventsScatterPlot-2D.py 2D 散点图（z 着色）
```

### 2.2 01：挑并合事件（`firstProgenitorId` / `nextProgenitorId`）

Millennium 的并合树里，一个星系要成为"并合事件"，必须同时满足：

- `firstProgenitorId != -1`（有第一代祖宗，即它是并合产物）；
- 第一代祖宗的 `nextProgenitorId != -1`（第一代还有**兄弟**祖宗，即至少两个分支合过来）；
- **两个祖宗的 blackHoleMass 都不为 0**（没黑洞就不算双黑洞并合）。

满足就记一行：并合后星系 ID、红移、位置、双方黑洞质量。
**这就是"并合"的判据**——我们的项目把 BPS/并合延迟列为 P3-OPTIONAL，如果将来要做，
这个 `firstProgenitor/nextProgenitor` 双非空判据是最低配实现。

### 2.3 02：共动距离与"外半径"

- 宇宙学参数硬编码：**Ωm=0.25, ΩΛ=0.75, h=0.73**（Millennium 的参数，注意和我们项目的
  Planck 参数不同）；
- `comoving_distance(z) = c/H0 × ∫dz/√(ΩΛ+Ωm(1+z)³)`——标准共动距离；
- `ComovingDmax`：事件在**下一个快照**红移处的共动距离。含义：这个事件从当前红移"走"到
  下一快照红移之间，都可能发生——事件在光锥里可能落在的内/外半径就是
  [当前距离, 下一快照距离]，即**径向厚度 = 一个快照间隔**。这和我们 1.3 的壳层思想一致。

### 2.4 03：光锥选择（本组最核心）

对盒内每个事件，把所有周期镜像位置 `(x/h + i·L, y/h + j·L, z/h + k·L)` 枚举出来
（i,j,k ∈ [−q−1, q]，q = 外半径/盒长），只保留到原点距离落在
[inner_radius, outer_radius] 的镜像。**这就是周期平铺建光锥**——原点（观察者）放在盒子角上，
把所有镜像盒子里落在壳层里的事件都捞进来。我们项目 1.3 做的是同一件事的工程化版本。

### 2.5 04：引力波频率与振幅

- 频率：`invF_f(np.random.random(), M1+M2)`——**注意依赖外部模块 `generateGWfrequency`**
  （老师没给，见 §4）。物理是：给总质量一个随机 Inspiral 时间，反解出该时间对应的 GW 频率；
- 振幅（`GWAmplitude` 函数，标准啁啾质量公式）：

```
M_chirp = (M1·M2)^(3/5) / (M1+M2)^(1/5)          # 啁啾质量
A = √(32/5) · G^(5/3) · M_chirp^(5/3) · (πf)^(2/3) / c⁴ / D_L
```

- 光度距离：`D_L = 共动距离 × (1+z)`，红移由位置反查（`CoDisReds(CoD)`）。

**振幅公式和我们项目的接口**：我们 4.2 装配给每个 BH 位置和质量，这个公式就是
"质量谱 → 可观测量"的最后一环。啁啾质量 M_chirp 是双星系统的"有效质量"——
系统越重、频率越高（接近并合）、距离越近，振幅越大。

### 2.6 05：各向同性应变

把 10⁻⁹–10⁻⁶ Hz（PTA 频段）按 log 频率分箱（step=0.3 dex），每箱累加 `amp²`，
最后画 `log10(√(Σamp²/Δf))`。这就是把成千上万个源的振幅**非相干叠加**成
背景应变曲线——PTA 探测的超大质量双黑洞背景正是这么做预期的。

### 2.7 06/07：画图

纯 matplotlib 散点，3D 版看空间分布，2D 版用 z 着色看深度结构。代码很短，一看就懂。

## 3. 两组代码 vs 我们项目：对不上的地方

| 维度 | 老师代码 | 我们项目 | 影响 |
|---|---|---|---|
| 宇宙学 | Ωm=0.25/ΩΛ=0.75/h=0.73（Millennium） | Planck（config/cosmology.yaml） | 距离/体积换算差几个 %，参数不能混用 |
| 太阳金属丰度 | 0.0134 | 0.02（Spera 口径）/0.0142（观测 MZR 口径） | Z 换算差 1.5 倍，必须声明口径 |
| IMF | 随 Z 变形的经验 IMF（-1.35 高质端） | Salpeter 固定（⟨m⟩=0.351369） | 我们更严格；老师的金属-IMF 耦合是简化 |
| 遗迹质量 | 直接从 IMF 抽 mBH（无 PISN/无完整轨迹） | Spera+15 附录 C 全轨迹 + PISN 开关 | 我们的 2.2 是老师这套的严格版；`m_BH_m_ZAMS.py` 附录 C 式子我们已逐行复现 |
| 延时时间 | 零延时（祖先 SFR 全部在当前时刻并合） | 4.1 推前默认瞬时爆发；DTD 为 P3 | 老师的假设和我们"瞬时爆发"决策一致 |
| 光锥 | 盒内周期平铺 + 半径壳层 | 1.3 洋葱皮 + 周期平铺（有测试守护） | 同思想，我们的有标校测试 |
