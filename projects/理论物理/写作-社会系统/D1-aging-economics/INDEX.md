# D1-aging-economics — 人口老龄化对区域经济的影响

> **起源**: 2026-05-23 · 成璐
> **领域**: 经济学实证研究
> **状态**: Phase 0-7 全部完成 (合成数据完整分析流程验证通过: baseline + DID + mechanism + robustness + 英文论文初稿 v1 10页/227KB, 含 prediction section)
> **方法**: 面板数据 + DID + 因果推断

## 一句话

用中国省级面板数据和政策冲击，量化老龄化对区域经济增长的因果效应。

## 核心研究问题

1. **老龄化是否抑制经济增长？** — 主效应，面板固定效应
2. **传导机制是什么？** — 储蓄率、劳动力供给、消费结构
3. **异质性何在？** — 东中西部差异、不同老龄化阶段
4. **结果稳健吗？** — PSM-DID、替换指标、安慰剂检验

## 数据源

- 中国统计年鉴（分省） — 年度面板
- 中国老年长期护理保险试点（2016起） — 政策冲击变量
- CHNS 中国健康与营养调查 — 微观验证
