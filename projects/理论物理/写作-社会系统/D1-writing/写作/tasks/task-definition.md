# Task Definition

## 一句话任务

## 边界
- 范围：准备发布内容、检查格式、生成发布脚本
- 边界：不直接登录 Twitter 发布（需要用户账号），不做内容创作

## 失败标准
- 无法通过现有工具发布
- 内容格式不符合平台要求

## 硬约束
- Twitter/X 需要用户登录
- 博客发布需要确认最终内容
