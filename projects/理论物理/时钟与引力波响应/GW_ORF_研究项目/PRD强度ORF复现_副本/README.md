# PRD强度ORF复现_副本 —— 项目结构与开发规则说明

> **本副本与 `../手征ORF计算_主线/` 的目录结构、命名规则、调用规则完全一致**，
> 下面大部分内容是共享规则的复制，**只有"目的"部分不同**，请重点看第零节。

## 零、本副本的目的（与主线唯一的区别）

主线做的是**全新计算**——把 PRD 论文的精确留数方法应用到手征（圆偏振）物理设定上，
这是没有已知标准答案可以对照的计算。

本副本做的是**方法论验证**——用完全相同的坐标系构造、复变量代换、留数定理、
sympy化简技巧，去复现 **PRD 论文本身已经发表的强度 ORF 结果**（对称核 $\xi_I$，
不涉及手征反对称核 $\xi_V$）。因为强度ORF有已知的标准答案可以对照
（Hellings-Downs曲线、PRD论文Table I的数值、小天线近似的低频极限等），
这个副本能够独立确认：**我们这套计算方法本身没有系统性错误**，
从而为主线的手征计算结果提供额外的可信度支撑。

**核心差异一览**：

| | 主线 | 本副本 |
|---|---|---|
| 被积核 | $\xi_I$（对称，强度）**和** $\xi_V$（反对称，手征） | 只有 $\xi_I$（对称，强度） |
| 阶段1组件B | R0,R1,R2 已完成，R3,R4部分完成（均为手征版本 $R_k^V$） | 全部对应算强度版本 $R_k^I$ |
| 阶段2组件 | 分强度版/手征版两个组件 | 只有一个组件（强度版），外加"PTA退化验证"这一直接可以做的检验 |
| 阶段4组件D | 无对应 | 专门增加"与PRD论文Table I数值对比"这一项，这是本副本独有的验证目标 |
| 核心发现 | $-i$ 比例关系等手征特有现象 | 不适用（强度核没有这种偏振间的比例关系可言，因为只有一种偏振配对方式） |

## 一、总体设计哲学（与主线相同）

整条计算流水线分成 **4个大阶段**，每阶段内若干**地位平等的组件**（字母A、B、C…编号，不分主次），
每个组件下再按脚本性质分为最多三类子文件夹：

- `推导/`：从物理/数学原理出发构造公式结构、或诊断发现新现象的脚本
- `具体计算/`：真正跑符号/数值运算、得到解析或数值结果的核心脚本
- `数值验证/`：用独立方法交叉核对上面两类脚本结果的脚本

不预建空文件夹，只在真正有内容时才建。

---

## 二、四大阶段总览

```
阶段1_单向链路ORF核心积分/     ← 目标: 算出强度版 Γ_one^I(α,β_u,β_v,ŝ,û,v̂)
阶段2_ORF组装_GammaOne/       ← 目标: 组装I1~I4为完整Γ_one^I，并验证PTA退化为Hellings-Downs曲线
阶段3_具体探测器ORF/          ← 目标: 组装PTA/GbLI/SbLI具体探测器的Γ_IJ(f)
阶段4_探测器ORF反解与探测统计量/ ← 目标: 复现PRD论文Table I的数值结果、验证与论文完全一致
```

阶段间严格单向依赖，规则与主线完全相同（见下面第三、四节，与主线文档逐字一致）。

## 三、阶段1 详解

**目标**：算出两条一般单向链路间的**强度**ORF母函数 $\Gamma_{\rm one}^I$。

$$\Gamma_{\rm one}^I=\frac{1}{32\pi}\Big[I_1^I-e^{-i\beta_u}I_2^I-e^{i\beta_v}I_3^I+e^{i(\beta_v-\beta_u)}I_4^I\Big]$$

$$I_1^I=2\pi i\Big[\int dx\,e^{-i\alpha x}R_0^I(x)+\int dx\,e^{-i\alpha x}R_1^I(x)+\cdots+\int dx\,e^{-i\alpha x}R_4^I(x)\Big]$$

| 组件 | 内容 | 状态 |
|---|---|---|
| A_基础设施 | 坐标系、对称被积核 $\xi_I$ 的构造（可直接复用主线组件A里已验证过的 $\xi_I$ 部分） | ⏳ 待开始（预计很快，因为主线已验证过校验方法） |
| B_I1积分的留数分量 | $R_0^I,R_1^I,R_2^I,R_3^I,R_4^I$（强度版留数） | ⏳ 待开始 |
| C_I1完整封闭解 | 对5个留数做x积分，拼出 $I_1^I$，**可与PRD论文式18直接逐项对照** | ⏳ 待开始 |
| D_I2_I3_I4_替换导出 | 矢量替换规则导出 | ⏳ 待开始 |
| E_核心发现 | 本副本中若发现方法论层面的规律，记在这里 | ⏳ 待开始 |

**⚠️ 同样的重要澄清适用于本副本**：组件B算出的是"留数"，不是 $I_1^I$ 本身，
需要组件C做完x积分才是完整的 $I_1^I$。

## 四、跨组件/跨阶段调用规则（与主线逐字相同）

**规则1**：下游永远调用上游的"已验证产出"，不重复推导上游已经做过的事。

**规则2**：每个"具体计算"脚本开头必须写清楚依赖哪个上游产出（相对路径）。

**规则3**：产出的中间结果保存在产出它的"具体计算"文件夹里，下游需要时"拷贝一份"
到自己文件夹（不用远程相对路径读取），保证每个组件自包含可独立运行。

**规则4**：`推导`产出结论，`具体计算`产出可复用结果，`数值验证`只做交叉核对不产出新结果。

**规则5**：新增组件前先想清楚"这个新脚本产出的东西，下一步谁会来调用它"。

**规则6**（与主线逐字相同）：每个有实质产出的组件文件夹下，必须有一份
`结论与推导过程.md`，包含：(1)组件要解决的问题 (2)推导/计算过程的
叙事性说明 (3)**符号计算结果必须用 `sympy.latex()` 转成LaTeX贴出**（方便
和论文/草稿手推公式直接核对，不能只贴原始sympy字符串）(4)具体数值验证
结果 (5)如实记录的失败/未解决部分。详细写法规范见主线README规则6，
两边完全一致，不重复抄写。

## 五、本副本独有的验证优势

因为PRD论文本身给出了大量可以直接对照的"标准答案"，本副本在各阶段可以比主线
更方便地插入"论文复现对比"这一验证环节，具体机会点：

- 阶段1组件C：$I_1^I$ 应该能对照PRD论文式18逐项核对
- 阶段2组件A：$\alpha=0$ (PTA情形) 应严格退化为 Hellings-Downs 曲线，
  这是PRD论文自己做过的验证（式26-28），本副本重新走一遍能直接检验方法正确性
- 阶段4组件D：PRD论文Table I给出了PTA/GbLI/SbLI在具体频率点上的精确ORF数值
  （含耗时对比），本副本可以直接复现这张表格的数字，是最直接的"过关标准"
