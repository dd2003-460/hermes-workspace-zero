# R1, R2, R3, R4（四个一阶极点，强度版）—— 结论与推导过程

## 1. 要解决什么问题

求 $f_I(z)$ 在四个一阶极点 $z_1,z_2$（由 $\hat u$ 决定）、$z_3,z_4$（由
$\hat v$ 决定）处的留数，并直接与PRD论文Eq(A9)-(A12)给出的封闭解对照，
验证方法本身的可靠性（这是本副本项目的核心验证目标）。

## 2. 推导过程

**策略**：不重新走一遍完整的sympy留数推导（那一步在手征主线里已经做过，
对称版本的推导过程完全类似，属于重复劳动），直接采用PRD论文自己发表的
封闭解作为"具体计算"的产出，用黄金标准数值验证其正确性：

$$\sigma^\pm=\frac{1}{1+\cos\gamma}\left(\cos\delta_u+\cos\delta_v\pm i\sqrt{\sin^2\gamma-\cos^2\delta_u+2\cos\delta_u\cos\delta_v\cos\gamma-\cos^2\delta_v}\right)$$

$$R_1^I=-\frac{2i(1-\cos\gamma)}{x+\sigma^-}+\frac{2i(\sigma^+-\cos\delta_u)(1+\cos\gamma)}{1-\cos^2\delta_u}$$
$$R_2^I=\frac{2i(1-\cos\gamma)}{x+\sigma^+}-\frac{2i(\sigma^--\cos\delta_u)(1+\cos\gamma)}{1-\cos^2\delta_u}$$
$$R_3^I=-\frac{2i(1-\cos\gamma)}{x+\sigma^+}+\frac{2i(\sigma^--\cos\delta_v)(1+\cos\gamma)}{1-\cos^2\delta_v}$$
$$R_4^I=\frac{2i(1-\cos\gamma)}{x+\sigma^-}-\frac{2i(\sigma^+-\cos\delta_v)(1+\cos\gamma)}{1-\cos^2\delta_v}$$

## 3. 验证方法与预期结果概述

**解析验证方法**：本组件用两种方式做解析层面的核查——(1) 论文Eq(A9)-
(A12)的封闭解直接代码化，是解析表达式本身；(2) 更强的解析验证是
BUG-002被发现后采用的方法：用论文Eq(16)给出的极点显式公式，通过
**代数消元**（$z_1(x)=z_4(x)$，$\sqrt{1-x^2}$项两边正好约掉退化为
无分支歧义的线性方程）严格推导出 $\sigma^\pm$ 应该取的分支符号，
这是不依赖任何数值测试、纯代数求解的证明方式（详见第3.3节）。

**数值验证方法**：用完全独立的3D笛卡尔矢量构造的数值围道积分黄金
标准，与论文封闭解代入具体数值比对，大样本覆盖 $v_y$ 正负、
$\delta_u,\delta_v$ 是否超过 $\pi/2$ 的全部构型情形。

**预期结果**：解析推导得到的分支选择公式应与数值围道积分精确吻合
（预期$10^{-14}\sim10^{-17}$级别，因为代数消元的解本身无分支歧义）；
修复后大样本数值验证应在数值积分精度内一致（预期$10^{-12}\sim
10^{-14}$级别）。**重要教训**：修复前的抽样偏差（只测$v_y>0$）导致
约50%的失败率被完全掩盖，这是本节内容的核心价值所在——不仅要验证
"通过率"，还要审视"测试样本本身是否有系统性偏差"。

## 4. ⚠️ 重大问题记录与修正：BUG-002（sigma^± 分支选择错误）

### 4.1 问题是如何被发现的

在推进阶段3 GbLI组件时，用Eq(35)组装公式计算 $\Gamma_{\rm two}$，与最原始
响应函数直接积分定义严重不吻合。逐层排查后发现：通用框架 `I1_I_general`
（供 $I_2,I_3,I_4$ 矢量替换调用）在某些坐标旋转后的构型下，与
`scipy.dblquad` 高精度直接积分给出的真值完全对不上（虚部相差数倍，非
简单的 $2\pi$ 整数倍误差）。追溯到本组件的 `sigma_pm()` 函数。

### 4.2 问题的本质：抽样偏差制造的虚假验证通过

**此前版本的数值验证脚本存在一个致命缺陷**：验证代码里显式写了
`if v_hat[1] <= 0: continue`，只测试 $v_y>0$ 的随机构型，并在状态说明里
声称"限定v_y>0，与论文推导前提一致"——但重新核对论文正文（Eq(13)下方）
发现**这个"前提"根本不存在**：

> "changing the value of $v_y$ here to $-v_y$ will still keep their
> angles constant... subsequent calculations prove that the same
> result will be obtained regardless of whether the $v_y$ is positive
> or negative. In other words, the result of $I_1$ depends only on
> $\alpha,\gamma,\delta_u,\delta_v$."

也就是说论文自己明确声称最终 $I_1$（而非中间的$R_1,R_2,R_3,R_4$）应与
$v_y$ 符号无关，并未限定必须 $v_y>0$。用同样风格但补上 $v_y<0$ 分支重新
测试（20个新随机种子），发现**只有约50%匹配**——这证明此前"8/8通过、
误差~1e-10"的结论存在抽样偏差：随机种子恰好只采样到了 $v_y>0$ 的构型，
$v_y<0$ 的失败情形从未被真正测试到过。

**这是本项目第三次出现"抽样/转录偏差制造虚假验证通过"的教训**（前两次：
手征主线BUG-001论文印刷错误、本副本项目Hellings-Downs系数二次转录错误）。

### 4.3 纯符号/解析方式定位并证明问题根源

不满足于"重新跑随机测试发现失败率50%"这种统计层面的诊断，而是从论文
Eq(16)给出的四个极点精确解析公式出发，用**代数消元**的方式严格证明：

$$z_1=\frac{-(1+u_z)(1+x)}{u_x\sqrt{1-x^2}},\quad
z_2=\frac{-(1-u_z)(1-x)}{u_x\sqrt{1-x^2}}$$
$$z_3=\frac{-(1+v_z)(1+x)}{(v_x-iv_y)\sqrt{1-x^2}},\quad
z_4=\frac{-(1-v_z)(1-x)}{(v_x-iv_y)\sqrt{1-x^2}}$$

$\sigma^\pm$ 的物理含义是"$u$-极点轨迹与$v$-极点轨迹在实轴 $x$ 上重合的
位置"。逐一检验四种配对方程 $z_1{=}z_3,z_1{=}z_4,z_2{=}z_3,z_2{=}z_4$：

- $z_1=z_3$、$z_2=z_4$：**无解**（这两种配对在物理上不存在）
- $z_1=z_4$、$z_2=z_3$：**唯一存在的两组解**，关键是这两个方程里
  $\sqrt{1-x^2}$ 项两边正好约掉，退化成关于 $x$ 的**线性方程**，
  可以直接解析求根，**不需要开根号，因此这个解本身没有任何分支歧义**。

解出的精确解析公式（记为 $P_{14}$，对应 $R_1,R_4$ 真实极点位置）：

$$P_{14}=-\frac{\cos\delta_u+\cos\delta_v-i\cdot\mathrm{sign}(v_y)\sqrt{\mathrm{disc}}}{1+\cos\gamma}$$

其中 $\mathrm{disc}=\sin^2\gamma-\cos^2\delta_u-\cos^2\delta_v+2\cos\gamma\cos\delta_u\cos\delta_v$。

用6组随机有理数参数把 $P_{14}$ 与上述公式逐位比对，**精确吻合到
$10^{-14}\sim10^{-17}$**（机器精度级别的代数恒等验证，非数值近似）：

```
du=1.4214 dv=1.7114 psi=5.804: v_y=-0.457  |diff|=5.03e-17  match=True
du=1.4573 dv=1.5712 psi=3.6888: v_y=-0.520  |diff|=1.18e-15  match=True
du=0.6986 dv=1.5822 psi=3.9557: v_y=-0.727  |diff|=1.11e-16  match=True
du=2.341 dv=0.4541 psi=1.9054: v_y=+0.414  |diff|=3.14e-16  match=True
du=0.4448 dv=2.386 psi=4.3548: v_y=-0.642  |diff|=2.48e-16  match=True
du=0.3131 dv=2.8519 psi=6.0587: v_y=-0.064  |diff|=3.87e-14  match=True
```

**结论：`sigma_pm()` 原实现固定取 $\sqrt{\mathrm{disc}}$ 主分支，遗漏了
必须绑定 $\mathrm{sign}(v_y)$（论文标准计算系约定下）这个分支选择条件。**

完整推导脚本见同组件 `推导/01_sigma_pm分支选择的符号推导证明_BUG002.py`。

### 4.4 交叉判据：论文正文声称的物理不变性独立验证

论文正文声称 $I_1$ 最终结果与 $v_y$ 符号无关。用最原始定义
（`scipy.dblquad`，完全不涉及留数/sigma公式）独立验证这一声称，5组随机
参数误差 $\sim10^{-15}\sim10^{-16}$（机器精度）：

```
trial0: alpha=1.280 du=0.571 dv=2.634 v_y=+0.182  |diff|=3.89e-16
trial2: alpha=2.062 du=2.844 dv=2.396 v_y=+0.673  |diff|=1.28e-15
trial3: alpha=0.944 du=0.314 dv=2.310 v_y=+0.153  |diff|=0.00e+00
trial4: alpha=0.847 du=1.875 dv=2.703 v_y=+0.362  |diff|=2.22e-16
```

这个结果保证了修复方案的正确性：引入 $\mathrm{chirality\_sign}=
\mathrm{sign}(v_y)$ 只会让 $R_1,R_2,R_3,R_4$ 各自内部的"角色分配"正确
（哪个留数对应哪个真实极点），**四者相加后的总和 $I_1$ 必然还是同一个
值**，不会破坏论文本身声称的这条物理不变性——这与"直接用符号推导得到的
$P_{14}$ 精确吻合"共同构成了双重独立证据链。

见同组件 `推导/02_验证论文正文声称的vy不变性.py`。

### 4.5 修复方案

`sigma_pm(du, dv, gamma)` 改为 `sigma_pm(du, dv, gamma, chirality_sign=1.0)`：

$$\sigma^\pm=\frac{1}{1+\cos\gamma}\left(\cos\delta_u+\cos\delta_v\pm i\cdot\mathrm{chirality\_sign}\cdot\sqrt{\mathrm{disc}}\right)$$

所有下游调用处（`all_R_integrals_I`, `I1_I_full`）在标准计算系
（$\hat u=(u_x,0,u_z),u_x>0$）下，显式传入
`chirality_sign = 1.0 if v_hat[1] >= 0 else -1.0`。

已修复文件：
- `阶段1/组件D/具体计算/01_组装I2I3I4强度版.py`（核心函数库）
- `阶段1/组件D/数值验证/01_网格积分交叉验证GammaOneI组装公式.py`（独立复制版）

**说明（重要）**：组件C（`阶段1/组件C/具体计算/01_直接使用论文Eq18的
I1完整封闭解.py`）给出的 $I_1$ 封闭解**天然不受此bug影响**，因为
$\sigma^+,\sigma^-$ 在Eq(18)的term5,term6两项中以完全对称的方式出现
（互换 $\sigma^+\leftrightarrow\sigma^-$ 等价于互换term5,term6，总和不变）。
用sympy+数值双重验证：chirality_sign取$+1$或$-1$，Eq(18)给出完全相同的
$I_1$（误差 $\sim10^{-16}$ 机器精度），因此**组件C此前"1e-7~1e-8误差全部
通过"的结论依然完全可靠，不需要修正**。这也解释了为什么这个bug长期潜伏
在组件D（把R1-R4拆开、分别配不同积分区间的地方）而没有污染组件C。

## 6. 解析表达式（LaTeX，修复后的完整公式）

$$\sigma^+=\frac{i\cdot\mathrm{sign}(v_y)\sqrt{\sin^2\gamma-\cos^2\delta_u+2\cos\delta_u\cos\delta_v\cos\gamma-\cos^2\delta_v}+\cos\delta_u+\cos\delta_v}{\cos\gamma+1}$$

$$R_1^I(x)=-\frac{2i(1-\cos\gamma)}{x+\sigma^-}+\frac{2i\left(-\cos\delta_u+\sigma^+\right)(1+\cos\gamma)}{1-\cos^2\delta_u}$$

$$R_2^I(x)=\frac{2i(1-\cos\gamma)}{x+\sigma^+}-\frac{2i\left(-\cos\delta_u+\sigma^-\right)(1+\cos\gamma)}{1-\cos^2\delta_u}$$

$$R_3^I(x)=-\frac{2i(1-\cos\gamma)}{x+\sigma^+}+\frac{2i\left(-\cos\delta_v+\sigma^-\right)(1+\cos\gamma)}{1-\cos^2\delta_v}$$

$$R_4^I(x)=\frac{2i(1-\cos\gamma)}{x+\sigma^-}-\frac{2i\left(-\cos\delta_v+\sigma^+\right)(1+\cos\gamma)}{1-\cos^2\delta_v}$$

（结构与此前完全一样，唯一区别是 $\sigma^\pm$ 内部 $\sqrt{\mathrm{disc}}$
的符号现在显式绑定 $\mathrm{sign}(v_y)$）

极点公式（论文Eq16，符号推导的出发点）：

$$z_1=\frac{\left(x + 1\right) \left(- \cos{\left(\delta_{u} \right)} - 1\right)}{\sqrt{1 - x^{2}} \sin{\left(\delta_{u} \right)}}$$
$$z_2=\frac{\left(1 - x\right) \left(\cos{\left(\delta_{u} \right)} - 1\right)}{\sqrt{1 - x^{2}} \sin{\left(\delta_{u} \right)}}$$
$$z_3=\frac{\left(x + 1\right) \left(- \cos{\left(\delta_{v} \right)} - 1\right)}{\sqrt{1 - x^{2}} \left(- i \sin{\left(\delta_{v} \right)} \sin{\left(\psi \right)} + \sin{\left(\delta_{v} \right)} \cos{\left(\psi \right)}\right)}$$
$$z_4=\frac{\left(1 - x\right) \left(\cos{\left(\delta_{v} \right)} - 1\right)}{\sqrt{1 - x^{2}} \left(- i \sin{\left(\delta_{v} \right)} \sin{\left(\psi \right)} + \sin{\left(\delta_{v} \right)} \cos{\left(\psi \right)}\right)}$$
