# 组件B：I1积分的留数分量（强度版）—— 说明

## 目标
计算强度核 xi_I 在5个极点 z0,z1,z2,z3,z4 处的留数 R0^I, R1^I, R2^I, R3^I, R4^I。

方法完全比照主线组件B（手征版）的做法：
坐标系构造 → 逐个内积在极点处化简 → 组装e+/e×分量 → 组装numerator_I(zk) → 留数公式。

## 与主线手征版的关键差异
只是把 xi_V (反对称) 换回 xi_I (对称)，坐标系、极点公式、化简技巧完全复用主线
组件A已经验证过的基础设施。**预计比手征版更容易，因为不需要处理反对称核带来的
额外复杂性**（比如z0在手征版是三阶极点，强度版大概率仍是一阶或较低阶极点，需要验证）。
