# 组件D：I2, I3, I4（矢量替换导出，强度版）—— 结论与推导过程

## 1. 要解决什么问题

用PRD论文Eq(21)-(23)的矢量替换规则从组件C的 $I_1^I$ 导出 $I_2^I,I_3^I,I_4^I$，
并组装出完整的 $\Gamma_{\rm one}^I$，与手征主线同步复用/验证坐标系旋转
的实现（`build_computational_frame`）。

## 2. 推导过程与发现的bug

### 2.1 矢量替换规则的实现

与手征主线组件D完全对应，只是内部调用组件C的强度版 $I_1^I$ 而非手征版。

### 2.2 与手征主线同源的组装公式bug（在本副本独立复现，交叉印证）

初版把 $\Gamma_{\rm one}^I$ 组装成
$\frac{1}{32\pi}[I_1-e^{-i\beta_u}I_2-e^{i\beta_v}I_3+e^{i(\beta_v-\beta_u)}I_4]$，
用"单次网格积分"（把I1+I2+I3+I4合并成一个被积函数直接积分一次）交叉验证
时发现不对，排查后确认正确形式应为**简单相加**
$\frac{1}{32\pi}[I_1+I_2+I_3+I_4]$（因为 $I_2,I_3,I_4$ 定义本身已包含
相位因子）。这个bug与手征主线组件B（阶段2）发现的是**同一处根源**，
在两个项目里独立复现并确认，进一步佐证了这个修正是正确的。

### 2.3 ⚠️ BUG-002：sigma_pm分支选择错误对本组件的连带影响与修复

本组件的 `I1_I_full`（进而 `I1_I_general`, `I2_I`, `I3_I`, `I4_I`,
`Gamma_one_I`）全部依赖组件B(R1234)的 `all_R_integrals_I` / `sigma_pm`。
BUG-002的完整发现过程和符号推导证明详见
`../组件B_I1积分的留数分量/R1234/结论与推导过程.md` 第3节，此处只记录
本组件受到的连带影响与验证结果。

**受影响的具体位置**：`I1_I_full` 中 `all_R_integrals_I(alpha, du, dv,
gamma)` 调用未传入手性参数，固定使用 $\sqrt{\mathrm{disc}}$ 主分支。当
`I1_I_general` 内部通过 `build_computational_frame` 把任意朝向的
$(\hat s,\hat u,\hat v)$ 旋转到标准计算系后，得到的 `v_rot[1]`（即
$v_y$）符号是**不可控的**（随原始朝向随机变化），因此在约一半的调用中
会触发BUG-002，导致 $I_1$（进而 $I_2,I_3,I_4,\Gamma_{\rm one}$）出现
数量级错误甚至发散的结果。这正是阶段3排查GbLI的 $\Gamma_{\rm two}$
问题时，反复卡住数日的根本原因——因为矢量替换构造的中间坐标系
$\hat s_2,\hat s_3,\hat s_4$ 朝向本身是"合成"出来的，其手性无法提前
预知，必须让代码自动判断并修正。

**修复**：`I1_I_full` 内部改为
`chirality_sign = 1.0 if v_hat[1] >= 0 else -1.0`，显式传给
`all_R_integrals_I`。已同步修复"数值验证"文件夹内的独立复制版本。

## 3. 验证方法与预期结果

**解析验证方法**：矢量替换规则（Eq21-23）本身是论文给出的解析恒等式，
本组件直接实现代码化；组装公式的正确形式（简单相加而非再乘$e^{\pm
i\beta}$）是通过审视$I_2,I_3,I_4$定义本身已含相位因子这一解析结构
得出的结论，不是数值试凑出来的。

**数值验证方法**：(1) 组装公式：用"单次网格积分"（矢量化，把
$I_1+I_2+I_3+I_4$合并成一个被积函数直接积分一次）与公式组装结果交叉
比对；(2) BUG-002修复后：用`scipy.dblquad`原始定义直接积分对
$I_1$通用坐标系框架和任意朝向做大样本回归验证。

**预期结果**：(1)应在网格积分离散化精度内一致（预期$\sim10^{-6}$
量级）；(2)应在数值积分精度内一致（预期$\sim10^{-9}\sim10^{-11}$
量级）。

## 5. 解析表达式（LaTeX）

修正后的正确组装公式：
$$\Gamma_{\rm one}^I(\alpha,\beta_u,\beta_v,\hat s,\hat u,\hat v)=\frac{1}{32\pi}\Big[I_1^I(\alpha,\hat s,\hat u,\hat v)+I_2^I(\alpha,\beta_u,\hat s,\hat u,\hat v)+I_3^I(\alpha,\beta_v,\hat s,\hat u,\hat v)+I_4^I(\alpha,\beta_u,\beta_v,\hat s,\hat u,\hat v)\Big]$$

矢量替换关系（与手征版完全相同，因为这一步不涉及$\xi_I$还是$\xi_V$）：
$$\alpha_2\hat s_2=\alpha\hat s+\beta_u\hat u,\quad\alpha_3\hat s_3=\alpha\hat s-\beta_v\hat v,\quad\alpha_4\hat s_4=\alpha\hat s+\beta_u\hat u-\beta_v\hat v$$
