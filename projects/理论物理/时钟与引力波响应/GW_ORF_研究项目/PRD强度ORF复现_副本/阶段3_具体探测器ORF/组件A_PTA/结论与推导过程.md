# 组件A：PTA脉冲星对ORF —— 结论与推导过程

## 1. 要解决什么问题

利用PRD论文Eq(6)/(30)，计算任意一对脉冲星间的强度ORF $\Gamma_{\rm PTA}(f)$，
这是阶段3"具体探测器ORF"的第一个、也是最简单的探测器类型。

## 2. 推导过程：为什么不套用阶段1/2已验证的通用框架

### 2.1 诊断：PTA构型触发真实的坐标奇异性

PRD论文Eq(26)把PTA表达为通用 $\Gamma_{\rm one}$ 框架的特殊情形（$\alpha=0$），
其中第二项 $I_1(\beta_u,\hat u,\hat u,\hat v)$ 的"合成方向" $\hat s_2$ **恰好
等于** $\hat u$ 本身——这意味着 $\delta_u'=\angle(\hat u,\hat s_2)=0$。
而组件C/D验证过的 $R_1^I,R_2^I$ 含有 $1/(1-\cos^2\delta_u')$ 这样的因子，
$\delta_u'\to0$ 时分母趋于0。

用组件D的 `I1_I_general()` 函数做逼近实验（`推导/01...`）：

```
eps=0.5:  delta_u'=0.4636rad  I1 = -4.68-59.79j
eps=0.1:  delta_u'=0.0997rad  I1 = -4.77-339.85j
eps=0.01: delta_u'=0.0100rad  I1 = 91.05-3400.44j
s_hat=u_hat 精确代入:          I1 = nan+nanj
```
数值随 $\delta_u'\to0$ 发散，确认这是**真实的坐标奇异性**（论文用"计算坐标系"
约定，在这个特殊角度选择参考轴，必然导致球坐标基矢量退化，与直角坐标系
在两极的坐标奇异同源），不是代码bug。论文正文也因此专门推导了独立的
Eq(28)封闭解来绕开这个构型。

### 2.2 策略选择：直接定义式数值积分，而非逐项转录Eq(28)

Eq(28)项数众多、排版横跨两栏，转录风险很高——本项目已经两次在类似的
复杂公式转录上栽跟头（手征主线BUG-001、本副本项目Hellings-Downs系数
错误），转录得再准确也不会比"直接数值积分定义式"更有说服力。

采用PRD论文Eq(6)/(30)最原始的响应函数定义，直接对天球方向数值积分：
$$R_{\rm PTA}^A(f,\hat n)=\frac12e^A_{ab}(\hat n)u^au^bT_{\rm one}(\beta,\hat n\cdot\hat u)$$
$$T_{\rm one}(\beta,\hat n\cdot\hat u)=\frac{1-e^{-i\beta(1+\hat n\cdot\hat u)}}{1+\hat n\cdot\hat u}$$
$$\Gamma_{\rm PTA}(f)=\frac{1}{8\pi}\int d^2\Omega_{\hat n}\sum_AR_{{\rm PTA},I}^A(f,\hat n)R_{{\rm PTA},J}^{A*}(f,\hat n)$$

## 3. 验证方法与预期结果

**解析验证方法**：本组件最重要的解析论证是"诊断坐标奇异性"本身——
通过检验 $I_1^I$ 含有的 $1/(1-\cos^2\delta_u')$ 因子在 $\delta_u'\to0$
时是否发散（这是纯代数层面可预判的行为，不需要跑数值也能推断），据此
预判通用框架在此特殊构型会失效，进而选择绕开该框架、改用最原始定义
直接积分的策略——这是"先解析论证问题所在，再决定验证/计算路径"的
方法论体现。

**数值验证方法**：用两种完全独立的数值积分实现（网格积分vs
`scipy.dblquad`）交叉核对同一个最原始定义式的计算结果。

**预期结果**：(1) 逼近实验应观察到 $I_1$ 随 $\delta_u'\to0$ 发散（
确认坐标奇异性为真实现象）；(2) 两种独立数值积分方法应彼此一致
（预期$\sim10^{-5}\sim10^{-7}$量级，此精度由数值积分方法本身决定）；
(3) 大$\beta$极限下 $\Gamma_{\rm PTA}$ **不应该**简单趋近Hellings-Downs
曲线（这是先给出物理论证——脉冲星项修正不会随单个$\beta$增大而消失，
需要对大量随机脉冲星距离统计平均才会趋近HD曲线——再用数值验证这个
预期是否成立，属于"预测优先于观测"的检验方式）。

### 4.2 物理观察：大 $\beta$ 极限不会简单趋近Hellings-Downs曲线（如实记录）

```
Gamma_HD(gamma=1.5208) = -0.149162
beta~50:  Gamma_PTA = -0.049835+0.000356j
beta~100: Gamma_PTA = -0.049414-0.000142j
```
两者不趋于一致，这符合物理预期：完整 $\Gamma_{\rm PTA}$ 包含随
$\beta_u,\beta_v$ 振荡的"脉冲星项"修正（$e^{-2i\beta_u}$等相位因子），
对固定的 $\beta_u,\beta_v$ 不会消失；Hellings-Downs曲线对应的是"只保留
地球项"（$\kappa_{IJ}(\hat n)\approx1$）的近似，只有对大量随机脉冲星
距离统计平均后脉冲星项才会抵消、显现出HD曲线。这不是本组件的错误。

## 5. 解析表达式（LaTeX）
