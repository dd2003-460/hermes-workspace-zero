## 一句话总结这次修正

PRD论文 Eq(A6) 里 $\hat\theta\cdot\hat v,\hat n\cdot\hat v$ 两个公式的 $v_y$
项符号印刷有误（应为 $-i$，误印为 $+i$）。上一轮工作误信这处印刷错误，
反而错误地"修正"了本身正确的极点公式 $z_3,z_4$（论文Eq.16/A7），造成
两个错误互相抵消、产生虚假的"验证通过"。本轮工作通过独立的三层验证
（符号级恒等式证明、3D笛卡尔矢量数值抽样、以及用论文自己发表的R1-R4
封闭解做判决性检验）彻底钉死了问题所在，并借此机会发现了一个更强的
科学结果：手征留数与强度留数在全部4个一阶极点处都严格成正比
（$R_k^V=\pm iR_k^I$），完全解决了此前"R3V,R4V无法获得符号解"的困境。
