# 组件A：基础设施（坐标系与被积核）—— 结论与推导过程

## 1. 要解决什么问题

在"计算坐标系"下（分离矢量 $\hat s$ 沿 $z$ 轴，链路方向 $\hat u=(u_x,0,u_z)$ 锁定在
$x$-$z$ 平面，$\hat v=(v_x,v_y,v_z)$ 为一般方向），把球坐标切向基矢量
$\hat\theta,\hat\phi$ 与 $\hat u,\hat v,\hat n$ 的六个内积，用复变量代换
$x=\cos\theta,\ z=e^{i\phi}$ 写成显式的 $(x,z)$ 代数表达式。这是把球面积分
转成复围道积分、进而用留数定理求解的地基。同时构造强度对称核 $\xi_I$
（供 `PRD强度ORF复现_副本` 使用）与手征反对称核 $\xi_V$（本项目核心对象）。

## 2. 推导过程

### 2.1 六个基础内积（对应 PRD 论文 Eq.(A3)→Eq.(A6) 的变量代换）

标准球坐标基矢量定义（与论文无关，教科书公式）：
$$\hat n=(\sin\theta\cos\phi,\sin\theta\sin\phi,\cos\theta),\quad
\hat\theta=(\cos\theta\cos\phi,\cos\theta\sin\phi,-\sin\theta),\quad
\hat\phi=(-\sin\phi,\cos\phi,0)$$

用欧拉公式 $\cos\phi=\frac{z^2+1}{2z},\ \sin\phi=\frac{-i(z^2-1)}{2z}$ 代换，
结合 $\hat u=(u_x,0,u_z)$ 的规范选择，得到（脚本
`推导/01_坐标变换公式_PRD附录A复现.py`）：

$$\hat\theta\cdot\hat u=\frac{u_xx(z^2+1)}{2z}-u_z\sqrt{1-x^2}$$
$$\hat\phi\cdot\hat u=\frac{iu_x(z^2-1)}{2z}$$
$$\hat\theta\cdot\hat v=\frac{v_xx(z^2+1)}{2z}-\frac{iv_yx(z^2-1)}{2z}-v_z\sqrt{1-x^2}$$
$$\hat\phi\cdot\hat v=\frac{iv_x(z^2-1)}{2z}+\frac{v_y(z^2+1)}{2z}$$
$$\hat n\cdot\hat u=\frac{u_x\sqrt{1-x^2}(z^2+1)}{2z}+u_zx$$
$$\hat n\cdot\hat v=v_zx+\frac{\sqrt{1-x^2}\left(v_x(z^2+1)-iv_y(z^2-1)\right)}{2z}$$

**⚠️ 这里 $\hat\theta\cdot\hat v,\hat n\cdot\hat v$ 的 $v_y$ 项符号是 $-i$**，
与 PRD 论文 Eq.(A6) 原文打印的 $+i$ 不同——这正是 **BUG-001** 的修正点，
详见 `00_总览与汇报/重大问题修正记录/`。$\hat\theta\cdot\hat u,\hat\phi\cdot\hat u,
\hat n\cdot\hat u,\hat\phi\cdot\hat v$ 四个不含 $v_y$ 疑点的公式与论文完全一致。

### 2.2 对称核 $\xi_I$ 与反对称核 $\xi_V$ 的构造

利用 $e^+_{ab}u^au^b=(\hat\theta\cdot\hat u)^2-(\hat\phi\cdot\hat u)^2$、
$e^\times_{ab}u^au^b=2(\hat\theta\cdot\hat u)(\hat\phi\cdot\hat u)$（$v$ 同理），
构造两个核的分子（脚本 `推导/02_构造对称核xiI与反对称核xiV.py`）：

$$\text{numerator}_I=e^+_{uu}e^+_{vv}+e^\times_{uu}e^\times_{vv}\quad(\text{对称组装，强度})$$
$$\text{numerator}_V=e^+_{uu}e^\times_{vv}-e^\times_{uu}e^+_{vv}\quad(\text{反对称组装，手征})$$

## 3. 验证方法与预期结果概述

**解析验证方法**：$\xi_V$ 的反对称组装结构（$e^+_{uu}e^\times_{vv}-
e^\times_{uu}e^+_{vv}$）关于交换 $(\hat u,\hat v)\to(\hat v,\hat u)$
天然反号（$e^+_{uu}e^\times_{vv}-e^\times_{uu}e^+_{vv}\to e^+_{vv}
e^\times_{uu}-e^\times_{vv}e^+_{uu}=-(\text{原式})$），这是纯代数结构
上可以直接论证的性质，用作独立于数值计算的解析自洽性检验（见3.3节）。
另外，BUG-001涉及的 $v_y$ 项符号（$\pm i$）也是通过与论文原文逐字核对
再辅以数值交叉验证共同确认的。

**数值验证方法**：(1) 六个基础内积公式：用3D笛卡尔矢量点积直接构造
（不经过$(x,z)$复变量代换）作为黄金标准；(2) 极点公式：用修正后的
$\hat n\cdot\hat v$ 公式重新推导论文给出的 $z_3,z_4$ 极点表达式是否
仍然满足"$1+\hat n\cdot\hat v=0$"这一定义方程；(3) $\xi_V$ 反对称性：
用大量随机 $\hat n$ 方向直接代入数值计算两种参数顺序下的 $\xi_V$ 值。

**预期结果**：(1)(2) 应在机器精度内吻合（$\sim10^{-15}\sim10^{-16}$）；
(3) 应严格相差一个负号（数值误差应恰好为0，这是代数恒等式而非近似）。

### 4.2 极点公式的验证（脚本 `数值验证/01_验证极点公式_符号错误修正记录.py`）

最大残差 = 4.72e-15 (机器精度量级)

### 3.3 $\xi_V$ 关于 $(u,v)$ 交换的反对称性（脚本 `数值验证/02...`）

$$\xi_V(\hat n;\hat u,\hat v)=-\xi_V(\hat n;\hat v,\hat u)$$
20组随机 $\hat n$ 方向验证，误差**恰好为0**（严格代数恒等式，非近似）。

## 5. 解析表达式（LaTeX，供核对）

以下直接摘自脚本运行时 `sp.latex()` 的输出（运行 `推导/01_坐标变换公式_PRD附录A复现.py`
可重新生成，本文档贴的是最新一次运行的真实输出）：

$$\hat\theta\cdot\hat u = \frac{u_{x} x \left(z^{2} + 1\right)}{2 z} - u_{z} \sqrt{1 - x^{2}}$$

$$\hat\phi\cdot\hat u = \frac{i u_{x} \left(z^{2} - 1\right)}{2 z}$$

$$\hat\theta\cdot\hat v = \frac{v_{x} x \left(z^{2} + 1\right)}{2 z} - \frac{i v_{y} x \left(z^{2} - 1\right)}{2 z} - v_{z} \sqrt{1 - x^{2}}$$

$$\hat\phi\cdot\hat v = \frac{i v_{x} \left(z^{2} - 1\right)}{2 z} + \frac{v_{y} \left(z^{2} + 1\right)}{2 z}$$

$$\hat n\cdot\hat u = \frac{u_{x} \sqrt{1 - x^{2}} \left(z^{2} + 1\right)}{2 z} + u_{z} x$$

$$\hat n\cdot\hat v = v_{z} x + \frac{\sqrt{1 - x^{2}} \left(v_{x} \left(z^{2} + 1\right) - i v_{y} \left(z^{2} - 1\right)\right)}{2 z}$$
