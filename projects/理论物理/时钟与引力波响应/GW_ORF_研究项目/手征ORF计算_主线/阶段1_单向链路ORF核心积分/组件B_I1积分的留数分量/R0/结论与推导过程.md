# R0（原点极点 $z_0=0$）—— 结论与推导过程

## 1. 要解决什么问题

求手征被积核 $f_V(z)=\dfrac{\text{numerator}_V(z)}{iz(1+\hat n\cdot\hat u)(1+\hat n\cdot\hat v)}$
在 $z=0$ 处的留数 $R_0^V(x)=\text{Res}_{z=0}f_V(z)$。

## 2. 推导过程

### 2.1 意外发现：极点阶数判断需要小心（曾因BUG-001导致误判）

直接检验 $\lim_{z\to0}z^nf_V(z)$（脚本 `推导/01_发现z0是三阶极点而非简单极点.py`）：
- 用**修正后**（$-i$符号）的公式：$n=1$ 发散，$n=2$ **有限非零**，$n=3$ 为 $0$
  $\Rightarrow$ **二阶极点**
- 用错误的 $+i$ 符号（BUG-001修正前）：会得到三阶极点的假象——因为错误
  公式给分子多引入了一阶不该有的修正项，人为把极点阶数从2推高到3

用二阶极点公式 $R_0^V=\lim_{z\to0}\frac{d}{dz}[z^2f_V(z)]$（多项式除法实现，
规避了 `sp.limit` 对高幂次有理函数的数值不稳定问题）与 `sympy.residue()`
交叉验证：
```
sympy.residue()          = -1.6899174254561284-2.968186246001011j
二阶极点公式(多项式除法)  = -1.6899174254561278-2.9681862460010096j
两者差 = 1.49e-15  (应为0)
```

### 2.2 用 `sympy.residue()` 直接求解（脚本 `具体计算/01...`）

因为 `sympy.residue()` 本身能自动处理任意阶极点（内部做洛朗级数展开），
不需要用户预判阶数，直接调用即可：
- 数值代入版：0.27秒完成
- 符号版（保留全部几何参数 $u_x,u_z,v_x,v_y,v_z,x$）：2秒左右完成，
  得到含约209项（`sp.cancel()`通分后）的有理表达式

**关于因式分解的技术备注**：`sp.factor()` 在此规模的表达式上性能极差
（实测超过90秒未完成），改用 `sp.cancel()`（0.36秒），虽不如factor简洁但
可靠、可复现，是本组件的既定做法。

## 3. 验证方法与预期结果

**解析验证方法**：(1) 用`sympy.residue()`直接对洛朗级数展开求留数（自动
处理任意阶极点，不依赖人工预判阶数），与人工推导的二阶极点公式
$R_0^V=\lim_{z\to0}\frac{d}{dz}[z^2f_V(z)]$（多项式除法实现）独立对照，
两条完全不同的符号计算路径应给出相同的解析结果；(2) 极点阶数本身通过
检验 $\lim_{z\to0}z^nf_V(z)$ 在 $n=1,2,3$ 时是否发散/有限非零/为零来
确定，这是从留数理论定义直接导出的判据，不依赖任何数值积分。

**数值验证方法**：用完全独立于本组件符号推导路径的**3D笛卡尔矢量点积 +
数值围道积分**（对 $z_0$ 附近做小半径圆周积分数值求和，不使用洛朗级数
或sympy符号工具）计算留数，与符号解比对。

**预期结果**：(1) `sympy.residue()`与人工二阶极点公式应在机器精度内一致
（$\sim10^{-15}$）；(2) 数值围道积分与符号解应在数值积分精度内一致
（$\sim10^{-13}\sim10^{-14}$，非机器精度是因为数值围道积分本身有离散化
误差）；(3) $R_0^V/R_0^I$ 比值预期**不是常数**（与 $R_1\sim R_4$ 一阶
极点的$\pm i$恒等式不同，因为 $z_0$ 是二阶极点，物理机制不同）。

## 4. 关键数值结果

### 4.1 极点阶数判断的解析验证（脚本 `推导/01...`）

用修正后（$-i$符号）公式检验 $\lim_{z\to0}z^nf_V(z)$：$n=1$发散，$n=2$
**有限非零**，$n=3$为$0$ $\Rightarrow$ **二阶极点**（若用错误的$+i$符号，
会得到三阶极点的假象，见2.1节说明）。

### 4.2 两条独立符号计算路径的交叉核对

```

两者差 = 1.49e-15  (应为0，与预期完全相符)
```

### 4.4 负面结果：$R_0^V/R_0^I$ 不是常数（详见组件E）

与 $R_1,R_2,R_3,R_4$（一阶极点）不同，$R_0^V$（二阶极点）**不满足**
$R_k^V=\pm iR_k^I$ 这条核心恒等式。6组随机参数下比值范围
从 $-0.32+0.85j$ 到 $-0.01-1.05j$，明显不是常数，说明这个规律的适用范围
局限于"单一矢量决定的一阶极点"，不能推广到 $z_0$。
