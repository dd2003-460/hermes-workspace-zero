## 1. 要解决的问题

空间引力波探测器（LISA/Taiji/TianQin）由三颗卫星组成，两两之间用
激光链路互联，形成六条单向链路（每对卫星间双向各一条）。由于卫星
间距离远大于允许直接干涉的容差，实际数据处理采用TDI（Time-Delay
Interferometry，延迟时间干涉）技术，把六条单向链路的（含延迟的）
读数进行线性组合，构造出等效的、抵消激光频率噪声的干涉输出通道
（如Michelson型的X, Y, Z通道）。

本组件的目标：仿照组件B（GbLI，地基L型探测器両臂差分）的成功模式，
把TDI-X（或其他通道）的ORF用本项目阶段1-2已经完全验证过的
$\Gamma_{\rm one}/I_1$框架，通过"若干条单向链路响应函数的线性叠加"
表示出来，从而不需要重新推导复杂的天球积分，直接复用现成的、已验证
的核心函数。

## 2. 推导过程与已确认正确的中间结果

### 2.1 一代等臂长TDI-X代数分解（✅ 已验证为精确恒等式）

标准TDI-X定义（等臂长情形，$D=e^{-i\beta}$为单程延迟算子，
$y_{ij}$为从卫星$j$到卫星$i$方向单向链路的Doppler响应数据）：

$$X=(y_{31}-y_{21})+D(y_{13}-y_{12})+D^2(y_{21}-y_{31})+D^3(y_{12}-y_{13})$$

可因式分解为：

$$X=(1-D^2)\left[(y_{31}-y_{21})+D(y_{13}-y_{12})\right]$$

**验证方法**：sympy符号展开，`sp.simplify(sp.expand(lhs-rhs))`，随机
数值代入复核。**真实运行输出**（`推导/01...`本次重新独立运行）：

```
恒等式(1) [TDI-X代数分解] 符号diff = 0
  数值复核（随机y值+随机beta，3组）：
    trial0: |diff|=0.00e+00
    trial1: |diff|=0.00e+00
    trial2: |diff|=0.00e+00
```

严格成立，无异议。

### 2.2 往返链路精确分解（✅ 已验证为精确恒等式）

PRD论文Eq(34)定义的往返（双向）链路响应核函数
$T_{\rm two}(\beta,x)=T_{\rm one}(\beta,-x)-e^{-2i\beta}T_{\rm
one}(-\beta,x)$，可以精确改写为"回程方向($-\hat u$位置，相位系数
$1$) + 去程方向($+\hat u$位置，相位系数$e^{-i\beta}e^{i\beta x}$)"
两项之和：

$$T_{\rm two}(\beta,x)=T_{\rm one}(\beta,-x)\cdot1+e^{-i\beta}\cdot
T_{\rm one}(\beta,x)\cdot e^{i\beta x}$$

**真实运行输出**（`推导/01...`本次重新独立运行）：

```
恒等式(2) [往返链路精确分解] 符号diff = 0
  数值复核（随机beta,x，3组）：
    trial0: beta=1.921 x=0.806  |diff|=0.00e+00
    trial1: beta=0.302 x=-0.747  |diff|=0.00e+00
    trial2: beta=1.704 x=0.425  |diff|=0.00e+00
```

严格成立，无异议。这两条恒等式本身是正确的、可复用的数学结果，
是继续攻关SbLI时**唯一可以放心依赖**的既有产出。

## 3. 被严格证伪的猜想（如实记录，不可复用）

### 3.1 猜想A："$X=(1-D^2)\times\Gamma_{\rm GbLI}$"（组装捷径猜想）

**动机**：既然2.1节的$X$分解出现了$(1-D^2)$整体因子，是否$X$的ORF
可以直接写成$(1-D^2)$相关的标量因子乘以组件B已验证的GbLI两臂差分
ORF（把TDI三星结构近似看成"L型探测器"，两臂夹角60°而非90°，但结构
形式类似）？

**验证方法**：用六条单向链路的精确Doppler响应函数（`T_one`与
极化张量直接实现，而非复用$\Gamma_{\rm one}$框架），对多个随机
天球方向$\hat n$数值构造TDI-X的响应函数值，与$(1-D^2)\times
\Gamma_{\rm GbLI}$方案预测值比对。

**结果（本轮会话中实际运行得到，记录于对话历史）**：多组随机方向下
误差达$O(1)$量级甚至符号相反（如`trial1: X_plus=0.5684-1.4556j
GbLI_plus=-0.5657+1.4558j err=3.12e+00`）。**明确证伪**。

### 3.2 猜想B：往返链路拆分后套用$\Gamma_{\rm one}$框架整体展开

**动机**：既然2.2节给出了往返链路精确拆分为两条"方向确定"的单向
链路项，能否把这个拆分代入TDI-X的四条往返链路结构，整体展开成
$\Gamma_{\rm one}$（或更底层的$I_1$）项的线性组合，像组件B处理
GbLI那样直接调用现成函数？

**结果**：数值误差$10^{-2}\sim10^{-1}$量级，随参数随机波动、不
收敛，说明不是简单的系数错误。排查发现`Gamma_one_I`函数内部已经
通过`I2_I,I3_I,I4_I`打包了"往返/端点耦合"结构（即$\alpha\hat s+
\beta_u\hat u$这样的矢量合成方式），**不是"两条完全独立位置的纯
单向链路"接口**——它假设的是"以某个共同参考点为中心，两条链路各自
有固定的、与观测方向无关的位置偏移"这个特定几何结构，与TDI往返
链路"去程和回程分别对应卫星间实际连线上的不同点、且这些点由链路
方向本身决定"的几何结构不匹配。

### 3.3 猜想C：改用更底层的$I_1^{\rm general}(\alpha,\hat s,\hat u,\hat v)$重新尝试

**动机**：猜想B失败后，尝试绕过`Gamma_one_I`的封装，直接用最底层的
单向链路对ORF核心积分$I_1^{\rm general}$（对应
$-\int\xi_I(\hat n)e^{-i\alpha\hat n\cdot\hat s}d^2\Omega$）重新
构造，希望能更灵活地匹配TDI链路的位置结构。

**结果**：比值仍非常数（500~2500量级不稳定）。说明"用固定分离矢量
$\alpha\hat s$描述两条链路间位置关系"这个框架本身与"链路方向决定
其位置（$r=L\hat u$）"存在更深层的坐标系/相位定义冲突，超出简单
参数换算错误的范围。

### 3.4 猜想D（本轮新增独立验证）：外部文献$\eta_{ij}=y_{ij}+D\cdot
y_{ji}$约定与PRD论文$T_{\rm two}$可直接对应

**动机**：是否可以借用TDI教科书/外部文献（如与Shi & Tang风格类似的
处理，arXiv:2606.28071）中常见的"往返响应=去程+D×回程"约定
$\eta_{ij}=y_{ij}+D\cdot y_{ji}$，把它和PRD论文$T_{\rm two}$直接
换元对应，从而把外部文献的TDI结果代数结构套到PRD框架里？

**验证方法**（本轮`诊断_失败记录/01...`独立重新执行，非carry-over）：
用PRD论文自身的$T_{\rm one}$、$T_{\rm two}$定义（Eq34附近），构造
两种可能的$\eta_{\rm claim}$（正向、交换角色两种），与$T_{\rm two}$
符号相减化简。

**真实运行输出**：

$$T_{\rm two}(\beta,x)=\frac{\left(-xe^{2i\beta}+2xe^{i\beta(x+1)}-
x-e^{2i\beta}+1\right)e^{-2i\beta}}{x^2-1}$$

尝试1的diff（非零，含多个不同频率的三角函数项，是复杂的非平凡
表达式，非可化简为0的形式）：
$$\frac{2(x-1)(\cos\beta-\cos\beta x)\cos\beta+(x+1)(-\cos\beta+
\cos\beta(x-2)-\cos\beta(x-1)+1)-i(\cdots)}{(x-1)(x+1)}$$

尝试2的diff：
$$\frac{-e^{i\beta(x-1)}-e^{-i\beta(x+2)}+e^{-i\beta}+e^{-2i\beta}}
{x+1}$$

数值代入复核（5组随机$\beta,x$）：

```
 trial     beta        x      |diff1|      |diff2|
     0   1.1067  -0.6285   8.4529e-01   7.4906e-01
     1   2.0226  -0.7696   2.8962e+00   2.8145e+00
     2   1.7005  -0.2418   8.1875e-01   6.4707e-01
```

两种约定的diff均为$O(1)$量级（远超数值噪声~$10^{-10}$），**明确
证伪**：外部文献的$y_{ij}$ Fourier约定不能与PRD论文体系直接代数
对应。

**根源判断**：外部文献$y_{ij}$约定隐含的是Fourier域/时域相位参考点

two}$的推导中$x=\hat n\cdot\hat u/\hat v$是天球方向余弦、$\beta$是
链路延迟相位，两者的相位参考点绑定方式不同——不是简单代数替换能对齐
的，说明跨论文体系直接套用响应函数分解公式存在框架层面的相位约定
冲突。

## 4. 卡点性质的综合评估（如实记录）

综合3.1-3.4四次独立失败尝试，可以确认：这**不是**"选错了归一化
常数""搞错了符号"这类可修补的小问题，而是**框架层面的根本性
不匹配**：

- $\Gamma_{\rm one}/I_1$整套框架（阶段1组件A-E、阶段2组件A/B）的
  推导从一开始就假设"两条链路各自独立于观测方向$\hat n$的固定
  位置"（体现在$\alpha\hat s\pm\beta_u\hat u\pm\beta_v\hat v$这种
  矢量合成方式里，$\hat s,\hat u,\hat v$是三个独立自由参数）。这个
  假设对组件B（GbLI，地基L型探测器）完全成立——两个探测器各自的
  顶点位置固定，与臂的方向无关。

- 而SbLI/TDI的往返链路结构中，"链路方向"与"链路位置"是**耦合**的
  （因为链路本身连接两个不同位置的卫星，去程和回程对应链路上不同
  的端点，这个端点位置本身就是由链路方向和长度决定的：$\vec
  r=L\hat u$）。这种耦合关系已经被封装进$T_{\rm two}$/TDI代数
  本身，试图"拆开重新组装成$\Gamma_{\rm one}$能吃的独立参数形式"
  会引入框架不匹配——第2.2节的精确分解虽然数学上完全正确，但拆分
  出来的两项本身仍然带着这种耦合信息，不能直接套进假设"独立位置"
  的$\Gamma_{\rm one}$接口。

- 外部文献的TDI代数约定（猜想D）也不能作为"抄近路"的桥梁，因为
  不同论文体系对相位参考点的选取本身就不同，不是简单换元能对齐的。
