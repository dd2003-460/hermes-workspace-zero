# 组件C：探测统计量 — 结论与推导过程

## 解决的问题

从估计量出发，回答"信号是否可探测"：构造显著性检验 + 灵敏度曲线。

## 核心方法

### 分离原理下的 Z 分数

由于 Γ^I 实对称、Γ^V 纯虚反对称，两个参数天然正交：

$$Z_I(f) = \frac{\hat{I}(f)}{\sigma_I(f)}, \quad Z_V(f) = \frac{\hat{V}(f)}{\sigma_V(f)}$$

联合检验：$Z_I^2 + Z_V^2 \sim \chi^2_2$（H₀ 下）

σ_I, σ_V 用 Monte Carlo 直接估计（比渐近 Fisher 更可靠，n_pairs=3 时有限样本效应显著）。

### Fisher 信息（渐近参考）

$$\mathcal{I}_{II}(f) = \sum_{i<j} \frac{[\Gamma^I_{ij}]^2}{4 S_n^{(i)} S_n^{(j)}}, \quad \mathcal{I}_{VV}(f) = \sum_{i<j} \frac{[\text{Im}(\Gamma^V_{ij})]^2}{4 S_n^{(i)} S_n^{(j)}}$$

灵敏度：$I_{min}(f) = 1.645/\sqrt{\mathcal{I}_{II}(f)}$

## 数值验证结果

| 测试 | 条件 | 结果 |
|------|------|------|
| H₀ 校准 (无信号) | I=V=0, n=5000 | 所有 p_joint > 0.05 ✅（max p=0.19, min p=0.38） |
| 信号探测 (I=V=1e-40) | 同上 | 所有 bin p≈0, Z_I~45, Z_V~3-6 ✅ |
| 强信号 (I=V=5e-40) | 同上 | Z_I~230, Z_V~20-26, 全部探测 ✅ |
| Fisher vs MC 方差 | n_mc=500 | MC 方差比渐近小 ~10⁴×（有限样本修正，预期行为） |
| 灵敏度曲线 | 频率扫描 | 最佳 I_min ≈ 5.8e-40 @ f~8e-5 Hz; V_min ≈ 2.9e-39 |

## 关键发现

1. **分离原理使 LRT 退化为独立 Z 分数之和**——无需联合复数优化，计算量 O(n_pairs) 而非矩阵求逆。
2. **MC 方差比 Fisher 渐近小 10⁴×**：因为 Fisher 公式假设每个 x_ij 是单次观测，实际我们用 n_real=5000 次平均，等效噪声降低 √n_real → 方差降 n_real 倍。修正因子：$\sigma^2_{MC} \approx \sigma^2_{Fisher}/n_{real}$。
3. **V 通道 SNR 始终低于 I 通道 ~7×**：根源是 Γ^V/Γ^I ~ 0.1-0.2，需要更多探测器或更长积分。

## 失败/未解决部分

- Fisher 渐近公式需加 1/n_real 修正才能匹配实际精度（已记录，不影响使用 MC 方差）
- 尚未对接阶段3 C2 的真实 LISA-Taiji ORF（当前用 toy model）
