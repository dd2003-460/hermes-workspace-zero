## 任务来源

导师提出的要求（用户原话摘录，作为任务书）：

> "我需要你根据提供的《整合方案》文档，使用 Python 的 `sympy` 库完成手征 ORF 的解析推导。
> **目标**：求出 $I_1^V$ 的解析表达式。
> **具体步骤**：
> 1. 在 `sympy` 中定义极角 $\theta$、方位角 $\phi$，以及分离向量 $\hat s=(0,0,1)$，光束向量 $\hat u=(u_x,0,u_z)$ 和 $\hat v=(v_x,v_y,v_z)$。
> 2. 严格写出圆偏振基下的反对称分子 $\xi_V(\theta,\phi)\propto e^+_{ab}u^au^b\,e^\times_{cd}v^cv^d - e^\times_{ab}u^au^b\,e^+_{cd}v^cv^d$。
> 3. 进行变量代换 $z=\exp(i\phi)$，提取出被积函数 $f(z)$。
> 4. 代入原 PRD 论文中已知的那 5 个极点 $z_0,\ldots,z_4$，使用 `sympy.series` 或 `sympy.limit` 求出这 5 个极点对应的留数 $R_0^V,\ldots,R_4^V$。
> 5. 打印出这些留数的表达式，并化简，观察是否比原版消去了某些偶次项。"

## 物理背景（回顾《整合方案》文档的核心逻辑）

- **PRD 论文**（Hu, Wang, Tan, Shao, Phys.Rev.D 111, 084065 (2025)）用"单向链路分解 + 复围道积分 + 留数定理"这套精确方法，算出了随机引力波背景强度 ORF（$\Gamma^I$）的解析表达式，不需要传统的短波/小天线近似。
- **JCAP 论文**（Chen, Liu, Zhang, JCAP 05, 050 (2025)）研究手征 ORF（$\Gamma^V$，描述宇宙学中宇称破缺产生的左右旋引力波不对称），但用的是精度受限的"长波近似"。
- **我们的任务**：把 PRD 论文的精确留数方法，套用到 JCAP 论文定义的手征反对称核 $\xi_V$ 上，得到不做任何近似的精确手征 ORF 公式。$I_1^V$ 正是这个精确公式推导链条里最核心、最难的一步。

## 本次计算要交付的东西

严格按任务书的5个步骤，用 sympy：

2. 构造反对称核 $\xi_V$
3. 做复变量代换，得到被积函数 $f(z)$
4. 对5个已知极点分别求留数
5. 观察留数结果是否比强度ORF的情形更简单（比如消去偶次项）
