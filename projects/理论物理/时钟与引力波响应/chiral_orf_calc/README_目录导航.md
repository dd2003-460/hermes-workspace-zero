# 手征 ORF 留数计算 —— 项目目录导航

本项目目标：用 sympy 严格推导手征引力波背景 ORF 的解析表达式，具体是求出
反对称核 $\xi_V$ 在方位角围道积分后对应的5个留数 $R_0^V,\ldots,R_4^V$。

## 按"性质"分类的说明

每个计算量（R0V, R1V, R2V, R3V/R4V）的文件夹下，按脚本性质细分为：

- **推导**：从物理/数学原理出发构造公式结构，或诊断发现新现象（如"z0是三阶极点"）
- **具体计算**：真正跑 sympy 符号运算、得到解析结果的核心脚本
- **数值验证**：用独立的数值方法（通常是围道积分）交叉核对符号计算结果
- **诊断与失败尝试** / **探索性尝试_已弃用**：记录走不通的路径和排错过程，
  保留是为了让后来者（包括未来的你）不用重复踩坑

## 快速上手：如何复现结果

1. 先看 `00_组会汇报与阶段报告/` 里的分阶段报告，了解整体逻辑和结论
2. 如果要复现某个具体计算，进入对应文件夹的"具体计算"子目录，
   按文件名前面的数字顺序运行（例如 02_R1V 下先跑01再跑02再跑03）
3. 每个"数值验证"脚本依赖同级"具体计算"文件夹生成的 `.pkl` 中间结果，
   已经预先复制好，可以独立运行
4. 所有脚本都可以直接 `python3 脚本名.py` 运行，无需额外参数

## 核心结论一句话总结

**成功**：$R_1^V, R_2^V, R_0^V$ 三个留数都严格算出并通过数值交叉验证；
发现 $R_1^V=-i R_1^I$、$R_2^V=+i R_2^I$ 这一精确的解析恒等式（06文件夹）。

**未完全成功**：$R_3^V, R_4^V$ 因 sympy 在多变量高次表达式上的性能瓶颈，
未能得到符号封闭式，但通过纯数值方法确认了"$-i$ 比例关系不能推广到这两个极点"，
并发现了两者严格互为复共轭的新规律。
