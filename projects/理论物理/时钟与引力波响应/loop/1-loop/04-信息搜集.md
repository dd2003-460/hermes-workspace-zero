### 2.3 理论公式一致性验证

**Transfer function** (`olc_transfer_function`)：
- 09 脚本与 01 脚本**完全一致**（同一函数实现）
- 公式：`T = (i * 2pi f L / c) * sinc[pi f L / c * (1 - cos(nu))] * exp[-i * pi f L / c * (1 - cos(nu))]`
- 来源：Lou Eq. 2-30，与 Hu PRD 适配 OLC 一致
- **结论：正确**

**Antenna patterns** (`antenna_patterns`)：
- 09 脚本与 01 脚本**完全一致**
- 公式：`F_plus = (th·u)^2 - (ph·u)^2`，`F_cross = 2(th·u)(ph·u)`
- 对应 `e_+^{ab} u_a u_b` 和 `e_x^{ab} u_a u_b`
- **结论：正确**

**Chiral factor**：
- 09 使用 `F1p * F2x - F1x * F2p`（反对称组合）
- 对应 Kato-Soda (2016) 的 `i(e_+* e_x - e_x* e_+)` 的实部（去掉虚数单位 `i` 的相位约定）
- 在实数基底（`F+, Fx` 均为实数）下，`F1p*F2x - F1x*F2p` 是正确的手征指标
- **结论：正确**

**Normalization**：
- 分母 `sqrt(auto1 * auto2)` 其中 `auto = sum((Fp^2 + Fx^2) * |T|^2 * dO)`
- 与标准 ORF 的归一化方式一致
- **结论：正确**

### 6.2 关键风险点详细分析

**风险点 A：共面构型的 dihedral 参数化**

`arm_directions_3d` 中 `dihedral=0` 产生的构型确实是共面的吗？

- 基本实现：`v = cos(gamma)*u + sin(gamma)*(cos(dh)*n1 + sin(dh)*n2)`
- 当 `dihedral=0`：`v = cos(gamma)*u + sin(gamma)*n1`，其中 `n1 = (uz - (uz·u)*u)/|...|` 是 `u` 与 `z` 轴张成平面内的垂直分量
- 因此 `u` 和 `v` 共面（都在 `u-z` 平面内）
- **结论：`dihedral=0` 确实产生共面构型**

**风险点 B：`compute_orf_chiral` 的实数/复数处理**

- 被积函数 `S = chiral_factor * T1 * conj(T2) * bp` 是复数
- `chiral_factor = F1p*F2x - F1x*F2p` 是实数（天线方向图为实数）
- `T1 * conj(T2)` 是复数（传递函数有相位）
- `bp = exp(-i*alpha*n_s)` 是复数（基线相位因子）
- 结果 `corr` 是复数，返回实部（Python 的 `sum()` 对复数求和后取 `/`）

**潜在问题**：脚本返回 `corr / denom`（复数除法），但测试使用 `np.abs(val)`。理论上 Gamma^V 是实数（手征 ORF 不应该是复数），复数部分来自数值积分的残余相位误差。

**影响**：低 — 复数部分的量级应远小于实部（数值误差），`np.abs(val)` 会捕捉总大小。如果实部接近零而虚部因数值误差显著，测试 3 可能失败。但这是 `compute_orf_chiral` 返回复数的问题，而非物理问题。
