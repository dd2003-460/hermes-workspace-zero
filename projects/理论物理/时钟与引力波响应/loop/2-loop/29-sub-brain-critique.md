## 质疑 1: P4-1 的 bug 清单是否穷尽？

**风险等级**: MEDIUM — 可能遗漏隐藏 bug

P4-1 的目标是修复"已知 bug"。但"已知"是否穷尽？v27 发现了 6 个主要 bug，v28 确认了其中 5 个。但：

- **SNR_single 计算中的数值步骤** (lines 1262-1276): 虽然算术已修正，但每个中间步骤是否使用了正确的约定？
- **N_sat 表的 Ω_GW 依赖** (lines 1417-1428): 表头是否有 Ω_GW=10⁻⁸ 或 Ω_GW=10⁻¹⁰ 的标注？这决定了数值的解释
- **constellation SNR 的归一化** (lines 1417-1428): 双卫星/星座1/星座2/星座3 的相对关系是否使用了正确的 N_sat ∝ Ω_GW⁻² 缩放？
- **(1/16) 因子的正式纳入**: v28 提到"声明 upper bound"而非正式纳入。但这是物理决定，应该明确写在论文的方法论部分

**建议**: P4-1 的任务描述中应包含一份完整的 bug 清单（已确认 + 待发现），在执行过程中发现的任何新 bug 都应记录。

## 质疑 2: P0-2 是否能在单次 Agent 调用中产生有价值的输出？

**风险等级**: HIGH — P3 产出 291 行但 QC FAIL

P3 也是 Agent 任务，产出 291 行但 QC FAIL（缺少 unified formulas）。P0-2（Hu PRD vs 代码对应）如果沿用同样的非结构化 prompt，可能产出类似的模糊对比文档。

**P0-2 必须避免的陷阱**:
1. 不要写 "代码 A 对应公式 B，代码 C 对应公式 D" — 这是 P3 的失败模式
2. **必须**输出具体的文件:行号 + 当前值 + 期望值 + 差距分析
3. **必须**包含 SNR 差距的定量分解：(H₀ 约定差异 → 因子 X)、(gamma 约定差异 → 因子 Y)、(L 值差异 → 因子 Z)

**建议的 Agent prompt 必须包含**:
```
验收标准:
1. 至少列出 8 个具体的代码:行号对应关系
2. 每个对应关系必须包含: 代码片段、Hu PRD 公式编号、正确值、当前值、差距因子
3. 必须输出一个总差距分解表 (所有差距因子的乘积 = 总差距)
4. 必须明确标注哪些差距是"乘性的"、哪些是"加性的"
```

## 质疑 3: P4-1 和 P0-2 的依赖关系是否被忽略？

**风险等级**: MEDIUM — P0-2 可能发现新的 bug，需要 P4-1 扩

P4-1 假设"已知 bug"是可穷尽的。但 P0-2 的 Hu PRD vs 代码分析可能发现**新的**约定不一致（比如遗漏的 (1/16) 因子处理、Ω_GW 的定义差异等）。

**更优策略**: P4-1 应分两轮:
- **P4-1a**: 修复已知 bug（已确认的 5-6 个）
- **P0-2**: 分析 Hu PRD vs 代码
- **P4-1b**: 根据 P0-2 发现修复新 bug

当前 Route 1 将 P4-1 和 P0-2 并行，但如果 P4-1 的修复依赖于 P0-2 的结果（比如 P0-2 发现 gamma_olc 的正确计算方式不是简单的 "0.5"），则 P4-1 可能修复错误。

**建议**: P4-1 的 prompt 应标注"仅修复已确认的 bug，待 P0-2 确认后方可执行未确认的修复"。

## 质疑 4: 为什么没有 P3 re-do？

**风险等级**: MEDIUM — P3 的 QC FAIL 未被解决

当前 Route 1 跳过了 P3 re-do。但 P3（交叉对比）的 QC 失败原因是"缺少 unified formulas"。如果不解决 P3 的 QC FAIL，后续 P4-2（基于理解的修正）和 P4-3（重新编译）可能建立在不一致的基础上。

**建议**: P3 re-do 可以与 P4-1 并行 — 因为 P3 的产出是验证性的，不依赖 P4-1 的修复结果。

## 质疑 5: Route 1 是否加速了收敛？

**风险等级**: HIGH — 收敛速度问题依然存在

## 总结: 三个关键发现

### 发现 A [MEDIUM] — P4-1 需要分两阶段

已确认的 bug 优先修复（P4-1a），P0-2 发现的新 bug 次之修复（P4-1b）。并行执行但有明确的"冻结清单"边界。

### 发现 B [HIGH] — P0-2 的 prompt 必须结构化

P3 的 QC FAIL 证明模糊 prompt 产生模糊产出。P0-2 的 prompt 必须强制输出代码:行号级对应关系和定量差距分解表。

### 发现 C [MEDIUM] — P3 re-do 可以与 P4-1 并行

P3 是验证性任务，不依赖 P4-1 的修复结果。可以并行执行，加速收敛。
