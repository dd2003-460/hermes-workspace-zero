## 研究问题

### RQ1：helicity flip 对称性在共面构型中是否数值实现为 Γ^V = 0？

Taiji x Taiji 是两个相同的共面探测器网络。解析理论（P-chiral-orf-analytical.md §4.3）证明：反射变换 (θ, φ) → (θ, 2π-φ) 使得 P^V → -P^V，积分对称性导致 Γ^V = 0。数值验证需要确认这一对称性在 60×120 积分网格上实现为 |Γ^V| < 1e-6（f → 0 极限）。

**关键子问题**：空间相位因子 exp(-2πif·Δx/c) 在 Taiji 内部探测器对之间的贡献是多少？由于两个 Taiji 探测器几乎在同一位置（~10^6 m 间距），Δx/c 极小，空间相位效应可忽略。但仍需数值确认。

### RQ2：helicity flip 对称性在非共面构型中是否保持（Γ^V ≠ 0 但奇偶性不变）？

LISA x Taiji 是非共面构型。Γ^V ≠ 0 是已知事实（非共面破缺了导致 Γ^V = 0 的反射对称性）。但 **helicity flip 奇偶性** 应保持：P^V(θ, φ) = -P^V(θ, 2π-φ) 在被积函数层面成立，即使积分后 Γ^V ≠ 0。

**关键子问题**：这是本次迭代最核心的物理验证。空间相位 exp(-2πif·path/c) 只依赖于路径长度 |Δx|，反射变换下路径长度的投影保持不变。因此 phase * chiral_corr 在反射下也应变号，Γ^V 的奇偶性应不受空间相位影响。

### RQ3：空间相位的存在是否影响 helicity flip 对称性的数值验证？

这是本次迭代的"新增"物理因素。Iteration 79 已证明空间相位引入了 ~40% 的 Γ^V 幅度偏差。但 40% 偏差是幅度缩放，不改变符号/奇偶性。本次验证需要确认：

- 包含空间相位：Γ^V_with_phase
- 不包含空间相位：Γ^V_without_phase
- 比值 |Γ^V_with_phase / Γ^V_without_phase| 应在 0.95-1.05 范围（对于 f = 0.01 Hz，Δx ≈ 1 AU 时偏差最大）

## 验收标准

### AC-1：T1 — 共面 Taiji×Taiji 的 Γ^V ≈ 0

**判定条件**：
- 对于 f = 0.001, 0.01, 0.1 Hz，三个频率点下的 Γ^V 均满足 |Γ^V| < 1e-6
- 在 f = 0.001 Hz 极限下，|Γ^V| < 1e-8（最低频率极限下反射对称性最精确）
- 使用 60×120 θ×φ 网格，提高网格分辨率至 120×240 时结果不变（网格收敛验证）
- **PASS**: 所有频率 |Γ^V| < 1e-6
- **FAIL**: 任一频率 |Γ^V| ≥ 1e-6

### AC-2：T2 — 反射对称性 P^V(θ, φ) + P^V(θ, 2π-φ) ≈ 0

**判定条件**：
- 对于 Taiji×Taiji 和 LISA×Taiji 两个场景，在 60×120 网格上逐点计算：
  - deviation(θ, φ) = |P^V(θ, φ) + P^V(θ, 2π-φ)| / (|P^V(θ, φ)| + |P^V(θ, 2π-φ)| + ε)
  - 其中 ε = 1e-20 防止分母为零
- 最大相对偏差 max(deviation) < 0.01（1%）
- 平均相对偏差 mean(deviation) < 0.001（0.1%）
- **PASS**: 所有网格点相对偏差 < 1%
- **FAIL**: 任一网格点相对偏差 ≥ 1%

### AC-3：T3 — 空间相位下 helicity flip 对称性保持

**判定条件**：
- 对于 LISA×Taiji 在 f = 0.001, 0.01, 0.1 Hz：
  - 分别计算包含和不包含空间相位时的 Γ^V
  - 分别计算包含和不包含空间相位时的 helicity flip 偏差 max(|P^V_with + P^V_without|)
- 不含空间相位时：helicity flip 偏差 max < 1%（基准，与 AC-2 相同）
- 含空间相位时：helicity flip 偏差 max < 2%（允许额外 1% 数值误差）
- 含/不含空间相位时 Γ^V 的比值 |Γ^V_with / Γ^V_without| 应在物理预期范围内（不要求精确为 1.0，因为 40% 偏差是已知物理效应）
- **PASS**: 含空间相位时 helicity flip 偏差仍 < 2%
- **FAIL**: 含空间相位时 helicity flip 偏差 ≥ 2%

### AC-4：T4 — 非共面 LISA×Taiji 的 Γ^V ≠ 0

**判定条件**：
- 对于 f = 0.001, 0.01, 0.1 Hz：
  - LISA×Taiji 的 |Γ^V| > 1e-10（可检测的非零值）
  - Γ^V 的符号在 helicity flip 下翻转（自洽性检查）
- **PASS**: 所有频率 |Γ^V| > 1e-10
- **FAIL**: 任一频率 |Γ^V| ≤ 1e-10

### AC-5：脚本独立运行并输出全部 4 个测试用例

**判定条件**：
- 脚本 `scripts/verify-helicity-flip-symmetry.py` 可独立运行：`python3 scripts/verify-helicity-flip-symmetry.py`
- 输出包含 4 个测试用例的名称、参数、数值结果和 PASS/FAIL 判定
- 总运行时间 < 120 秒（60×120 网格 × 3 频率 × 2 构型 × 2 相位条件）
- **PASS**: 脚本正常运行输出全部结果
- **FAIL**: 脚本崩溃、无输出、或测试不全部执行

## 硬约束（不可妥协）

1. **独立实现**：验证脚本不可导入或调用 `11-multi-constellation-chiral-orf.py` 中的核心计算函数。物理模型（天线方向图、传输函数、ORF 积分公式）可以相同实现，但代码必须独立编写。
2. **反射变换必须显式使用 (θ, φ) → (θ, 2π-φ)**：不可用启发式旋转或其他坐标变换替代。这是与解析证明的直接对应。
3. **空间相位因子必须使用 exp(-2πif·Δx/c)**，其中 Δx = |x_LISA - x_Taiji| ≈ 1 AU。不可使用近似或简化形式。
4. **测试必须覆盖至少三个频率点**：f = 0.001, 0.01, 0.1 Hz。
5. **数值积分网格分辨率不低于 60×120**（θ×φ）。
6. **四个测试用例必须全部执行**：缺少任一测试则整体 FAIL。

## 方案选择记录

关于 helicity flip 的具体数值验证方式，经过分析后选择：

**方案 A（推荐）**：对每个天空方向 (θ, φ)，验证 chiral_corr(θ, φ) + chiral_corr(θ, 2π-φ) ≈ 0

**理由**：
1. 与解析证明 §4.3 的反射对称性论证直接对应
2. 可在被积函数层面验证，不依赖积分收敛性
3. 对 LISA×Taiji 和 Taiji×Taiji 都适用
4. 计算成本低（不需要运行完整的 ORF 积分）

**方案 B 被排除的原因**：对两个探测器分别执行 helicity flip（交换 + 和 × 极化），虽然物理上等价，但实现更复杂（需要修改天线方向图的构造），且与解析证明的对应关系不直接。
