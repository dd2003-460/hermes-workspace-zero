## 子任务清单

### M1: 测试验证（`09-olc-chiral-orf.py tests`）

- **输入**：`scripts/09-olc-chiral-orf.py`
- **输出**：3 项测试全部 PASS 的终端输出
- **验证**：
  - 测试 1（共面零）：`|Gamma^V| < 1e-8` for dihedral=0, all arm angles
  - 测试 2（非共面非零）：Gamma^V 随 dihedral 单调递增，dihedral=90° 时 |Gamma^V| > 0.05
  - 测试 3（自关联零）：`|Gamma^V| < 1e-8` for a=b
- **回滚**：检查脚本语法错误；如脚本有问题，退回 01-任务澄清中的理论框架
- **置信度**：0.90 — 脚本已有完整实现，理论框架经 PTA 验证
- **前置依赖**：无
- **工作量**：2–5 分钟（纯测试运行）

### M2: 频率依赖 + 基线依赖分析

- **输入**：`scripts/09-olc-chiral-orf.py` 中的 `analyze_chiral_frequency_dependence()` 和 `analyze_chiral_baseline_dependence()`
- **输出**：
  - `results` dict（频率扫描数据，含 Re/Im/mag/std 四个通道）
  - `(d_vals, chiral_vals, std_vals)` 数组（基线扫描数据）
- **验证**：
  - 频率扫描：Gamma^V 在 1 mHz–100 Hz 范围内变化 < 20%（平坦性）
  - 基线扫描：Gamma^V 不随基线分离距离 d 剧烈震荡
- **回滚**：调整 `n_orient`、`ntheta`、`nphi` 提高积分精度；降低频率点数
- **置信度**：0.85 — 基于 M1 通过
- **前置依赖**：M1（测试通过后才进行正式分析）
- **工作量**：5–15 分钟（取决于网格分辨率和并行度）

### M3: 角度网格扫描

- **输入**：`scripts/09-olc-chiral-orf.py` 中的 `analyze_chiral_angle_scan()`
- **输出**：`(arm_angles, dihedrals, grid)` 二维网格，`grid[i,j] = |Gamma^V(arm, dih)|`
- **验证**：
  - 网格在 `dihedral=0` 列（coplanar）上接近零
  - 峰值位置：arm angle ~ 60°–90°, dihedral ~ 60°–90°
  - 峰值量级：`max(grid)` 落在 0.1–0.5 范围内
- **回滚**：降低 `n_orient` 从 12 到 8 以减少计算量；减小网格分辨率
- **置信度**：0.80 — 独立于 M2，2D 扫描计算量较大
- **前置依赖**：无（可与 M2 并行执行）
- **工作量**：10–30 分钟（2D 网格 × orient 平均，计算量大）

### M4: 图表生成（`plot_chiral_results`）

- **输入**：M2 和 M3 的数值结果（`results`, `d_vals`, `chiral_vals`, `std_vals`, `arm_angles`, `dihedrals`, `grid`）
- **输出**：
  - `figures/09-chiral-orf-frequency.png` — 频率依赖（4 panel）
  - `figures/09-chiral-orf-baseline.png` — 基线依赖
  - `figures/09-chiral-orf-angle-grid.png` — 角度网格热力图
- **验证**：
  - 3 个 PNG 文件均存在于 `figures/` 目录
  - 每个文件 > 10 KB（确保有效渲染，非空白图）
  - 频率图：所有曲线在预期范围内
  - 网格图：dihedral=0 列为最暗（Gamma^V 接近零）
- **回滚**：重新调用 `plot_chiral_results()`，检查 matplotlib 后端配置
- **置信度**：0.95 — 纯绘图，依赖已有 matplotlib 脚本
- **前置依赖**：M2 + M3
- **工作量**：1–2 分钟（绘图，不含计算）

### M5: 论文草稿 + 结果整合（`write_paper`）

- **输入**：M2 和 M3 的数值结果，M4 的图表文件
- **输出**：
  - `chiral-olc-paper-draft.md` — 论文补充章节（~20KB）
  - 包含：理论框架、数值结果表、与现有探测器的对比表、结论
- **验证**：
  - 文件存在且 > 5 KB
  - 包含数值结果表（dihedral angle vs Gamma^V/Gamma^I）
  - 包含与 PTA/LISA-Taiji/OLC 的对比表
  - 结构与论文第 7 章风格一致
- **回滚**：直接重写（write_paper 函数为纯文本生成，无复杂逻辑）
- **置信度**：0.90 — 纯模板填充，脚本已包含完整框架
- **前置依赖**：M4（图表完成后整合）
- **工作量**：1–3 分钟（纯文本生成）

## 优先级与并行调度

| 优先级 | 子任务 | 说明 |
|--------|--------|------|
| P0 | M1 | 必须最先通过，阻塞后续所有子任务 |
| P0 | M3 | 可立即与 M2 并行，无依赖 |
| P1 | M2 | 与 M3 并行（M1 通过后） |
| P2 | M4 | 等待 M2 + M3 完成后执行 |
| P2 | M5 | 等待 M4 完成后执行 |

**并行执行策略**：
```
M1 ──> M2 ──┐
           └─> M4 ──> M5
M3 ──────────┘
```
- M2 和 M3 可并行（M1 通过后）
- M4 必须等 M2 + M3 都完成
- M5 必须等 M4 完成
