#### P1-1: 创建 core/ 共享模块
**任务**：创建 `/scripts/core/` 目录，包含以下文件：

- `core/__init__.py` — 导出所有共享函数
- `core/transfer.py` — `olc_transfer_function(f, L, cos_nu)`
  - 公式：`i*2*pi*f*L/c * sinc(pi*f*L/c * (1-cos_nu)) * exp(-i*pi*f*L/c*(1-cos_nu))`
  - 来源：script 01 `olc_transfer_function`，已验证正确（1-cos_nu 修复后）
- `core/antenna.py` — `antenna_patterns(th, ph, u, x, y, z, arm_angle)`
  - 公式：`F+ = th^2-ph^2`, `Fx = 2*ph*sqrt(1-(u·n)^2)`
  - 来源：script 01/09/04/10/12，全部 byte-identical
- `core/orf.py` — `compute_orf_two_arm(f, ...)` — 标准 ORF 计算
  - 公式：sky integration of `F_+1*F_+2 + F_x1*F_x2 * T1*T2* * phase`
  - 来源：script 01 `compute_orf_two_arm`
- `core/chiral.py` — `compute_orf_chiral(f, ...)` — Chiral ORF 计算
  - 公式：sky integration of `(F1+*F2x - F1x*F2+) * T1*T2* * phase * dOmega / (4*pi)`
  - 来源：script 09 `compute_orf_chiral`
- `core/common.py` — `arm_vector`, `arm_directions`, 几何工具函数
  - 来源：多个脚本重复定义

**验证标准**：`python -c "from core import *; print('import OK')"`
