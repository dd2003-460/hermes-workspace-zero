### 天区平均的局限性

`orf_orient_avg_chiral` 和 `orf_orient_avg_standard` 采用"半平均"策略：
- 对 `phi_s` 做 12-16 点平均（覆盖 0 到 2pi）
- `theta_s` 固定为 `pi/4`
- 这不是完整的 $4\pi$ 天区平均

**影响评估**：
- 对 $\Gamma^V/\Gamma^I$ 比值的影响较小（系统性偏差会部分抵消）
- 但绝对量级可能与真正的全天区平均有 10-30% 的差异
- 与判定标准 #5 的"峰值在 0.1-0.5"阈值比较时需要考虑此不确定性
- **置信度降级**：判定标准 #5 的置信度从 0.90 降至 0.70

### 复数返回值的影响

`compute_orf_chiral` 返回复数（被积函数是复数），测试使用 `np.abs(val)`。
- 理论上 $\Gamma^V$ 应为实数（手征 ORF 没有虚部）
- 复数部分来自数值积分的残余相位误差
- 风险：如果实部接近零而虚部因数值误差显著，测试可能误判
- **实际影响**：低。对于非零构型，实部远大于数值误差

## 进入 2-loop 条件评估

**目标置信度**：根据全局规格，1-loop/06 决策阶段要求整体置信度 > 0.75 方可进入 2-loop

**当前评分**：0.71 < 0.75

**结论**：**建议 rework，不建议直接进入 2-loop**

### 退回原因

1. **测试 2 缺少断言**是最主要的问题（-0.05）。在 chiral 模式下运行时，如果打印数据显示单调性不成立，将直接导致硬约束失败。
2. **判定标准 #4 和 #5 无断言**（-0.04）。即使数据看起来合理，脚本也不会确认。
3. 这三个缺口在 2-loop 执行阶段需要被补充，但理想情况下应在 1-loop 阶段就解决。

### 建议补救措施（在 2-loop/03 执行前补充）

1. **在脚本中为测试 2 添加单调性断言**：
   ```python
   vals = [np.abs(orf_orient_avg_chiral(f, L, L, ..., dh)) for dh in dihedrals]
   assert all(vals[i] <= vals[i+1] + 1e-6 for i in range(len(vals)-1)), \
       "Chiral ORF should be monotonically increasing with dihedral"
   ```

2. **为频率平坦性添加断言**：
   ```python
   max_variation = (np.max(mag) - np.min(mag)) / np.mean(mag)
   assert max_variation < 0.20, f"Frequency dependence too strong: {max_variation:.2%}"
   ```

3. **为峰值量级添加断言**：
   ```python
   assert 0.1 <= max(grid) <= 0.5, f"Peak |Gamma^V| out of range: {max(grid):.3f}"
   ```

4. 完成 2-loop 执行：`python3 scripts/09-olc-chiral-orf.py chiral`

### 如果不补救直接执行的风险

- **风险 A**：测试 2 不通过（单调性假设错误）→ 脚本返回非零退出码 → 2-loop/03 执行失败
- **风险 B**：频率平坦性不满足（数值积分精度不足）→ 需调整 ntheta/nphi 后重试
- **风险 C**：峰值超出预期范围（天区半平均偏差）→ 需扩大天区覆盖或调整阈值
