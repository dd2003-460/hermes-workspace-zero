## 1. ORF 函数中唯一被替换的组件

### 1.1 标准基底 → 手征基底的替换

在 Hu PRD 通用 ORF 框架中，被积函数依赖于偏振响应函数 F_A(F)（A = +, ×）。替换如下：

```
标准基底:  F_+,  F_×
手征基底:  F_L = (F_+ + iF_×)/√2,  F_R = (F_+ - iF_×)/√2
```

在 chiral ORF (Γ^V) 的公式中，唯一的变化就是：
- 用 F_L, F_R 代替 F_+, F_×
- 这导致被积函数中的交叉项 F1p*F2x - F1x*F2p → Im(w_1^2 * w_2^{*2})
  其中 w_i = (u_i·x̂) + i(u_i·ŷ)

### 1.2 其他组件完全不改变

以下组件在替换基底前后完全不变：
- **传递函数**：olc_transfer_function = i*2*pi*f*L/c * sinc(beta) * exp(-i*beta)
  其中 beta = pi*|f|*L/c * (1-cos_nu)
- **脉冲传播矢量**：u_i, x̂, ŷ, n̂（几何量，与偏振基底无关）
- **sinc 函数的极点结构**：sinc(z)exp(-iz) 的极点位置不变
- **积分路径**：沿实轴的 k 积分 → 上半平面闭合，留数求和

## 2. 复变函数解法不受偏振基底替换影响的证明

### 2.1 极点结构的独立性

被积函数的核心形式为：

```
f(k) = [偏振因子] × olc_transfer_function(k) × olc_transfer_function(k)
```

其中 `olc_transfer_function(k) ∝ sinc(β(k)) × exp(-iβ(k))`

**关键观察**：
- β(k) = pi*L/c * |f| * (1-cos_nu) × [k-相关项]
- sinc(z) 的极点仅在 z = nπ (n≠0)，即 beta = nπ
- 这些极点位置仅取决于 L, c, f, cos_nu —— **与偏振基底无关**

因此，替换偏振基底后：
- 极点位置 k_n 不变
- 极点的阶数不变（都是一阶极点）
- 积分路径不变（上半平面闭合）

### 2.2 留数值的变化

替换基底后，被积函数的留数值发生变化：
- 标准基底：留数是实数
- 手征基底：留数是复数

但这不影响留数定理的应用：

```
∫_{-∞}^{∞} f(k) dk = 2πi × Σ Res[f(k), k_n]
```

无论留数是实数还是复数，这个公式都成立。Γ^V 的值就是这些复数留数的求和（取虚部）。

### 2.3 Hu PRD I1-I4 5极点留数法的普适性

Hu PRD 中的 I1-I4 积分对应 5 个极点：
1. k = 0 (来自 sinc 的分子)
2. k = ±k_0 (来自 exp(-iβ) 的指数因子)
3. k = ±k_0* (复共轭极点)

这 5 个极点的位置由传递函数的解析结构决定，与偏振基底无关。
替换基底后：
- 极点数不变（仍然是 5 个）
- 极点位置不变
- 留数从实数变为复数
- **Hu 的 I1-I4 5极点留数法完全照搬**
