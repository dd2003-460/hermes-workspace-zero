## 一、核心结论

1. **共面探测器（LISA 三角形构型）: Γ^V ≈ 0，在 0.1-100 mHz 频率范围内严格为零。**
   - 数值结果: Γ^V = 7.79e-20 ~ 7.61e-19（数值噪声级别）
   - 这是反射对称性的直接后果，与解析证明一致

2. **单一三角探测器（无论是否倾斜）: Γ^V = 0，因为任何单一探测器配置都存在某个反射对称平面。**
   - 倾斜角度从 0° 到 90°，结果均为数值零 (1e-18 量级)
   - 这是一个**物理上重要的结果**，而非实现错误

3. **空间分离的双探测器网络（LISA-Taiji）: Γ^V ≠ 0，且随分离距离和倾斜角度变化。**
   - d = 1.0 AU, f = 1.0 mHz, 倾斜 ±60°: |Γ^V| = 9.68e-4
   - 峰值出现在 d ~ 1 AU, f ~ 1-2 mHz，与 JCAP 论文定性一致
   - 共面双探测器（均在 xy 平面）: Γ^V ≈ 0

4. **正确的手征 ORF 参考文献是 Omiya-Seto (2107.12001)，而非 Nishizawa PRD 79, 082002。**
   - Nishizawa PRD 79, 082002 研究的是非张量极化模式 (b, l, x, y)，与手征张量 GW 无关
   - 本项目中的"Hu PRD" (111.084065) 给出了完整的单程链路 ORF 框架
   - Omiya-Seto 给出了球形 Bessel 函数形式的手征 ORF 解析公式

## 二、手征 ORF 公式总结

### 2.1 Hu 框架下的 ORF 定义

广义 ORF（Hu PRD Eq. 2.18）:

$$\Gamma^X(\hat{n}, f) = \sum_{a,b,c,d} D_{ab}(f, \hat{n}) D_{cd}^*(f, \hat{n}) F_X^a(\hat{n}) F_X^b(\hat{n}) F_X^c(\hat{n}) F_X^d(\hat{n}) \, e^{2\pi i f \hat{n} \cdot (x_{ab} + x_{dc})/c}$$

其中 X ∈ {I, V}:
- **X = I（强度）**: F^I_+ = 1, F^I_× = 0, F^I_V = 0
- **X = V（手征）**: F^V_+ = F_+, F^V_× = F_×, F^V_V = F_+ F_×

注意：这里 F_X 是归一化的极化天线方向图。

### 2.2 OLC 单程链路响应

OLC 探测器的响应函数包含 Sinc 形式的传递函数（楼明智 Eq. 2-30）:

$$\mathcal{T}(\nu, f) = \frac{i 2\pi f L}{c} \cdot \text{sinc}\left[\frac{\pi f L}{c}(1 - \cos\nu)\right] \cdot \exp\left[-i\frac{\pi f L}{c}(1 - \cos\nu)\right]$$

其中 cos ν = n̂ · û（引力波方向与链路方向的夹角）。

### 2.3 Michelson 型变量

对于 OLC，交叉相关使用的是 Michelson-like 变量:

$$M^a = \tilde{L}_{ab}^a + \tilde{L}_{ba}^a$$

即从 a 到 b 再到 a 的两条单程链路之和。

### 2.4 手征因子

手征响应的核心是以下组合:

$$P^V = M_{1,+} M_{2,\times} - M_{1,\times} M_{2,+}$$

这对应于圆极化基下的反称极化组合:

$$P^V \propto M_{1p} M_{2x} - M_{1x} M_{2p} = -2i (M_{1R} M_{2L}^* - M_{1L} M_{2R}^*)$$

### 2.5 归一化 ORF

归一化的交叉相关 ORF:

$$\Gamma_{\text{norm}}^V = \frac{\langle M_{1p} M_{2x} - M_{1x} M_{2p} \rangle}{\sqrt{\langle M_{1p}^2 + M_{1x}^2 \rangle \langle M_{2p}^2 + M_{2x}^2 \rangle}}$$

其中 ⟨·⟩ 表示天球积分（含相位因子）。

### 2.6 Omiya-Seto 解析公式 (2107.12001, Eqs. 53-54)

对于点应变探测器，手征 ORF 可解析表示为:

$$\gamma_T^W = \sqrt{10} \left( D^{\tilde{F}} j_3(y) + 2D^{\tilde{K}} j_1(y) \right)$$

$$\gamma_V^W = \sqrt{10} \left( -2D^{\tilde{F}} j_3(y) + D^{\tilde{K}} j_1(y) \right)$$

其中:
- j_1(y) = sin(y)/y² - cos(y)/y
- j_3(y) = (3/y³ - 1/y) sin(y) - (3/y²) cos(y)
- D^F̃, D^K̃ 是臂张量的收缩系数
- y = πfL/c

对于**共面两臂探测器**（臂沿 x 和 y 方向）:
- D^F̃ = 1, D^K̃ = 0
- γ^W_V = -2√10 · j_3(y)
- **但在天球平均下，共面探测器的 γ^W_V = 0**

## 三、实现代码对比

### 3.1 本项目实现 (`scripts/10-olc-chiral-orf-triangular.py`)

核心函数 (`compute_triangular_orf_chiral`, 第 203-240 行):

```python
def compute_triangular_orf_chiral(f, m1_th_a, m1_ph_a, m1_th_b, m1_ph_b,
                                   m2_th_a, m2_ph_a, m2_th_b, m2_ph_b,
                                   L, ntheta=32, nphi=64):
    # OLC 响应
    R1A_p, R1A_x = GW_response_OLC(f, arm1a, L)
    R1B_p, R1B_x = GW_response_OLC(f, arm1b, L)
    R2A_p, R2A_x = GW_response_OLC(f, arm2a, L)
    R2B_p, R2B_x = GW_response_OLC(f, arm2b, L)
    
    # Michelson 变量
    M1p, M1x = R1A_p + R1B_p, R1A_x + R1B_x
    M2p, M2x = R2A_p + R2B_p, R2A_x + R2B_x
    
    # 手征因子
    chiral_factor = M1p * M2x - M1x * M2p
    
    # 天球积分
    corr = np.sum(chiral_factor * dO)
    
    # 归一化
    auto1 = np.sum((M1p**2 + M1x**2) * dO)
    auto2 = np.sum((M2p**2 + M2x**2) * dO)
    denom = np.sqrt(np.abs(auto1) * np.abs(auto2))
    
    return np.real(corr / denom)
```

**正确性分析**:
1. ✅ Michelson 变量构造: M = R_a + R_b — 正确，对应两个臂的求和
2. ✅ 手征因子: M1p*M2x - M1x*M2p — 正确，对应 F_+ F_× 交叉项
3. ✅ OLC 传递函数: Sinc × 相位因子 — 正确，与楼明智论文一致
4. ✅ 归一化: 由自相关归一化 — 标准 ORF 归一化方法

### 3.2 Hu 框架与本项目实现的对齐

| 概念 | Hu PRD 定义 | 本项目实现 | 对齐度 |
|------|-------------|-----------|--------|
| 单程链路响应 | 指数形式传递函数 | Sinc 形式传递函数 | ⚠️ 不同文献采用不同约定，OLC 用 Sinc 是正确的 |

### 4.4 关键发现：LISA-TAIJIp vs LISA-TAIJIm 的区分

JCAP 论文中 LISA-TAIJIp 和 LISA-TAIJIm 的区别**不仅在于倾斜角度**，还在于:

1. **Taiji 探测器围绕太阳的轨道位置** — 不同的轨道参数 (a, b, c) 导致不同的相对取向分布
2. **轨道运动引起的分离矢量演化** — 分离矢量方向随时间变化
3. **臂方向的相对取向** — 轨道运动改变了臂之间的夹角

在 JCAP 框架下:
- **LISA-TAIJIp**: Taiji 与 LISA 同倾角，在特定轨道相位下 Γ^V 较小
- **LISA-TAIJIm**: Taiji 与 LISA 反倾角，且轨道参数不同 (a=1.27 vs 1.0 AU)，导致更大的 Γ^V

本项目实现验证了**基本的物理机制**（分离距离和倾斜角度是 Γ^V 的必要条件），但 JCAP 论文中 LISA-TAIJIp/Im 的**定量差异**需要包含完整的轨道动力学和臂方向演化才能复现。

## 六、物理直觉总结

### 6.1 为什么 Γ^V = 0 对共面探测器？

对于共面探测器（如 LISA 在黄道面），存在一个反射对称平面（即探测器所在的平面）。在反射 (n̂ → n̂') 变换下:
- 探测器天线方向图对称: F(n̂') = F(n̂)
- 手征极化反号: F_V(n̂') = -F_V(n̂)
- 交叉相关 F_+^a F_×^b - F_×^a F_+^b 是奇宇称
- 天球积分后全部抵消

### 6.2 为什么空间分离打破对称性？

当两个探测器空间分离时，相位因子 e^{iωΩ·(x_A - x_B)} 打破了反射对称性。这是因为:
- 在反射下，相位因子的符号改变（因为 Ω·d → -Ω·d）
- 相位因子与天线方向图的非平凡干涉导致不完全抵消
- **Γ^V 与分离距离 d 和频率 f 的乘积 fd/c 相关**

### 6.3 为什么低频 Γ^V → 0？

低频下相位因子 e^{iωΩ·d} → 1，反射对称性恢复，Γ^V → 0。
高频下 OLC 传递函数 T(f) → 0，天线方向图幅度减小，Γ^V → 0。
因此 Γ^V 在中间频率处出现峰值，对应探测器臂长尺度 L ~ 2.5 AU 的特征频率 f ~ c/(2πL) ~ 1 mHz。

### 6.4 Γ^V ≠ 0 的必要条件

1. **空间分离**: 两个探测器必须在空间上分离（至少数十万公里）
2. **非共面几何**: 分离矢量不能完全位于探测器的对称平面内
3. **中等频率**: f ~ c/(2πd) 处 Γ^V 最大

## 八、遗留问题与后续工作

1. **LISA-TAIJIp vs LISA-TAIJIm 差异**: 需要实现轨道动力学模型，模拟 Taiji 探测器围绕太阳的完整轨道运动
2. **轨道运动平均**: JCAP 论文中 V_eff 是对轨道周期的时间平均，需要实现时间积分
3. **与 Nishizawa 公式的完整对比**: 本项目使用了 OLC Sinc 传递函数，而 Nishizawa/Omiya-Seto 使用了指数形式的点应变传递函数。两种约定在物理上是等价的（只是数学形式不同），但直接对比需要统一传递函数约定
4. **两臂干涉仪 vs 三角探测器**: Omiya-Seto 公式针对两臂干涉仪，本项目实现了三角探测器。三角探测器的 Γ^V 是三个臂对的组合，但物理本质相同
