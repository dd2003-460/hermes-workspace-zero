## 4. 推荐方案

**"Playwright 渲染 → 截图 → Claude 视觉分析"流水线**

流程：
1. 用 Playwright 打开文档（PDF/HTML/Markdown 渲染页）
2. 截图保存
3. Claude 用 Read 工具读取截图进行视觉 review
4. 给出 review 反馈
