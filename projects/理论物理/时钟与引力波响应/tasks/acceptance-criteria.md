# 验收标准：OLC ORF 频率依赖分析

## 硬性标准（必须满足）

- [ ] **公式实现正确**：单向 link ORF H_{12}(f,n) 代码与 Hu PRD 公式 (28) 数值验证一致
  - 验证方式：在 100 个随机 (f,L,n) 点比对解析公式和代码实现，相对误差 < 1e-10
- [ ] **Pan(t) 平均正确**：时间平均 (rotation of arm directions) 实现与 Hu PRD 数值方法一致
  - 验证方式：与 Hu PRD 图 2 (PTA case) 对比，fL/c < 0.1 区域匹配到 5%
- [ ] **f-L 热力图**：至少 3 种臂长构型（L=1m, 10m, 100m）在完整频率范围 [10^{-15}, 10^3] Hz 的热力图
- [ ] **结论可量化**：明确回答
  - ORF 是否随频率变化？变化幅度多少？
  - 臂长如何影响敏感度边界？
  - 与 PTA (NANOGrass) 和 LISA 的敏感频段差异

## 质量标准（应当满足）

- [ ] 频率范围覆盖完整 fL/c 三个区域：
  - **小天线区** (fL/c ≪ 1): ORF 接近常数
  - **过渡区** (fL/c ~ 1): ORF 开始变化
  - **短波区** (fL/c ≫ 1): arm response 主导抑制
- [ ] 对比所有 OLC 常见构型（co-planar polygon, linear, 3D）
- [ ] 误差来源分析（数值积分误差 vs 解析误差）

## 可妥协部分

- 如果时间不够：
  - 可以跳过 3D 构型（聚焦共面 case）
  - 频率下限可以从 10^{-9} Hz 开始（跳过极端低频）
  - 但 f-L 热力图不可删减
