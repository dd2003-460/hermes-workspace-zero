# 成璐知识库 (Knowledge Base)

## 这是什么

成璐的**跨领域知识参考** — 作为成璐(或非常相似的好朋友), 了解他的兴趣方向后, 为他写详细领域 note + 教材。成璐**懒惰、兴趣驱动**: 除学过领域外, 所有领域的工具/名词他都有**定义/动机/来源**疑问。本项目记录"他知道什么"(knowledge) 并为"他没学过但感兴趣"的领域写"名词定义+动机+来源+疑问"的教材式 note。

**与 persona 项目的区别**:
- D1-persona-align = **怎么想/怎么说**(思维/语言/决策风格, 从交互数据复刻)
- D1-knowledge-base = **知道什么/对什么有兴趣**(知识内容 + 兴趣方向)

两者互补: persona 让 AI"像成璐地想", knowledge-base 让 AI"知道成璐在乎什么、学过什么、对什么有疑问"。

## 笔记格式(教材式, 给懒惰兴趣驱动的人)

每个领域 note 两段:

**A. 名词表(核心)**: 对该领域每个工具/名词, 给 4 项:
1. **定义** — 一句话, 说人话(不堆术语)
2. **动机** — 为什么存在, 解决什么问题
3. **来源** — 从哪来(哪篇论文/哪个概念/谁提出)
4. **疑问** — 边界/不严格处/成璐会质询什么(他的"撞数据墙"习惯)

**B. 成璐视角(收尾)**: 判断/自我质询/动机/新 idea/明确砍掉/一句话(沿用 proactive-note 结构, drift-check 可验)。

## 目录

- `notes/INDEX.md` — note 纯索引
- `tasks/state.md` — 当前状态
