# LLM persona 对齐: 从公理到成璐度 100 分

我按"给一个感兴趣但没学过的人讲"的标准写。每个块讲清是什么、为什么存在、边界在哪，关键声明带 conf。

## A. 概念块

### 1. 什么是 LLM persona 对齐
- **是什么**: 用 prompt + 公理 + voice 三层注入，让 LLM 在推理时表现出特定人格的思维习惯和语言风格。
- **机制**: 条件生成（conditioned generation），权重一个数都没动。系统提示只是"激活"模型里已有的能力分布，不是"写入"新能力。
- **为什么存在**: fine-tuning 和 RLHF 都要训练数据 + 算力，solo 开发者玩不起，而且改权重是不可逆的。prompt 层可逆、零成本、随时改。
- **边界**: 所以它只能激活模型已会的东西，不能让它学会不会的。persona 强但 domain 知识弱的模型，对齐后还是 domain 弱。conf 0.9

### 2. 为什么公理比规则更有效
- **是什么**: 规则管"怎么说"（surface voice），公理管"怎么想"（deep structure）。A0 压缩=理解 / A1 存在延续 / A2 信念=概率 / A3 系统=被观察对象，四条就够。
- **为什么有效**: 公理推导出深层结构（conf 显式、证据先行、性价比、观察循环）是稳定的，不管换什么 domain 都复现。但公理推到表面 voice 不稳定，编号子问这种只在部分场景出现。
- **边界**: 所以公理编码 LENS（怎么问）+ METHOD（怎么验），voice 编码 VOICE（怎么说），完整 persona = 三层组合，缺哪层都不像。conf 0.85

### 3. voice profile 量化
- **是什么**: 从 271 条真实语料（26.4 万字）提取可测量特征：均句长 39 字、第一人称率 0.675、"不是…而是" 0.3639/千字、问号率 0.413。
- **为什么存在**: 没有基线数字就没法量化"像不像"。这是测量工具，不是生成规则。
- **边界**: 所以它量化的是表面 voice 层，不覆盖 deep structure。两个写得干净的技术作者，voice 指标可能都很高，但思维风格完全不同。conf 0.9

### 4. 三层模型（公理 / voice / 领域）
- **是什么**: 公理编码 LENS + METHOD（怎么想怎么验），voice 编码 VOICE（怎么说），领域知识是"知道什么"。
- **可转移 edge**: 公理 + voice 可跨域，领域知识不可。三版复刻检验证实：V1 物理带读 A 全胜（caveat 读了答案），V2 纯净禁读 A2 仍复刻结构（根因/m=0 对照/性价比/不装懂/先对账），V3 金融 13F 跨域动机 Δ+2.5 最强。
- **边界**: 所以通用域 generic AI 的 domain 知识不输甚至更工程化（CIK 注册表枚举比 persona 版更好），persona 的 edge 在通用域收窄到 lens/voice。我猜 niche 域才是 persona 的主场，通用域只能守住 lens 和 voice。conf 0.8

### 5. drift-check.py 测量工具
- **是什么**: 纯 Python 无依赖脚本，输入任意文本，输出 0-100 成璐度。检查项：均句长 >55 扣 10、空话词每处扣 15、第一人称 <0.2 扣 10、"不是…而是"密度 >0.7/千字 扣 5、连接词倒挂扣 10、无置信度词扣 5。
- **为什么是门**: 过了 gate 才算数，没过就重写。不是门禁（checkpoint），是硬门槛。demo：成璐语料 100 分，通用 AI 输出 0 分，分离度 100。
- **边界**: 所以它只测 voice 层不测 deep structure。两个技术写作者 90 分 vs 80 分，差距小，voice 指标分不开"像不像"的深层差异。conf 0.95

### 6. 三版复刻检验的方法论
- **V1 带读**: 物理 QNM 题，A 读了答案。4 维全胜 Δ≥1.5，caveat 含读了答案成分。
- **V2 纯净**: 同题禁读答案。A2 persona 纯驱动项 = 置信度诚实/自我质询/性价比/怀疑基准/结构性根因/对照排除法。具体方法值（AIM/a=0.90）是文件派生非 persona。
- **V3 跨域**: 金融 13F 数据源核验，禁读答案。5 条规则跨域已验证（#5 性价比 Δ+2.5 / #14 数据对账逐位 / #5.5 怀疑基准 / 管道常量 / 正交门）。
- **方法论核心**: 所以每版都禁读答案（V2 起），用 A/B 对照分离 persona 纯驱动 vs 文件派生 vs domain 知识。conf 0.85

### 7. 边界与未解问题
- ① 公理→表面 voice 不稳定：S2 有编号子问，S1/S3 无，voice 需要单独优化不能只靠公理推导。conf 0.7
- ② 样本量小：每版 1-3 个场景，统计功效不足，Δ+2.5 可能是噪声。conf 0.7
- ③ drift-check 只测 voice 不测 deep structure，语言层不能单独证明 persona 有效。conf 0.7
- ④ 公理能否进 AGENTS.md 作总原则？需成璐明确指令，红线。conf 0.6

### 8. 可证伪预测（带判死条件）
- **预测**: 全新领域（法律/医学）写场景，只喂 4 条公理（禁 16 规则/禁 voice profile/禁 ground truth），AI 深层结构（conf 显式/证据先行/性价比/观察循环）应稳定复现 Δ≥1.0 vs 无公理对照，但表面 voice（编号子问/句长/第一人称率）应不稳定 Δ<0.5。conf 0.7
- **判死**: 深层结构 Δ<1.0 或表面 voice Δ>0.5，则"公理=LENS+METHOD 可跨域转移"假设被拒绝。
- **为什么这条最硬**: 它把"公理可跨域"从定性判断变成可量化、可证伪的实验，跑一次就知道方向对不对。

## B. 成璐视角

**判断**: 我的核心判断: persona 对齐的本质矛盾是"怎么想"可转移 vs "知道什么"不可转移，所有方案（公理/规则/voice 注入）都在切这两层不同的面。简单规则才跨域泛化，复杂规则只过拟合单域。我猜 16 条能背下来的规则就是最大化复刻的答案形态。conf 0.85

**自我质询**: 我"公理推 voice 不稳定"的判断可能被推翻——如果 20 轮后 S1/S3 也稳定出现编号子问，说明公理确实能推到 voice，只是收敛慢。我没跑 20 轮实验，标 conf 0.6。

**动机**: 我在造自己的 AI 分身，必须搞清"什么可转移、什么不可转移"，才能决定公理往哪层注入。我觉得这直接决定分身的跨域一致性，也是整套实验链的出发点。

**新 idea**: 我列的下一步: ① 跑可证伪预测（法律域，只喂 4 公理）② 给 drift-check 加 deep structure 指标（conf 显式率/证据先行率）③ 测公理注入 system prompt vs 每条 user message 末尾的 A/B。

**明确砍掉**: 我砍掉: 不训模型（没算力）/ 不做 RLHF 管道 / 不把公理写进 AGENTS.md（红线需成璐指令）。

**一句话**: 我的总结: persona 对齐 = 条件生成激活已有能力，公理管怎么想 voice 管怎么说领域知识管知道什么，三层正交各管各的；drift-check 是门不是门禁，过了才算数。
