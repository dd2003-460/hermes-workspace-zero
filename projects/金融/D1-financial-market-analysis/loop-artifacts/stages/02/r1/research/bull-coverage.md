# 可得数据跨度能否覆盖牛市

**disposition**: confirmed（confidence 0.78）
**观察时间**: 2026-10-17（子代理 6d18700c 调研）

## 关键主张与来源

1. **A股日线数据从 2004 起（AkShare）**
   - 来源: AkShare 指数数据文档
   - URL: https://akshare.akfamily.xyz/data/index/index.html
   - 观察: 日线从 2004 起，完整覆盖 2005-2007、2014-2015、2019-2021 三轮牛市
   - 不确定性: 退市股覆盖另见 data-history-depth.md（未证实）
2. **美股日线覆盖 1993/1950 起（Yahoo/Stooq）**
   - 来源: AkShare 加密货币数据文档（交叉引用数据源起点）
   - URL: https://akshare.akfamily.xyz/data/dc/dc.html
   - 观察: 完整覆盖 2009-2020（11年）大牛市及 2022末-2025
   - 不确定性: 免费全历史深度受源限制（AV 免费档仅100根，见 data-history-depth.md）
3. **加密：Binance USDT-M 期货 2019.9 上线，funding rate 历史自此开始**
   - 观察: 可覆盖的完整牛市仅 2019.9–2021.11 一段（约26个月）；2013、2016-2017 牛市无 funding rate
   - 不确定性: 2019.9 上线时间为领域共识，官方文档未在本次直接取证
4. **主场景 S1 判断**: 5 年回测窗口 = 2019.9 → 2024.9+，含 2019-2021 牛 + 2022 熊 + 2023-2024 震荡，满足 A4（≥5年含牛熊震荡）约束；但无法回测 2019 年前的完整牛市周期（funding rate 不存在）。

## 2026-10-17 主代理一手复核修正

- 原结论"窗口锚定 2019.9"基于 API/产品上线时间（先验，未取证）。**一手 HTTP 直探 data.binance.vision 证实：官方免费批量文件（逐日 K 线 + monthly fundingRate）最早 = 2020-01**（2019 各月 404，2020-01 206；详见 data-history-depth.md 复核节）。
- 修正后窗口锚定 = **2020-01 起**。5 年窗口 = 2020-01 → 2025-01+，仍含 2020-21 牛（2020-03 崩盘+2021 主升）+ 2022 熊 + 2023 震荡 + 2024-25 牛 → **A4 仍满足**。
- 损失：2019-09~12 段（2019-11 局部牛顶）不可免费批量获取。

## 对阶段03的建议输入

- A4 约束在 S1 下的可行窗口锚定为 **2020-01 起**（免费批量数据实证起点；2019.9 为产品上线先验，免费不可得）。
- "覆盖所有历史牛市" 在 S1 下不可行且不必行：funding rate 信号 2019.9 前不存在，回测范围 = 信号存在范围。
