## 2. 类-funding 信号构造

### S2 美股（无 funding rate）
**替代信号**：动量因子（Momentum）
- **定义**：12-1 月动量（过去 12 个月收益，剔除最近 1 个月）
- **方向**：正动量 → long，负动量 → short（与 S1 funding"拥挤→反转"假设相反，测试动量 vs 反转）
- **阈值**：q10/q90 分位数（先验：±1σ）
- **PIT 规则**：月度调仓（00:00 UTC 月初），使用 t−1 月数据

### S3 A股（无 funding rate）
**替代信号**：换手率因子（Turnover）
- **定义**：20 日平均换手率
- **方向**：高换手 → short（拥挤交易 → 反转），低换手 → long
- **阈值**：q10/q90 分位数（先验：±1σ）
- **PIT 规则**：月度调仓（00:00 UTC 月初），使用 t−1 月数据；A股 T+1 限制（决策日 00:00，成交日 09:30）

**诚实标注**：美股/A股无 funding rate，类-funding 信号为**代理变量**（动量/换手率），非直接等价。

## 3. 判稳协议

### 3.1 跨窗口方向一致性（C4）
- S2/S3 在其各自 OOS 窗口族上，信号方向须跨窗口一致
- **判据**：≥3/4 窗口方向一致（与 S1 同标准）

### 3.2 逐窗口统计判据（C5）
- T ≥ 2.0（t 统计量）
- ≥30 笔交易
- 扣费后净超额 > 0
- 方向一致
- Permutation p < 0.001（B=2000）
- PSR > 0.95

### 3.3 多重检验
- **全局 trial count**：S1（45）+ S2（45）+ S3（45）= 135
- **DSR deflate**：对 135 个 trial 统一 deflate（防跨市场选择偏差）
- **BH-FDR**：α=0.05，135 检验

### 3.4 跨市场"稳"的判定
- S1 + S2 + S3 三市场均通过 §2 全部判据 → "跨市场稳定"
- 任一市场失败 → 如实报告该市场失败，**不得用其他市场的通过掩盖**
- **结论呈现**：逐市场通过表（public-benchmarks F4）

## 5. 边界与风险

### 5.1 数据可得性
- **Yahoo Finance**：限流风险（需确认 API 可达性）
- **新浪财经**：起点 2004-01-02（S3 窗口 2005 起，安全）
- **风险**：若 Yahoo 限流，S2 窗口起点可能 >2005（需诚实标注）

### 5.2 信号等价性
- **美股/A股无 funding rate**，类-funding 信号（动量/换手率）为**代理变量**
- **风险**：代理变量与 funding rate 的经济学含义不同（动量 vs 拥挤），结论的跨市场泛化性需谨慎解读

### 5.3 A股 T+1 限制
- **决策日 00:00 UTC**，成交日 09:30 CST（T+1）
- **风险**：信号时滞（1 天），可能降低 alpha
