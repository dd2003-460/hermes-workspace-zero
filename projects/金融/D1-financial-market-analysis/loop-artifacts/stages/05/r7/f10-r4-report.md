## 分项解读

### 1. 主判据 (校准) — PASS, 但增量很小

- 条件概率模型 (logistic on [T_atr_z, T_fund_z, T_vol_z, mom24, |funding|z]) 的 Brier 在三个 symbol 上均低于无条件频率基准, 差距 0.002–0.011。
- 单调性成立: p_hat 五分位 vs 实际事件率严格递增 (BTC: 0.34/0.40/0.42/0.44/0.55 vs 预测均值 0.28/0.35/0.41/0.48/0.64)。温度 T 确实携带"未来 4h 出现 >2σ"的信息。
- **但**: 触发子集的事件命中率 (0.41–0.46) 只比全样本基线 (0.27–0.29) 高 ~15pp; 且 Brier 改善主要来自对高频事件 bar 的概率抬升, 幅度不足以支撑交易成本。
- 结论: "温度高 → 带宽宽" 的分布级可预测性**存在但弱**, 与 A.md "可预测性是分布级的" 一致, 但强度低于 R1 时期 DVOL 单信号的实测 (60% 触发后 4h 内 >2σ)。多源 max 聚合稀释了单一强信号 (DVOL 缺席本轮特征集 — Deribit API 已失效, 见 r6 数据边界)。

### 2. 次判据 (方向) — FAIL, 显著为负

- 方向正确率 13–15% (n≈1100/symbol, binomial p = 1.0 朝错误方向)。**顺 24h 动量方向在 T≥1.5 触发时系统性亏损**。
- 分解: 止损出场占 65%, 止损组方向正确率 32%; 未止损组方向正确率 88% (n=1141)。即: 动量方向本身不是错的, **√Q 止损把盈利单提前扫掉了**。
- 机制诊断 (post-hoc, 不进判据): σ_base 是 30d 滚动 std, 在 T 高的时段恰恰被前期波动推高 → 止损距离 ∝ σ 随温度同步膨胀, 失去选择性; 而 4h 窗口内的反向噪声 (mean |1h ret| ≈ σ/√… ) 频繁触及 1×σ 级别止损。R2 的教训 (ATR 固定倍数止损 80-84% 被扫) 以另一种形式复现: **止损宽度必须相对"当前 4h 窗口的预期波动"而非 30d 长期波动**。
- 注意: 方向正确率的定义含止损出场 (gross 符号), 若只看持有到期的 1141 笔, 方向正确率 88% — 这说明失败点在退出规则不在入场方向。预注册判据口径不变, 如实报 FAIL。

## 诚实约束与局限

1. **R4-A-degraded**: c_套利/carrying capacity 条件缺失 (aggTrades 历史未拉取, 策略篮未构造) → 倒U左支筛选未生效, 触发集合偏大 (每 symbol ~2300 次触发)。完整版本 research_required。
2. **拥挤度调节缺失**: C.md 结论 ΔOI 作拥挤度代理被双重否定, 本轮未启用仓位 ∝ (1-crowding)。
3. **DVOL 缺席**: R1 的最强温度源 (Deribit IV) API 已失效, 本轮 T 只用 ATR/funding/vol 三件套 — 主判据的弱增量可能部分源于此。
4. Y=1.0 未标定 (A.md 只给形状); 止损下限 (2×成本) 触发占比 <0.1%, 不影响结论。
5. 跨月 kline zip 有重复 ts, 本轮 loader 加去重 (R6 原 loader 未去重, 属执行层修复, 不改规则)。
