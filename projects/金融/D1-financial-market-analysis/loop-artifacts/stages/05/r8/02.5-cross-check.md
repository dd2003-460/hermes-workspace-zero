## 3. 对抗核验（对自己结论发起攻击，逐条反驳或降级）

> 规则（02.5 §5, 2026-10-29 r29 补丁）：主动找漏洞 → 反驳 → 继续追问，直到**数学理论瓶颈**或**个人信息搜集瓶颈**才停。

**A1 · 攻击 C1+C5"无宏观交互先例"**
- 攻击：这是**无证据断言**（absence of evidence）。我只做了约 9 次检索，S5 是在第 3 个查询才出现；SSRN/arXiv 全库未穷尽，付费库（JF/JFE 全文）不可读。
- 反驳：无法反驳 → 降级措辞为"**在可检索范围内未发现**"，并给出检索覆盖清单（§4）。
- conf：0.80 → **0.55**
- 停止理由：**个人信息搜集瓶颈**（无法穷尽付费库与全库检索，且无 LLM 交叉询问通道补盲）。

**A2 · 攻击 C6"价格自算的状态"**
- 攻击：S11 用 percentile rank 定义 bullish/bearish，**与信号本身同源（都是过去收益）** → 分状态回归的 t 值可能只是"过去收益的持续效应"的另一种写法，不是独立的条件变量。存在**用结果定义条件**的循环。
- 反驳：S11 同时报告"坏状态下系数恒不显著"，若纯粹是持续性效应，坏状态也该有（负的）显著性 → 部分反驳成立，但仍有 selection 风险。
- conf：0.75 → **0.65**，并标注"需 PIT 化的独立状态变量才能用于回测"。

**A3 · 攻击 C3+C4"宏观对带宽有用"**
- 攻击：**来源与结论不匹配**。S3/S4 是**事件窗口**研究（FOMC 当天 ±1 小时），不是**regime**研究。"事件窗口波动大" 推不出"regime 可预测带宽"。真正测 regime→带宽 的只有 S6，而 S6 对 BTC 的 OOS 是**失败**（MSFE 1.009）。
- 反驳：无法反驳 → 必须把"宏观预测带宽"降级为**仅 1 条来源且 OOS 失败**。
- conf：0.70 → **0.40**
- 附带修正：S6 的失败幅度极小（1.009 vs 1.000），但方向确定为"变差"，不能算 pass。

**A4 · 攻击 C8"宏观冗余"**
- 攻击：S8 是硕士论文（无同行评审），S-补充是单资产（BTC）2017-2023。用这两条支撑"宏观冗余"过强；且 M3 显示 IMF 有相反方向的证据。
- 反驳：部分成立 → 改为"**冗余风险高**"（弱表述），不作为定论。
- conf：0.65 → **0.50**

**A5 · 攻击 C10 与 r7 冲突的处理**
- 攻击：我只测"现在"，不能证明 r7 当时错。若我写"r7 表述不成立"就是**用当前状态否定历史观测**，方法上不成立。
- 反驳：成立 → 措辞改为"**当前实测可用；r7 记录的中断无法回溯验证**"，并建议 F10-R4 的"DVOL 缺席"解释**需要重跑才能定论**（不是"必须推翻"）。
- conf：0.85 → **0.80**

**A6 · 攻击 M4（把 S5 当作 H1 的依据）**
- 攻击：S5 是**单人预印本**、用 2021-2026 样本、13 币——若它与我们的 BTC/ETH/SOL 2020-2025 样本高度重叠，则 H1 的"独立验证"其实是**同一段数据的二次利用**（共线），不构成 OOS。
- 反驳：无法反驳 → H1 必须使用**S5 未覆盖的窗口**（如 2020-2021 或 2026 之后）作为 OOS，或在同一窗口上要求**方向一致且效应量不缩水**，并在报告里显式声明"非独立验证"。
- conf：0.55 → **0.50**，且该约束**写入 Q3 的 H1 判定条件**。

**A7 · 攻击"02 阶段没有 LLM 交叉询问"是否等于没做门禁**
- 攻击：02 §2 把网页 LLM 交叉询问列为**必须先做**的一步。本轮完全缺失 → 按 SOP 应判 02 阶段不完整。
- 反驳：02 §2 同时规定"若通道以未授权/未配置状态快速失败，记录完整失败原因后继续公开网页资料搜集，不得等待或循环重试" → 满足豁免条款；且 §0 已记录完整失败原因。
- 结论：**程序合规**，但证据强度按任务书【失败降级】第 1 条**全局降一级**。
