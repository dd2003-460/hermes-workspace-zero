## 0. 一页结论（先给判决，再给证据）

**H_macro 是否成立：无法在文献层面成立；在本项目可做的实验层面，只有 1 条值得花的假设，且它的"条件变量"严格说不是宏观。**

三条硬结论：

1. **日频方向这条路基本堵死。** 两个独立团队分别用 141 个变量（OOS）和 510 次周频预测（OOS）测得：宏观类变量的样本外胜率是**最低的一档**（5.6% 跑赢基准，技术类 32.2%），宏观块在已有 crypto-native 变量时**无增量、甚至拖累线性模型**。这与 F10 前三轮"微观结构全 FAIL"是同一个病：**公开、慢、低频的信息在 BTC 日线上已被吃掉**。

2. **宏观真正有信号的地方是"波动/带宽"，不是"方向"。** 两条独立证据（arXiv 2302.10252 的 NYXBT 5 分钟数据、FRL 2026 的 Coinbase 小时线，41 次 FOMC）一致显示：FOMC 声明后一小时 BTC 平均绝对收益从 0.66% 跳到 1.25%（p<0.001），成交量 2.54×。但**同一批文献也证明这不可套利**：Kalshi 宏观合约的 Fed 渠道样本外 MSFE = 1.009（**变差**），只有衰退风险信号勉强 0.979。

3. **最接近"条件有效"的那篇论文，条件不是宏观。** Shek (2026) 用 274 次**负 funding 极值**事件证明：上涨日的事件 24h 反转 **+1.88%**，下跌日的事件继续 **−1.74%**，差 **3.62pp**（CI [2.60, 4.67]，7 次外生冲击 7/7 同号）。条件变量是**当日价格方向**——一个快变量。这恰恰是 F10-R2 **没有做**的分组（R2 用的是 |funding| p95 + OI 骤降，未按方向切）。**所以本轮最高价值的产出，不是"加宏观"，而是"R2 的 funding 失败可能是漏了一个分组维度"。**

**给成璐的一句话建议**：宏观维度按现有证据**不值得单独开一轮**；若还要再花一次预算，应该先花在 **H1（把 S5 的方向分组复现到我们自己的 funding 数据上）**——它便宜、可证伪、且不需要任何宏观数据。这条如果也 FAIL，F10 就该收束为候选 D 的负结果报告。

### 1.2 四个子问题逐项作答

#### (a) 宏观变量的**条件预测力 / 交互效应**（不是相关性）

| 证据 | 结论 |
|---|---|
| S2 | 宏观公共因子**只在季度**频率显著 → 与 F10 的 4h-24h 持有期差 2-3 个数量级，是 **horizon mismatch** |
| S5 | 条件化**确实能**救活一个失效信号（funding 反转），但条件是**当日方向**（快变量），不是宏观 |
| S7 | 用**水平**（VIX level、EPU）做 regime → 无效；用**溢价**（VIX futures − spot）→ 有效 |
| S6 | 宏观信号**渠道特异**（BTC 对货币政策、山寨对 CPI）+ **regime 依赖**（单 regime 集中 → OOS 崩） |
| S11/S12 | 状态条件有效，但有效状态均由**价格自算**（percentile / HMM on returns） |

**净判断**：文献里"条件有效"的案例全部落在 **快变量 / 风险溢价 / 价格自算状态**上；**没有任何一篇**证明"用慢宏观变量（利率、美元、M2）划分 regime 能让一个日频微观信号从无效变有效"。→ **G2 = 无先例**（措辞已按 02.5 A1 降级为"可检索范围内未发现"）。

#### (b) 事件研究（Fed 决议周、CPI、QT/QE 切换）

- **Fed 决议**：S3 + S4 双独立确认 —— 波动放大 1.5-2×、成交量 2.5×、方向效应**只对 BTC/ETH 显著**。S4 是**本轮质量最高的一条证据**（同行评审、41 次事件、跨交易所复现、安慰剂对照）。
- **CPI**：仅 S6 一条（Kalshi CPI 合约 → 山寨波动，t 从 −2.1 到 −3.4）。**单一来源**，且用预测市场而非 CPI 发布本身。
- **QT/QE 切换**：**未找到任何直接证据**。这是一条明确的**证据空洞**（02 阶段 G5 已标"无标准定义"）。
- **重要限定**：S4 的作者自己写明研究的是"**可预测的风险时点**，不是方向可预测性"。把它当作"宏观能让方向信号变有效"的证据是**误读**（02.5 A3 专门拦了这一点）。

#### (c) 链上数据与宏观的**重叠度**（F7 冗余风险的翻版）

- S8：链上在场时宏观块**无增量**、线性族**变差**。
- S9：宏观类变量 OOS 胜率**最低**（5.6%）。
- S10：相关性上升说明**传导**增强，但 S8/S9 说明**领先预测力**未增强 → **两者不矛盾**，只是容易被混为一谈（02.5 M3）。
- **判断**：**冗余风险高**（不是"已证明冗余"——两来源权重都不高）。若加宏观，必须先做"宏观 vs 链上 vs 微观"的增量分解，否则重蹈 F7。

#### (d) 已发表 crypto×macro 因子模型中 **2022-2025 存活者**

- S1：主流定价模型里**没有**宏观因子（只有 market/size/momentum）。
- S10：2023-25 **无稳定 regime**（IMF 自己的措辞）。
- S6：唯一在 2022 之后样本上做过 OOS 的宏观类信号里，**只有衰退风险活下来**（MSFE 0.979），Fed 渠道**死了**（1.009）。
- **结论：2022-2025 没有"存活的宏观因子"。存活的只有"宏观事件作为风险时点"这一非因子用法。**

> 全部假设遵守：**≤3 个**、每个引 Q1 编号、每个用 **F6/F7 的 8 gate**（t≥2 / ≥30 trades / net>0 / 跨窗≥3/4 / perm p<0.001 (B=2000) / PSR>0.95 / BH-FDR@60 / DSR>0）、成本 **0.05% taker + 0.01%/0.02% slippage**、PIT **00:00 UTC 决策 + ts≤t−1d**。
> **进回测前必须走预注册冻结（human + ai 双签）**——任务书边界。

### H1（最高优先，且**不需要宏观数据**）

> **H1**：当 BTC 当日收益 > 0 时，已有"负 funding 极值"信号的 24h 反转幅度，会**大于**当日收益 < 0 时的同一信号（差距 > 0），且仅在前者上可通过 8 gate。

- **理论依据**：**S5**（gap +3.62pp, CI [2.60,4.67]；7/7 外生冲击同号）+ **S13**（funding 套利的方差由 funding 风险与市场风险主导，regime 分层有结构）。机制 = limits-to-arbitrage 下的"条件套利容量"：上涨日套利资本充足 → 负 funding 被快速修正（反转）；下跌日资本撤离 → 拥挤继续（延续）。
- **所需字段**：Binance/OKX perp funding（8h → 日聚合）、BTC/ETH/SOL 日线 OHLC、以及 F10-R2 已有的 `|funding|` p95 事件表（可复用，不改口径）。
- **判定阈值**：**双条件**——
  ① 分组差：Δgap 的 block bootstrap 95% CI **不含 0**，且方向为"上涨日 > 下跌日"；
  ② 策略层：**上涨日**子样本的 8 gate **全过**（这是"条件有效"的强形式）；下跌日是否盈利**不作为要求**（S5 已示其为负）。
- **已知的最强反驳**（02.5 A6）：S5 样本 2021-2026 与我们的 2020-2025 **高度重叠** → 不是独立验证。**必须在预注册里写死**：OOS = 2020-01→2020-12 + 2025-01→2025-12 两段（S5 未重点覆盖），或明确标注"非独立验证、仅作复现"。
- **conf（先验）**：0.45
- **如果 H1 成立而 H2/H3 全 FAIL**：结论 = "条件有效性存在，但**不是宏观驱动**"——这本身就是对 H_macro 的**否定性回答**，价值不低于阳性结果。

### H2（veto 式：宏观流动性决定"该关掉"而不是"该打开"）

> **H2**：当稳定币总供应 4 周变化 ≤ 0（或 WALCL 4 周变化 ≤ 0）时，已有 funding/basis carry 信号的净收益会**下降并转为不显著**；扩张状态下不劣于无条件基线。

- **理论依据**：**S5** 的"资本水平"机制（conditional arbitrage capacity 的两个维度之一是 capital level）+ **S13**（高波动 regime 需降杠杆）+ **S10**（流动性传导增强）。在数据上这是唯一"宏观 → 套利资本 → 微观信号容量"的**可测链条**。
- **为什么用 4 周而不是日**：**S2** 明确宏观因子只在季度尺度显著 → 用日频做 regime 是自欺；4 周是"季度信号"与"日频执行"之间的最小公约数。
- **所需字段**：DefiLlama 稳定币总供应（日，需自建切片）、WALCL（周 → 日 ff）、funding/basis 序列（既有）。
- **判定阈值**：**非对称**（必须在预注册里写明这是放宽）——
  ① 扩张状态下 8 gate **全过**；
  ② 收缩状态只需 **分组差 t 检验显著为负**（不要求收缩期策略赚钱——veto 假设的目标是"少亏"，不是"反手赚"）。
- **conf（先验）**：0.35
- **数据风险**：稳定币供应端点响应体极大且需自建聚合 → `03` 阶段 A5 已列为失败点，若 3 天内搞不定则标 `data_blocked`，**不得用 US M2 顶替而不标 proxy**。

### H3（折现率通道）

> **H3**：当 10Y 实际利率（DFII10）20 日变化 ≥ +25bp 时，basis carry 的净收益会**下降**，且"做多 perp 收 funding"这条腿表现最差。

- **理论依据**：**S2**（产出/宏观公共因子对 BTC 期望收益为负）+ **S6**（货币政策渠道对 BTC 有效但 regime 依赖、且对国债收益率正交化后仍有余量）+ **S1**（宏观未进定价模型 → 若有效，更可能通过 carry 的现金流折现，而非价格方向）。
- **所需字段**：DFII10（日）、basis = (perp − spot)/spot、funding、以及腿级收益分解。
- **判定阈值**：8 gate（在高波动子样本上）+ 分组差符号为负。**+25bp 阈值冻结，不得事后调**（这是本假设最容易过拟合的地方）。
- **conf（先验）**：0.30
- **为什么排最后**：S2 的显著性在季度尺度，H3 用 20 日窗口**已经偏离该证据**；这是三条里最可能"用错的频率做对的事"的一条。
