## 目标

不验证已有套利空间（F9 已证明旧空间在衰减），而是建模资金主体的最优策略，
**预测哪些位置会涌现新的价格偏离（=可交易套利空间）**。

## 核心假设（待验证）

H1: 新套利空间出现在"结构变化 + 主体反应延迟"的交点。
    - 结构变化 = 新规则/新工具/新参与者进入（如 ETF 审批、新交易所上线、期权到期制度变更）
    - 反应延迟 = 不同主体的信息到达时间和决策速度不同

H2: 套利空间的持续时间 ≈ 超额收益 / 竞争资本流入速率。
    - 校准锚点: F9 跨资产 funding spread, p95 从 0.056%(2020-21) → 0.01%(2022-25), 约 2-3 年磨平

H3: 被迫流动(forced flow)制造临时性低估/高估，且可预测（期权大到期日、保证金追缴级联）。

## 主体分类（第一版）

| 类型 | 信息优势 | 约束 | 反应速度 | 典型行为 |
|------|---------|------|---------|----------|
| HFT/做市商 | 极低延迟 | 库存限制 | ms级 | 价差收窄、撤单保护 |
| 统计套利基金 | 多所数据 | 容量限制 | s级 | 跨所/跨品种搬砖 |
| 趋势/CTA | 无信息优势 | VaR限额 | min-h级 | 追涨杀跌、止损触发被迫流 |
| 散户/杠杆客 | 滞后 | 保证金追缴 | h级 | 情绪驱动、爆仓=forced sell |
| 机构/ETF | 研究团队 | 合规/规模 | d级 | 调仓=大额被动流 |

## 可回测的预测规则（第一版候选）

R1: **流动性真空预测** — DVOL 跳升前夜(IV regime shift) + 订单簿深度骤降 → 预测未来 1-4h 出现 >2σ 价格偏离
    - 数据: Deribit DVOL (已有) + Binance klines (已有)
    - 逻辑: 做市商在波动率骤升时撤单(adverse selection保护), 深度变薄, 小资金推动大价差

R2: **被迫平仓级联** — funding rate 连续 N 期极端 + OI 骤降 → 预测未来 8-24h 反向弹射
    - 数据: Binance funding (已有) + OI (需拉)
    - 逻辑: 保证金追缴→强制平仓→超调→均值回归

R3: **跨市场传导延迟** — BTC 现货大单(链上/ETF赎回) vs 永续价格反应的时间差
    - 数据: 需外部源(玻璃节点/ETF flows), 当前不可得 → 标记 research_required

## 验收标准

- [ ] 至少 1 条规则(R1/R2)通过 walk-forward 检验 (样本外 Sharpe > 1, t > 2)
- [ ] 预测的偏离方向正确率 > 55% (binomial test, p < 0.05)
- [ ] 预测的持续时间与实际收敛时间偏差 < 50%
- [ ] 所有参数冻结在回测前 (预注册)
