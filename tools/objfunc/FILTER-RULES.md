## S20 结论修正

S20（2026-11-20）原结论：cli shell 命令 = D 的行为信号（dense signal），不过滤。
**修正**：D 确认 shell 命令不是他发的（"我是 cs 白痴，所有 shell 应该都是你或其他 AI 搞的"）。
→ 行为信号（cli）这一类数据源假设错误，**全部排除**。
→ 信号只剩两类：评价信号（反问/建议/纠正，来自 weixin/qqbot 中文消息）+ 可能的行为信号（未来若 D 主动用 cli 则重新纳入，当前无此数据）。

## 分类粒度

- 50 条/批（400 条/批 27b 截断挂，2026-11-20 三次验证）
- 输出紧凑 JSON（无 indent），quote ≤30 字，gap ≤20 字
- 只把 signal 类（反问/建议/纠正）放 signals 数组，其余只计数

## 判据（继承 objfunc-signal-log.md）

- 反问 = 断言式质疑（难道/不是应该/怎么不）
- 建议 = D 提出做法
- 纠正 = D 指出做错了
- instruction = 指令 / status_check = 问进度 / chitchat = 闲聊 / noise = 无信息
