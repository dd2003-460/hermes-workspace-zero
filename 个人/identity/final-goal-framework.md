# 最终目标框架

**来源**：D 2026-11-25 完整表述（微信消息原话见底部）
**性质**：全局目标框架，指导所有路径决策

## 一、最终目标
永生。

## 二、当前策略（暂定）
多阶段积累，主要积累三类资源：
1. 钱
2. 人脉
3. 技术资源

"暂定" = 当前最佳估计，可被新证据推翻。

## 三、优化标准
**最具有性价比的达到目标的方式。**

**完整目标函数 = 数量 × 质量**（乘积，不是加和，D 2026-11-25 明确）。要让整体最大，两者都要——但哪个是当前瓶颈取决于阶段：

**早期特征（公开信息阶段）**：提升质量对数量的边际影响微乎其微。原因：只有公开信息时，单条的质量（对齐度）天花板很低，且回复/成功数量由其他因素主导（对方是否 receptive、时机、运气），打磨单条质量几乎不增加成功数量。→ **数量是约束项，质量不是。** 早期优先扩数量（触达完整的相关集合），不在单条质量上过度投入（超过最低对齐门槛后 ROI 很低）。

统计方法计算最可能的路径：
- 对每条候选路径估计 E[收益] 和 Var[收益]
- 选 E[收益]/成本 最大且 Var 可控的

方差控制（按路径结构区分）：
- **串行路径**：方差要紧。一个环节失败拖累整条链。→ 选小方差（确定性高的路径）。
- **并行路径**：方差无所谓。单个失败不影响整体。→ 用数量从"几乎不可能"中获取收益（如套磁：触达完整相关集合，多数不回但少数高价值连接即回本）。

## 四、可验证里程碑
- 盈利
- 发表
- 技术改进（例如稳定的 bench 提升?）

注：D 对"稳定的 bench 提升"带问号——如果是代理指标（如 coverage），它本身可能是局部陷阱。

## 五、警示
- **反例**：那些"看起来对但实际上失败"的案例。每次宣布"完成"或"提升"时，主动找反例。
- **局部陷阱**：优化局部指标（代理指标）但偏离全局目标（真指标）。最典型：coverage vs correctness 脱钩。

## 六、路径决策检查清单
每次选路径时问：
1. 串行还是并行？
2. 方差多少？（串行→要小；并行→无所谓）
3. 性价比（E[收益]/成本）如何？
4. 是不是局部陷阱？（优化的是真指标还是代理指标？）

## 七、当前已识别的局部陷阱
1. **coverage vs correctness 脱钩**：pfb/bench 测的是 coverage（bge-m3 嵌入相似度），不是 correctness（推理链/结构对齐）。优化 coverage ≠ 优化 correctness。这是最大的局部陷阱。
2. **串行/并行失衡**：当前工作几乎全是串行（research-AGI + bench），缺并行任务（套磁/合作）。套磁 = 数量 × 质量：早期公开信息下质量边际收益低，数量（触达完整相关集合）是约束项；质量保证最低对齐门槛（给对方关心的角度，不臆测），但不为单条过度打磨（D 2026-11-25 两轮澄清：先"数量换收益"，后"必须对齐偏好"，合起来=乘积）。
3. **bench 提升作为里程碑的疑问**：如果是 coverage，那它本身就是局部陷阱（看起来提升了，但真指标没动）。
